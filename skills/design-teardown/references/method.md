# 建拆解页 + 文档 · 详细方法

动手建 `teardown.html` 与文档前读这份。目标:深度对齐「源码级」标杆(每个数值可回溯、有可跑的签名 demo),
视觉完全用被拆对象自己的语言。

## 一、拆解页 `teardown.html` 的分节(可增减,但深度别缩水)

以下每节都基于 `tokens.json`、`manifest.json` 的真实值,不是观感:

1. **Hero**:该站视觉语言的浓缩。真实底色 + 真实字体大标题 + 一句「这不是观感,下面每个值都来自真实抽取」+
   若干真实值 chip(强调色、主缓动、字体、关键媒体、框架)。**页面自身用该站的真实主缓动运动**(拆解页像被拆对象一样动),是个好细节。
2. **定位、设计意图**:它想给谁、什么气质;若有「营销层 vs 产品层」之分要点破。
3. **色彩系统**:真实色值表(基底、品牌、强调、语义),**色板点击复制**。每个值标实锤(topHex、CSS 变量命中)或推断。
4. **字体系统**:真实字族(标题、正文、等宽),用第 3 步接入的**真字体**当样张;商业字体注明。
5. **动效系统**:真实缓动曲线(画出 cubic-bezier + 可重放的跑块 demo)、时长梯(常见「电影级慢层 + 敏捷微交互」双时间尺度)。
6. **签名视觉母题 + 可跑 demo(必做)**:复现该站最标志性的那个效果,纯 CSS/JS、用真实缓动、时长。举例(按气质对号入座,别硬套):
   - 极黑极简型 → 中心光环、光晕 + 品牌字色散故障;首屏内嵌对话输入框。
   - 精密工具型 → 发丝线 + 动画点阵矩阵 + 招牌「模糊到清晰」渐入。
   - 电影感型 → 全屏真实大图 + 滚动视差 + 产品裱设备框(如 macOS 窗口)。
   - 艺术叙事型 → 氛围插画 + 打字机式代码叙事 + 技能走马灯。
   - 收敛、物理型 → 景深浮动小球随交互向心汇聚。
   - 极简纯白型 → prompt 建议卡海 + 柔和渐变托底产品图。
   - 亲和型 → 彩色高亮胶囊 + 手绘头像 + 漂浮描边图标。
   - Agent 工作台型 → 思考步骤逐条浮现 + 生成物网格弹入。
7. **工艺细节**:圆角、玻璃 blur、阴影、栅格、媒体选型(为什么这个效果用视频、那个用 CSS、头像用 Lottie)。
8. **复刻**:把真实 `:root` token 直接给出 + 复现签名效果的关键代码。
9. **出处与方法**(页内简版):实锤 vs 推断一句话交代,指向 `real-assets/manifest.json`。

配一张 **as-seen 真实渲染截图**(`screenshots/full.jpg` 或关键帧),注明是真实抓取,与页内 CSS 复现对照。

## 二、三份文档

- **设计解构.md** — 上面 1-8 节的文字完整版,真实 token 表,逐值标**实锤、推断**。
- **复刻指南.md** — 可复制 `:root`(真实值)+ 签名效果代码片段 + 选型决策表 + 工程坑(严格 CSP、预加载重资源、声音需手势解锁、暖白非纯白、尊重 `prefers-reduced-motion` 等)。
- **出处与方法.md** — 抽取链路(playwright 计算样式 + 服务端抓样式表原文、资产)、实锤清单、推断清单、局限(哪些没拿到、为什么)。

## 三、两份审查(对抗性,别省)

- **事实核查.md** — 做一张逐项对照表:页面里出现的每个数值 → 真实抽取里的对应值 → 是否一致 → 漂移则改正。
  重点抓这几类真错误:把探针 `accentGuess`(只是猜测)当「实测品牌色」;把第三方内嵌色(Google、Atlassian 图标带进来的)当品牌色;
  把 `.15s` 误读成 `15s`;把「声明条数」当「去重后条数」过计;把某截图误当真实产品页(可能是 Cloudflare、登录墙)。
- **设计评审.md** — 以顶级设计视角评审这份拆解的精度与完成度:达标在哪、相对原站还差在哪(体裁取舍要说明)、给 3 到 6 条可执行改进(能当场改的就改)。

## 四、写作与视觉红线

- **真实值优先**;拿不准标「推断」;**绝不编造精确数值**。
- **针对性视觉**:拆解页用被拆对象的真实底色、字体、强调色、圆角、缓动,不套统一模板。
- 面向人读的产物:**零 emoji**;**禁点串**(不写 `A · B · C`、`A × B`、`A / B` 这类堆砌;单个分隔符如一个「·」或破折号可以,别成串);
  **不写真实人名**(用 role,如「产品设计师」);规范现代汉语 + 规范中文标点。
- 图、媒体不烧文字进去(文字用 HTML,便于双语与清晰)。
- 相对路径引用一切素材,保证克隆、拷走后完整可用。

## 五、常见坑

- 截图、抽取可能命中 **Cloudflare 人机校验页或登录态页**(字节数异常小、内容是校验框):识别出来,改用真实滚动录屏关键帧作 as-seen,并在文档里如实说明。
- **懒加载、滚动揭示**:验证时必须逐屏滚动触发 IntersectionObserver,否则整页截图大面积空白。
- **CJK 变量字体** `document.fonts.check()` 常返回 false(假阴性):以肉眼字形判断真字是否生效。
- **字体别全接**:很多站加载几十支(多权重 + 多文种 + 图标字 + 无障碍字),只接标题、正文、等宽真正用到的 1 到 3 支。
- **视频张冠李戴**:先判断视频到底是不是 hero(首屏可能是 canvas 驱动,视频是别处的演示、装饰),别把演示视频当首屏背景。

## 六、质量自检(交付前)

- [ ] 每个数值都能在 `tokens.json`、`manifest.json` 找到出处,或明确标了「推断」。
- [ ] 拆解页视觉是被拆对象的语言,不是模板;至少一个签名效果可跑。
- [ ] 真字体已接入并肉眼确认无 tofu;真媒体已嵌(或说明为何没有)。
- [ ] 事实核查表逐条过完,漂移已改;两份审查齐全。
- [ ] 零 emoji、无点串堆砌、无真实人名;相对路径;控制台 0 报错。
- [ ] 受版权素材、商业字体仅内部比对,仓库私有。
