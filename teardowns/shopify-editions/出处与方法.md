## 二、实锤清单（直接抽取）

- **色**：topHex 词频表（#292919 与 #f7f7ee 各 23 并列第一）；样式原文中 #dcdcd0/#e2e2d9/#909083/#5c5c4e/#8051ff/#D7D7CF/#434343；JS 常量 uGlowColor=8969727（=#88DDFF）、面罩 #7126ff、Sobel 底色 [.995,.995,.933]
- **字**：4 支字体真文件（24,792 / 30,440 / 15,572 / 67,188 B）；@font-face 原文含 feature 设置；全部字阶 clamp 公式；`text-box:trim-both cap alphabetic`；JP/DE 覆写
- **缓动**：14 条 cubicBezier 计数表；四支主曲线原文（back/frame/lines/fade）；Lenis easeOutExpo 函数体
- **滚动**：Lenis 实例化五参数原文；分区公式（earlyCrossfade .2）；导航阈值三组数（.4/.7/.75 与 [−.85,.15]/[−.3,.7]/[−.25,.75]）
- **WebGL**：13 份 Theatre state 文件名与 3 份内容（对象清单、sequence 长度 10）；场景资产 40 个 KTX2 URL（bg + desktop + 13 张移动 fallback）；bloom 默认值四参数；序曲 100ms/5000ms/三次方；detect-gpu tier 映射与降级链；KTX2 流式（80 字节头、ZSTD wasm、worker 池）
- **蝴蝶**：顶点/片元着色器全文；50 上限；rest.json 与贴图字节数；出生分布公式
- **技能星座**：2.1/0.7/400/0.4、斥力 80、碰撞间距 50、扇区数 3、连线 #D7D7CF 1px .8、弹窗 grid-rows 与方向翻转变量、计数 1s 三次方、emoji 参数、vibrate(10)、GLSL hash 常量、SSE init/update 事件名与字段（topSkillsSSEEndpoint 由 CMS 下发）
- **商店**：quantity/dollars/cents 三个 upper-roman counter；`cart/{variantId}:{qty}`；开 800ms/收 500ms；#beanie 深链逻辑；「Renaissance Person / Beanie / $14.52 / All sales are final」文案（截图可证）
- **构造线**：SVG 全部 path/circle 坐标（黄金分割线 y=336.13/543.87、螺旋台阶 80.25/49.04/30.65、圆 r=425/550/805/917）；章→组映射表；描线/闪烁/加载三段时序与四支曲线；roman counter 目录
- **工艺**：View Transition 三命名；inert 清单；视频 12 路 source 矩阵；卸源逻辑；content-visibility 500ms；Rive 300/600ms 与 rootMargin；console 彩蛋字符画本体；emoji-pack zip 下载链接；popup wheel 0.15
- **文案与结构**：12 章 id 与 h2、12 段章导语全文、每章 article 计数（合计 200）、hero 高度 150svh translate −100%

## 三、推断清单

前次为推断、经外部核验升为实锤的一条：**Hydrogen + Oxygen**——线上响应头直接给出 `powered-by: Shopify, Oxygen, Hydrogen`，且 HTML 含 `window.__remixContext`、后端店铺 editions-winter-2026.myshopify.com（外部研究通道抓取核验）。

| 推断 | 依据 | 置信 |
| --- | --- | --- |
| 美术为 AI 生成 + 人工拼贴 | 资产文件名残留提示词「painting of forest and flowers by Sandro Botticelli」 | 高（该图实锤，全量美术为类推） |
| 「作坊/手稿」为有意母题 | 构造线 + 罗马数字 + 花体 + 网格纸 + Sobel 素描的系统性 | 高（意图类） |
| zustand 为状态库 | create/subscribe/getState 形态 | 高 |
| SSE 端点实时性 | 代码路径完整（EventSource + init/update），端点 URL 由 CMS 注入、未实抓流量 | 中高 |

## 四、局限（没拿到什么）

1. **Background chunk（1,045,525 B）未逐行**：three.js 核心 + 合成着色器混编；overlay/darken/fadeCenter/Sobel 的 uniform 名已从调用侧证实，片元实现未展开。
2. **SSE 实时流未抓包**：verification 会话未触发直播端点（CMS 配置 topSkillsLiveFeedEnabled），协议结构自代码读出。
3. **Rive 文件未逆向**：.riv 二进制未解包，状态机名（idleState 等）与事件名自 JS 读出。
4. **十三份 Theatre state 只抽样三份**：其余十份 URL 已记录，未全量落盘（体积与重复性考虑）。
5. **移动端真机行为**：断点与触摸逻辑来自源码，未真机实测。
6. **整页截图失败**：页面 51,725px 超出单帧上限，full.jpg 为 0 字节——以 33 张逐屏截图 + 8 帧关键帧替代（更高保真）。
7. **外部反响仅节选**：行业评论以公开可检索来源为准，收录于《设计解构》附录；社媒短评未系统归档。

## 五、复算口径

- 「200 张产品卡」= 12 个 section 内 `<article id>` 计数之和（20+2+23+17+13+10+22+6+14+12+7+54）；官方口径「150+ updates」为营销计数，两者不冲突。
- 「#88DDFF」= uGlowColor 整数 8969727 的十六进制换算（136,221,255）。
- 「黄金比台阶」：80.2484/49.0407=1.6364、49.0407/30.6522=1.5999，取 ≈φ（1.618）的方形化近似——原站坐标反推，非我方拟合。
- 「headline-1 最大 220px」= clamp 上限 13.75rem×16。
- 「章高」以 832px 视口探针为参考（sidekick 8,196px 至 shop-app 2,220px），1440 视口下另行伸缩。
