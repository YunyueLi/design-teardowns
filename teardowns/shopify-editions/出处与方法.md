## 三、推断清单

前次为推断、经外部核验升为实锤的一条：**Hydrogen + Oxygen**——线上响应头直接给出 `powered-by: Shopify, Oxygen, Hydrogen`，且 HTML 含 `window.__remixContext`、后端店铺 editions-winter-2026.myshopify.com（外部研究通道抓取核验）。

| 推断 | 依据 | 置信 |
| --- | --- | --- |
| 美术为 AI 生成 + 人工拼贴 | 资产文件名残留提示词「painting of forest and flowers by Sandro Botticelli」 | 高（该图实锤，全量美术为类推） |
| 「作坊/手稿」为有意母题 | 构造线 + 罗马数字 + 花体 + 网格纸 + Sobel 素描的系统性 | 高（意图类） |
| zustand 为状态库 | create/subscribe/getState 形态 | 高 |
| SSE 端点实时性 | 代码路径完整（EventSource + init/update），端点 URL 由 CMS 注入、未实抓流量 | 中高 |
| useKeyPopupStore 的 keyUnlock/POPUP_CENTER 主窗消费端未启用 | store 定义完整但全部已下载 chunk 中无 setFromPopupCenter/keyUnlock 调用方；ShippingScene 仅 import 未接线 | 中高（也可能藏于未公开分支） |
| KEY_ANIMATED_OUT = 主画面钥匙飞离动画完成信号 | 消息名 + ShippingScene 发送时机 + 实测截图中的金色飞行轨迹 | 中高 |

## 四、局限（没拿到什么）

1. **Background chunk（1,045,525 B）未逐行**：three.js 核心 + 合成着色器混编；overlay/darken/fadeCenter/Sobel 的 uniform 名已从调用侧证实，片元实现未展开。
2. **SSE 实时流未抓包**：verification 会话未触发直播端点（CMS 配置 topSkillsLiveFeedEnabled），协议结构自代码读出。
3. **Rive 文件未逆向**：.riv 二进制未解包，状态机名（idleState 等）与事件名自 JS 读出。
4. **十三份 Theatre state 只抽样三份**：其余十份 URL 已记录，未全量落盘（体积与重复性考虑）。
5. **移动端真机行为**：断点与触摸逻辑来自源码，未真机实测。
6. **整页截图失败**：页面 51,725px 超出单帧上限，full.jpg 为 0 字节——以 33 张逐屏截图 + 8 帧关键帧替代（更高保真）。
7. **外部反响仅节选**：行业评论以公开可检索来源为准，收录于《设计解构》附录；社媒短评未系统归档。
8. **/key 的 GLB 模型未落盘**：12 件收藏品 + 锁孔 + Shoppy + 金币的 URL 全部在册，但 3D 模型为受版权资产，不下载不入库；双窗实录截图即证据。弹窗会话有一处 404（次要贴图，未影响流程）。
9. **双窗实测为无头环境**：window.screenX 恒 0，「拖窗对齐」的位移分量未实测（公式与 lerp 从源码读出）；真机拖窗行为未录屏。

## 五、复算口径

- 「200 张产品卡」= 12 个 section 内 `<article id>` 计数之和（20+2+23+17+13+10+22+6+14+12+7+54）；官方口径「150+ updates」为营销计数，两者不冲突。
- 「#88DDFF」= uGlowColor 整数 8969727 的十六进制换算（136,221,255）。
- 「黄金比台阶」：80.2484/49.0407=1.6364、49.0407/30.6522=1.5999，取 ≈φ（1.618）的方形化近似——原站坐标反推，非我方拟合。
- 「headline-1 最大 220px」= clamp 上限 13.75rem×16。
- 「章高」以 832px 视口探针为参考（sidekick 8,196px 至 shop-app 2,220px），1440 视口下另行伸缩。
