## 二、发现并已改正的漂移

| # | 漂移 | 处置 |
| --- | --- | --- |
| 1 | 《设计解构》六称舞台恒为 5350vh | CSS 有 `@media (width<=720px){.stage{height:7300vh}}`——手机舞台是 **7300vh**，比桌面**更高**。已在《设计解构》六与本页注明两个值。 |
| 2 | 《设计解构》六把手机 `Me` 表描述为「压缩各段」 | 读 JS 9730–9757 行：`Me` 是**分段线性重映射表**，把手机的 7300vh 进度映射回桌面道路进度；总量不是压缩而是**重新分配**——九段主体归一到 .983，末尾两段页脚只分到 .005 与 .012。「压缩」是误述，已改为「重新分配比例，并把页脚两段压到 1.7%」。 |
| 3 | 「四芒星 7 秒一闪」未提延迟，且与页脚星混用 | 三处 `shine` 参数不同：覆盖层 `.ov .gx` 为 7s 延迟 2.4s，问答卡 `.fq .st` 为 7s 无延迟，页脚 `.ft-st` 为 **6s**。已分列。 |
| 4 | 亮度阈值只写了桌面 168/132 | 完整式为 `innerWidth <= 720 ? a > (Le ? 150 : 185) : a > (Le ? 132 : 168)`——手机档为 **185 进 / 150 退**。已补。 |
| 5 | 亮度采样区域只写了桌面裁切 | 手机走另一支：`drawImage(e, t*.3, n*.15, t*.4, n*.75, …)`，即宽 30%–70%、高 15%–90%。已补。 |
| 6 | 未记录「段自带亮态」旁路 | JS 12534 行：若当前段 `ee.lit` 为真，直接加 `on-light` 而**跳过采样**；采样只在未声明亮态的段生效。已补。 |

## 三、易错点自查

- **两个「40」不是一回事**：蒙版刷新阈值是 40ms（`n - Bt > 40`），亮度采样是 160ms（`t - Re > 160`）；《复刻指南》给的是前者，《设计解构》给的是后者，不可互换。
- **`--color-sky #015186` 仍标为「未见使用」**：样式表与 JS 全文检索只在 `@layer theme` 声明处与两条 Tailwind 工具类（`.bg-sky`、`.focus:border-sky`）出现，页面 DOM 未挂这两个类。定级维持「推断为预留」，未升实锤。
- **`.cf-send` 金色按钮**：CSS 规则存在，当前 DOM 渲染的是 `.cf-cta`。文档与 token 文件均已标「当前 DOM 未用」，未当作在用的品牌色。
- **「1,056 帧」是单档计数**：等于 121+362+121+89+121+121+121，其中 reel 的 bridge 段按一部影片计；768 档另有一份同结构计数，未计入。
- **整页截图为空不是抓取失败**：5350vh 超过单帧上限，`screenshots/full.jpg` 为 0 字节属预期；替代物是 35 张道路截图，已在《出处与方法》四注明。
- **影像制作方式不作判断**：文档全程只描述画面与文件，不对「是否 AI 生成」下结论。

## 四、结论

抽样逐项与抽取源一致；六处漂移全部当场改正并在本页留痕，其中两处（手机舞台高度 7300vh、`Me` 表语义）改变了原结论的方向，已同步回《设计解构》。所有推断项均保留级别标注，未有推断被写成实锤。
