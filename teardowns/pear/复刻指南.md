### 1. 舞台与自研滚动


```css

```

```js
const L={target:scrollY,current:scrollY,on:!reduced && !coarse};
addEventListener('wheel',e=>{ if(e.ctrlKey)return; e.preventDefault();
  const k=e.deltaMode===1?16:e.deltaMode===2?innerHeight:1;
  L.target=clamp(L.target+e.deltaY*k,0,maxScroll()); },{passive:false});
function frame(){ requestAnimationFrame(frame);
  if(L.on){ L.current+=(L.target-L.current)*.085; if(Math.abs(L.target-L.current)<.08)L.current=L.target; scrollTo(0,L.current); }
  else { L.target=scrollY; L.current+=(L.target-L.current)*.3; }
  const road=clamp(L.current/maxScroll(),0,1); render(road); }
```

九段路按 vh 长度分配：`[1200,600,300,900,300,600,500,250,700]`，每段进度 `seg = clamp((road − start)/len, 0, 1)`。

### 2. 帧序列装载器（二分预取 + 邻域扫描）

```js
// 取帧：先在 want±24 内找未加载的，再按二分顺序补齐；并发上限 8；失败重试 3 次
const url=i=>`/films/${name}${tier}/f_${String(i+1).padStart(3,'0')}.webp?r=13`;
```

### 4. 撕裂圆环（着色器核心，节选）

```glsl
vec2 p=(uv-org)*vec2(aspect,1.); float r=length(p)/reach;
float ang=atan(p.y,p.x);
float wob=(fbm(vec2(ang*1.9+3.,t*.20))-.5)+(fbm(vec2(ang*5.3,t*.38))-.5)*.55;
float W=.30, R=prog*(1.+2.*W)-W+wob*.30, ph=r-R;
float pass=smoothstep(W,-W,ph);                 // 0 前沿之前，1 之后
float band=clamp(1.-abs(ph)/W,0.,1.); band=band*band*(3.-2.*band);
float fld=fbm(uv*3.4+vec2(t*.06,t*.31))*.72+(.5+.5*sin(r*46.-t*1.1))*.28;
float brk=smoothstep(.62-band*.26,.80-band*.18,fld)*band;
// 行撕裂 7px @15Hz、块 11px（24% 概率 ×.28）、每块独立交接、13px 色散、9px ASCII 拓片、闪光
vec3 flare=vec3(1.,.94,.80)*band*band*.62; col=1.-(1.-col)*(1.-flare);
```

5×5 位图字形（十级）：` .:-+=*%#@`，每字形五行 5 位整数，用 `mod(floor(row/exp2(x)),2.)` 取位，无贴图。

## 三、选型决策表

| 需求 | 原站做法 | 为什么 |
| --- | --- | --- |
| 首屏 10 秒影像 | mp4 视频 | 连续镜头，视频最省 |
| 滚动刮擦的镜头 | webp 帧序列 + 自研装载器 | 视频 seek 不可靠，帧序列可任意位置命中；二分预取保证「先有粗帧」 |
| 镜头之间的转场 | 片元着色器 | 撕裂、燃烬、纸纹需要逐像素控制，DOM 做不到 |
| 规则线的遮挡 | 2D canvas + 蓝天键控 | 免去为每帧做遮挡层，一行阈值公式解决 |
| 文案入场 | DOM + 逐字 span + 行内 transform | 文字保持可选可读，动画只改 transform/opacity |
| 表单玻璃 | CSS backdrop-filter + conic 边 | 纯 CSS 可交互，`@property` 让角度可动画 |
| 页脚过渡 | 第二支小着色器 | 与主着色器解耦，只在最后 13% 路上存在 |
| 平滑滚动 | 自写 lerp | 不引 Lenis，行为可精确到 .085 与 .08px 吸附 |

## 四、工程坑（原站已踩并留注）

1. **cover-fit 的手机裁切**：竖屏按高适配后水平只有 `(1 − k)/2` 的余量，pan 超出即采样到边外的黑；要 `clamp(pan, −slack, slack)`。
2. **接缝是镜子**：沿直线分开的画面读作镜像，需要一团被 fbm 咬边的米色遮住接缝，并把符号翻转做成 `smoothstep(−soft, soft, x − axis)` 的斜坡而不是阶跃。
3. **点画的阈值要门控**：`step(a, b)` 在 Bayer 与 hash 都为 −.5 时会在覆盖为 0 处误触发，整张纸瞬间起斑；要乘 `step(.0005, charT)`。
4. **`max(edge, 0)` 的暗幕**：前沿之前的像素 `edge < 0`，`exp(−max(edge,0)/d)` 恒为 1，会把整张纸一起压暗；改为 `exp(−|edge|/d)`。
5. **纸的纹理不能在半路出现**：纸浆、纹理、光斑全部乘同一个 `uFlat`，否则观众会看到「质感开关」被打开。
6. **局部变量名遮蔽函数**：GLSL 里名为 `cover` 的局部变量会遮蔽同名的 cover-fit 函数，原站把它改名 `covr`。
7. **Safari 的 rAF 可能量化到 30Hz**：`?hud` 面板会检测连续 150 帧中 80% 落在 31 到 36ms 时提示 LPM。
8. **`history.scrollRestoration = 'manual'`** 并在启动时强制 `scrollTo(0,0)`，否则刷新后落在半路却没有帧。
9. **减弱动态**：关闭 lerp、去掉 1.06 的呼吸放大、规则线一次到位（`_ = 10`）。
10. **字体**：不要为兜底字体引第三方 css 链路；自托管，`font-display: swap`，只加载真正用到的字重。
