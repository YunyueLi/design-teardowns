# Latrix 拆解 · 设计评审

> 以顶级设计视角,评审这份拆解相对原站 `latrix.ai` 的**精度**与**完成度**:哪些已达标、还差在哪(体裁取舍要说明),并给出可执行改进。能当场改的已改,标注「已改」;其余给出做法与取舍。

---

## 1. 总评

这份拆解最大的价值,是**没有停在观感,而是一路追到站点自己的源码,把三处会误导人的坑挖了出来**:

1. **时长的真相**。挖掘产物 `tokens.json` 把亚秒时长抹成了整数秒,顺着它很容易写出一层「16 到 76 秒的电影级氛围慢层」——那会是个漂亮但虚假的叙事。核对站点 CSS 原文后确认:Latrix 的时长梯**全是亚秒微交互**,招牌缓动 `cubic-bezier(.22,1,.36,1)` 配 `.76s` 的滚动揭示,气质是「跟手」而非「慢」。这条纠偏(见 `事实核查.md` D1)是本拆解的诚信底座。
2. **签名母题的机制**。那条捻动的 `LATRIX` 绳,站点自己把容器命名为 `_homeDnaBackdrop`(实锤)——「数字生命的 DNA 链」是设计者的原意,不是我们的附会;而且它跑在唯一的 `<canvas>` 上、由 JS 驱动,CSS 里**没有任何 3D 变换**。把复刻的 CSS 3D 版明确降格为「近似」,而不是冒充还原,是对的。
3. **色彩的命名怪癖**。`--accent` 其实是墨色,真正的强调色是 `--warm`;深浅两支橙分属常态与悬停。这些都如实点破了。

配合对字体统计(404 次 Noto 的真相)、`cssBytes` 构成的复核,这份拆解的**数据可信度**过关:每个数值要么可回溯到计算样式/源码原文,要么明确标了推断。

---

## 2. 已达标(相对原站,且证据够硬)

- **色彩系统**:暖灰白 + 墨 + 一点橙的极克制配色,色值与用途都对得上;两支橙、透明度阶梯、命名怪癖都讲清了。
- **字体与排版**:Playfair 展签衬线 + Space Mono 图注的反差抓得准;H1「常规字重 + 0.92 行高」这条最反直觉、也最关键的实锤没有漏;全大写走 `text-transform` 的craft也点到了。
- **动效语言**:单一招牌缓动、亚秒时长梯、滚动揭示的 `.76s + .26s`、唯一循环 `_brandBounce 2.4s`,以及两处 `prefers-reduced-motion`,均为实锤复现。
- **签名母题**:DNA 绳的意图(容器类名坐实)、载体(唯一画布)、机制(JS 驱动、无 CSS 3D)三件事都落到了实锤,复刻给了低门槛 CSS 版与更贴手感的 JS 版,并都要求尊重减弱动效。
- **工艺洞察**:药丸导航与直角橙 CTA 的刻意对撞、古典名作 + 被重写展签词的策展叙事、画布 `aria-hidden` 的体面细节,都抓住了。
- **出处诚实**:实锤与推断分栏清楚,`tokens.json` 的两处失真被主动下架,而非顺着抄。

---

## 3. 相对原站仍存在的差距(含体裁取舍)

1. **下方古典名作叙事区仍是「文本级」还原,不是「版面级」**。抓取以首屏为主,那条 DNA 绳看得很清楚;但成段的名作图版区没有逐屏渲染留证,目前靠 `manifest.json` 的图片清单 + `index.html` 的 `alt` 文案与小标题原文重建。**文案是实锤,但这些名作在页面上如何排布、如何随滚动揭示、图与展签词怎样对位,尚未看全**——这是本拆解当前最大的完成度缺口。
2. **DNA 绳是 CSS 近似,不是原站画布螺旋的逐像素还原**。原站在画布上用 JS 做出的「收成窄柱又摊成两股」的分合手感、引导线随之伸缩的细节,CSS 3D 版只能近似;绳的自转周期(用了 `18s`)是自拟值,非实测。已明确标注,属有意的再诠释,非疏漏。
3. **`--hand`(Italianno)只确认「备好了」,没确认「用在哪」**。字体已加载、变量已定义(实锤),但页面落点未取到,只能标推断。这支书法花体若真有显眼用处(多半在下方叙事区),目前没覆盖到。
4. **H1 的计算值与源码类未完全对齐**。计算样式 `126.72px / letter-spacing normal` 与首页标题源码类 `clamp(40px,5.6vw,82px) / -.025em` 对不齐;本拆解以计算值为准并标注了差异,但没能定位探针到底测的是哪一处 H1 实例。
5. **技术栈无定论**。未检出已知库,构建工具只能从类名哈希推断,属预期局限。

## 4. 可执行改进

标「已改」的本轮已落地;「建议」的给出做法与取舍。

1. **【已改】三处失真下架并写正**。时长(D1)、`001ms`(D2)、404 次 Noto(D3)按站点源码原文订正,详见 `事实核查.md`。
2. **【已改】签名母题机制归位**。把 DNA 绳从「CSS 3D」纠正为「画布 2D + JS」,CSS 复刻降格为近似,并要求尊重减弱动效。
3. **【建议】补下方叙事区的逐屏关键帧**。逐屏滚动触发 IntersectionObserver,给古典名作区各截 1 帧存进 `keyframes/`,再把每张名作图与其被重写的展签词在 `设计解构.md` 第 7 节配成对照表(alt 文案已是实锤,补上版面即可从「文本级」升到「版面级」)。这是当前性价比最高的完成度提升。
4. **【建议】给 DNA 绳做一版真实 rAF 画布 demo**。按 `复刻指南.md` 3.0 的思路,用画布 + `requestAnimationFrame` 还原「分合手感 + 引导线伸缩」,比 CSS 3D 更贴原站;并从录屏 `recording/scroll.webm` 估一个更接近的自转周期区间(仍标推断,但比 `18s` 的纯自拟更有据)。
5. **【建议】定位 Italianno 的真实落点**。在下方叙事区截图里找那支书法花体的实际用处(标题花字或引文),确认后把「落点推断」升级为实锤,或明确它在本页确未启用。
6. **【建议】用真字体做一张样张对照**。四支字体全是 Google Fonts、可全保真嵌入(实锤),值得在拆解页并排放 Playfair 大标题、Space Mono 图注、Italianno 花字的真字样张,让展签、图注与花体的反差一眼可见,而非仅靠文字描述。

---

## 5. 一句话结论

这份拆解在**色彩、字体、缓动、圆角、签名母题机制**上都与原站源码逐条对齐,更难得的是把 `tokens.json` 里两处「看起来确定、其实是失真」的数据主动挖出来改正——它既讲清了 Latrix「策展式数字人文」的设计语言,又经得起逐条追问。剩下的差距(下方名作区的版面级还原、DNA 绳的画布级复刻、Italianno 落点)都清晰、低成本,不影响它作为一份可复刻、可自证的高精度拆解成立。
