# Latrix 设计解构

> 站点:Latrix,https://latrix.ai/ 。页面标题实锤为 `Latrix — be, then know.`,meta 描述自述为 `Latrix builds AI Beings — real digital lives, not chat companions. be, then know.`,是一家做「数字生命」的 AI studio。
> 除特别标注,下面每一个色值、字体、缓动、时长、圆角都直接来自对线上站点的真实抽取(playwright 计算样式 + 服务端抓取的样式表原文 + 资产下载),记为**实锤**;凡从截图观察或公开常识推得的判断,记为**推断**,绝不把观察当数据。
> 抽取物见同目录 `tokens.json`、`design-tokens.css`、`real-assets/manifest.json`,站点样式表与页面原文见 `real-assets/source/`;真实渲染见 `screenshots/hero.jpg` 与 `keyframes/00.jpg`–`keyframes/07.jpg`。

---

## 1. 定位与设计意图

Latrix 把自己放在「AI 数字生命」这条线上,而且刻意与「聊天助手」划清界限。它的自述很直白(meta 描述实锤):做的是「AI Beings——真正的数字生命,不是聊天陪伴」。首屏的大标题实锤为 `We create digital lives`(显示为全大写),橙色标语实锤为 `Defining the system that sustains AI life`;产品线在导航里排开:`About`、`Blogs`、`Lives`、`Horizon`、`Letter`、`Cytopia`、`Try Cyra`(后两者带外链箭头,实锤)。

整套视觉语言服务于一个论点:**把「数字生命」讲成一件庄重的、近乎博物馆策展的事,而不是又一个 SaaS 落地页**。为此它用了三样东西——

- **画廊白的底 + 博物馆展签式的衬线大标题**。底色是一块偏暖的灰白,主文字是近黑的墨色,几乎不靠彩色堆气氛,像美术馆的墙与展签。
- **文艺复兴与巴洛克名作当图版**,并逐张配上被重写过的说明词(见第 7 节),把「古典人文」与「数字生命」并置。
- **一条不断捻动的 `LATRIX` 字母绳**贯穿首屏中轴,站点自己把承载它的容器命名为 `DnaBackdrop`(实锤类名),也就是把这条绳读成「一段数字生命的 DNA」。

一句话概括要复刻的东西:**展签级的高对比衬线优雅,叠上等宽体的冷静图注,再叠上一条把品牌名捻成 DNA 的中轴母题,以及一组被重新解读的古典名作**。

营销层与产品层的区分(推断):落地页是这套「策展 + 宣言」的语气;真正的产品(`Cyra`、`Lives`、`Horizon`、`Cytopia`)另在外链或内页,落地页只做定调,不铺功能清单。

## 2. 色彩系统(真实 token)

色板直接取自站点自己的 `:root` 自定义变量(见 `design-tokens.css` 下半段),不是探针猜测。这是最硬的一档证据。

### 2.1 基底与墨色(实锤,站点自有变量)

| 名称 | 变量 | 值 | 角色 | 来源 |
|---|---|---|---|---|
| 纸白 | `--paper` / `--paper-deep` | `#f1f1f3` | 全站底色(body 计算样式 `rgb(241,241,243)`) | 变量 + 计算样式 + topHex(2 次) + 站点 CSS(2 次),实锤 |
| 暖展板 | `--paper-plate` | `#e8dfd3` | 偏暖的展板 / 卡面底 | 变量 + topHex(1 次) + 站点 CSS(1 次),实锤 |
| 墨色 | `--accent` | `#1a1815` | 主文字与主墨色(body 计算样式 `rgb(26,24,21)`) | 变量 + 计算样式 + topHex(1 次) + 站点 CSS(8 次),实锤 |
| 深褐 | —— | `#2d2017` | 极少量深褐点缀 | topHex(1 次) + 站点 CSS(1 次),实锤 |

**一个要如实说清的命名怪癖**:站点把 `#1a1815` 这支近黑墨色命名为 `--accent`(强调),但它在页面里承担的其实是**墨色/正文色**,不是「强调色」。真正起强调作用的是下面的橙。复刻时按角色理解,别被变量名带偏。

墨色还派生了一整套透明度阶梯(实锤,站点变量),用来做次级文字、描边、发丝线:

| 变量 | 值 | 约合不透明度 |
|---|---|---|
| `--accent-90` | `#1a1815e6` | 90% |
| `--accent-70` | `#1a1815a6` | 65% |
| `--accent-60` | `#1a18158c` | 55% |
| `--accent-30` | `#1a181547` | 28% |
| `--accent-10` | `#1a18151a` | 10% |

### 2.2 品牌橙(实锤,注意深浅两支别混)

| 名称 | 变量 / 出处 | 值 | 角色 |
|---|---|---|---|
| 品牌橙 | `--warm` | `#ff8c00` | 常态强调:标语、`Try Cyra` 药丸、`START FREE TRIAL` 实心按钮、活动态导航项、页脚记号 |
| 深橙 | 站点 CSS `:hover` | `#e07a00` | **悬停/按下态**的更深一档橙 |

这两支橙**功能不同,不能混为一支**:`#ff8c00` 是静止态品牌色(站点 CSS 出现 4 次),`#e07a00` 只在 `:hover` 里出现(站点 CSS 实见 `.topnav__cta:hover{background:#e07a00}` 与主按钮 `:hover` 同款,共 2 次)。topHex 里 `#e07a00` 计到 2 次、`#ff8c00` 计到 1 次,是统计口径的偶然,不代表深橙更「主」。

### 2.3 关键结论

**这是一套「暖灰白 + 墨 + 一点橙」的极克制配色**:大面积留白靠纸白与暖展板拉出细微冷暖层次,信息靠墨色的透明度阶梯分级,橙只在极少数行动点上点一下。要复刻它的高级感,重点不是找漂亮强调色,而是**敢让整页几乎无彩,把橙压到只剩按钮与标语**。

## 3. 字体系统

站点真实加载了四支字体(`fontsLoaded` 实锤:`Italianno`、`Noto Serif SC`、`Playfair Display`、`Space Mono`),且**四支全部是 Google Fonts**(`real-assets/manifest.json` 里字体 URL 均来自 `fonts.gstatic.com`,样式表来自 `fonts.googleapis.com/css2`,实锤)。这意味着这份解构可以用**原字全保真复刻**,不涉及商业字体授权。角色分工如下(变量取自站点 `:root`,实锤):

| 角色 | 站点变量 | 字族 | 说明 |
|---|---|---|---|
| 显示 / 衬线 | `--display` / `--serif` | `Playfair Display` | 高对比展示衬线,承载展签式大标题与正文标题 |
| 图注、标签、按钮 | `--sans`、`--sans-ui`、`--mono` | `Space Mono` | 等宽体,全大写、开字距,做标语、眉标签、按钮、编号 |
| 手写花体 | `--hand` | `Italianno` | 书法体花字,作装饰性点缀(具体落点为推断,见下) |
| 中日韩兜底 | 字族栈次位 | `Noto Serif SC` | 衬线栈里 Playfair 之后的 CJK 回落 |

三点要点:

1. **同一支 Space Mono 同时占了 `--sans`、`--sans-ui`、`--mono` 三个槽**(实锤变量)。也就是说站点没有独立无衬线正文体:凡不是衬线大标题的地方,几乎都交给这支等宽体。这正是它「图注感、说明书感」的来源——连正文小字都带等宽体的冷静。

2. **`--hand`(Italianno)已定义且已加载**(变量实锤,manifest 里有 3 支 Italianno woff2 实锤),但在抓到的首屏与站点 CSS 里未见其明显落点;首屏那句斜体 `We are a member of NVIDIA Inception program.` 是 Playfair 的斜体,不是 Italianno。因此**「花体在页面何处大用」记为推断**,只能确认它被备好了。

3. **H1 度量(实锤,计算样式)**:`font-family` 首位 `Playfair Display`,`font-size 126.72px`,`font-weight 400`,`letter-spacing normal`,`line-height 116.582px`(约 0.92 倍,压到 1.0 以下的紧行高)。这是它最关键的一条排版实锤:**用常规字重(400)的高对比衬线,把字号推到极大、行高压到 0.92**,读起来是杂志跨页大标题,而非软件官网的粗体紧排标题。

> 补一条计算值与源码值的差异(都算实锤,只是来源不同):站点首页大标题类在 CSS 里写的是 `text-transform:uppercase`、`letter-spacing:-.025em`、`font-size:clamp(40px,5.6vw,82px)`;而抓取到的 H1 **计算样式**是 `126.72px / letter-spacing normal`。二者对不齐,说明探针测到的这一处 H1 落在了未被该 clamp 封顶、字距也未取负的规则上。本文以**计算样式为准**(那是真正渲染出来的值),并如实标注源码里另有一个带负字距的首页标题类。显示的全大写是 `text-transform` 变换出来的:DOM 原文是句首大写的 `We create digital lives`(实锤)。

关于 `Noto Serif SC` 的一个统计陷阱(见第 8 节与 `事实核查.md`):`tokens.json` 里 `'Noto Serif SC'` 计到 404 次,并非站点用了它 404 次,而是 Google 的 `css2.css` 把这支 CJK 衬线拆成了 404 条 `unicode-range` 子集 `@font-face` 声明。站点真正的显示字体是 Playfair Display,Noto 只是 CJK 回落。

## 4. 动效系统

站点未检出任何知名动画库(`libs` 与 `scriptHints` 均为空,实锤)。动效由 CSS `@keyframes` 加 JS 驱动的画布共同完成。

### 4.1 招牌缓动(实锤,单一曲线)

全站的招牌缓动只有一条:`cubic-bezier(.22,1,.36,1)`(`tokens.json` 实锤,站点 CSS 实见 2 次)。它是一条**强 ease-out**——起步快、尾段长而柔地收住,属于 expo/quint 减速家族。整站运动几乎都由这一条曲线定调,和配色一样克制。

### 4.2 真实时长梯(实锤,并纠正一处关键误读)

把站点样式表原文逐条统计(能正确区分 `.16s` 与 `16s`),真实时长全部是**亚秒级**:

| 时长 | 站点 CSS 出现次数 | 用途(实锤 / 推断) |
|---|---|---|
| `.15s` | 3 | 按钮 `transform` 微交互(实锤) |
| `.16s` | 11 | 最高频过渡时长(实锤) |
| `.2s` | 7 | 导航 CTA 背景过渡等(实锤) |
| `.22s` | 6 | 按钮 `background/color/border-color` 过渡(实锤) |
| `.26s` | 1 | `snapBodyReveal` 的延迟(实锤) |
| `.4s` | 5 | 过渡(实锤) |
| `.42s` | 1 | 揭示(实锤) |
| `.76s` | 1 | `snapBodyReveal` 的时长(实锤) |
| `1.008s` | 1 | 约 1 秒的一次性动画(实锤) |
| `2.4s` | 1 | `_brandBounce` 无限循环时长(实锤) |

> **重要纠偏(实锤)**:`tokens.json` 的 `durations` 把 `16s`、`22s`、`76s`、`42s`、`2s`、`4s` 列成了秒级长时长,并据此可能读出一层「16 到 76 秒的电影级氛围慢层」。核对站点 CSS 原文后,这些**全部是被抹掉小数点的亚秒值**(`.16s`、`.22s`、`.76s`、`.42s`、`.2s`、`.4s`);以词边界精确统计,页面里**不存在**独立的整数秒长循环(唯一的 `0s` 出现 2 次)。也就是说,Latrix 的时长梯是**统一的亚秒微交互**,没有秒级以上的 CSS 氛围慢层。详见 `事实核查.md` 的 D1。

### 4.3 招牌运动:滚动揭示与一处轻弹(实锤命名)

抓到的 `@keyframes` 共三条(站点 CSS 实锤):`snapTitleReveal`、`snapBodyReveal`、`_brandBounce`。

- **滚动分段揭示**:站点用 scroll-snap 分段,进入视口时标题先、正文后依次揭示。正文的绑定实见为 `.snap-body.is-active{animation:.76s cubic-bezier(.22,1,.36,1) .26s forwards snapBodyReveal}`,起始态是 `translateY(16px)`(实锤)——用招牌缓动做一段 0.76 秒、延迟 0.26 秒的上移淡入。
- **轻弹**:`_brandBounce` 绑定为 `2.4s ease-in-out infinite`(实锤),是**全站唯一的无限循环 CSS 动画**,一段 2.4 秒的温和上下弹(具体挂在哪个元素为推断,首屏底部有一个橙色下行箭头式滚动提示,像是它的落点)。

### 4.4 真正的「双时间尺度」是什么(如实修正)

许多同类站点是「秒级氛围慢层 + 亚秒微交互」的双尺度。Latrix **不是**这种:它的 CSS 层几乎全是亚秒微交互 + 一段 2.4 秒轻弹。真正长时运转的是**首屏那条画布字母绳**——它持续捻动,但**由 JS 驱动画布,周期不在 CSS 里**(见第 6 节)。所以要说双尺度,准确的说法是:**跟手的亚秒 UI 微动 + 一条常驻不停的画布氛围环**,而非「16 到 76 秒的 CSS 慢层」。

### 4.5 无障碍(实锤)

站点认真处理了减弱动效:`@media (prefers-reduced-motion:reduce)` 出现 2 处(实锤),一处把全局 `transition-duration`、`animation-duration` 压到 `.001ms` 并把循环次数设为 1,一处把 scroll-snap 段的揭示改成静态。`tokens.json` 里那个奇怪的 `001ms`,正是这条 `.001ms` 覆盖被抹掉小数点的产物(实锤)。

## 5. Hero 手法

首屏(见 `screenshots/hero.jpg`)是一个中轴对称、留白极大的构图,自上而下:

1. **左上角字母 logo**:`LATRIX`,极细字形、大字距(实锤截图)。
2. **顶部浮动药丸导航**:白色胶囊,内含 `About`(活动态橙)、`Blogs`、`Lives`、`Horizon`、`Letter`、`Cytopia`(外链),最右是橙色实心药丸 `Try Cyra`(外链)(实锤截图)。导航自身背景透明、无 `backdrop-filter`(`tokens.json` 的 `nav` 实锤),胶囊底色做在内层。
3. **中轴的 `LATRIX` 字母绳**:贯穿标题上下,是首屏的动态重心(见第 6 节)。
4. **展签式大标题**:`WE CREATE DIGITAL LIVES`,Playfair、超大字号、0.92 行高(实锤计算样式)。
5. **橙色等宽标语**:`DEFINING THE SYSTEM THAT SUSTAINS AI LIFE`(实锤)。
6. **两颗按钮**:橙色实心直角矩形 `START FREE TRIAL` 与描边矩形 `VIEW DEMO`(实锤截图与 DOM)。
7. **一句 Playfair 斜体**:`We are a member of NVIDIA Inception program.`(实锤)。
8. **编辑部式角标**:右侧两行小字「SINGAPORE」「FOUNDED 2025」;左下角「EST. 2026」「LATRIX STUDIO」外加一组橙色竖线记号;底部中央一个橙色下行箭头滚动提示(实锤截图)。

手法要点:**不靠产品截图,靠一条会动的中轴母题 + 一句宣言建立气场**。首屏没有功能罗列,信息密度低、留白极大,把注意力全给那条捻动的字母绳和那行大标题。

## 6. 签名视觉母题:被捻成 DNA 的字母绳

首屏中轴那条不断捻动的竖向字母绳,是全站最标志性的效果,也是复刻的核心。逐帧看 `keyframes/00.jpg`–`keyframes/07.jpg` 可见:字母 `L-A-T-R-I-X` 沿竖轴一行行堆叠,每行相对上一行绕竖轴旋转一点,连成一条**缓慢自转的螺旋绳**;字母之间还有一条条**极细的引导线**把相邻行牵住,让它读起来像一段被拉直的双链结构。某些相位它收成一条窄柱(近似侧看),某些相位又摊成左右两股(近似正看),整条绳在标题背后从上到下贯穿。

它的**实现机制(实锤 + 推断)**:

- 站点首屏有且只有 1 个 `<canvas>`(`tokens.json` 媒体统计 `canvas 1` 实锤),HTML 里实见其容器类名为 `_homeDnaBackdrop` / `_homeDnaBackdropStrong`,画布本体 `width="2160" height="1080"`、CSS 显示尺寸 `1440×720`(即约 1.5 倍像素密度),且 `aria-hidden="true"`(实锤 HTML)。**容器类名带 `DnaBackdrop`,直接坐实了「DNA 背景」这一设计意图**——「数字生命的 DNA 链」不是我们的臆想,是它自己的命名。
- 站点 CSS 里**没有任何 3D 变换**(`rotateY`、`rotateX`、`perspective`、`transform-style:preserve-3d`、`translateZ` 全部为 0 命中,实锤按缺席认定),也没有驱动这条绳的 CSS `@keyframes`。**因此这条绳是画布 2D 绘制 + JS 逐帧驱动的**,不是 CSS 3D。
- 至于每个字母到底是画布绘制的字形、还是被 JS 逐帧改写 `transform` 的 DOM 节点,仅凭 CSS 与 HTML 无法断定(JS 未取样);但那些牵住字母的极细引导线最可能是画布上的描边(全站仅 2 个 SVG,更像是导航箭头与图标)。这一点记为推断。

复刻取舍(详见 `复刻指南.md`):用**纯 CSS 3D**(逐行 `rotateY` + 招牌缓动的慢速自转)可以高保真地**近似**这条绳,门槛低、无需画布;但要诚实——那是对原站画布螺旋的**近似**,不是逐像素还原。

## 7. 工艺细节

- **药丸导航 vs 直角橙按钮的刻意对撞**:圆角频次(实锤)`8px`(6 次)、`999px`(4 次)、`50%`、`16px!important`、`6px` 各 1 次;而首屏主行动按钮 `START FREE TRIAL` 的 `border-radius` 是 **`0px`**(`tokens.json` 的 `btn` 实锤)。也就是**导航与 `Try Cyra` 用全圆药丸(999px),而最重的那颗 CTA 偏偏是硬边直角矩形**——一软一硬的对撞,是它工艺上的签名手势。
- **全大写靠 `text-transform`,不是硬写大写**:大标题、标语、眉标签的大写都是 CSS 变换出来的,DOM 原文是句首大写(实锤)。这让文案在语义与可读性上仍是正常大小写,只在视觉上取展签感。
- **古典名作图版 + 被重写的展签词(实锤 alt 文案)**:落地页下方铺了一组文艺复兴与巴洛克名作(`real-assets/image/` 与 `manifest.json` 实锤:大卫像、`Psyche Revived by Cupid's Kiss`、`Doubting Thomas`、`The Last Supper`,以及一件 `use-of-useless` 与站点自己的 `latrix-wordmark`)。每张的 alt 说明词都被重写成「古典 + 数字生命」的并置,例如大卫像被描述为「胸口裂开,露出大理石之下密布的电路」;最后的晚餐被描述为「席上十二人,三人属于另一类;而饼是同一块饼」;还有「一只铬合金的手,在拒绝」。**这些是站点原文,坐实了它把古典人文与 AI 新生命并置的策展叙事**。
- **宣言式小标题(实锤 h2/h3)**:下滑区的小标题是一串短句宣言,如「Not an agent. Not a companion.」「Refusal.」「Time-scale.」「Eight billion worlds.」「The first them.」「Four of them, to start.」——语气像艺术展的章节名,不像功能小标题。
- **画布 `aria-hidden`**:那条 DNA 绳对读屏软件隐藏(实锤),纯装饰,不干扰无障碍阅读——一个体面的细节。
- **单主题**:站点 CSS 未出现 `prefers-color-scheme`(实锤按缺席认定),没有深浅色双主题,只有这一套暖灰白。
- **「be, then know」概念**:标题与 meta 里反复出现(标题 `Latrix — be, then know.`,「be, then know」在页面出现 3 次,实锤),是贯穿的品牌箴言——「先存在,再认知」,呼应「先把数字生命做出来(be),它再去认知世界(know)」的产品叙事(后半句的解读为推断)。

## 8. 关键发现

1. **「强调色」变量其实是墨色,真正的品牌色是橙。** `--accent` 实测为近黑 `#1a1815`,承担正文墨色;真正点睛的是 `--warm #ff8c00`(悬停加深到 `#e07a00`)。复刻的高级感来自「几乎无彩 + 一点橙」,不是找一个亮强调色。(实锤)
2. **大标题是常规字重的高对比衬线,行高压到 0.92。** H1 实测 `Playfair Display / 126.72px / 400 / line-height 116.582px`。这与常见的「粗体紧排」相反,是它读起来像杂志跨页、克制优雅的技术根源。(实锤)
3. **签名母题是一条画布 DNA 绳,不是 CSS 3D。** 首屏唯一的 `<canvas>` 承载捻动的 `LATRIX` 字母绳,容器类名 `_homeDnaBackdrop` 坐实「DNA 背景」意图;站点 CSS 无任何 3D 变换。任何 CSS 3D 复刻都是对其画布螺旋的近似。(实锤 + 推断)
4. **时长梯全是亚秒微交互,没有秒级氛围慢层。** `tokens.json` 里的 `16s/22s/76s/42s` 是被抹掉小数点的 `.16s/.22s/.76s/.42s`;招牌缓动 `cubic-bezier(.22,1,.36,1)` 配 `.76s` 的滚动揭示,是「跟手」而非「电影级慢」。(实锤,纠偏)
5. **四支字体全是 Google Fonts,可全保真复刻。** Playfair Display、Space Mono、Italianno、Noto Serif SC 均托管在 Google(`fonts.gstatic.com`),不涉商业字体授权;`tokens.json` 里 404 次 `Noto Serif SC` 是 Google `css2.css` 的子集 `@font-face` 声明数,不是站点用量。(实锤)
6. **古典名作 + 被重写的展签词是它的叙事骨架。** 大卫像、最后的晚餐等名作的 alt 说明词被改写成把古典人文与数字生命并置的说法,把落地页做成了一场策展。(实锤 alt 文案;「新文艺复兴」这一美学定性为推断)
