# Latrix 拆解 · 出处与方法

> 交代这份拆解的每个数值从哪来、怎么取、哪些是实测(**实锤**)、哪些是判断(**推断**)、哪些没拿到(**局限**)。原则:计算样式与样式表原文优先,拿不准标推断,绝不编造精确数值。

---

## 1. 抽取链路

对线上 `https://latrix.ai/` 用三条互补的路子取证,产物落在同目录:

1. **playwright 计算样式探针**:在真实浏览器里读关键元素(body、h1、nav、btn)的**计算样式**——即浏览器最终渲染出来的值,是最硬的一档。产物见 `tokens.json` 的 `probe` 段(含 body 底色 `rgb(241,241,243)`、墨色 `rgb(26,24,21)`、H1 `126.72px/400/normal/116.582px`、按钮 `border-radius 0px` 与过渡、媒体计数、已加载字体等)。
2. **服务端抓样式表与页面原文**:直接取站点的 CSS 与 HTML 原文,产物见 `real-assets/source/`:
   - `41a207_index-qQLVfn_2.css`(站点自有样式,约 61 KB)——招牌缓动、`@keyframes`、真实时长、圆角、`:hover` 深橙、`prefers-reduced-motion`、首页标题类等都在这里逐条可查。
   - `1d5ec7_css2.css`(Google Fonts 样式表,约 474 KB)——四支字体的 `@font-face` 与子集声明。
   - `index.html`——首屏结构、`<canvas>` 容器类名、导航与文案、古典名作图的 `alt` 说明词、`<title>` 与 meta 描述。
   `design-tokens.css` 是从上面提炼出的 `:root`,并附带站点自有变量原样节选。`tokens.json` 的 `tokens` 段是对样式表的字面统计(色值、缓动、字族、时长、圆角、keyframe 频次)。
3. **资产下载**:用拆解 skill 的 `capture_site.py` 把字体、图片、样式表原文抓到本地,清单见 `real-assets/manifest.json`(含每个文件的原始 URL、本地名、字节数)。字体落 `real-assets/fonts/`,图片落 `real-assets/image/`。
4. **真实渲染留证**:整屏截图 `screenshots/hero.jpg`、`screenshots/full.jpg`,滚动录屏关键帧 `keyframes/00.jpg`–`keyframes/07.jpg`,以及录屏 `recording/scroll.webm`——用来对照 CSS 复现,并观察那条 DNA 字母绳的逐帧形态。

## 2. 实锤清单(计算样式或样式表原文可证)

- **色值**:`--paper #f1f1f3`、`--paper-plate #e8dfd3`、`--accent #1a1815`(墨色)、`--warm #ff8c00`(品牌橙)、`:hover` 深橙 `#e07a00`、深褐 `#2d2017`,以及墨色透明度阶梯 `--accent-90/70/60/30/10`。均见站点 `:root` 变量与样式表原文,并与 body/h1 计算样式一致。
- **字体**:四支 `Playfair Display`、`Space Mono`、`Italianno`、`Noto Serif SC`,变量分工 `--display`/`--serif`/`--sans`/`--sans-ui`/`--mono`/`--hand` 明确;四支 URL 全部来自 `fonts.gstatic.com`(Google 托管),样式表来自 `fonts.googleapis.com/css2`。
- **排版**:H1 计算样式 `126.72px / 400 / letter-spacing normal / line-height 116.582px`(≈0.92);全大写由 `text-transform:uppercase` 变换(DOM 原文句首大写);首页标题类源码另写 `clamp(40px,5.6vw,82px)` 与 `letter-spacing:-.025em`。
- **缓动**:全站单一 `cubic-bezier(.22,1,.36,1)`(样式表 2 次)。
- **时长(真实值,亚秒级)**:`.15s`、`.16s`、`.2s`、`.22s`、`.26s`、`.4s`、`.42s`、`.76s`、`1.008s`、`2.4s`;按钮过渡 `background/color/border-color .22s, transform .15s`,导航 CTA `background .2s, transform .15s`;滚动揭示 `.snap-body.is-active{animation:.76s cubic-bezier(.22,1,.36,1) .26s forwards snapBodyReveal}`。
- **关键帧**:`snapTitleReveal`、`snapBodyReveal`、`_brandBounce`;`_brandBounce` 绑定 `2.4s ease-in-out infinite`,是全站唯一无限循环 CSS 动画。
- **圆角**:`8px`(6 次)、`999px`(4 次)、`50%`、`16px!important`、`6px` 各 1 次;首屏主 CTA `border-radius 0px`。
- **媒体**:`video 0`、`canvas 1`、`svg 2`、`img 7`;`preloadVideo 0`、`preloadFont 0`。
- **签名母题的机制**:首屏唯一 `<canvas width="2160" height="1080" style="width:1440px;height:720px">`,`aria-hidden="true"`,容器类名 `_homeDnaBackdrop` / `_homeDnaBackdropStrong`;站点 CSS **无任何 3D 变换**(`rotateY`/`perspective`/`preserve-3d`/`translateZ` 零命中)。
- **无障碍与主题**:`prefers-reduced-motion` 两处(其一全局压到 `.001ms`);无 `prefers-color-scheme`(单主题)。
- **文案与资产**:标题 `Latrix — be, then know.`;meta 描述 `Latrix builds AI Beings — real digital lives, not chat companions. be, then know.`;导航 `About、Blogs、Lives、Horizon、Letter、Cytopia、Try Cyra`(后两者外链);古典名作图及其被重写的 `alt` 说明词(大卫像、`Psyche Revived by Cupid's Kiss`、`Doubting Thomas`、`The Last Supper` 等),清单见 `manifest.json`。

## 3. 推断清单(有依据的判断,非实测)

- **整体气质定性**:古典人文与 AI 新生命并置的策展式美学(美术馆墙面的暖灰白、展签式衬线、等宽体图注、古典名作、书法花体)。名作确为文艺复兴与巴洛克时期公共艺术品,这是事实;但把整套语气概括为「新文艺复兴」是美学判断,记为推断。
- **DNA 绳的绘制细节**:确定它跑在那个 `<canvas>` 上、由 JS 驱动(CSS 无 3D、无对应 keyframe,均实锤);但每个字母是画布绘制的字形还是被 JS 改写 `transform` 的 DOM 节点、引导线画在何处、自转周期多长,JS 未取样,记为推断。
- **`--hand`(Italianno)的页面落点**:变量已定义、字体已加载(实锤),但抓到的首屏与站点 CSS 未见明显用处;其具体装饰位置为推断。
- **`_brandBounce` 挂在哪个元素**:CSS 绑定实锤,落点(疑为首屏底部的橙色下行滚动提示)为推断。
- **营销层与产品层的分工**:落地页定调、产品在外链/内页(`Cyra`、`Cytopia` 带外链箭头),为结构推断。
- **技术栈**:未检出任何知名库(`libs`/`scriptHints` 为空,实锤);类名带 `_1v68c_`、`_1ygrg_` 一类哈希后缀,像 CSS Modules 构建产物,记为推断,不据此断言具体框架。

## 4. 局限(哪些没拿到、为什么)

- **抓取以首屏为主**。截图与滚动关键帧集中在 hero,那条 DNA 字母绳看得很清楚;但**下方成段的古典名作叙事区没有被完整渲染留证**——它们目前主要靠 `manifest.json` 的图片清单与 `index.html` 的 `alt` 文案、小标题原文来还原(文本是实锤,版面与动效呈现未逐屏截图)。滚动揭示需逐屏触发 IntersectionObserver,未完整跑到底。
- **JS 行为未取样**。DNA 绳的画布绘制逻辑、自转周期、鼠标交互(若有)都在未抓取的脚本里,只能从 CSS/HTML 反推机制,不能给出其确切参数。
- **计算样式只覆盖被探针点到的元素**(body、h1、nav、btn)。H1 计算值与首页标题源码类在字距、字号上对不齐(见 `事实核查.md`),说明探针测到的 H1 未必是应用了该 clamp/负字距规则的同一实例;本拆解以计算值为准并如实标注差异。
- **`tokens.json` 的挖掘统计有已知失真**。其 `durations` 段把带小数点的亚秒值抹成了整数秒(例如把 `.16s` 记成 `16s`),`fontFamily` 段把 Google 子集 `@font-face` 声明数当成用量(`Noto Serif SC` 404 次)。这些已在 `事实核查.md` 逐条纠正,本拆解正文一律以站点样式表原文为准。
- **技术栈无定论**。未检出已知动画/UI 库,构建工具从类名哈希只能推断,不下结论。
- **受版权素材仅内部比对**。古典名作图与站点字体、页面原文仅用于本地拆解核对,仓库须私有。

> 逐值对照与漂移订正见 `事实核查.md`;精度与完成度评审见 `设计评审.md`。
