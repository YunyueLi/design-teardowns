# Latrix 复刻指南 —— 可直接接进产品的 token 与代码

> 下面的 `:root`、缓动、时长、圆角全部用**实测值**(来源见 `出处与方法.md`,逐条核对见 `事实核查.md`)。签名效果(捻成 DNA 的 `LATRIX` 字母绳)给两份实现:一份纯 CSS 3D、逐行 `rotateY` 慢转,门槛最低;一份用少量 JS 逐帧驱动、更贴近原站画布螺旋的手感。**要诚实:原站这条绳是画布 2D + JS 绘制的(容器类名 `_homeDnaBackdrop`,实锤),下面的 CSS 3D 是对它的近似,不是逐像素还原。**

## 2.0 签名效果一:纯 CSS 3D 的 DNA 字母绳(门槛最低)

思路:一列重复的 `LATRIX` 字母,套一层 `perspective`,每个字母按行号绕竖轴 `rotateY` 递增,再让整条绳用招牌缓动缓慢自转;字母之间用一条极细伪元素线做「引导线」。

```css
.dna{--n:60; --step:24deg; perspective:900px; width:min(45vw,340px); margin-inline:auto;}
.dna__col{transform-style:preserve-3d; animation:dnaSpin 18s linear infinite;}
/* 18s 为复刻自拟的氛围周期(原站周期在 JS 里,未取样)*/

.dna__ch{
  display:block; text-align:center;
  font-family:var(--sans); font-weight:700; text-transform:uppercase;
  color:var(--accent);
  transform-style:preserve-3d;
  transform:rotateY(calc(var(--i) * var(--step)));
  opacity:.55;
  position:relative;
}
/* 引导线:牵住相邻字母的极细斜线 */
.dna__ch::after{
  content:""; position:absolute; left:50%; top:100%;
  width:1px; height:14px; background:var(--accent-30);
  transform-origin:top center;
  transform:translateX(-50%) rotate(8deg);
}
@keyframes dnaSpin{to{transform:rotateY(360deg);}}

@media (prefers-reduced-motion:reduce){
  .dna__col{animation:none;}   /* 尊重减弱动效:静止成一条定格螺旋 */
}
```

配一小段生成字母与行号变量的脚本:

```js
function buildDNA(host, rows = 60, word = "LATRIX"){
  const col = document.createElement("div");
  col.className = "dna__col";
  for (let i = 0; i < rows; i++){
    const ch = document.createElement("span");
    ch.className = "dna__ch";
    ch.textContent = word[i % word.length];   // L A T R I X 循环
    ch.style.setProperty("--i", i);            // 行号 i 决定每行 rotateY 递增
    col.appendChild(ch);
  }
  host.appendChild(col);
}
```

这一版无需画布,靠 `rotateY` 的逐行递增就能读出「捻动的螺旋」,且天然响应 `prefers-reduced-motion`。局限:它是绕整轴匀速转,和原站画布里那种带透视收束、两股分合的手感不完全一致。

## 3.0 签名效果二:JS 逐帧驱动,更贴近原站画布手感

要更像原站(绳会收成窄柱、又摊成两股,字母沿正弦横向摆动、引导线随之伸缩),用一段 `requestAnimationFrame` 逐帧算每个字母的横向位移与明暗最省心。可绘制在 DOM,也可绘制在 `<canvas>`(原站即画布,`2160×1080` 背衬、`1440×720` 显示、约 1.5 倍像素密度,实锤)。核心思路:

```js
// 每个字母:纵向等距堆叠;横向 = 振幅 * sin(相位);明暗随 sin 起伏 —— 合成「捻绳」
function frame(t){
  const cycle = 18000;                 // 复刻自拟周期(ms);原站周期在其 JS 内,未取样
  chars.forEach((el, i) => {
    const phase = (t / cycle) * Math.PI * 2 + i * 0.5; // 逐行相位差形成螺旋
    const x = Math.sin(phase) * amp;                   // 横向摆动
    const depth = (Math.cos(phase) + 1) / 2;           // 0..1,近大远小
    el.style.transform = `translateX(${x}px) scale(${0.9 + depth * 0.2})`;
    el.style.opacity = 0.35 + depth * 0.5;             // 正看亮、侧看淡
  });
  requestAnimationFrame(frame);
}
```

工程上:相邻字母之间再画一条随 `x` 差值倾斜的发丝线(用 `--accent-30` 描边)即可还原「引导线」。控制字母在数十量级、标签页隐藏时 `requestAnimationFrame` 自动暂停、并为 `prefers-reduced-motion` 提供一版静态定格,性能无虞。

## 5.0 选型决策

- **展示用 Playfair Display,图注用 Space Mono**。高对比衬线负责「展签 / 杂志跨页」的优雅,常规字重(400)+ 0.92 行高是关键,别加粗别紧排;等宽体负责全大写、开字距的冷静图注与标签,连正文小字也交给它,做出「说明书感」。两者反差正是它的气质来源。
- **主 CTA 直角、导航药丸,是刻意对撞**。最重的行动点 `START FREE TRIAL` 用 `border-radius:0`(实锤),导航与 `Try Cyra` 用 `999px` 全圆(实锤)。一硬一软,别为了「统一」把 CTA 也改圆。
- **橙只点睛,别铺开**。`--warm #ff8c00` 只落在标语、主 CTA、活动态导航、页脚记号;悬停才加深到 `#e07a00`。其余全交给墨色的透明度阶梯(`--accent-90` 到 `--accent-10`)分级。
- **DNA 绳优先纯 CSS 3D**。静态或规律的螺旋用 2.0 的逐行 `rotateY` 最省;要贴合原站画布那种分合手感,再上 3.0 的 rAF 版。无论哪版,都给 `prefers-reduced-motion` 一版静态定格。
- **全大写走 `text-transform`,不硬写**。语义与可读性保留句首大写,视觉才取大写(实锤做法)。

## 6.0 工程坑

- **四支字体都靠 Google Fonts,首屏要防跳字**。用 `<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>` 预连接,`@font-face` 带 `font-display:swap`,并在 JS 里用 `await document.fonts.ready` 再启动 DNA 绳的绘制,避免字母绳在字体到位前用回落字形闪一下。
- **CJK 衬线子集很重,别整支拉**。Google 的 `css2.css` 把 `Noto Serif SC` 拆成了 404 条 `unicode-range` 子集 `@font-face`(实锤),整支体量巨大。只在真出现中文时按需触发对应子集,别在首屏无脑请求全部;纯拉丁内容甚至可以不加载 Noto。
- **暖灰白不是纯白**。底色是 `#f1f1f3`(暖灰白)、展板是 `#e8dfd3`(更暖),别用 `#fff`;白色只留给导航胶囊那类需要「浮起来」的面。纯白会立刻失掉那层美术馆墙面的暖调。
- **两支橙别混**。`#ff8c00` 是常态,`#e07a00` 只用于 `:hover`/`:active`。把静止态直接用成深橙,会丢掉悬停的反馈层次。
- **DNA 绳务必尊重 `prefers-reduced-motion`**。原站有两处减弱动效规则(实锤),其一把全局动画压到 `.001ms`。复刻时给字母绳一版**静态定格螺旋**,别让它在「减弱动效」下仍无限旋转。
- **画布记得按像素密度放大**。若走 3.0 的画布版,像原站那样用约 1.5 到 2 倍的背衬分辨率(原站 `2160×1080` 背衬对 `1440×720` 显示,实锤),否则字母边缘发虚。画布容器加 `aria-hidden="true"`(实锤做法),纯装饰不进读屏。
- **周期是复刻自拟值**。DNA 绳的自转周期(上面用了 `18s`)原站在 JS 里、未取样,属**推断**;CSS 层能确认的长循环只有 `_brandBounce` 的 `2.4s`(实锤)。别把 `18s` 当成实测值对外宣称。
