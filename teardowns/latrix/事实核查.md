## 3. 本轮发现的漂移与订正

### D1(实质漂移)· 亚秒时长被误记成整数秒 —— 「秒级氛围慢层」不存在

- **失真源**:`tokens.json.durations` 列出 `2s(6)`、`16s(6)`、`22s(2)`、`4s(2)`、`76s(1)`、`42s(1)`、`2.4s(1)`、`1.008s(1)`、`001ms(2)`,像有一层 16 到 76 秒的电影级氛围慢层。
- **复核证据**:对站点 `41a207_index-qQLVfn_2.css` 原文精确统计——以「非小数点、非数字」为前缀的整数秒时长**只有 `0s`(2 次)**;而带小数点的 `.16s(11)`、`.22s(6)`、`.76s(1)`、`.42s(1)`、`.2s(7)`、`.4s(5)` 均存在。也就是说 `tokens.json` 的挖掘**抹掉了前导小数点**,把 `.16s` 记成了 `16s`。这是方法论里点名的「把 `.15s` 误读成 `15s`」同类错误,只是规模更大。
- **订正**:本目录文档一律以站点 CSS 原文为准,时长梯写作亚秒级;并明确 Latrix **没有秒级以上的 CSS 氛围慢层**,唯一无限循环 CSS 动画是 `_brandBounce 2.4s`;那条长时运转的 DNA 绳由 JS 驱动画布,周期不在 CSS 里,复刻用的 `18s` 为自拟值(推断),不对外当实测。

### D2 · `001ms` 是减弱动效覆盖值,非真实时长档

`tokens.json` 的 `001ms(2)` 来自 `@media (prefers-reduced-motion:reduce)` 里把全局 `transition-duration`/`animation-duration` 压到 `.001ms` 的覆盖(同样被抹了小数点)。已在文档中作为无障碍处理说明,而非当成一档正常时长。

### D3 · `Noto Serif SC` 404 次是子集声明数,不是站点用量;`cssBytes` 是两表之和

- `tokens.json.fontFamily` 里 `'Noto Serif SC'` 计到 **404**,并非站点用了 404 次。复核 `1d5ec7_css2.css`:`@font-face` 共 455 条,其中 Noto Serif SC 404 条、Playfair Display 36 条、Space Mono 12 条、Italianno 3 条——即 Google 把 CJK 衬线拆成了 404 条 `unicode-range` 子集声明。站点真正的显示字体是 Playfair Display(`var(--serif)/var(--display)`),Noto 只是 CJK 回落。
- `tokens.json.cssBytes 535768` 约等于站点 CSS(`61431`)+ Google Fonts CSS(`474335`)之和,主要体量来自 Noto 的子集声明。文档已据此说明,不把 404 当成「站点最常用字体」。

### D4 · `--accent` 变量名与其功能不符(命名怪癖,已如实点破)

站点把近黑墨色 `#1a1815` 命名为 `--accent`(强调),但它承担的是**正文墨色**;真正的强调色是 `--warm #ff8c00`。文档按角色理解,并明确提醒复刻者别被变量名带偏。

### D5 · 两支橙不可合并

`#ff8c00`(常态,`--warm`)与 `#e07a00`(仅 `:hover`)功能不同。topHex 里深橙计到 2 次、常态橙 1 次只是统计口径的偶然,不代表深橙更「主」。文档全程分开。

### D6 · 签名母题是画布 2D + JS,不是 CSS 3D

任务简介把这条绳描述为「3D 捻转的字母绳」,复刻时也用了 CSS 3D 逐行 `rotateY`。核对后:站点 CSS **无任何 3D 变换**,这条绳跑在唯一的 `<canvas>` 上(容器类名 `_homeDnaBackdrop`,实锤),由 JS 逐帧驱动。文档已把 CSS 3D 明确标为**对原站画布螺旋的近似**,非逐像素还原。

## 4.「实锤 vs 推断」标注复核

- **实锤**(计算样式或源码原文可证):全部色值与阶梯、四支字体及分工、H1 计算度量、招牌缓动、亚秒时长梯、三条关键帧、圆角、主 CTA `0px`、媒体计数、`<canvas>` 尺寸与容器类名、无 3D 变换(缺席认定)、两处减弱动效、单主题、全部文案与资产清单。
- **推断**(有依据的判断,已明确标注):「新文艺复兴 / 数字人文」美学定性、DNA 绳的画布绘制细节与自转周期、`--hand`(Italianno)页面落点、`_brandBounce` 挂载元素、营销层与产品层分工、构建工具/技术栈。
- 唯二会被误当实锤的坑——`tokens.json` 的整数秒时长与 404 次 Noto——已在 D1、D3 下架改正。
