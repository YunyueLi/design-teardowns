# Lovart 复刻指南

把 Lovart 的「克制优雅 + 设计工作台叙事」接进你的产品。下面的 token 全部是真实抽取值（见 `design-tokens.css` 与 `../_data/lovart.json`），代码片段复现它的签名效果。本指南代码段推荐用开源字体作合法替身、商业原字需自购；拆解页 `teardown.html` 另内嵌了站点真实字体，仅限内部比对。

## 2. 签名效果一：填空式衬线标题

关键词坐在下划线上、逐字浮现再循环。纯 CSS 下划线 + 一小段 JS 打字机。

```html
<h1 class="fill">Design a <span class="blank" id="b1"></span><br>for a <span class="blank" id="b2"></span></h1>
```
```css
.fill{font-family:var(--serif);font-weight:400;letter-spacing:.01em}
.blank{border-bottom:2px solid var(--ink);padding:0 .12em;min-width:5ch;
       display:inline-block;text-align:center}
.blank::after{content:"";display:inline-block;width:1px;height:1em;
       background:var(--ink);margin-left:1px;animation:caret 1s step-end infinite}
@keyframes caret{50%{opacity:0}}
```
```js
const pairs=[["Promotional Video","Hiking Brand"],
             ["Campaign Poster","Eyewear Label"],
             ["Brand Identity","Coffee Roaster"]];
const b1=document.getElementById('b1'), b2=document.getElementById('b2');
let p=0;
async function type(el,txt){for(let i=0;i<=txt.length;i++){el.textContent=txt.slice(0,i);await wait(55)}}
async function erase(el){let t=el.textContent;for(let i=t.length;i>=0;i--){el.textContent=t.slice(0,i);await wait(28)}}
const wait=ms=>new Promise(r=>setTimeout(r,ms));
async function loop(){while(true){const[a,b]=pairs[p];await type(b1,a);await type(b2,b);
  await wait(1600);await erase(b2);await erase(b1);p=(p+1)%pairs.length;}}
if(!matchMedia('(prefers-reduced-motion:reduce)').matches) loop();
else{b1.textContent=pairs[0][0];b2.textContent=pairs[0][1];}
```

## 3. 签名效果二：智能体思考步骤逐条浮现 + 微光扫过

复现站点自带的 `agent-shimmer-sweep`：进行中的步骤有一道微光横扫，完成后打勾定格。步骤逐条淡入用最高频的 `easeOutCubic`。

```css
.step{display:flex;gap:10px;align-items:center;font-family:var(--sans);
      font-size:14px;color:var(--ink-2);opacity:0;transform:translateY(6px);
      transition:opacity var(--dur-in) var(--ease-main),transform var(--dur-in) var(--ease-main)}
.step.show{opacity:1;transform:none}
.step .ico{width:18px;height:18px;flex:none;border-radius:50%;
      border:1px solid var(--line-2);display:grid;place-items:center;color:var(--ink-3)}
.step.done .ico{background:var(--ink);color:var(--bg);border-color:var(--ink)}

/* 进行中：一道微光扫过文字 */
.step.active .txt{background:linear-gradient(100deg,
      var(--ink-3) 30%,var(--ink) 50%,var(--ink-3) 70%);
      background-size:200% 100%;-webkit-background-clip:text;background-clip:text;
      color:transparent;animation:agent-shimmer-sweep 1.2s var(--ease-std) infinite}
@keyframes agent-shimmer-sweep{from{background-position:200% 0}to{background-position:-200% 0}}
```
```js
const steps=[...document.querySelectorAll('.step')];
async function run(){
  for(const s of steps){
    s.classList.add('show','active');
    await wait(1100);                       // 微光扫过时长
    s.classList.remove('active');s.classList.add('done');
    await wait(300);
  }
  buildGrid();                              // 思考完毕 → 生成视觉网格
}
```

## 7. 选型决策表

| 元素 | 选型 | 理由 |
|---|---|---|
| 设计工作台、思考步骤、视觉网格 | 纯 DOM 加 CSS 加 img | 站点媒体清单 `canvas 0`，无 WebGL，前端直接做即可 |
| 关键氛围段 | 少量 video（站点仅 2 段） | 只在真正需要的地方用视频，其余靠 CSS |
| 图标 | 线性 SVG（站点 50 个） | 轻、可染色、随主题变 |
| 卡片高光与微倾 | 鼠标跟随 `--glare-*` 变量 | 用 CSS 变量记录指针位置，`background`/`transform` 消费 |
| 慢氛围（渐变流动、走马灯） | CSS `@keyframes` 加 `218s` / `5000s` 级超长时长 | 站点用超长时长纯 CSS 实现，不引库 |
| 微交互（悬停、按钮） | CSS `transition` 加 `0.15s`–`0.2s` | 配 `--ease-btn` 减速曲线，跟手 |
| 滚动条 | OverlayScrollbars 或原生 | 站点用 OverlayScrollbars 统一深色滚动条样式 |

## 8. 工程坑

- **单色是策略，不是偷懒**。落地页只用暖黑与纸白，彩色留给应用内。别急着加强调色。
- **显示字重压到 400 到 500，字距设正**。这是它优雅感的来源，套上粗体紧排就毁了。
- **纸白不是纯白，底不是纯黑**。用 `#F5F4EF` 与 `#100F09`（暖），比 `#fff` 与 `#000` 更耐看、更少眩光。
- **思考步骤的可信度来自「有始有终」**：进行中微光扫过，完成打勾，最后触发产出。缺了收尾，演示就像假的。
- **`prefers-reduced-motion` 必须兜底**：关掉打字机、微光、逐个弹入，直接显示终态文案与静态网格。
- **字体授权**：`featureDisplay`、`featureDeck`、`gtStandard`、`gtStandardMono` 均为商业字体，生产需自购。本指南代码段推荐 Fraunces、Inter、JetBrains Mono 作合法开源替身；`teardown.html` 为逐像素比对已内嵌站点真实字体的 woff2 子集，仅限内部研究、务必私有，不得随页面外发或用于生产。
