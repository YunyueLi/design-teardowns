# 出处与方法（Provenance）

## 抽取对象

线上站点 Lovart，`https://www.lovart.ai`，页面标题 `Lovart – World's First AI Design Agent | Create Pro Designs in Minutes`，语言 `en`。这是对**公开线上页面**的静态抽取，不涉及登录态、不逆向任何客户端安装包。

## 抽取链路

1. **playwright 计算样式**：用无头浏览器打开首页，读取 body、H1、nav、按钮等关键节点的 `getComputedStyle`，拿到最终生效的颜色、字体、字距、行高、圆角、过渡等真实值。这一层是「浏览器实际渲染成什么样」，最可信。
2. **服务端抓取样式表文本**：直接按 URL 拉取页面引用的 6 个样式表全文（合计约 1.03 MB），用文本解析统计其中出现的色值、`cubic-bezier`、`transition-duration`、`border-radius`、`@keyframes` 名、`font-family`、CSS 自定义变量及其出现频次。这一层不受 CORS 限制，能看到计算样式之外的完整 token 词表。
3. **字体清单**：读取 `document.fonts` 已加载的字体族名（`fontsLoaded`），以及 `<link rel="preload" as="font">` 的数量。
4. **媒体清单**：统计页面内 `video`、`canvas`、`svg`、`img` 元素数量。
5. **真实渲染截图**：首屏 `assets/actual-hero.jpg` 与整页 `assets/actual-full.jpg`，另有滚动过程关键帧 `keyframes/00–07.jpg`，作为「as-seen」证据图。

抽取产物汇总在 `../_data/lovart.json`，蒸馏后的 token 见同目录 `design-tokens.css`。

## 什么是实锤

以下来自上述抽取，属于**实锤**：

- **基底与文字**：body 底色 `rgb(16,15,9)`、文字 `rgb(245,244,239)`；按钮纸白填充加深墨黑文字、圆角 `999px`、过渡 `0.2s cubic-bezier(0,0,0.2,1)`。
- **品牌 accent 变量**：`--accent` 实测解析为 `lab(96.52% ~0 ~0)`（近白中性）。
- **H1 排版**：`featureDisplay`，`48px / font-weight 400 / letter-spacing 0.48px / line-height 52.8px`。
- **字体家族**：`poppins`、`barlowCondensed`、`inter`、`gtStandard`、`gtStandardMono`、`featureDeck`、`featureDisplay`，以及思源黑体、宋体的 SC、TC、JP。
- **8 条不重复的 cubic-bezier 及其频次**（去重跨全部样式表），最高频为 `cubic-bezier(0.33,1,0.68,1)`（字面 5 次）。
- **时长梯及频次**：`0.15s`（最高，46 次）、`0.1s`（34 次）、`0.2s`、`1s`，直到 `218s`、`5000s`（各 6 / 9 次）的超长值；样式表内并不存在独立的 `15s`（一轮把 `.15s` 误读为 `15s`，二轮已更正）。
- **圆角梯**：`0`、`10px`、`8px`、`4px`、`3px`、`16px`、`2px`、`18px`，按钮 `999px`。
- **keyframe 名单**：含 `agent-shimmer-sweep`、`gradient`、`spin`、`slide-down-fade`、`collapsible-down/up`、`swipe-out-*`。
- **技术栈信号**：`--mantine-*`（Mantine，React UI 框架）、`--os-*`（OverlayScrollbars）、`--glare-x/y` 与 `--edge-x/y`（自研鼠标跟随高光与微倾）。
- **Mantine 主题色板**：lovart-green、ocean-blue、bright-pink、lovart-black 各十阶的完整取值。
- **高频色值频次表**：`#fff`、`#3b82f6`、`#c1c5cc`、`#000`、`#141414`、`#100f09`、`#86909c`、`#2f3640`、`#f5f5f5`、`#147dff`、`#f6f5f1` 等。
- **媒体清单**：`video 2`、`canvas 0`、`svg 50`、`img 38`、`preloadFont 6`。
- **库检测**：`libs` 与 `scriptHints` 均为空，即未检出 GSAP、Lenis、Framer Motion 等已知库的全局签名。

## 什么是推断

以下来自截图观察或常识判断，属于**推断**，未经数据证实：

- **各条 cubic-bezier 与时长的具体用途**（例如「回弹用于卡片 pop」「218s / 5000s 用于渐变流动」）。抽取只给出取值与频次，不给绑定关系。
- **画布蓝 `#147DFF` 用作选框颜色**。色值与频次是实锤，把它对应到截图里的蓝色选框是观察推断。
- **填空式标题的循环打字行为、思考步骤的具体节奏**。母题与文案（`Analyzed user intent` 等）在截图里可见（as-seen 实锤），但精确的时序参数是复现时的推断。
- **显示字体一轮用替身属推断**（已被二轮取代）。站点族名 `featureDisplay`、`gtStandard`、`gtStandardMono` 是实锤；第二轮已把这三支真实字体的 woff2 子集内嵌进 `teardown.html`（见 `real-assets/manifest.json`），Fraunces、Inter、JetBrains Mono 降级为兜底。商业字体仅限内部研究，不得外发或用于生产。
- **落地页单色、应用内彩色的策略解读**。基于「落地页几乎不出现 Mantine 三色、而主题里注册了它们」这一事实做出的合理推断。

## 局限

- 抽取是**某一时刻的首页快照**。站点若做 A/B 或改版，数值可能变化。
- 计算样式只覆盖抽取脚本访问到的节点；未展开的交互态（悬停终态、弹层内部）未必完整。
- 未检出动画库不等于「一定没用」，只说明没命中已知全局签名；不排除以模块方式内联打包。
- 第二轮起，`teardown.html` 的视觉网格、实拍区视频与画廊均为从站点提取的真实媒体（见 `real-assets/manifest.json`），含版权素材，仅限内部逐像素比对、务必私有；一轮的 CSS 渐变占位已被替换。
