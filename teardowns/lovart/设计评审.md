# Lovart 拆解页 · 设计评审（第二轮）

以顶级设计的眼光，评审 `teardown.html` 相对原站 `lovart.ai` 的**精度**与**完成度**：哪些已经达标，哪些仍有差距，
并给出可执行的改进（能当场改的已改，标注清楚；其余给出做法与取舍）。

## 一、总评

这一轮把拆解页从「气质临摹」推进到「材质级还原」。最大的两处进步来自真素材回填：

1. **真字接入是决定性的一步。** 换上原站的 `featureDisplay` 后，大标题不再是 Fraunces 那种偏时装、对比更极端的味道，
   而是原站那种收敛、像书籍内文标题的调性；正文 `gtStandard`、标签 `gtStandardMono` 也回到原站的中性工业感。
   字重压到 400、字距微正的「铁律」现在是用**原字**在演示，说服力质变。
2. **真媒体裱进工作台，签名效果第一次“可信”。** 视觉网格从 CSS 渐变色块换成原站真实的眼镜影像战役产出，
   加上实拍区两段真实视频与一组产出画廊，「一个设计智能体正在产出可用成品」这个论点终于有了实物支撑，而不是占位。

配合这轮对缓动条数、时长、圆角的数值订正（见 `事实核查.md`），页面的**数据可信度**也同步提高。

## 二、已达标（与原站基本对齐）

- **色彩系统**：暖墨黑加纸白的单色叙事、`#147DFF` 画布蓝的功能点缀，色值与频次都对得上，克制感到位。
- **标题排版**：真字加 `.01em / 1.1` 的度量，与原站 H1 实测一致；斜体样张直接复用了原站「An Accessory That Speaks」的真实斜体。
- **动效语言**：主曲线 `cubic-bezier(.33,1,.68,1)`、回弹入场、按钮减速、`agent-shimmer-sweep` 微光，均为实锤复现；双时间尺度（微交互对超长氛围）表述已订正为真实的 `.15s` 与 `218s / 5000s`。
- **圆角语言**：小圆角（`3` 到 `20px`）与全圆 pill（`999px`）的对比，样例已按真实频次排布。
- **工艺论点**：零 canvas、纯 DOM 加 CSS 的复刻门槛判断准确，是这份拆解最有价值的洞察之一。
- **出处诚实**：实锤与推断分栏清楚，真字与真媒体的版权边界（仅限内部、务必私有）交代到位。

## 三、相对原站仍存在的差距

1. **中标题字型不完全等同。** 原站的 section 级标题实际用的是 `featureDeck`（Feature 家族的 deck 尺寸切),
   本轮未下载该字族，页面所有衬线标题统一由 `featureDisplay` 承担。Display 与 Deck 在中等字号的字怀、对比会略有差异，属可感知但不显眼的差距。
2. **竖构图裱进横向网格有裁切。** 真实战役图多为 `1792×2400` 竖幅，裱进工作台 4:3 网格必然裁切。已把裁切重心上移到 `50% 32%` 保住人物面部，但仍非原比例呈现。
3. **鼠标跟随高光只讲未演。** 原站 `--glare-x/y`、`--edge-x/y` 驱动的卡片高光与微倾是它「实体质感」的来源，页面目前只有文字描述，没有真实互动 demo。
4. **视频首帧有一瞬空白。** 两段 `<video>` 未配 `poster`，加载到首帧前会短暂黑屏；原站是流式贴合的。
5. **CJK 仍走思源兜底。** 三支真字都不含中文，中文标题回落 Noto。这一点其实与原站行为一致（原站 CJK 也用思源系），不算缺陷，但要清楚：页面里的中文并非原站商用字体渲染。

## 四、可执行改进

标注「已改」的本轮已落地；「建议」的给出做法与取舍，留给后续或主协调者在渲染核对后决定。

1. **【已改】缓动条数、时长、圆角三处数值订正。** 14 条改 8 条、最高频时长 `15s` 改 `0.15s`、氛围层改 `218s / 5000s`、圆角样例补 `3px`，详见 `事实核查.md`。
2. **【已改】真字优先字体栈 + 无 tofu 自检。** 六支真字全部 `@font-face` 接入，Latin 覆盖完整，CDN 与 Noto 分别兜底 Latin 与 CJK。
3. **【已改】真视频与真产出图裱入 + 网格裁切重心上移。** 工作台网格、实拍区视频与画廊换成真素材，人物面部保住。
4. **【建议】补下载并接入 `featureDeck`。** 让 section 级标题用 Deck、主标题用 Display，与原站的字型分工完全一致，是下一步性价比最高的精度提升。
5. **【建议】给两段视频加 `poster` 首帧。** 用 `ffmpeg` 抽第 1 秒帧存进 `real-assets/`，消除加载空白；成本很低。
6. **【建议】加一个真实的 glare / tilt 卡片 demo。** 用 `--glare-x/y` 记录指针位置、`background` 与 `transform` 消费，把原站的高光微倾从“描述”变成“可摸”，补齐互动维度的还原。

## 五、一句话结论

真字与真媒体到位后，这份拆解在**材质**与**数据**两条线上都逼近了原站；剩下的差距（Deck 中标题、glare 互动、视频 poster）都是清晰、低成本的收尾项，不影响它作为一份可复刻、可自证的高精度拆解的成立。
