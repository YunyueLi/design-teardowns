# Lovart 拆解页 · 事实核查（第二轮）

对 `teardown.html` 里出现的每一个数值（色值、字体、缓动、时长、圆角、keyframe、媒体统计）逐条核对真实抽取，
列出漂移并当场改正，并复核「实锤」与「推断」的标注。核对源为 `real-assets/source/` 下的 6 个真实样式表、
`real-assets/fonts/` 的 6 支字体，以及 `design-tokens.css`。频次均为对样式表全文的字面统计（去空白、大小写不敏感）。

## 一、结论摘要

- 第一轮的**色值、H1 排版、缓动曲线取值、keyframe 名单、媒体统计**全部经得起复核，无漂移。
- 发现并改正 **5 处数值漂移**，集中在「缓动条数」和「时长」两类；其中「最高频时长是 15s」是最实质的一处错误。
- 完成本轮的两项精度升级：把 6 支**真实字体**接进页面（替换开源替身），把**真实视频与真实产出图**裱进工作台与实拍区（替换 CSS 占位）。
- 真字读回自检：三支字体的 Latin 覆盖完整，**无 tofu**；中文交由 Noto 兜底，与原站一致。

### 2. 字体（本轮由替身升级为真字）

`real-assets/source/` 的字体样式表里，三支字族的 `@font-face` 与文件一一对应（实锤）：

### 3. 排版（实锤，已校准）

- H1 实测 `48px / font-weight 400 / letter-spacing 0.48px / line-height 52.8px`，换算为 `.01em / 1.1`，实锤。
- 校准：首屏 `h1.fill` 由 `.005em / 1.08` 改为 `.01em / 1.1`，字体样张 `.specimen` 行高由 `1.06` 改为 `1.1`，与实测对齐。

### 4. 缓动（改正一处条数漂移）

- **漂移 D1**：页面多处称「14 条 cubic-bezier」。对全部样式表去重统计，实为 **8 条**不重复曲线：
  `(.33,1,.68,1)`、`(.4,0,.2,1)`、`(.34,1.56,.64,1)`、`(.23,1,.32,1)`、`(.4,0,.6,1)`、`(.4,0,1,1)`、`(0,.5,.5,1)`、`(0,0,.2,1)`。
  已把标题描述、正文、`<meta>`、代码注释、出处「实锤」项里的「14 条」统一改为「8 条（去重）」。
- 页面展示的五条均在其中，取值全部实锤。主曲线 `(.33,1,.68,1)` 字面出现 5 次，是所有曲线里最多的，「最高频」的说法成立。
- **漂移 D4（次级）**：五条曲线的括号硬次数（原写 4 / 4 / 3 次）与字面 grep（2 / 3 / 2 次）不一致，疑因第一轮把 `var(--ease-*)` 的引用次数也计入。已删去这几处有争议的硬次数，只保留可复核的主曲线「5 次」。

### 5. 时长（改正最实质的一处漂移）

清洗后的时长频次（能正确区分 `.15s` 与 `15s`）：`.15s` 46、`.1s` 34、`.2s` 22、`.3s` 15、`.5s` 12、`1s` 10、`5000s` 9、`218s` 6。

- **漂移 D2**：页面称「最高频时长是 `15s`（出现 34 次）」。真相是样式表里**根本没有独立的 `15s`**（以词边界精确统计为 0 次），第一轮把 `.15s` 误读成了 `15s`。真正的最高频是 `0.15s`（46 次），是一个**微交互**时长，而非秒级氛围时长。已改正文案。
- **漂移 D3**：时长条形图与「工程坑」里把 `15s` 当作环境慢层。已换成真实存在的超长值 `218s`（6 次）与 `5000s`（9 次）；条形图的对数上界同步由 `218000` 改为 `5000000`。
- `218s` 与 `5000s` 均实锤存在，「秒级以上超长值用于氛围层」的推断保留，成立。

### 6. 圆角（补一处频次漂移）

`border-radius` 字面频次：`10px` 11、`3px` 9、`4px` 7、`8px` 7、`20px` 6、`16px` 4、`2px` 3、`18px` 3、`12px` 3、`24px` 3，按钮 `999px`。

- **漂移 D5**：第一轮的圆角样例缺了高频的 `3px`（第二高），却收了低频的 `2px`、`18px`。已把样例改为按频次的 `3 / 4 / 8 / 10 / 16 / 20 / 999`，并在文案标注「`10px` 最高、`3px` 次之」。
- 卡片、图片、工作台大窗所用的 `10px / 16px / 20px` 均为真实存在值，未改（此前担心的「16 / 20px 非真实」经复核不成立）。

### 7. keyframe 与技术信号（实锤，无漂移）

- Mantine 断点与色板变量、OverlayScrollbars 的 `--os-*`、库检测为空（未检出 GSAP / Lenis），均与第一轮一致。
