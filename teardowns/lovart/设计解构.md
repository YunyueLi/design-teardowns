# Lovart 设计解构

> 站点:Lovart，https://www.lovart.ai ，自称「全球首款 AI 设计智能体」。
> 除特别标注，下面每一个色值、字体、缓动曲线、时长、圆角都直接来自对线上站点的真实抽取（playwright 计算样式 + 服务端抓取样式表文本），记为**实锤**；凡从截图观察或公开资料得出的判断，记为**推断**，绝不把观察当数据。
> 抽取物见同目录 `../_data/lovart.json` 与 `design-tokens.css`；真实渲染截图见 `assets/actual-full.jpg` 与 `assets/actual-hero.jpg`。

---

## 1. 定位与设计意图

Lovart 把自己定位成一个「会做设计的智能体」，而不是又一个「文生图」工具。页面标题实锤为 `Lovart – World's First AI Design Agent | Create Pro Designs in Minutes`。它的整套视觉语言服务于一个论点：**AI 的产出只是起点，真正的价值在于像一个设计伙伴一样，把意图、参考、版式、文字一层层做进一个可继续编辑的成品里**。

这决定了它的基调不是炫技，而是克制优雅。相较于同类里走艺术叙事的站点，Lovart 收得更紧：

- **底色是暖墨黑加纸质纹理**，主文字与按钮是纸白，几乎不用鲜艳色。真实抽取显示品牌 `--accent` 变量解析为 `lab(96.52% ~0 ~0)`，也就是一个接近纯白的中性色——**它的「强调色」不是某个亮色，而是纸白本身**（实锤）。落地页刻意做成单色，把彩色留给应用内。
- **用衬线大标题承载优雅**，且以常规字重加微正字距排版（详见第 3 节），读起来像高级杂志的版面而非软件官网。
- **靠真实产品 mock 说话**，不靠形容词。首屏正下方就是一个深色的「设计工作台」演示，把智能体分析意图、检索参考、生成视觉网格的过程直接演给你看。

一句话概括要复刻的东西：**编辑部级的衬线优雅，乘以一整套「设计工具」的界面隐喻，再叠上把智能体工作过程可视化的叙事**。

## 2. 色彩系统（真实 token）

### 2.1 落地页主色（单色系，实锤）

| 名称 | 值 | 角色 | 来源 |
|---|---|---|---|
| 暖墨黑 | `rgb(16, 15, 9)` ≈ `#100F09` | 全站底色 | body 计算样式（实锤） |
| 纸白 | `rgb(245, 244, 239)` ≈ `#F5F4EF` | 主文字、按钮填充 | body 与按钮计算样式（实锤） |
| 品牌 accent | `lab(96.52% -0.00003 0.00001)` ≈ 近白中性 | `--accent` 变量实测，几乎等于纸白 | 变量实测（实锤） |
| 次级纸白 | `#F6F5F1` | 卡面、次级面 | 样式表高频色 top（实锤，出现 16 次） |
| 深板黑 | `#141414` | 深色面板 | 样式表高频色（实锤，25 次） |
| 更深黑 | `#0C0C0D` | 深层背景 | 样式表高频色（实锤，14 次） |

按钮的完整实测配方是纸白填充加深墨黑文字，圆角 `999px`，过渡 `0.2s cubic-bezier(0, 0, 0.2, 1)`（实锤）。

### 2.2 功能灰与画布蓝（实锤色值，用途为推断）

| 名称 | 值 | 用途 | 说明 |
|---|---|---|---|
| 画布蓝 | `#147DFF` | 设计工具选框、交互蓝 | 色值实锤（18 次）；用作选框颜色为推断 |
| 次蓝 | `#3B82F6` | 蓝色调 | 实锤（31 次） |
| 冷灰四阶 | `#C1C5CC` / `#86909C` / `#4A535F` / `#2F3640` | UI 次级文字与描边层次 | 实锤（高频色 top） |

### 2.3 应用内产品色板（Mantine 主题，落地页不用，实锤）

站点用 Mantine 搭建，主题里注册了三组彩色（`--mantine-color-*`），落地页几乎不出现，推断用于应用内界面：

- **lovart-green**：从 `#F4FFF0` 到 `#002E25` 十阶，主色约 `#57C74A`，亮色 `#85FF75`。
- **ocean-blue**：从 `#7AD1DD` 到 `#147885`，主色约 `#09ADC3`。
- **bright-pink**：从 `#F0BBDD` 到 `#AD1374`，主色约 `#FF00A1`。
- **lovart-black**：十阶全部是 `#000000`（有意压成纯黑档）。

### 2.4 关键结论

**落地页与应用内是两套色彩策略。** 落地页故意做成暖墨黑加纸白的单色叙事，把「克制优雅」推到底；应用内才放出绿、蓝、粉的三色系统。要复刻它「高级」的观感，重点不是找一个漂亮的强调色，而是**敢于只用一对暖黑与纸白**。

## 3. 字体系统

站点真实加载了一整个字体家族（`fontsLoaded` 实锤）：`poppins`、`barlowCondensed`、`inter`、`gtStandard`、`gtStandardMono`、`featureDeck`、`featureDisplay`，以及思源系（`notoSans/Serif` 的 SC、TC、JP）。角色分工如下。

> 第二轮：`teardown.html` 已内嵌站点真实字体的 woff2 子集（见 `real-assets/manifest.json`），下表「本页所用」即真字优先、CDN 兜底。

| 角色 | 站点字体（实测名） | 本页所用（真字优先） | 说明 |
|---|---|---|---|
| 显示大标题 | `featureDisplay` / `featureDeck` | 真实 `featureDisplay`（Fraunces 兜底） | 高对比编辑体衬线，承载优雅气质；`featureDeck` 本轮未下载 |
| 正文与 UI | `gtStandard`（正文计算样式回落到 `inter`） | 真实 `gtStandard`（Inter 兜底） | 中性 grotesque，导航、按钮、正文 |
| 标签与数字 | `gtStandardMono` | 真实 `gtStandardMono`（JetBrains Mono 兜底） | 大写字距的眉标签、`Image 1440 x 800` 一类尺寸标注 |
| 备用显示 | `poppins`、`barlowCondensed` | 未用 | 已加载但落地页少见，推断用于特定组件 |
| 多语言 | 思源黑体 / 宋体 SC、TC、JP | Noto Sans / Serif SC | CJK 兜底 |

**最关键的一条实锤**：H1 计算样式为 `featureDisplay`，`font-size: 48px`，`font-weight: 400`，`letter-spacing: 0.48px`，`line-height: 52.8px`（即 1.1 倍行高）。

也就是说，它的衬线大标题用的是**常规字重加微微张开的正字距**，而不是常见的「粗体加紧排」。这一反直觉的排版选择，正是它读起来克制、优雅、像书籍内文标题的技术根源。复刻时务必把显示字重压到 400 到 500，字距设为接近零或略正，切忌套用一般落地页那种 `-0.03em` 的紧排粗标题。

标题还有一个观察级母题（推断）：**关键词加下划线的「填空句」**，例如 `Design a ` 下划线上依次浮现 `Promotional Video`，再 `for a ` 下划线上浮现 `Hiking Brand`，像在一张表单上一格格填空。

## 4. 动效系统

站点没有检出任何知名动画库（`libs` 与 `scriptHints` 均为空，实锤），动效由 CSS `@keyframes` 加 React 状态驱动。样式表去重后共 **8 条 cubic-bezier** 与一整套时长梯。

### 4.1 双时间尺度（实锤）

时长分布呈现明显的两层：

- **环境慢层**：`218s`、`5000s`（各 6 / 9 次）这类超长值，另有 `1s`、`2s`、`3s` 的中层。推断用于渐变缓慢流动、marquee 走马灯、背景氛围的无限循环。样式表内并不存在独立的 `15s`（一轮把 `.15s` 误读为 `15s`，二轮已更正）。
- **手感微交互**：`0.15s`（46 次，最高频）、`0.1s`（34 次）、`0.2s`、`0.3s`。按钮过渡实测就是 `0.2s`。

把很慢的氛围层叠在很快的微交互上，是这类高级站点的通用手法——氛围负责「呼吸感」，微交互负责「跟手」。

### 4.2 签名缓动（真实取值 top）

| 曲线 | 值 | 样式表频次 | 用途（推断） |
|---|---|---|---|
| 减速三次 easeOutCubic | `cubic-bezier(0.33, 1, 0.68, 1)` | 5 | 位移与淡入的主曲线 |
| Material 标准 | `cubic-bezier(0.4, 0, 0.2, 1)` | 4 | 通用进出过渡 |
| 回弹 back | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 4 | 弹入、卡片 pop |
| 减速五次 easeOutQuint | `cubic-bezier(0.23, 1, 0.32, 1)` | 3 | 长尾滑入 |
| 纯减速 decelerate | `cubic-bezier(0, 0, 0.2, 1)` | 2 | 按钮 `0.2s`（实测按钮过渡就是它） |

### 4.3 关键 keyframe（实锤命名）

抽取到的 `@keyframes` 名单里，有几条直接点出了它的签名动效：

- **`agent-shimmer-sweep`**：一道微光扫过。结合截图里智能体思考步骤的呈现，推断这是**思考步骤在「进行中」时的微光扫动**——是站点自带的命名，不是臆造。
- **`gradient`**：渐变流动，配合 `218s` / `5000s` 慢层。
- **`spin`**：加载旋转。
- **`slide-down-fade`**、**`collapsible-down/up`**、**`swipe-out-left/right/up/down`**：下拉淡入、折叠、卡片四向滑出，都是产品级交互的动画。

### 4.4 鼠标跟随高光（实锤，工艺细节）

自定义属性里有 `--glare-x`、`--glare-y`、`--edge-x`、`--edge-y`（实锤）。这是一套**鼠标跟随的高光与微倾（glare / tilt）**参数：卡片会根据指针位置渲染一道移动的高光并做轻微 3D 倾斜。这解释了它的卡片为什么有「实体质感」。

## 5. Hero 手法

首屏是一个居中构图，自上而下的节奏是：

1. **mono 眉标签**：全大写、开字距，`YOUR AI DESIGN PARTNER`。
2. **衬线大标题**：`Design a ___ for a ___`，关键词落在下划线上、逐字浮现（填空式，推断为循环打字）。
3. **纸白 pill 主按钮**：`Design now`，全圆角、纸白填充、深字。
4. **深色设计工作台 mock**：裱在一张纸质纹理的水彩蓝底上，是整个首屏的重心。

工作台 mock 本身就是产品界面的缩影：

- **左侧画布**：左上角一个带项目名的小标题（`Hiking Brand Campaign Video`），画布里生成的**视觉网格**，每张图带 `Image  1440 x 800` 一类的尺寸角标，选中的图上有**蓝色选框加四角手柄**。
- **右侧对话面板**：`New Chat`，一个深色 prompt 气泡装着用户请求，下面是**智能体思考步骤逐条浮现**（`Analyzed user intent`、`Searching for high-quality references`，均为截图实锤文案），底部是输入栏 `What shall we design together?` 加一个圆形发送按钮。

手法要点：**不吹产品，直接把「一个设计智能体正在工作」演示出来**。首屏没有一句功能罗列，全靠这个会动的工作台建立可信度。

## 6. 签名视觉母题

1. **设计工具隐喻**：画板（artboard）、`Image 宽 x 高` 角标、蓝色选框与四角手柄、prompt 气泡、来源徽标（截图可见 Google、Pinterest、Behance、Dribbble 的小圆标）。**落地页本身被做成一块设计工具的画布**，浏览页面就像在看别人操作软件。
2. **智能体思考可视化**：思考步骤逐条淡入（已分析用户意图、已探索视觉趋势、已收集参考资料），进行中的步骤带 `agent-shimmer-sweep` 微光扫过，完成后定格。这是本站最值得借鉴、也最适合用来展示「仿真运行过程」的母题。
3. **拼贴与剪贴簿**：旋转粘贴的照片卡、便利贴、漂浮的抠图物（一顶绿色毛线帽、一本书），带手作的错落感与投影，冲淡纯数字界面的冷感。
4. **填空式衬线标题**：把大标题做成一张待填的表单，关键词坐在下划线上循环变换。
5. **纸质水彩底**：暖墨黑叠纸纹理，局部一块淡淡的水彩蓝，配合大留白，section 之间明暗与疏密交替。
6. **实拍级真实产出**：产出占位用的是运动、编辑摄影风格的**真实感图片**，而不是矢量插画——强调「产出可用」。

## 7. 工艺细节

- **圆角语言**：卡片与图片多为 `8px` 到 `18px`（实测 top 有 `10px`、`8px`、`16px`、`18px`、`4px`、`3px`、`2px`），按钮一律 `999px` 全圆 pill。小圆角的理性与全圆 pill 的亲和形成对比。
- **浮动 pill 导航**：顶部是一条悬浮的胶囊形导航条，logo 居左、主链接居中、`Get started` pill 居右（截图实锤）。注意 nav 元素本身计算样式是透明底、无 `backdrop-filter`（实锤），胶囊的底色与模糊做在内层容器上。
- **发丝线描边**：分隔与卡片边框用纸白的低透明度（如 8% 到 16%）细线，几乎不可见但足以界定层次。
- **版式栅格**：三种版式交替——居中大标题、左文右图、拼贴散点。
- **媒体选型（实锤，最有信息量的一条）**：`canvas 0`、`video 2`、`img 38`、`svg 50`。**全站没有一个 canvas**，也就是说「设计工作台、思考步骤、视觉网格」这些签名效果**全部由 DOM 加 CSS 加图片实现，没有 WebGL**。这把复刻门槛压得很低。SVG 多达 50 个，是图标；视频只有 2 段，用于关键氛围。
- **技术栈（实锤，来自自定义属性）**：Mantine（React UI 框架，`--mantine-*`）、OverlayScrollbars（自定义滚动条，`--os-*`）、自研 glare/tilt 高光（`--glare-*`、`--edge-*`）。未检出 GSAP、Lenis、Framer Motion 等动画库。
- **主题与多语言**：footer 有 Auto、深色、浅色三档主题切换与语言切换（截图实锤），说明站点支持明暗主题与国际化。

## 8. 关键发现

1. **「强调色」是纸白，不是某个亮色。** `--accent` 实测为近白中性（`lab(96.52%)`）。落地页刻意单色，彩色（Mantine 三色）全留给应用内。要复刻它的高级感，关键是敢只用一对暖黑与纸白。
2. **衬线大标题用常规字重加微正字距。** H1 实测 `48px / 400 / +0.48px / 1.1`。这与一般落地页的「粗体紧排」相反，是它读起来优雅克制的根因。
3. **零 canvas，签名效果全是 DOM 加 CSS。** 媒体清单证明工作台与思考步骤没有用 WebGL，纯前端就能高保真复刻。
4. **`agent-shimmer-sweep` 是命名级实锤。** 思考步骤的微光扫动是站点自带 keyframe，本解构据此复现，而非凭空设计。
5. **双时间尺度用纯 CSS 实现。** `218s`、`5000s` 的环境慢层叠 `0.1s` 到 `0.2s` 的微交互，思路与更「电影感」的站点一致，但这里只用 CSS keyframe，不引任何库。
