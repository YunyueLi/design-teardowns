# 对抗性审查 · 设计评审

以设计总监视角，评审这份拆解页相对原站 `gemini.google` 的精度与完成度，分 MUST-FIX 与 POLISH。以下均已在 `teardown.html` 落地。

## 相对原站：已达标 vs 仍有差距

**已达标**：暖白底 `#fdfcfc`、单支品牌蓝 `#0b57d0`、浅蓝容器、满圆角药丸输入框、被主缓动 `cubic-bezier(.2,0,0,1)` 统治的运动语言；四色 spark 现为真实站点资源；默认光晕的浅蓝主调与整页留白布局与截图基本一致。

**仍有差距**：没有真实字体，Roboto Flex 只是气质替身，字宽与字形与 Google Sans 有可感差异，标题处尤其明显；签名光晕的半径、位置、透明度是 CSS 近似而非逐帧还原；缺完整营销页，无法拆多屏动线。

## MUST-FIX（已修）

1. **品牌 spark 用错了渐变**。原为紫到青加珊瑚，是全页最刺眼的失真——它直接决定品牌辨识度。已改为真实的 Google 四色极光（红黄绿蓝），并用真实 spark PNG 替换手绘 SVG，色值采样自真实资产并经截图交叉核对。
2. **字体局限没有在页内讲清**。真实资产未含字体文件，若继续只写「Roboto Flex 替身」会让读者误以为已尽力逼近真字体。已在四处如实说明：真实字体未能提取、替身仅作近似、唯一真实字形只见于字标位图。不硬造、不含糊。
3. **页面出现了站点没有的紫色顶光**。固定顶部柔光里有一处紫色径向，站点并无。已改为真实蓝，全页不再出现原站不存在的颜色。

## POLISH（已采纳）

1. **默认光晕放大并居中**（主光团 `60% × 74%`、上移居中），更贴近截图里那团宽而柔、居中偏下的浅蓝 bloom。
2. **「品牌多色」控件更名「四色极光」**，与真实品牌一致，避免「多色」这种含糊说法误导读者。
3. **欢迎语字重 500 改 400**，贴近截图的规整感；并在事实核查里标注此为推断、非实测。
4. **色板 spark 四格换成真实红黄绿蓝**，并把出处从「avatar v2」改成「真实资产采样」；可复制 token 块里的 `--spark` 同步为四色。

## 未阻断的判断与诚实说明

- **Roboto Flex 不等于 Google Sans**：字形与字宽存在可感差异，标题处最明显。这是资产客观局限，不是设计选择，已在页内标明，不构成误导。
- **光晕运动属推断复现**：采样帧字节一致（单屏静止），观感接近但非站点逐帧比对；页面已把「缓慢流动」标为推断。
- **下一轮若能拿到登录后或营销态**：优先补真实字体文件、抓多屏营销动线、对签名光晕做逐帧核对，进一步收窄与原站的差距。

整体：二轮把最刺眼的品牌 spark 失真修正为真实四色极光并接入真实资产，精度明显提升；字体因客观限制仍为替身，但已如实交代。达到可发布水准，不像 AI 套模板——真实 token、真实资产、与抽取数值绑定的交互俱在。
