# 对抗性审查 · 事实核查

第二轮：接入真实资产后，逐条把拆解页里出现的数值与真实抽取（`_data/gemini.json`、`design-tokens.css`、`real-assets/`）比对。

## 结论

页面里的色值、缓动、时长、圆角、字体清单、媒体数量、CSS 字节数与 keyframe 名，经复核**全部可溯源到真实抽取**。本轮发现并改正了一处被误标为实锤的品牌 spark 渐变，另修正一处缓动计数与两处观感设定。**最重要的局限如实记录在案：本轮真实资产未包含任何字体文件，真实字体未能提取。**

## 已修正

1. **品牌 spark 色（本轮最关键的一处改正）**。第一轮把 spark 标成紫到蓝到青加珊瑚，并冠以「实锤·头像 v2」。复核发现这四个色值既不在 `topHex`，样式表里也找不到对应停靠点，且与真实站点资源不符——它更像早期某个头像资产的调色，不是现行品牌标记。真实资产 `gemini_sparkle_4g_512.png`、`gemini_sparkle_aurora.svg` 与字标锁定图一致显示：现行 spark 是 **Google 四色极光**——上尖红 `#f94442`、左尖黄 `#f9bd13`、下尖绿 `#0cba63`、右尖蓝 `#3186ff`（蓝为主导）。已全站改正（顶栏与复刻舞台的 spark、色板四格、可复制 token 块、色彩与签名文案），并把真实 spark PNG 直接内嵌替换手绘 SVG。校验双路交叉：PNG 逐点采样 + 站点截图取色一致；`#3186ff` 与真实 SVG 的 `radial-gradient` 蓝色停靠点完全相同。
2. **减速缓动计数**。`cubic-bezier(0,0,.2,1)` 由「约 9 次」改为「约 13 次」（三种写法 7+4+2）。
3. **页面固定顶光的紫色径向**。原 `rgba(145,104,192,.10)`（站点并无此紫）改为真实蓝 `rgba(49,134,255,.08)`，去掉了站点不存在的颜色。
4. **可见欢迎语字重**。由 500 改为 400，更贴近截图；该字重非 token 实测（唯一实测的 h1 700 是隐藏的无障碍标题），页内按推断处理。

## 需知的溯源细节与局限

- **真实字体本轮未能提取（重点）**。`real-assets/manifest.json` 的 `fonts` 为空数组：抓取落在登录态／受限页，`document.fonts` 只能报出字族名（Google Sans 家族），拿不到字体二进制；Google Sans 本身也是专有、未公开发行。因此正文与标题**继续用 CDN Roboto Flex 作替身**（等宽用 Roboto Mono），只求字形气质接近，不是真字体。这一局限已在页内四处如实标明：字体节导语、字标锁定图说明、出处节「局限」卡、页脚。全页唯一能看到真实 Google Sans 字形的地方是字标锁定图，但它是位图，不是可用字体文件。
- **完整营销页仍未获取**。只有入口态单屏，无多屏滚动叙事，页面据此未做任何「营销层动线」判断。
- `#1a73e8`（表单激活蓝）未在 `topHex` 独立出现，属据 Google 交互蓝的推断；色板以「form-active」标注而非出现次数，未冒充实锤。
- 页面自身卡片圆角用 `--r-md:16px`，那是本拆解页的 chrome，不是 Gemini 的 token；面向复制的 token 块里用的是真实的 `8px`，两者未混淆。
- 各色值出现次数为第一轮抽取所得，本轮与 `_data/gemini.json` 复核一致，未重新爬站。
