# 复刻指南：把 Gemini 的柔光对话入口接进你的产品

配套文件是同目录的 `design-tokens.css`（复制即用，含真实抽取的 token）。本文只给「够用且忠实」的最小实现，签名效果用纯 CSS，无任何依赖。

## 2. 签名效果之一：缓慢流动的多色柔光（纯 CSS）

思路是叠三四个低透明度的径向渐变，各自用不同的超长时长缓慢漂移与缩放，色相取浅蓝主调，掺入品牌紫、青与一点珊瑚粉。用真实主缓动 `--ease-emph` 与环境层时长。

```css
.glow-stage{position:relative;background:var(--bg);overflow:hidden;isolation:isolate}
.glow-stage::before,
.glow-stage::after{content:"";position:absolute;inset:-20%;z-index:0;pointer-events:none;
  filter:blur(20px);will-change:transform,opacity}

/* 主光团：浅蓝到品牌蓝，居中偏下缓慢呼吸 */
.glow-stage::before{
  background:
    radial-gradient(38% 32% at 50% 54%, rgba(168,199,250,.85), transparent 62%),
    radial-gradient(30% 26% at 62% 46%, rgba(86,132,209,.55), transparent 60%),
    radial-gradient(26% 24% at 40% 60%, rgba(194,231,255,.75), transparent 60%);
  animation:glow-drift 22s var(--ease-emph) infinite alternate}

/* 副光团：品牌紫与青、珊瑚粉，错相流动做出多色 */
.glow-stage::after{
  background:
    radial-gradient(24% 22% at 40% 44%, rgba(145,104,192,.34), transparent 62%),
    radial-gradient(22% 20% at 64% 62%, rgba(27,161,227,.30), transparent 60%),
    radial-gradient(18% 18% at 54% 40%, rgba(214,92,103,.20), transparent 60%);
  animation:glow-drift 16s var(--ease-emph) infinite alternate-reverse;
  mix-blend-mode:multiply;opacity:.9}

@keyframes glow-drift{
  from{transform:translate3d(-3%,-2%,0) scale(1)}
  to  {transform:translate3d(3%,4%,0)   scale(1.12)}}

@media (prefers-reduced-motion:reduce){
  .glow-stage::before,.glow-stage::after{animation:none}}
```

要更贴近实测的「以蓝为主」，就压低 `::after` 的紫粉透明度；要更贴品牌的多色气质，就调高。两端都在真实取色范围内。

## 4. 品牌四角星 spark（SVG + 动画渐变）

四角星的形状用两条相交的四点星，填色走品牌渐变停靠点。

```html
<svg class="spark" viewBox="0 0 24 24" width="28" height="28" aria-hidden="true">
  <defs>
    <linearGradient id="sparkGrad" x1="0" y1="0" x2="1" y2="1">
      <stop offset="0"  stop-color="#9168c0"/>
      <stop offset=".5" stop-color="#5684d1"/>
      <stop offset="1"  stop-color="#1ba1e3"/>
    </linearGradient>
  </defs>
  <path fill="url(#sparkGrad)"
    d="M12 2c.5 4.7 2.8 7 7.5 7.5C14.8 10 12.5 12.3 12 17c-.5-4.7-2.8-7-7.5-7.5C9.2 9 11.5 6.7 12 2Z"/>
</svg>
```

要让 spark 也「呼吸」，给渐变加缓慢的 `rotate` 或用 `animateGradient` 思路平移色标（对齐站点真实 keyframe 名 `animateGradient`）。

## 5. 选型决策表

| 元素 | 选型 | 理由 |
|---|---|---|
| 背景柔光 | 纯 CSS 多重径向渐变 + 长时长动画 | 站点无 video、无 canvas，纯 CSS 最省且忠实 |
| 对话输入框 | 单个圆角容器 + `focus-within` | 满圆角药丸是 Gemini 的核心手势 |
| spark 图标 | 内联 SVG + 线性渐变 | 5 个 SVG、3 个 img，图标是矢量 |
| 悬停与聚焦 | CSS transition，`.2s` 配 `--ease-emph` | 对齐实测微交互时长与主缓动 |
| 慢氛围流动 | CSS animation，`15s~25s` | 对齐实测环境层时长 |
| 字重与字宽 | Roboto Flex 可变轴 | 替 Google Sans Flex 的 `wght`／`wdth` 轴 |

## 6. 工程坑

- **暖白不是纯白**。底色用 `#fdfcfc`，比 `#ffffff` 更耐看、更少眩光；输入框才是纯白，靠这点差异「浮」起来。
- **字体是专有字体**。Google Sans 与 Google Sans Flex 不能直接用于生产，需授权；开发占位用 Roboto Flex 临摹几何无衬线的气质，并在交付时说明替换。
- **别被 computed 的 `Times` 带偏**。抓计算样式时 webfont 可能未生效而返回系统衬线，字体设计意图要以实际加载清单为准。
- **主缓动定全局**。把 `cubic-bezier(.2,0,0,1)` 设成默认过渡曲线，是抓住 Gemini 手感的关键一步。
- **尊重 `prefers-reduced-motion`**。柔光流动属于装饰动画，减少动态偏好开启时应停掉。
- **光晕要压在内容下层**。用 `z-index` 与 `isolation` 把渐变层压到输入框之下，避免糊住文字与可点区域。

## 7. 复刻清单

- [ ] 引入本目录 `design-tokens.css` 或上面的 `:root` 块
- [ ] 暖白底加近黑文字，品牌蓝只做主操作与链接
- [ ] 居中的满圆角对话输入框，聚焦轻微升起
- [ ] 背后多重径向柔光，浅蓝主调掺品牌紫青粉，缓慢流动
- [ ] 四角星 spark 用品牌渐变停靠点
- [ ] 全局主缓动设为 `cubic-bezier(.2,0,0,1)`，微交互 `.2s`、环境 `15s~25s`
- [ ] 字体用 Roboto Flex 替身并注明，等宽用 Roboto Mono
- [ ] 开启减少动态偏好时停掉柔光流动
