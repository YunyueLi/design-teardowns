01 — 定位与设计意图

几乎不做设计,才是它的设计

产品主张是获取答案、寻找灵感、提升效率。首屏那句话实测为 Now you can chat, work & code all in one place. 页面把所有戏剧性让给产品截图本身,框架退到几乎不可见——用极致的克制换取信任感。

底色

不是纯白

全站底色 #fcfcfc,比 #fff 压低一档,降眩光、更耐看。纯白只留给需要浮起的卡片面。

层级

全靠灰度

从 #0d0d0d 到 #fcfcfc 之间铺了近二十档灰,层级不靠颜色,只靠灰度拉开。

颜色

稀缺资源

颜色只出现在两处:产品截图下的水彩托底,和首屏一个词的四色描红。其余全交给黑白灰。

要点:大标题的分寸全在负字距 -4.7px 与 1.0 行高上。字越大,字母间与行间越要收紧,否则松散廉价——这是把 100px 巨字做出高级感的关键。

字体家族(出现次数 top)

OpenAI Sans 绝对主力,样式表里合计约 90 次;其后依次是无障碍字体 OpenDyslexic、可变多文种版 OpenAI Sans Variable Scripts 与旧字族 Circle。h1、导航、按钮的计算字体都落在 OpenAI Sans,只有 body 的兜底计算值才退回系统无衬线栈。

加载清单里的可贵之处

实测加载了阅读障碍友好字体 OpenDyslexic 与低视力友好字体 Atkinson Hyperlegible Mono,还有一整套 KaTeX 数学排版字体。无障碍字体做成可切换项,是"面向所有人"意图的实证。

06 — 动效系统

200 毫秒的手感,叠上 9 分钟的呼吸

零 video、零 canvas,所有运动都是 CSS,分成两个截然不同的时间尺度。点任一卡片重放,曲线与时长均为线上真实取值。

双时间尺度 · 时长梯(样式表实测,对数刻度)

签名主曲线 · 出现最多

cubic-bezier(.23,1,.32,1) 在样式表里出现 18 次,是全站默认手感——快出、长尾、缓缓落定,像被"松手放开"而非"拉着走"。它与 Comet 的主曲线同属"快出长尾"家族。

氛围层是纯 CSS 渐变

pricing-gradient-* 系列 keyframe 配合 15s 到 533s 的超长时长,让水彩 blob 极慢地呼吸与迁移。零 canvas、零 video 就是它是纯 CSS 的硬证据。

09 — 如何复刻

把这些数值直接接进你的产品

1 · 落地 token(复制即用)

:root{
  --bg:#fcfcfc; --ink:#0d0d0d;
  --ink-2:#5d5d5d; --ink-3:#8f8f8f;
  --gray:#f9f9f9; --hairline:#ededed;
  --accent:#0285ff;
  --ease:cubic-bezier(.23,1,.32,1);
  --micro:.2s; --pill:999px;
}

2 · 水彩 blob 托底(纯 CSS)

.stage::before{content:"";position:absolute;
 inset:-24%;filter:blur(46px);
 background:radial-gradient(38% 44% at 22% 28%,
   rgba(2,133,255,.34),transparent 62%),
  radial-gradient(40% 42% at 80% 24%,
   rgba(16,163,127,.3),transparent 64%);
 animation:blob 22s var(--ease) infinite alternate}

3 · prompt 能力卡(悬停提白上浮)

.ps{background:#f9f9f9;border:1px solid #ededed;
 border-radius:14px;
 transition:transform .2s var(--ease),
   background .2s var(--ease),
   box-shadow .2s var(--ease)}
.ps:hover{transform:translateY(-3px);
 background:#fff;
 box-shadow:0 12px 30px -14px rgba(0,0,0,.16)}

工程要点与坑

  • 底色不是纯白:用 #fcfcfc;纯白只留给要浮起的卡片面
  • 药丸别写天文数字:自己写 999px,别照抄 3.4e38px
  • 渐变要揉:水彩感来自 filter:blur(),不 blur 就是生硬色斑
  • 尊重 reduced-motion:关掉 blob 呼吸与一切氛围漂移
  • #1a73e8 不是品牌色:那是第三方 Google 图标带进来的

字体授权

OpenAI Sans 是定制商业字体。本页为求还原精度,直接接入了从站点提取的真实字体文件(仅标题 700、正文 400 两支),仅供研究与复刻比对;生产环境需自购或获得授权,不可照搬这份提取件。若无授权,用 Inter 等系统 neo-grotesque 临摹气质并注明替身即可。无障碍字体 OpenDyslexic 与 Atkinson Hyperlegible 有开源版,可直接接入做可切换项。

10 — 方法与出处

每个数值从哪来

抽取方法
用 playwright 读页面真实元素的计算样式(底色、墨色、h1 排版、导航透明且不做毛玻璃),再服务端抓取 7 个 CSS 文件的原文(约 1.83MB)做词频统计,得到高频色值、14 条缓动曲线、时长梯、圆角与全部 --* 变量。服务端抓文本不经浏览器 CORS,能拿到完整样式表。
实锤(源自抽取)
底色墨色、h1 全部指标、导航透明无毛玻璃、高频色值及次数、缓动曲线及次数、时长梯(含 218s 与 533s 超长项)、圆角(含天文数字药丸)、命名 keyframe(含水彩渐变系列)、弹簧时长、产品布局 token、指向 Tailwind v4 的 --tw-*、加载字体清单、零 video 零 canvas。
推断(观察与公开资料)
"work" 四色描红的精确色值(仅蓝 #0285ff 为实锤,绿金橙为观察估值)、手绘星芒与像素花、大面板约 22px 圆角、框架为 Next.js、以及 prompt 卡海的"铺满态"是对能力卡母题的复现。
真实资产回填(第二轮)
标题与正文已换成从站点下载的真实 OpenAI Sans(Regular 400 + Bold 700 两支 woff2),经 @font-face 接入,Inter 退为 CDN 兜底;为守"只接标题+正文"的边界,其余 30 多支权重、多文种与无障碍字体未接。as-seen 区新增六张能力卡产品原图,favicon 换成站点真实 OpenAI 标记。全部真实文件与来源 URL 见 real-assets/manifest.json。

一处数据纠正了观感

#1a73e8 与 Google Sans 看似品牌资产,实为页面 Google 工作套件集成图标带进来的第三方色与字。凡此类冲突,以"它是谁的资产"为准判断,而非出现次数。

局限

JS 库未被探针识别(代码经打包混淆),Tailwind v4 由变量间接坐实;整页探针截图命中 Cloudflare 校验,实拍改用真实滚动录制的关键帧;可能内联在 SVG 或位图里的颜色抓不全,一律标推断而不编造精确值。
