## 2. 签名一 · prompt 卡海(纯 CSS 网格 + 悬停微交互)

铺满宽度的浅灰能力卡,悬停时轻抬、描边加深、露出箭头,全用签名缓动。

```css
.cardsea{
  display:grid;
  grid-template-columns:repeat(auto-fill,minmax(210px,1fr));
  gap:12px;
}
.psuggest{
  background:var(--surface-gray-2);
  border:1px solid var(--hairline);
  border-radius:14px;
  padding:16px 16px 14px;
  cursor:pointer;
  transition:transform var(--micro) var(--ease-signature),
             background var(--micro) var(--ease-signature),
             border-color var(--micro) var(--ease-signature),
             box-shadow var(--micro) var(--ease-signature);
}
.psuggest:hover{
  transform:translateY(-3px);
  background:#fff;
  border-color:#dadada;
  box-shadow:0 10px 30px -12px rgba(0,0,0,.16);
}
.psuggest .icon{color:var(--ink-3);transition:color var(--micro) var(--ease-signature)}
.psuggest:hover .icon{color:var(--ink)}
.psuggest .go{opacity:0;transform:translateX(-4px);
  transition:opacity var(--micro) var(--ease-signature),transform var(--micro) var(--ease-signature)}
.psuggest:hover .go{opacity:1;transform:translateX(0)}
```

要点:卡片默认 `#f9f9f9` 浅灰,悬停"提白"到 `#fff` 并浮起——浅灰到白的反差就是微交互的全部,不需要更多。

## 3. 签名二 · 柔和水彩蓝色 blob 托底(纯 CSS,慢呼吸)

线上是 `pricing-gradient-*` 系列 keyframe 加 `15s`/`218s`/`533s` 超长时长实现的。下面用多重径向渐变加极慢 `breathe` 复现,产品截图叠在其上。

```css
.blobstage{position:relative;border-radius:24px;overflow:hidden;padding:64px}
.blobstage::before{
  content:"";position:absolute;inset:-20%;z-index:0;filter:blur(40px);
  background:
    radial-gradient(38% 44% at 22% 30%, rgba(2,133,255,.34), transparent 62%),
    radial-gradient(40% 42% at 78% 26%, rgba(16,163,127,.28), transparent 64%),
    radial-gradient(46% 50% at 62% 82%, rgba(120,180,255,.30), transparent 66%),
    radial-gradient(40% 40% at 32% 78%, rgba(90,210,180,.22), transparent 64%);
  background-color:#eef4fb;
  animation:blob-breathe 22s var(--ease-signature) infinite alternate;
}
@keyframes blob-breathe{
  from{transform:scale(1) translate(0,0)}
  to  {transform:scale(1.08) translate(1.5%,-1.5%)}
}
.blobstage > .mock{position:relative;z-index:1} /* 产品截图与窗口叠在渐变之上 */
```

蓝绿取自实测高频蓝 `#0285ff` 与品牌绿 `#10a37f`(绿为推断)。`blur(40px)` 是把渐变揉成"水彩"的关键;超长时长让它几乎静止地活着。

## 7. 选型决策表

| 元素 | 官方选型 | 理由 |
|---|---|---|
| 水彩蓝色渐变托底 | 纯 CSS 多重径向渐变 + 超长 keyframe | 零 `video`、零 `canvas`(媒体清单实锤),渐变全 CSS,成本几乎为零 |
| 药丸圆角 | `3.40282e38px`,等效 `9999px` | 天文数字保证任何高度都收成半圆;复刻用 `999px` 等效 |
| 大标题手感 | 负字距 `-4.7px` + 行高 1.0 | 字越大越要收紧,负值撑起高级感 |
| 微交互 | CSS `transition` 200ms + 签名缓动 | 跟手即时,不上 JS |
| 氛围漂移 | CSS 动画 15–533s | 慢到近乎静止,让画面"活着"而不打扰 |
| 底色 | `#fcfcfc` 而非 `#fff` | 压低一档降眩光、更耐看 |
| 边框 | `#ededed` 与 `#e5e7eb` 发丝级 | 几乎不可见,只划极浅的界 |
| 样式框架 | Tailwind CSS v4(`--tw-*` 实锤) | 原子化;圆角走 `--radius-*` 语义变量 |

## 8. 工程坑

- **底色不是纯白**:全站用 `#fcfcfc`;纯白 `#fff` 只留给需要"浮起"的卡片面,靠这一档差把卡片从底色里托出来。
- **药丸别写天文数字**:线上的 `3.40282e38px` 是 `float` 上限的产物,自己写 `border-radius:999px` 即可,别照抄那串数字。
- **渐变要揉**:水彩感来自 `filter:blur()` 把多重径向渐变揉开;不 blur 会是生硬的色斑。
- **尊重 `prefers-reduced-motion`**:关掉 blob 呼吸与一切氛围漂移。
- **`#1a73e8` 不是品牌色**:它是页面里 Google 集成图标带进来的第三方蓝,别当 ChatGPT 品牌蓝用;品牌强调蓝是 `#0285ff`。
- **字体授权**:`OpenAI Sans` 是定制商业字体,生产需自购或授权;开发占位用 `Inter` 等系统 neo-grotesque 临摹气质即可,并注明为替身。无障碍字体(`OpenDyslexic`、`Atkinson Hyperlegible`)有开源版可直接接入做可切换项。
