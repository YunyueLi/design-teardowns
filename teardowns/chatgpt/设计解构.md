# ChatGPT 概览页 · 设计解构

> 顶级 UI 视角的完整拆解,对象是 `https://openai.com/chatgpt/overview/`。除特别标注,所有数值都来自对该页的真实抽取(playwright 计算样式 + 服务端抓取的样式表文本,共 7 个 CSS 文件、约 1.83MB),均为**实锤**;凡从截图观察或公开资料得来的,标注为**推断**。
>
> 一句话:这一页几乎不做设计——纯白底、近黑字、极大留白、一个黑色药丸按钮。它的高级感不来自装饰,而来自克制本身。下面把这份克制拆到可复刻的每一个数值。

---

## 1. 定位与设计意图

- **产品主张**:获取答案,寻找灵感,提升效率。页面标题实测为 `ChatGPT | AI Chatbot to Discover, Learn & Create`(`lang="en-US"`)。
- **首屏那句话(实锤)**:`Now you can chat, work & code all in one place.`——把三件事(聊天、工作、写代码)收进一句,强调"一个地方全搞定"。
- **设计意图**:用极致的克制换取信任感。目标用户是所有人,所以界面刻意做到零门槛、无棱角、不炫技。留白负担一切节奏,黑白负担一切层级,颜色只在两处出现:一是产品截图底下的柔和水彩托底,二是首屏标题里被"描红"的一个词。
- **和同类的区别**:同为 AI 落地页,Linear 走深黑张力、Comet 走电影级宇宙叙事,而 ChatGPT 走的是"安静的白"。它把所有戏剧性都让给产品截图本身,页面框架退到几乎不可见。

**读法**:这是一套几乎没有彩色的灰阶系统。从 `#0d0d0d` 到 `#fcfcfc`,中间铺了十几档灰(`#101010`→`#181818`→`#1c1c1c`→`#212121`→`#303030`→`#393939`→`#414141`→`#5d5d5d`→`#767676`→`#8f8f8f`→`#afafaf`→`#b9b9b9`→`#cdcdcd`→`#cecece`→`#e5e7eb`→`#ededed`→`#f3f3f3`→`#f9f9f9`→`#fcfcfc`→`#fff`),层级全靠灰度拉开,不靠颜色。

### 两处出现的"颜色"

1. **交互蓝** `#0285ff`(实锤,17 次):链接与可点元素的强调蓝。
2. **首屏"work"描红**(推断,观察自关键帧):首屏标题里 `work` 一词被逐字上色——`w` 绿、`o` 蓝、`r` 金、`k` 橙,下方压一条绿到蓝的渐变下划线。这是全页唯一的一处"俏皮",四个字母四种颜色,呼应品牌一贯的多彩气质。精确色值未从样式表抽出(很可能内联在 SVG 或图片里),故标注为推断:绿约 `#10A37F`、蓝取 `#0285ff`、金约 `#F5A524`、橙约 `#FF6B35`。

> **实锤纠错**:`#1a73e8` 出现 17 次,乍看像品牌蓝,但它正是 Google 标准蓝;结合样式表里同时出现 `Google Sans,arial,sans-serif` 字体族(见字体节),几乎可以断定这两者来自页面中"Work"卡里的 Gmail、Google Drive、Google Docs 等第三方集成图标,**不是 OpenAI 的品牌色**。ChatGPT 自身的强调蓝是 `#0285ff`。复刻时不要把 `#1a73e8` 当作品牌色来用。

## 3. 字体系统

### 标题字(h1 实测,实锤)

| 属性 | 值 |
|---|---|
| 字体 | `"OpenAI Sans", "OpenAI Sans Variable Scripts", sans-serif` |
| 字号 | `100.08px`(桌面态实测) |
| 字重 | `700` |
| 字距 | `-4.70376px`(约 −4.7%,负字距把大标题收紧) |
| 行高 | `100.08px`(行高等于字号,即 1.0 倍行距,行与行几乎贴合) |
| 颜色 | `#0d0d0d` |

要点:**大标题的分寸全在两个负值上**——负字距 `-4.7px` 与 1.0 行高。字越大,字母间与行间就越要收紧,否则松散廉价。这是把 100px 巨字做出高级感的关键手法。

### 字体家族(fontFamily 出现次数,实锤)

`OpenAI Sans`(60 + 30 次,绝对主力)领衔;`OpenAI Sans Variable Scripts`(可变的多文种版本)、`Circle`(6 次)、`Atkinson Hyperlegible Mono`(4 次)、`Google Sans`(2 次,第三方)其后。正文的 `font-family` 计算值退回系统栈:`-apple-system-body, ui-sans-serif, -apple-system, "system-ui", "Segoe UI", Helvetica, Arial, sans-serif`——即字体没加载完时,用系统无衬线兜底。

### 实际加载的字体(fontsLoaded,实锤)

`Circle`、`OpenAI Sans`、`OpenAI Sans Arabic`、`OpenAI Sans Variable Scripts`、`OpenDyslexic`、`OpenDyslexic Mono`、`Atkinson Hyperlegible Mono`,以及一整套 `KaTeX_*`(数学公式排版字体,共 12 个切)。

> **可贵的发现**:加载清单里有 `OpenDyslexic`(阅读障碍友好字体)和 `Atkinson Hyperlegible Mono`(低视力友好字体)。这说明产品把无障碍字体作为可切换选项内建进来——是这套克制美学背后"面向所有人"意图的实证。`KaTeX_*` 则是为了在对话里排版数学公式。

**字体授权**:`OpenAI Sans` 是 OpenAI 定制商业字体,不可直接复刻到生产。本拆解页用开源无衬线 `Inter` 作最接近的替身临摹其气质,并明确标注为替身。

## 4. 动效系统

零 `video`、零 `canvas`(见媒体清单),这一页的所有运动都由 CSS 完成,分成截然不同的两个时间尺度。

### 4.1 双时间尺度

- **微交互层(极快)**:`0.2s`(200ms)是悬停与焦点的手感节奏;样式表里还有 `1ms` 与 `0s`,用于"瞬间"或禁用过渡。
- **氛围层(极慢)**:一批以秒计的长时长专供背景水彩渐变缓慢流动——`2s` `3s` `4s` `4.5s` `5s` `6s` 是呼吸与微光循环,`15s` `22s` `25s` `32s` 是慢速漂移,而 `218s`(约 3.6 分钟)与 `533s`(约 8.9 分钟)是渐变的超慢"迁移"。人眼几乎察觉不到它在动,却能感到画面是活的。

时长出现次数(top,实锤):`3s`(36)、`15s`(21)、`2s`(14)、`4s`(13)、`1s`(12)、`0s`(11)、`25s`(8)、`32s`(8)、`0.2s`(5)、`218s`(4)、`6s`(4)、`533s`(4)、`1ms`(4)、`4.5s`(4)、`5s`(4)、`22s`(4)。

### 4.2 缓动曲线(样式表实测,14 条)

| 曲线 | 次数 | 性格与用途 |
|---|---|---|
| `cubic-bezier(.23,1,.32,1)` | 18 | **签名主曲线**。快出长尾、缓缓落定,最"顺"的那种减速。出现频次第一,是全站运动的默认手感 |
| `cubic-bezier(.19,1,.22,1)` | 8 | Expo Out,比主曲线更陡的冲出与更长的尾 |
| `cubic-bezier(0, 0, .2, 1)` | 6 | 标准减速(Material decelerate),进场用 |
| `cubic-bezier(.4, 0, .2, 1)` | 6 | 标准进出(Material standard),两端对称 |
| `cubic-bezier(.22,1,.36,1)` | 6 | easeOutQuint,减速收尾 |
| `cubic-bezier(.4, 0, 1, 1)` | 3 | 加速离场(ease-in) |
| `cubic-bezier(.4, 0, .6, 1)` | 3 | 轻微对称进出 |
| `cubic-bezier(.8, 0, .4, 1)` | 3 | 先慢后快再稳,戏剧性稍强 |
| `cubic-bezier(.65, 0, .4, 1)` | 3 | 偏进的对称缓动 |
| `cubic-bezier(.65, 0, .35, 1)` | 3 | easeInOutQuint,大位移的对称进出 |
| `cubic-bezier(0.16, 1, 0.3, 1)` | 2 | easeOutExpo,极"高级"的减速 |
| 其余 `.4,0,.2,1` 等变体 | 1–2 | 同类去重 |

> **对照发现**:ChatGPT 的签名主曲线 `cubic-bezier(.23,1,.32,1)` 与 Comet 的主曲线 `cubic-bezier(.19,1,.22,1)` 属同一族(都是 Expo/Quint 型的"快出长尾")。顶尖产品在"顺滑减速"上的选择高度趋同——这类曲线让运动看起来是被"松手放开"而非被"拉着走"。

### 4.3 弹簧与关键帧(customProps 与 keyframes 实锤)

样式表把一整套弹簧时长做成了变量:`--spring-fast-duration:.667s`、`--spring-common-duration:.667s`、`--spring-bounce-duration:.833s`、`--spring-slow-bounce-duration:1.167s`、`--spring-fast-bounce-duration:1s`,还有一条精确到毫秒的 `--easing-spring-elegant-duration:.58171s`。通用缓动 `--easing-common:ease-in-out`。文字微光遮罩另有 `--tw-mask-shimmer-duration:4s`。

命名过的 `@keyframes` 里,几条直接点明了签名效果的实现:

- `pricing-gradient-light-breathe`、`pricing-gradient-blue-light-breathe`、`pricing-gradient-dark-migration`、`pricing-gradient-reveal`——**这就是水彩蓝色渐变的"呼吸"与"迁移"**,配合上面 `15s`/`218s`/`533s` 的超长时长,渐变在背景里极慢地流动。它是纯 CSS,不是视频、不是 canvas。
- `upgrade-button-text-shine`——升级按钮上的文字流光。
- `edge-fade`、`sR_mOW_slide-up`、`sR_mOW_slide-down`、`sR_mOW_popover-thread-enter`——边缘淡出、上下滑入、弹层入场等产品级微动效(带构建期哈希前缀)。

## 5. Hero 手法

- **结构**:透明导航(见下)之下,一句居中的巨号黑标题占满首屏视觉;标题下是黑色药丸主按钮加一个纯文字次级链接;再往下,产品截图斜着"飘"进来。
- **标题**:`OpenAI Sans` 100px、字重 700、负字距、1.0 行高,居中。中间的 `work` 一词被四色描红并压渐变下划线,是唯一的彩色破格。
- **主按钮**:黑色药丸 `Try it now*`(带星号脚注,页脚解释"今日起在桌面端全量,随后数日推向各套餐"),右侧配纯文字链接 `Download the app ↗`。药丸即黑色填充,文字白色,无边框。
- **导航(computed 实锤)**:背景 `rgba(0, 0, 0, 0)` 完全透明,`backdrop-filter: none` **不做毛玻璃**。左侧是"花结"品牌标加 ChatGPT 字标,中间一排链接(About、Features、Learn、Codex、Business、Pricing、Download),右侧 `Log in`(黑色实心药丸)与 `Sign up for free`(白底描边药丸)。被探测到的那颗导航按钮:背景透明、文字 `#5d5d5d`、圆角 `0px`、过渡 `all`。
- **产品截图**:浏览器与应用窗口做成带柔和投影的"飘浮卡",带轻微 3D 倾斜,营造纵深。截图内容是真实产品界面(如把对话生成为一份 Leadership Deck 的 PPTX)。
- **手绘俏皮标记**(推断,观察自关键帧):首屏散落着手绘黑色星芒(`✳` 状涂鸦)与一个中心带黑方块的粉色像素花。极简里埋一点手作感,免于冷硬。

## 6. 签名视觉母题

1. **浅灰能力卡(prompt 卡海)**:用一张张浅灰圆角卡片罗列"ChatGPT 能帮你做什么"。当前概览页把它表达为 Writing、Images、Work 三张大号浅灰卡加横向轮播;更早的版本与产品空状态里,则是**铺满整屏的 prompt 建议卡海**——同一母题的疏密两态。卡片是浅灰底(`#f3f3f3`/`#f9f9f9`)、发丝边、圆角,悬停有轻微抬起与描边加深的微交互。本拆解的第一个交互 demo 复现其"铺满"态。
2. **柔和水彩蓝色 blob 托底产品图**:产品截图不是硬摆在白底上,而是垫一层缓慢呼吸的蓝色水彩渐变(`pricing-gradient-*` 系列 keyframe 实锤)。渐变把冷硬的界面截图"焐"暖,也是全页除描红外唯一的成片颜色。第二个交互 demo 用纯 CSS 多重径向渐变复现这层托底。
3. **"work" 四色描红加渐变下划线**:首屏唯一的彩色破格,四个字母四种颜色,呼应品牌的多彩气质。
4. **手绘星芒与像素花**:极简里的一点手作俏皮(推断)。
5. **黑色药丸 CTA**:全站主按钮统一为黑色实心药丸,是这套黑白系统里最强的召唤视觉。

## 7. 工艺细节

- **圆角(radii 实测)**:药丸按钮用 `3.40282e38px`(即 `float` 最大值,等效"无穷大圆角",把两端收成半圆)与 `9999px`;卡片用 `10px`、`var(--radius-3xl)`、`var(--radius-md,.375rem)`(即 6px);还有 `50%` 与 `100%`(圆形头像与圆点)。bento 大面板目测约 16–24px(推断)。**用天文数字当圆角**是把"药丸"做绝对的偷懒又稳妥的写法,复刻时用 `999px` 即可等效。
- **边框**:发丝级 `1px`,颜色取 `#ededed` 或 `#e5e7eb`(Tailwind 的 gray-200),几乎看不见,只在卡片间划出极浅的界。
- **技术栈线索(实锤)**:满屏 `--tw-*` 自定义属性(`--tw-border-style`、`--tw-gradient-*`、`--tw-ring-*`、`--tw-mask-*` 等)与 `--radius-md,.375rem`、`--radius-3xl` 一起,明确指向 **Tailwind CSS v4**。前端框架未被探针直接确认(很可能是 Next.js,标注为推断)。
- **产品级布局 token(实锤)**:输入条宽度 `--composer-bar_width:768px`、高度 `--composer-bar_height:52px`、底栏 `--composer-footer_height:32px`、滚动条 `--scrollbar-width:10px`、输入条安全边距 `--composer-bar_safe-margins:20px`。这些是产品里对话输入框的真实尺寸,复刻 mock 时可照抄。
- **媒体选型(实锤)**:`video 0`、`canvas 0`、`svg 23`、`img 43`、`preloadVideo 0`、`preloadFont 0`。全页没有视频与画布——渐变全是 CSS,插画与图标是 SVG(23 个),产品截图与照片是位图(43 张)。这是"重内容轻框架"的取舍:钱花在真实产品截图与摄影上,视觉框架本身几乎零成本。

## 8. 关键发现

1. **克制是主动设计,不是偷懒**:近乎单色的灰阶系统(近 20 档灰)、1.0 行高的负字距巨标题、发丝边、无穷大圆角药丸——每一处都精确,只是精确地"少"。
2. **颜色是稀缺资源,只用在两处**:产品截图下的水彩托底,与首屏一个词的四色描红。其余全交给黑白灰。
3. **渐变是 CSS,不是视频或 canvas**:`pricing-gradient-*` keyframe 加超长时长(最长 533s)证明水彩 blob 是纯 CSS 的慢速呼吸与迁移。零 canvas、零 video 是硬证据。
4. **双时间尺度**:200ms 的微交互手感与 15–533s 的氛围漂移叠在一起,快得跟手、慢得像活着。
5. **签名缓动与顶尖同侪同族**:主曲线 `cubic-bezier(.23,1,.32,1)` 与 Comet 的 `cubic-bezier(.19,1,.22,1)` 同属"快出长尾"家族。
6. **无障碍是内建的**:加载了 `OpenDyslexic` 与 `Atkinson Hyperlegible Mono`,把无障碍字体做成可切换项。
7. **一处观感易错点被数据纠正**:`#1a73e8` 与 `Google Sans` 不是 ChatGPT 品牌资产,而是页面里 Google 工作套件集成图标带进来的第三方色与字。品牌强调蓝应取 `#0285ff`。

> 交互式版见同目录 `teardown.html`(含可玩的 prompt 卡海、水彩 blob 托底、缓动曲线实验台与真实关键帧)。
