# 事实核查 · ChatGPT 概览页拆解

对照真实抽取(`teardowns/_data/chatgpt.json` 的 computed 样式与样式表词频、`design-tokens.css`、`real-assets/manifest.json`),逐项核对 `teardown.html` 里出现的每一个数值,确认实锤标注无误,并记下本轮发现的漂移与修正。核查只做静态比对,不起本地服务。

## 一、色值

页面上所有色块都来自样式表高频统计(topHex)或 computed 实测,逐一对得上,无编造。

## 二、字体

- 标题字族实测为 `OpenAI Sans`(h1 computed `font-family:"OpenAI Sans","OpenAI Sans Variable Scripts",sans-serif`),导航、按钮的 computed 字体同样落在 `OpenAI Sans`。本轮已把站点真实的 `OpenAI Sans` 接入:正文 `Regular 400`、标题 `Bold 700` 两支 woff2。
- 读回自检:两支 woff2 均以 `wOF2` 魔数开头;内部 name 表 family 为 `OpenAI Sans`,子族分别为 `Regular`(usWeightClass 400)与 `Bold`(usWeightClass 700),与 `@font-face` 的 `font-family` 和 `font-weight` 一一对应,不存在张冠李戴或 tofu 隐患。
- h1 排版指标逐项对齐 computed 实测:字号 `100.08px`、字重 `700`、字距 `-4.70376px`、行高 `100.08px`、颜色 `#0d0d0d`,页面样张与指标卡完全一致。

## 四、时长

时长梯的九档全部命中样式表实测的 `durations`:`1ms`(4 次)、`200ms`(即 `0.2s`,5 次)、`2s`(14 次)、`3s`(36 次,确为最高频,“出现最多” 准确)、`4.5s`(4 次)、`15s`(21 次)、`32s`(8 次)、`218s`(4 次)、`533s`(4 次)。换算无误:`218s` 约 3.6 分钟、`533s` 约 8.9 分钟,标题 “叠上 9 分钟的呼吸” 取整合理。水彩托底用的 `22s` 亦为实测时长(4 次)。

## 五、圆角与布局 token

- 药丸圆角线上写成 `3.40282e38px`(float 上限,出现 10 次),复刻用 `999px` 等效,页面表述准确。
- 输入条宽 `768px`、高 `52px` 对齐 `--composer-bar_width`、`--composer-bar_height`;底栏 `32px`、安全边距 `20px`、滚动条 `10px` 均为实测自定义属性。

- 媒体清单 `video 0 / canvas 0 / svg 23 / img 43` 与 probe 实测一致,“纯 CSS 氛围层” 的判断成立。

## 六、本轮发现的漂移与修正

1. **卡片圆角 12px → 10px(已改)**。原页面 `--r-card` 取 `12px`,并在圆角示意里用 `12px` 方块配 “10px” 标签,自相矛盾。真实 `radii` 统计中并无 `12px`,最高频的显式小圆角是 `10px`(6 次,即 `design-tokens.css` 的 `--radius-6:10px`)。已将 `--r-card` 与示意方块一并校准为 `10px`,标签改为 “10px / radius-3xl”。
2. **字族排序措辞(已改)**。原文称 `OpenAI Sans` “其后是 Variable Scripts 与 Circle”,漏掉了出现 12 次、排在 Circle(6 次)之前的无障碍字体 `OpenDyslexic`。已按真实词频改为 “OpenDyslexic、Variable Scripts、Circle” 的次序,并补明 h1、导航、按钮的 computed 字体都是 `OpenAI Sans`,只有 body 的兜底计算值才退回系统无衬线栈。
3. **字体从替身升级为真字(已改)**。原页面用 `Inter` 临摹,现已 `@font-face` 接入真实 `OpenAI Sans`,页面正文与指标卡样张即为真字,`Inter` 降为 CDN 兜底。相关表述(头注、字体节、复刻节字体授权、出处、页脚)已同步更新。

## 七、实锤与推断复核

- **实锤标注全部成立**:底色墨色、h1 全部指标、导航透明无毛玻璃、全部高频色值及次数、四条缓动曲线及次数、时长梯、圆角(含天文数字药丸)、布局 token、弹簧时长、加载字体清单、零 video 零 canvas。
- **推断标注全部保留且措辞克制**:四色描红中绿金橙三色、手绘星芒与像素花、大面板约 `22px` 圆角(`radius-3xl` 的解析像素未被抓到)、前端框架为 Next.js、`#1a73e8` 归属第三方 Google 图标、prompt 卡海的 “铺满态” 为母题复现。这些都未被冒充为实测。

## 八、遗留的一处可选精度项(非漂移)

大面板圆角 `--r-panel` 取 `22px`,标注为推断。若确认该站沿用 Tailwind v4 的默认 `--radius-3xl:1.5rem`,则更贴近 `24px`;因未抓到解析后的像素值,本轮维持 `22px` 并保留推断标注,不擅自坐实。

核查结论:除上述已修正的三处外,页面全部数值与真实抽取一致,实锤与推断标注无误。
