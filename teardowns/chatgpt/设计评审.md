# 设计评审 · ChatGPT 概览页拆解页

以顶级设计视角,评审这份拆解页在真素材回填后的精度与完成度:相对原站已经追平在哪、还差在哪,并给出可执行的改进。能当场改的已经改,余下的标明理由与取舍。

## 一、总体判断

这一版最关键的精度跃迁,是把真实 `OpenAI Sans` 接进了页面。首屏那句 100px 巨标题过去靠 `Inter` 临摹气质,总差一口气——`OpenAI Sans` 的字腔更收、字重转折更硬,配上真实的 `-0.047em` 负字距与 1.0 行高,那种 “大而不散、静而有力” 的手感这才真正立住。色彩系统本就是对真实灰阶的逐档还原,加上运动统一走签名缓动、氛围层纯 CSS,页面的 “克制” 已经不是描述,而是可核对的事实。作为一份拆解页,它的完成度很高;作为一次 “克隆”,它有意不做到位,这也正确。

## 二、已追平的部分

- **字体**:标题与正文都是站点真字(`Regular 400` 与 `Bold 700`),`Inter` 只在加载失败时兜底。指标卡里的样张即真字,读者所见即所测。
- **色彩**:底色 `#fcfcfc`、墨色 `#0d0d0d`、18 档中间灰、两处唯一的彩色,全部来自真实词频统计,零编造。
- **动效语言**:全页统一调用出现最多的签名主曲线 `cubic-bezier(.23,1,.32,1)`,并如实呈现从 200 毫秒手感到 9 分钟呼吸的双时间尺度。
- **克制的物证**:非纯白底、发丝边、药丸 CTA、颜色只从内容里长出来——这些判断都配了实测数值或真实素材,不停留在观感。
- **真实素材对照**:as-seen 区新增六张能力卡产品原图,与 HTML 复现的 “卡海” 并置,复现证明结构,原图锁定观感。

## 三、仍存在的差距(相对原站)

1. **次级字重靠兜底顶上**。为守住 “只接标题与正文两支” 的边界,页面只嵌了 400 与 700。原站导航约 500、药丸与标签约 600,现在这些元素会就近回落——500 偏轻、600 偏重。属于有意识的取舍,而非疏漏。
2. **等宽字是拆解页自己的嗓音,不是原站的**。眉标与标签用了 `JetBrains Mono`,而原站几乎通篇只有 `OpenAI Sans`,并无展示型等宽字。这是这类拆解页的编辑体例,但也是全页最显眼的 “这不是原站” 的信号。
3. **滚动叙事未被复刻**。原站的骨架是滚动驱动的叙事(Chat、Work、Codex 竖排进度导航带动产品截图切换),本页是注解式的文档布局。这是体裁使然,但也意味着原站的运动编排没有被还原。
4. **水彩托底是演示速度**。原站由 `pricing-gradient-*` 系列 keyframe 在 218s 到 533s 的超长尺度上迁移,本页用单条 22s 的 blob 作演示。作为示意足够,但那种 “几乎察觉不到的漂移” 不是 22s 能给的。
5. **四色描红仍有三色是估值**。绿金橙未出现在样式表词频里,真值可能内联在被 Cloudflare 挡住的首屏资产中,暂只能观察估值。

## 四、可执行改进

1. **接入真实 OpenAI Sans,校准字族栈**(已改)。两支 woff2 经 `@font-face` 接入,`--sans` 以真字打头,`Inter` 与 `Noto Sans SC` 兜底。本轮精度的最大来源。
2. **校准卡片圆角到真实 10px**(已改)。原 `12px` 在真实 `radii` 里查无此值,已对齐最高频的显式圆角 `10px`(即 `--radius-6`),圆角示意方块同步修正。
3. **补真实能力卡原图作对照**(已改)。六张站点产品图进入 as-seen 区,给纯手写复现提供了 ground-truth 锚点。
4. **精校首屏标题的字距与行高**(已改)。按真实比例把 h1 定为 `-0.047em` 与行高 `1.0`,让真字的字间与行间关系与原站一致。
5. **如放宽 “两支” 边界,补一支 Semibold 600**(未改,取舍)。这能让导航与药丸落在真实字重上,是当前最划算的下一步精度项;因本轮明确 “只接标题与正文”,故留作可选。
6. **大面板圆角可考虑对齐 24px**(未改,存疑)。若坐实该站沿用 Tailwind v4 默认 `radius-3xl:1.5rem`,`--r-panel` 更贴近 `24px`;因未抓到解析后的像素,维持 `22px` 并保留推断标注,不擅自坐实。

## 五、结论

真字一接,这份拆解页从 “形似” 跨到了 “神似”:首屏标题、灰阶、运动三条主线都已可核对地贴住原站。剩下的差距集中在次级字重、等宽字的编辑嗓音,以及有意不做的滚动叙事复刻——前两者是明确取舍,后者是体裁边界。若要再进一步,补一支 Semibold 是回报最高的一小步。
