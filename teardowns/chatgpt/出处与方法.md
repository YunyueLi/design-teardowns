# 出处与方法 · Provenance

## 抽取对象

线上页面 `https://openai.com/chatgpt/overview/`。抽取产物落在 `teardowns/_data/chatgpt.json` 与 `teardowns/chatgpt/design-tokens.css`,原始渲染证据落在 `teardowns/chatgpt/keyframes/*.jpg` 与 `teardowns/chatgpt/recording/scroll.webm`。

## 提取链路

1. **计算样式(playwright)**:用无头浏览器打开页面,读取 `body`、`h1`、`nav`、按钮等真实元素的 `getComputedStyle`,拿到底色 `rgb(252,252,252)`、墨色 `rgb(13,13,13)`,以及 h1 实测的字体 `OpenAI Sans`、字号 `100.08px`、字重 `700`、字距 `-4.70376px`、行高 `100.08px`,还有导航透明背景与 `backdrop-filter:none` 等。这些是浏览器渲染后的最终值,最硬。
2. **样式表文本(服务端抓取)**:直接抓取页面引用的 7 个 CSS 文件的原文(合计约 1,832,826 字节),再做词频统计,得到高频色值(topHex)、缓动曲线(cubicBezier)、时长(durations)、圆角(radii)、字体族(fontFamily)、命名过的 `@keyframes` 与全部 `--*` 自定义属性。服务端抓文本不经浏览器 CORS,能拿到完整样式表。
3. **加载字体清单**:从渲染态读取 `document.fonts`,得到 `OpenAI Sans`、`OpenDyslexic`、`Atkinson Hyperlegible Mono`、`KaTeX_*` 等真实加载的字体。
4. **媒体清单**:统计页面内 `video`/`canvas`/`svg`/`img` 与预加载资源数量,得到 `video 0`、`canvas 0`、`svg 23`、`img 43`。
5. **渲染证据**:滚动录制 `recording/scroll.webm`,并抽出 8 张关键帧 `keyframes/00.jpg`–`07.jpg`(首屏、Chat/Work/Codex 滚动叙事、能力卡轮播、Plans and pricing、Designed to keep you safe、Get inspired、页脚)。

## 实锤 vs 推断

- **实锤(源自抽取)**:页面底色与墨色、h1 全部排版指标、导航透明且不做毛玻璃、全部高频色值及出现次数、14 条缓动曲线及次数、时长梯(含 `218s`/`533s` 超长项)、圆角(含 `3.40282e38px` 药丸)、命名 keyframe(含 `pricing-gradient-*` 水彩渐变、`upgrade-button-text-shine` 流光)、弹簧时长变量、产品布局 token(`--composer-bar_width:768px` 等)、`--tw-*` 指向 Tailwind v4、加载字体清单(含无障碍字体)、零 video 零 canvas 的媒体清单。
- **推断(观察与公开资料)**:首屏"work"四色描红的精确色值(很可能内联在 SVG 或图片里,未从样式表抽出,仅蓝 `#0285ff` 为实锤,绿金橙为观察估值)、手绘星芒与像素花等装饰、bento 大面板约 16–24px 圆角、前端框架为 Next.js、`prompt 卡海`作为"铺满态"是对 ChatGPT 能力卡母题的复现(当前概览页呈现为三张大卡加轮播的"疏"态)。凡推断处正文均已标注。

## 局限

- **`actual-hero.jpg` 与 `actual-full.jpg` 命中了 Cloudflare 人机校验**:这两张探针整页截图抓到的是 `Verify you are human` 验证页,不是真实产品页,不可作视觉依据。因此本拆解的"as-seen 实拍"证据改用 `keyframes/00.jpg`–`07.jpg`(真实渲染的关键帧)。
- **JS 库未被探针直接识别**:`libs` 与 `scriptHints` 均为空(代码经打包混淆)。Tailwind v4 由 `--tw-*` 变量间接坐实;框架为推断。
- **`#1a73e8` 与 `Google Sans` 的归属**:数据只给出现次数,不给用途。结合两者同为 Google 标准资产、且页面"Work"卡含 Gmail/Drive/Docs 图标,判定它们来自第三方集成图标而非 OpenAI 品牌资产——这一步是有据推断,非样式表直接声明。
- **精确色值只到样式表**:描红字母等可能以内联 SVG/位图承载的颜色,词频统计抓不全,故标注推断而不编造精确 HEX。

## 第二轮 · 真实资产回填

第一轮用的是近似替身字体与 CSS 近似媒体;第二轮已把站点真实资产接进拆解页,提升还原精度。真实文件与来源 URL 全集见 `real-assets/manifest.json`。

- **真实字体(精度关键)**:从 `real-assets/fonts/` 里只挑了标题与正文两支——`OpenAISans-Regular`(权重 400)与 `OpenAISans-Bold`(权重 700),经 `@font-face` 接入,`--sans` 以真字打头,`Inter` 降为 CDN 兜底。站点另外下到的 30 多支(各权重、希腊、西里尔、阿拉伯、希伯来、天城文、谚文等多文种,以及无障碍字体)有意未接,以免喧宾夺主。读回自检:两支 woff2 内部 name 表 family 均为 `OpenAI Sans`,子族与权重和 `@font-face` 对得上,无 tofu。
- **真实图像**:as-seen 区新增六张能力卡产品原图(写作、图像、编程、语音、健康、财务),与 HTML 复现的 “卡海” 互为对照;favicon 换成站点真实 OpenAI 标记。清单无视频与音频(`video` 与 `audio` 均为空),故不嵌视频。首屏实拍仍是 Cloudflare 校验页,as-seen 继续以真实滚动关键帧为证据。
- **token 校准**:卡片圆角由 `12px` 校准为真实的 `10px`,首屏标题字距与行高按真实比例精校为 `-0.047em` 与 `1.0`。底色 `#fcfcfc`、墨色 `#0d0d0d`、签名缓动 `cubic-bezier(.23,1,.32,1)` 本已对齐,无需再调。
- 逐值核对见 `事实核查.md`,精度与完成度评审见 `设计评审.md`。
