# EasyCode（imlagom.com/projects/easycode/）设计解构

> 抓取于 2026 年 7 月 30 日，Chromium 148，1440×900 @1.5x。**实锤**来源特别丰厚：本页 main.js（1306 行）与 main.css 均未压缩且带中文注释——动效契约、调参史、装置规则皆为源码原文。

## 一、世界观：一张被批改的作业纸

- 开场自陈（原文）：「红灯，绿灯。通过，或不通过。这几乎是传统刷题网站能告诉你的全部。」主张：「把刷题，变成被指导的练习。」
- **十六屏 = 一道题的一生**：遇题（LeetCode 704 二分查找）→ 写码（30 秒快照回放）→ 验证（浏览器本地判题）→ 卡壳 → 求助（四层台阶）→ 提交 → 五维评级 → 面试追问（分镜墙）→ SRS 复习 → 工作台 → 数据主权 → 收尾；其间五张全景「节拍」幕换气。
- 视觉母题：**白纸、红笔、楷体批注**。正文系统黑体，主张用宋体，批改用马善政楷体——三副笔迹即信息层级。
- 技术底盘：手写静态页（资产带 `?v=` 版本号，推断），vendored GSAP core、ScrollTrigger、SplitText、CustomEase、Lenis（注释自称「零外部请求」，实锤）；**GSAP 缺失时六台装置全部呈现已解态**（静态兜底，实锤）；另用 `@supports (animation-timeline: view())` 门控的**原生 CSS 滚动驱动动画**跑全景显影（实锤）。

## 四、动效：一部写进注释的成文法（全部实锤，注释原文）

1. **全局法则（用户明令）**：「双向可重演——窗口经过即重演，向上向下都演，但运动方向必须与滚动方向一致：向下从下方进入/向上离开，向上从上方进入/向下离开；仪式（印章/盖章/描画）同样反向响应。章节标题例外：只在首次经过时做一次行级轻揭，回滚不重演。」由「方向感知的双向调度器」统一实现。
2. **签名曲线同源**：`CustomEase.create("sig","0.22,1,0.36,1")` 与 CSS `--ease` 同值（注释「6.1 收敛」）；例外只有两个——盖章用 `power2.in` 冲击（「仪式」）、scrub 用 none。
3. **节奏三档**：`--t-fast 120ms / --t-medium 180ms / --t-slow 240ms` 管界面反馈；GSAP 侧 0.24 至 1.05s 管演出；回弹 `(.34,1.56,.64,1)` 2 处。
4. **keyframes（11 个）**：gradeStamp（评级章收环：scale 1.08 rotate −1° 落定 + 3px 语义色 box-shadow 环消散）、gradeLetter、blink、radar 四连（Fill/Line/Dot/Label）、sda 三连（Img/Hero/Art，原生 view() 时间线专用）、np-wash（与主站共享）。
5. **红笔描画纪律**：dashoffset 描线「长度运行时实测，宁准勿估」；hero「刷题」二字先稳笔划除再补淡复笔；眉批「无论向下首演还是回顶重演，都从左往右一笔笔写出」。
6. **SplitText 纪律**：等 `document.fonts.ready`（1.2s 兜底）再拆字；autoSplit 随视口重排重建，「杜绝旧行盒残留造成的 mask 裁切错位」。
7. **调参史入注释**：红绿灯水波「间隔 1.05→0.8、每环 0.95→0.78、错开 0.18→0.13」；面试语料「用户拍板 2026-07-17」；分镜到站墙「2026-07-27 重写」。

## 五、十六屏逐屏（详见 teardown.html 走查区）

1. **#verdict-beat 红灯绿灯**：两枚判定丸按滚动方向先后落定，各荡三环水波（.78s、错开 .13s）；波纹将尽页边批一笔写出。
2. **主张**：SplitText 断行 + scrub 逐行读亮（start top 78% 至 end top 34%），「滚动的速度就是读它的速度」。
3. **#meet 遇题**：LeetCode 704 真题卡（样例、mono 标注、楷体眉批），44px 横线格卷面母题。
4. **#code 快照回放**：每 30 秒 diff 快照，回放装置 4 帧至 1:30；面板高度按最大帧预撑；窄屏降级按钮版。
5. **#verify-beat**（节拍）：「写完最后一笔，是时候开始验证了。」原生 view() 显影。
6. **#test 判题机**：「判题机就跑在你的浏览器里：不排队、不上传，断网也能验。」真可运行：先红（边界 bug）后由你改对转绿；「代码块常驻，改完也不消失」。
7. **#stuck-beat**（节拍）：唯一深底幕，情绪低点。
8. **#help 求助台阶**：四层（思路方向、关键观察、伪代码骨架、完整代码），「一次只上一层——只有下一层可点」；第四层「演示到骨架为止，这一层不给」——价值观做成交互约束。
9. **#submit-beat**（节拍）：「区间加宽让它驻留可感知，不再一闪而过（3.6）」。
10. **#review 五维评级**：主诊断、代码质量 9/10、复杂度 O(log n) · O(1)、过程复盘、训练处方；gradeStamp 落章；「如果当时没抓住那个 bug?」平行宇宙 B 档对照；五维雷达 radarFill。
11. **#interview 面试分镜墙**：桌面 GSAP pin + scrub 逐轮推进 +「到站墙」夹住真实滚动（程序化滚动不受夹）；窄屏按钮版互斥；规则「面试只能收紧，不能放水。终局评估只在严格低于当前评级时才采纳。」
12. **#consolidate-beat**（节拍）：「面试结束，但训练尚未完结。」
13. **#srs 复利数轴**：**产品真实算法**——A14/B7/C3/D1 天，连续巩固 ×2.0 与 ×1.3，封顶 180 天，对数轴刻度（注释「刻度为真实算法节点」）。
14. **#daily 工作台**：待复习队列（低评级与逾期最久排最前）、本局复盘、历史页并排；data-rv-lag 分批显影。
15. **#yours 数据主权**：「测试跑在你的浏览器里、评委由你任命、数据永远是你的」，与 #test 首尾呼应。
16. **#closing 收尾**：尾花转正（双向），终章印章「盖上不撤」，预藏条件「仍位于视口下方」防刷新竞态（注释逐句）。

## 六、关键发现

1. **源码即设计文档**：动效法则、例外、调参史、竞态处理全部写在注释里，且逐条落实——这是被拆四页中工程文化浓度最高的一页。
2. **双向可重演 + 方向一致**是罕见的滚动叙事纪律：多数站点只做一次性显影；这里上下滚都演且方向语义正确。
3. **GSAP 与原生滚动驱动动画混编**：装置归 GSAP，氛围归浏览器（view() 时间线），预算分明。
4. **基调系统**用 color-mix 把语义色派生为整套外观，一类切肤。
5. **降级到已解态**：无 GSAP 时不是没有动画的页面，而是一张已经批改完的卷子——降级方案本身贴合世界观。
