| 步骤 | 做法 | 产物 |

## 二、实锤清单

- 42 个 `:root` 变量、4 条贝塞尔（.32,.72,0,1 ×4；.34,1.56,.64,1 ×2；.23,1,.32,1 ×2；.22,1,.36,1 ×1）、11 个 keyframes：tokens.json 与 main.css 原文。
- 动效成文法（双向可重演、方向一致、标题例外）、CustomEase "sig" 同源声明、水波调参史（1.05→0.8 等）、「宁准勿估」、到站墙 2026-07-27 重写、面试语料 2026-07-17 拍板：main.js 注释原文。
- SRS 参数（A14/B7/C3/D1、×2.0/×1.3、封顶 180、对数轴）、面试规则（只收紧不放水）、四层台阶文案、评分单五维语料：JS 数据区与 HTML 原文。
- H1 计算样式 124px/700/−1.488px；body 白底墨字系统黑体：运行时探针。
- `animation-timeline: view()` ×2、`animation-range: cover 0% cover 100%` ×2、@supports 门控：main.css 原文。
- vendored 脚本清单（gsap、CustomEase、ScrollTrigger、SplitText、lenis + main.js?v=20260717-6）：HTML 原文。
- 三支字体子集字节（130,680 / 134,400 / 42,348 B）与 18 张图：落盘 + manifest。

## 三、推断清单

| 推断 | 依据 | 置信 |
| --- | --- | --- |
| 手写静态页（无打包器） | `?v=` 查询串版本、目录形态、未压缩产物 | 高 |
| 判题机在浏览器内执行用户代码 | 页面文案「跑在你的浏览器里、断网也能验」+ 装置行为 | 高（实现载体 Worker 与否未深挖） |
| 「作业纸」世界观归纳 | 视觉与文案一致性 | 高（意图类） |

## 四、局限

1. 分镜到站墙的每站滚动区间、夹持力度未逐一实测标定。
2. 判题沙箱实现细节（Worker、超时、内存）未深挖。
3. GSAP 时间轴的逐帧参数未全部誊录（11 条时间轴，已按注释与关键数值归纳）。
4. 移动端真机未实测；按钮交互版仅在窄视口模拟确认存在。
5. `pano-*` 五张全景与 `art-*` 六张插画的创作来源未考（推测为生成或委托美术，不影响数值结论）。

## 五、复算口径

- 「十六屏」= `<section>` 计数（含五张节拍幕与无 id 主张节）。
- 「11 条时间轴、8 个 ScrollTrigger、6 处 SplitText」= main.js 相应调用计数。
- 「11 个 keyframes」= main.css `@keyframes` 唯一名计数（含 np-wash）。
- 评分单「9/10、O(log n) · O(1)、04:24」等为演示语料（页面自陈的示例复盘），非用户真实数据。
