## 三、易错点自查

- **GSAP 时长与 CSS 时长未混写**：--t-* 三档属界面反馈（CSS），.24 至 1.05s 属演出（GSAP），两处分开表述。
- **np-wash 归属**：该 keyframe 与主站共享（导航世界卡），未计入本页独创。
- **「零外部请求」**：注释自述且脚本清单全为同源路径，Cloudflare beacon 除外（分析脚本，非动效依赖）——文档措辞为「动效底座零外部请求」，准确。
- **评级章冲击缓动**：power2.in 属 GSAP 侧（JS），gradeStamp keyframe 属 CSS 侧，二者协同不重复计。
