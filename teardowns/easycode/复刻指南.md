## 三、签名效果

### 1. 评级章 gradeStamp（收环落定）

```css
@keyframes gradeStamp{
  from{ box-shadow:0 0 0 0 color-mix(in srgb,var(--tone-mark,currentColor) 24%,transparent);
        transform:scale(1.08) rotate(-1deg) }
  to  { box-shadow:0 0 0 3px transparent; transform:none } }
/* GSAP 侧冲击缓动:power2.in(注释点名的「仪式」例外) */
```

### 2. 判定丸水波（方向感知节拍）

- 每丸底部预注入 3 个环元素；时间轴驱动 scale/opacity。
- 节拍（注释调参史终值）：环时长 .78s、逐环错开 .13s、两丸间隔 .8s。
- 方向法则：向下滚「未通过 → 通过」，向上滚反演；两枚荡完，页边批才 clip-path 揭写（轻微搭接在末环将尽处）。

### 3. 红笔仪式

```css
/* 划除:两笔。主笔慢(像老师稳稳落笔),复笔更淡、延迟入 */
.strike i{ height:3px; background:var(--red); transform:scaleX(0); transform-origin:left; rotate:-1.2deg; }
.strike i.re{ height:2px; opacity:.45; rotate:-.6deg; }
.strike.on i{ transform:scaleX(1); transition:transform .9s var(--ease); }
.strike.on i.re{ transition:transform .7s var(--ease) .55s; }
/* 眉批/页边批:永远从左往右写(inset 右缘 100% → 0) */
.note{ clip-path:inset(-12% 102% -14% -2%); transition:clip-path .8s var(--ease); }
.note.in{ clip-path:inset(-12% -3% -14% -2%); }
/* 描画(圈、下划线):stroke-dashoffset,路径长度运行时 getTotalLength 实测 */
```

### 4. 原生滚动驱动的全景显影

```css
@supports (animation-timeline: view()){
  .pano img{ animation:sdaImg both; animation-timeline:view(); animation-range:cover 0% cover 100%; }
}
@keyframes sdaImg{ 0%{opacity:0;transform:scale(1.045) translateY(30px)} 22%{opacity:1;transform:none} 100%{opacity:1;transform:none} }
```

装置归 GSAP、氛围归浏览器；不支持的浏览器落回静态图，零 JS 负担。

### 5. 方向感知的双向调度器（骨架）

```js
// 全局法则:窗口经过即重演,方向与滚动一致;标题例外(一次性)
ScrollTrigger.create({
  trigger: el, start: "top 82%", end: "bottom 18%",
  onEnter:     () => play(el, +1),   // 向下进入:从下方进
  onLeave:     () => reset(el),
  onEnterBack: () => play(el, -1),   // 向上进入:从上方进
  onLeaveBack: () => reset(el),
});
```

### 6. 分镜到站墙（pin + scrub + 输入夹持）

- 桌面：`ScrollTrigger.create({ pin: true, scrub: true })` 推进对话；每轮问答一「站」。
- 到站墙只夹**真实输入**（wheel/touch），程序化滚动（锚点 glide）放行——判据是 Lenis scrollTo 的 programmatic 标记。
- 窄屏保持按钮交互版，两套互斥。

## 四、选型决策表

| 取舍点 | 它的选择 | 为什么成立 |
| --- | --- | --- |
| 动效引擎 | GSAP 全家桶 vendored + 原生 SDA 混编 | 装置要编排力，氛围要零成本；「零外部请求」 |
| 重演策略 | 双向可重演 + 方向一致（成文法） | 上下滚都讲故事；方向语义不撒谎 |
| 判分外观 | --tone-* 基调系统 | color-mix 派生整套皮肤，语义与外观解耦 |
| 求助设计 | 四层台阶，第四层禁用 | 产品价值观直接做成交互约束 |
| 降级 | 无 GSAP 呈现「已解态」 | 降级卷面仍完整，甚至更快 |
| 拆字 | SplitText 等字体就绪 + autoSplit | 中文断行安全，重排不残留 |

## 五、工程坑（多为注释自曝）

1. SplitText 在字体未就绪时量错行——必须 `document.fonts.ready` 后拆（1.2s 兜底）。
2. pin/scrub 区域内的元素要从通用显影管理中剔除，否则互相打架。
3. 「盖上不撤」的元素要处理预藏竞态：只在仍位于视口下方时预藏，防止刷新停在底部时永久隐身。
4. 定高滚动框：挂 `data-lenis-prevent`，且只在内容真溢出时才拦截页面滚动。
5. scrub 文本读亮的触发器要随 autoSplit 重建，否则窗口缩放后行号错位。
6. color-mix 需要现代浏览器；老栈给静态回退色。
7. 描画路径长度不要手写常量——`getTotalLength()` 实测（「宁准勿估」）。
