# 海龟汤事务所 拆解：出处与方法

## 一、抽取链路

| 步骤 | 做法 | 产物 |
| --- | --- | --- |
| 全量捕获 | `capture_site.py`（Playwright，Chromium 148，1440×900 @1.5x）单次会话 | tokens.json、design-tokens.css、real-assets（6 视频 + 18 图 + 源码）、recording/scroll.webm、keyframes、screenshots |
| 样式精读 | 53,103 B 主样式展开为 576 行逐节读完 | 九屏全部选择器级数值、18 个 keyframes 定义 |
| 脚本反推 | 追加抓取打包 JS（160,322 B），按常量、类名与文案字符串反推交互 | Q&A 数据、盖章链路、压灯与传送带类名、打字节奏 |
| 逐屏截图 | Playwright 逐屏滚动触发揭示后，按 section 顶、中、尾各截 1440×900 视口图 | assets/screens/00 至 08 共 15 张 |
| 素材补抓 | 服务端直连补抓字体 5 支、纸纹、颗粒、软木、台面、四枚判语章、三张剧场照片、品牌两件（`manual_`/`extra_` 前缀） | real-assets 补全 |

## 二、实锤清单

- 32 个 `:root` 变量、4 条贝塞尔、18 个 keyframes、时长与圆角词频：tokens.json 与样式表原文。
- 九屏结构（#hero #case #why #door #play #kitchen #soups #career #join）、全部引文、判语四章文案、进度五档、六问与两案（茶馆案、出租车案）文本：HTML 原文与打包 JS 字符串。
- H1 计算样式 128px/700/字距 5.12px/行高 135.68px、body 底色 `rgb(10,8,6)`：运行时探针。
- 六段视频（街景 1,554,100 B、雨幕 1,224,560 B、汤碗 446,737 B、开案 301,750 B、档案墙 783,762 B、开蜡 265,691 B）与 18 + 13 张图：manifest.json 与补抓落盘字节。
- 五支字体自托管路径与字节（157,740 / 162,660 / 53,296 / 48,836 / 63,360 B）：CSS @font-face 原文 + 落盘。
- Lenis：运行时探针 libs；`html.static-capture` 捕获模式、`html.kitchen-dim` 压灯：样式表原文。

## 三、推断清单

| 推断 | 依据 | 置信 |
| --- | --- | --- |
| Vite 构建 | `./assets/index-<hash>.js` 与 CSS 命名形态 | 高 |
| 「空间动线」叙事意图 | 九屏文案连续性与物件一致性 | 高（意图类） |
| #play 桌面端按滚动进度切拍 | 400vh + sticky + 绝对叠拍结构；打包 JS 含 scrollY 映射 | 高 |
| 传送带自动模式细节 | `.is-conveyor` 类与 overflow 切换；具体速度未实测 | 中 |

## 四、局限

1. 打包 JS 未逐行还原（160KB 含 Lenis），交互参数以样式表与字符串证据为准；打字速率取自复现实测感（约 46ms/字）标注为近似。
2. 图片配额（18 张）外的素材按 CSS 与 HTML 引用清单补抓了 13 张关键件，仍有部分装饰图（如 obj-11-newspaper 等）未落盘，manifest 有完整 URL。
3. `--par` 视差的映射斜率、#play 每拍的滚动区间未实测标定。
4. 移动端真机（触摸、safe-area）未实测。
5. 雷达图数值与坐标为示例数据，不代表真实用户档案。

## 五、复算口径

- 「九屏」= `<section>` 计数（不含 nav、footer、wire 分隔）。
- 「18 个 keyframes」= 样式表 `@keyframes` 唯一名计数（含与主站共享的 np-wash）。
- 「六段视频」= manifest video 类目条数；字节为服务端抓取值。
- 视口截图 15 张 = 9 屏中高于 1400px 的分节按顶、尾（高于 2900px 加中段）多点取样。
