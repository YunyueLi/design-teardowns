## 三、选型决策表

| 取舍点 | 它的选择 | 为什么成立 |
| --- | --- | --- |
| 质感来源 | 实拍材质图（纸、颗粒、软木、台面） | 上限高于程序纹理；CSS 只负责混合与裁切 |
| 雨夜氛围 | 图、视频、雨幕三层叠加 | 任何一层失败画面仍成立；雨幕 screen 混合不刷白 |
| 印章 | 真实印泥图 + 统一滤镜链 | 四章色泽一致，且能参与 brightness 闪光动画 |
| 聚光 | fixed 遮罩 + z-index 夹层 | 两行 CSS，零脚本成本 |
| 剧场 | 400vh + sticky + 绝对叠拍 | 桌面滚动驱动，移动端一键降级为 IO 流 |
| 进度 | 叙事化五档文案 | 把滚动进度写成破案进度，功能变戏份 |

## 四、工程坑

1. `filter` 动画每帧必须写完整链；漏写即闪跳。
2. 蜡屑用 55% 中间帧近似抛物线；纯 ease 出不来「上抛再坠」。
3. 压灯夹层要求舞台不透明，否则遮罩从缝里透出来。
4. `steps(24)` 打字擦除的步数要跟文字长度匹配，太少像卡顿。
5. 雨幕视频必须 `muted playsinline`，播放失败要静默保留 CSS 雨幕（本站首页的做法；本页雨幕本身就是视频，失败则只剩街景层，可接受）。
6. 挂牌的 sway 要和视差变量共存：把 `translateY(var(--par))` 写进 keyframes 的每一帧，否则视差会被动画覆盖。
7. `border-radius` 八值血招（回形针）在 Safari 老版本表现不稳，给个圆角兜底。
8. 缺 `prefers-reduced-motion` 全局关断时（原站如此），自己复刻务必补上。
