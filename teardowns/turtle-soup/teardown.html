04 动效系统

一条签名缓动，十八个 keyframes

--ease-sig cubic-bezier(.2,.9,.3,1) 通吃全站微交互;氛围层分钟级(实锤)。

stamp-drop .42s

印章四帧物理:scale 2.3 → .93(过冲)→ 1,rotate −12° → 2° → 0,亮度 1.5 → 1.55 → 1.15 → 1,配金辉 drop-shadow。

本页 demo 完整复现
thud .3s

盖章瞬间整张卡片下沉 2px 并微转 .15°——「桌子震了一下」。用在案卡、质检卡、雷达卡。

dust-fly .75s

盖章溅起墨尘:血红 3px 与黄铜 2px 圆点,随机 --dx/--dy 抛出,12% 处最亮后消散。

wax-breathe 3s / wax-fly .9s / bloom-out .8s

蜡封三连:金辉呼吸引导点击;蜡屑(三种多边形 clip-path)两段式飞散;红色辉光爆开。

sign-in .9s + sway 7s

门面挂牌先落下(−30px、−5° 入场),再以 −1.4° ⇄ 1.6° 永续轻摆——雨夜的风。

kick-wipe 1s steps(24)

打字机式擦除:例签以 24 步阶梯 clip-path 展开,像色带敲出来的。

rise-in .85s

标题行位移 26px + blur 5px → 0 的入场;H1 两行错峰 .2s 与 .34s。

band-lit / band-lit-final

办案手册的工位胶囊逐个点亮(铜色),最后一枚点成血红——流程走完,该结案了。

caret 1s steps(1)

所有打字文本共用的血红光标 ▌;汤面、真相、电报纸带、灵感纸条四处出现。

次级缓动:菜单沿用主站 cubic-bezier(.23,1,.32,1) 与卡片 cubic-bezier(.32,.72,0,1)(各 2 与 4 处,实锤);蜡屑专用 cubic-bezier(.16,.62,.42,1)。氛围:挂牌 7s、蜡封呼吸 3s、雨幕视频循环、42s 与 45s 级的环境长循环(样式表时长词频)。

06 签名效果 · 可跑复现

印章的物理，蜡封的仪式

全部使用真实印泥图、真实缓动与真实时序。

一、判语落章 — stamp-drop + thud + ink-dust

复现自 #case 的问题纸条链路

点击任一问题:印章 .42s 四帧落下(scale 2.3 → .93 → 1),卡片 thud 震 2px,溅出血红与黄铜墨尘(随机 --dx/--dy)。印泥为四张真实素材,统一滤镜链 --stamp-ink。
