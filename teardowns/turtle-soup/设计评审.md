# 海龟汤事务所 拆解：设计评审

> 以顶级设计视角检验这份拆解的精度与完成度。

## 一、达标之处

1. **世界语言成立**：拆解页整体生活在事务所的夜黑纸暖里——真实颗粒（grain.webp overlay .14）、真实纸纹 multiply、血红印泥、黄铜细节、打字机例签与手写旁注，与被拆对象同气连枝。
2. **逐屏走查完整**：九屏一屏一账（用户要求的核心），每屏配真实渲染截图（长屏多点取样共 15 张）、站点原文引文、数值 chips 与实现注记，全部可回溯。
3. **签名效果是「可玩的」**：印章物理（四帧落章、桌震、墨尘）与蜡封亲启（呼吸辉光、蜡屑两段抛物、红辉爆开、双图切换）两个 demo 用真实印泥图、真实信封素材、真实缓动与时序复现。
4. **实锤与推断分级**：Vite（推断）与 Lenis（实锤）不混写；打字速率这类近似值明确标注。

## 二、相对原站的取舍

- **400vh 剧场未做成滚动驱动 demo**：走查区以三张关键拍截图 + 结构注记呈现；在拆解页内再造一个滚动接管容器会与页面自身滚动冲突，属有意取舍。
- **传送带自动模式（is-conveyor）与 --par 视差斜率**未实测标定，文档如实注明。
- **门牌点灯**只在走查里讲解，未做 demo（实现是两行 filter 过渡，代码块已给全）。
