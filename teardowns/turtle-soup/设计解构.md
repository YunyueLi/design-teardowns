# 海龟汤事务所（imlagom.com/projects/turtle-soup/）设计解构

> 抓取于 2026 年 7 月 30 日，Chromium 148，1440×900 @1.5x。**实锤** = 计算样式、样式表原文、HTML 与资产直读；**推断**单独标注。它是 Lagom 主站「案卷柜」第一格抽屉对应的完整产品页，拥有独立的导航、字体与世界观。

## 一、世界观

- 站点自述（hero 原文，实锤）：「一人一桌一盏灯，AI 主持的海龟汤推理游戏。汤，永远新鲜。」
- **九屏 = 一条侦探社的空间动线**（推断，文案连续性证据强）：门面（雨夜）→ 先喝一口（试玩案）→ 为什么开所（好汤稀缺）→ 推门（铜牌点灯）→ 办案手册（400vh 剧场）→ 后厨（出题流水线）→ 汤谱（每日一汤）→ 人事档案（生涯）→ 挂号信（蜡封 CTA）。
- 左下角常驻「侦破进度」HUD，五档文案（实锤）：迷雾重重、初见端倪、渐入佳境、胜券在望、真相在握——滚动进度被叙事成破案进度。
- 技术底盘：Vite 构建（`./assets/index-*.js` 命名，推断）、Lenis 平滑滚动（运行时探针，实锤）、Cloudflare beacon（实锤）；页面脚本打包后 160,322 B；样式 53,103 B；**六段视频**、42 张图、5 支自托管字体（实锤）。

## 四、动效

- 签名缓动 `--ease-sig: cubic-bezier(.2,.9,.3,1)`（实锤）；次级沿用主站 `(.32,.72,0,1)`（4 处）与菜单 `(.23,1,.32,1)`（2 处）；蜡屑专用 `(.16,.62,.42,1)`。
- **18 个 keyframes（实锤，逐个读出）**：sign-in（挂牌落位）、sway（挂牌 7s 摇摆）、kick-wipe（例签 steps(24) 打字机擦除）、rise-in（标题 26px + blur 5px 入场）、rain-in（雨幕 1.4s 淡入）、qa-in、stamp-flash（盖章闪光）、stamp-drop（印章四帧物理：scale 2.3→.93→1、rotate −12°→2°→0、亮度过冲）、thud（卡片下沉 2px 微转 .15°）、dust-fly（墨尘 12% 峰值抛散）、caret（血红 ▌ steps(1)）、pin-in（拍立得钉入）、band-lit 与 band-lit-final（工位胶囊点亮，末枚转血红）、wax-breathe（蜡封金辉 3s 呼吸 .14⇄.6）、wax-fly（蜡屑两段式 55% 关键帧）、bloom-out（红辉 scale .3→1.55）、np-wash（与主站共享）。
- 时长分布（样式表词频，实锤）：微交互 .2 到 .9s；氛围 3s、5s、7s、8s、9s；长循环 18s、24s、32s、42s、45s。

## 五、九屏逐屏（细节见 teardown.html 走查区，全部实锤）

1. **#hero 门面**：三层媒体（街景图 + 街景视频 1.55MB + 雨幕视频 1.22MB screen 混合 .5）；挂牌真图 + 牌面字 8.2cqw 容器单位 + `--par` 视差 + sign-in/sway；H1 clamp(56px,9.5vw,128px)；双层暗角。
2. **#case 先喝一口**：纸卡 34px 渐变折角；汤面打字（血红 caret）；6 问纸条 → 四种真实印泥图落章（是、不是、是也不是、无关；每枚不同 rotate 与高度微调）；stamp-drop + thud + ink-dust；真相顶 2px 血线打字；判语图鉴错峰 `--i×.13s`；附汤碗视频（446,737 B）。
3. **#why 稀缺论**：空椅子图 opacity .55 + 100° 渐变压左；三行痛点铜线清单；`.lux-key` 关键词逐个点亮（.25 起，.8s）。
4. **#door 推门**：街景视频满屏；铜牌 filter `brightness(.42) sepia(.12)` → door-lit 1.6s 点灯 + 金辉 `drop-shadow(0 0 34px rgba(229,200,105,.3))`；登记簿引言纸条 rotate −.6° 浮起。引文：「进来吧，先生 / 女士。外头雨大，先在簿子上留个名。我们这儿，只接来历不明的怪谈。」
5. **#play 办案手册**：外层 400vh、内层 sticky 100dvh；拍（beat）绝对叠放按滚动切换；判语回执纸（「主持人只盖四种章：是、不是、是也不是、无关。」）；软木板 + 三张拍立得 pin-in（边框 6px 纸白 + 26px 底）；结案 SVG 大章 mix-blend multiply rotate −7°；工位胶囊 band-lit 逐亮；移动端降级为 IO 逐拍。
6. **#kitchen 后厨**：**html.kitchen-dim 全页压灯**（fixed 遮罩 `#0604028c` z-39，台面 z-41）；台面图双层（blur 18px 光晕 + 上下渐隐实景）；六工位（构思、建档、组装、质检、盲解、修复）scroll-snap 传送带（虚线 `#b8996899`）+ is-conveyor 自动传送模式；质检卡三关（规则、审查、盲解）铜圈章逐落，「合格」double 边框大章；数据文案：「盲解这一道关，把多解的检出率从 7% 提到了 64%」；手写旁注「这道关，是我立的」。示例汤：「雨夜，出租车司机看了一眼后视镜，随即把车开进了河里。」
7. **#soups 汤谱**：视差横幅（inset −12%、高 124%）；报纸翻面（perspective 700px、rotateX 180°）读「雨停了，全城的伞却少了一把」；海报扇（hover ±12° 展开 + 竖排类目签 犯罪、恐怖、异闻 + 金辉光源 `--sx/--sy`）；点单条打字「灵感一句就够，别啰嗦」。
8. **#career 人事档案**：12 列拼贴——执照（−2.4°，手写代号「夜行者」）、主任批语（手写 30px）、五维雷达 SVG（敏锐、洞察、专注、胆识、韧性；fill `#8b744052`、stroke 2.5px；右上 58px 双圈血红等级章）、回形针小票（铜皮回形针 = `border-radius:46% 54% 48% 52%/60% 46% 58% 42%`）、小卖部（铜币）。
9. **#join 挂号信**：信封完好/开裂双图；蜡封热区 clamp(96px,24%,190px) 金辉呼吸 + 龙藏体「亲启」；点击 → 12 片蜡屑（三种 clip-path 多边形、三档红）两段轨迹 + bloom-out 红辉 + thud + 图切换（有视频时换开蜡实拍 265,691 B，env-has-video）；信纸 45° 血红丝带（双 inset 高光阴影）+ 手写落款 + 落章。

幕间：**摩斯电报带**分隔条（两侧 `repeating-linear-gradient` 铜色点划线 + 中央纸带打字机逐字打出）；页脚旋钮回顶（hover 上浮左转）。

## 六、工艺与无障碍

- 颗粒：真实 `grain.webp` 480px 平铺、opacity .14、mix-blend overlay、z-60（盖过一切内容，胶片感统一）。
- 纸纹：`paper.webp` 多尺寸复用（720/600/560/500/320/220px 六档 background-size 对应不同纸物件，实锤）。
- 印章滤镜链 `--stamp-ink: saturate(1.65) contrast(1.4) brightness(.86) drop-shadow(0 0 0 …)` 统一四章色泽。
- 站主自备 `html.static-capture` 模式：一键关闭全部动画并强制所有终态（用于截图或预渲染，实锤）——罕见的工程自觉。
- 无障碍：`:focus-visible` 铜色 2.5px；蜡封热区可聚焦并有 aria-label；打字文本配 sr-only 完整文案（case-qa 隐藏区）；`prefers-reduced-motion` 未见全局覆盖规则（见《设计评审》改进项）。

## 七、关键发现

1. **印章是一套完整的物理系统**：落章（四帧过冲）+ 桌震（thud）+ 墨尘（dust-fly）+ 闪光（stamp-flash），四个 keyframes 协同，一次点击四重反馈。
2. **全页压灯**只用两层 z-index 与一块 fixed 遮罩，没有 mask、没有 canvas——聚光灯的最便宜实现。
3. **视频三层叠加**（图 + 循环视频 + 雨幕 screen 混合）让「雨夜」可降级：任何一层失败画面都成立。
4. **进度条叙事化**：五档破案文案把「你滚到哪了」变成「案子破到哪了」。
5. **材质全部实图**（纸、颗粒、软木、台面），CSS 只做混合与裁切——质感上限由摄影素材决定，这是与主站（CSS 造质感）完全不同的路线。
