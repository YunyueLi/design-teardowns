# JourneyPilot（imlagom.com/projects/journeypilot/）设计解构

> 抓取于 2026 年 7 月 30 日，Chromium 148，1440×900 @1.5x。**实锤** = 计算样式、样式表原文（647 行展开通读）、HTML 与资产直读；打包 JS（168,460 B）按类名、字符串与结构反推，标注为推断处单列。

## 一、世界观：复古航空海报里的一台真仪表盘

- Hero 原文：「你的旅行，背后有一支机组。」副题：多智能体旅行规划——「一支研究编队为你并行调研、逐条核证、反复打磨，直到一份句句有出处的行程送到你面前。」
- **十一屏 = 一次航程**：出发大厅（hero + 出发信息板）→ ch1 编队起飞 → ch2 双引擎 → ch3 计划门 → 幕间「已批准。编队爬升中。」→ ch4 句句有出处 → ch5 记忆 → 幕间「巡航高度。目的地临近。」→ ch6 成稿 → ch7 引擎盖下（放行单）→ arrival 降落盖邮戳。
- **阅读值机系统**（实锤，样式与 JS 字符串）：第一章附近有一张奶油色登机牌「领取」按钮（`.pass-claim`，−1.4° 斜放、虚线打孔）；点击后一个 fixed 的 `.pass-fly` 层把牌「飞」到右下角驻留为 `.pass-stub`（284×68，pass-stub.webp 纹理）；每读完一章盖一格章，`.ps-toast` 弹「已盖章 · 值机」；卡面可展开（pass-card.webp）。进度条被改造成收藏欲。
- 视觉基因：复古航空平面（靛蓝夜空、奶油纸、橙徽、窄体大写、圆形邮戳、虚线航迹）+ 全部装置真实可操作（翻牌、播放暂停刮擦、拨杆、版本机、盖章）。
- 底盘：Vite（推断）、Lenis（探针实锤）、3 段幕间视频懒加载（`data-src`，实锤）、1 处 canvas 2d（JS 含 star 字符串，推断星空或帧绘制）、Cloudflare beacon（实锤）。

## 二、色彩（:root 原值，实锤）

| 族 | 值 |
| --- | --- |
| 夜空四档 | `--navy #0D1F3C`、`--navy-2 #12294B`、`--panel #0A1830`、`--panel-deep #071224` |
| 纸与字 | `--cream #F2E9D8`、`--cream-dim #C9BFA9`、`--slate #8CA3BF`、`--ink #071224` |
| 强调 | `--orange #E4571F`、`--orange-soft rgba(228,87,31,.16)` |
| 线 | `--line rgba(242,233,216,.16)`、`--line-soft rgba(242,233,216,.09)` |

规律：暗界面全部层级只靠奶油两档加蓝灰一档；线是奶油的透明度而非新色；橙唯一强调（selection 也是橙底藏青）；ch7 放行单整块反转为奶油亮面板——全页唯一亮区。

## 三、字体（实锤）

| 角色 | 字族 | 说明 |
| --- | --- | --- |
| 正文与大标题 | 系统黑体栈（SF Pro Display、PingFang SC 等） | H1 实测 102px、字重 **760**（可变权重）、字距 −1.02px |

| 仪表数字 `--font-digits` | Archivo Narrow 600（自托管子集 13,920 B） | 统计带与放行单大数；`tabular-nums` + `font-kerning:none` |

## 四、动效（实锤）

- 主缓动 `--ease-out cubic-bezier(.16,1,.3,1)`；回弹 `(.34,1.56,.64,1)` 只给拨杆旋钮（.18s）。
- 6 个 keyframes：`kburns`（首屏 2.8s，scale 1.07→1）、`flapTick`（.1s，rotateX 0→−86°→+86°→0，JS 半程换字）、`gatePulse`（1.1s 橙环 .6→1.7，70% 处 .25，复用作邮戳墨圈）、`flIn`（日志行 .45s 浮入）、`rise`（hero 四档延迟 0/.12/.24/.38s）、`flash`（1s 橙底闪褪，数据变更）。
- 入场双轨：hero 用 rise 动画，正文用 IO `.reveal`（`--rv-y/--rv-d` 参数化）。
- **刮擦免动画纪律**：`.scrubbing` 下航线、站点、日志全部 `transition:none!important`、动画直接终态——拖拽多快都不拖影。
- 描线统一 `pathLength="1"` 归一（dasharray 与 dashoffset 都是 1），不量真实路径长度。

## 五、十一屏逐屏（详见 teardown.html 走查区）

1. **出发大厅**：Ken Burns 开镜；出发信息板（栅格 92px/1fr/84px/118px；翻牌格背景中缝 1px 奶油线；active 行橙字）；双层云带（alpha 通道图，一层 scaleX(−1) 镜像）；`take-frames` 类可把背景切换为帧序列层（canvas 接管，推断用于滚动序列）。
2. **ch1 编队起飞**：调度剧场——播放、暂停、mono 时钟、相位刮擦轨（`--fill` scaleX、hover 增粗）；左日志 flIn 逐行，右 SVG 航线 seg 描线 .9s、站点转橙、计划门与风险门 gatePulse；实时计数行（地点落图、工具调用、引用来源、全程用时）；八人机组名册，悬停浮职责卡（thea-card，−50% 定位翻转 below 变体）。
3. **ch2 双引擎**：物理拨杆（轨槽内阴影、橙旋钮、回弹）切 fast/deep；飞行剖面 SVG（快答低弧一点、深研高弧五点 .14s 步进）；快答卡带来源行；深研卡编队扇形描线。原文：「低空短途，1 次直答；高空长航，4 名研究员。」
4. **ch3 计划门**：企划单（虚线票头、三步、角色标注）；偏好 chips 选中转橙；审查注记「本次无高风险建议，免审放行」；「已批准」橙描边大章 1.6→1 落定（rotate −9°），approved 态锁卡。
5. **幕间一**：「已批准。编队爬升中。」编队图 + 懒加载循环视频。
6. **ch4 出处**：行程节选内 claim 点线句 ↔ 右侧来源卡 lit（橙描边 + 左移 6px + 新鲜度徽章「官方核验」「上周核验」）；degraded 句表示来源缺失。
7. **ch5 记忆**：记忆开关切换同题两答；含花生餐厅划除 + 「已排除」橙标 + 替补推荐 flash；「这次回答中包含了六层记忆」——SYSTEM、PREFERENCES、PORTRAIT、ANCHOR、FACTS、MESSAGES 六条量条逐层点亮。原文示例：「依据：家庭档案『孩子花生过敏』，你在三周前提到过。」
8. **幕间二**：「巡航高度。目的地临近。」舷窗图。
9. **ch6 成稿**：东京底图（chart-tokyo.webp 打底 + SVG 路线）五日二十一站；Day chips 切换（路线虚线转橙、站点亮、日卡与预算联动，总额 ¥19,080 flash）；**版本机**：四刻度物理滑轨拖点切 v1 至 v4，差异行 flash、白笔批注（mrev 7px 白描边）重画；拖拽期间 knob 无过渡。
10. **ch7 引擎盖下**：奶油放行单五行——RAG +105%、MCP 13 舱、CTX 6 层、SSE 逐事件、COST 每一步；右列 Archivo Narrow 大数、首行橙；技术数值带脚注上标，页尾 fine 区对应（营销页自带引用规范）。
11. **arrival 降落**：跑道图缓推 + 进近虚线；圆形邮戳（stamp-arr.webp）悬停 −4px，落章 −8° + 虚线着陆圈转实线 + gatePulse 橙墨圈；`landed` 状态才开放点击；页脚罗马数字 MMXXVI。

## 六、关键发现

1. **值机登机牌是「进度条游戏化」的完成度天花板**：领取、飞行入坞、逐章盖章、toast 反馈、卡面收藏，全链路道具化。
2. **翻牌字的半程换字**（49% 帧换字符）用 .1s 一格加 30ms 错峰，声画感极强而实现极小。
3. **刮擦免动画**是所有可刮擦装置（剧场、版本机）的共同纪律——拖拽要的是标尺，不是动画。
4. **pathLength="1" 归一**让描线动画与路径几何解耦，改图不改动画。
5. **系统字大标题 + 微型海报字**：23KB 装饰字预算撑起整个复古航空气质，与海龟汤的「实拍材质路线」、EasyCode 的「书法批注路线」三分天下。
