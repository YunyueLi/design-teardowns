## 二、签名装置

### 1. 翻牌字（split-flap）

```css
.fcell{ display:inline-block; width:1.18em; text-align:center;
  font-family:var(--font-board); backface-visibility:hidden; border-radius:3px; padding:3px 0;
  background:linear-gradient(to bottom, var(--panel-deep) 49.5%,
    rgba(242,233,216,.1) 49.5%, rgba(242,233,216,.1) 50.5%, var(--panel-deep) 50.5%); }
.fcell.tick{ animation:flapTick .1s linear; }
@keyframes flapTick{ 0%{transform:rotateX(0)} 49%{transform:rotateX(-86deg)}
  51%{transform:rotateX(86deg)} to{transform:rotateX(0)} }
```

```js
// 半程换字 + 逐格 30ms 错峰
cells.forEach((cell, i) => setTimeout(() => {
  cell.classList.add('tick');
  setTimeout(() => cell.textContent = next[i], 50);     // .1s 的 49% 处
  cell.addEventListener('animationend', () => cell.classList.remove('tick'), { once:true });
}, i * 30));
```

要点：格子背景的 1px 奶油中缝就是「翻轴」；`backface-visibility:hidden` 防背面闪字。

### 6. 值机登机牌（结构要点）

- 领取按钮 `.pass-claim`：奶油底、−1.4° 斜置、左侧 2px 虚线打孔、hover 上浮。
- 飞行层 `.pass-fly`：`position:fixed` 的独立元素做 FLIP 式位移（起点 = 按钮矩形，终点 = 右下坞位），`pointer-events:none`。
- 坞位 `.pass-stub`：284×68、pass-stub 纹理、进度点；展开卡 `.pass-card` 网格盖章位。
- 章格提示 `.ps-toast`：坞位上方浮出「已盖章 · 值机」。

## 三、选型决策表

| 取舍点 | 它的选择 | 为什么成立 |
| --- | --- | --- |
| 大标题字体 | 系统黑体 760 可变字重 | 中文海报级标题零字体成本；装饰字只买 23KB |
| 描线动画 | pathLength="1" 归一 | 动画参数与路径几何解耦，改图不改代码 |
| 可刮擦装置 | scrubbing 全局禁过渡 | 拖拽是标尺不是演出 |
| 幕间媒体 | 底图先行、视频 data-src 懒加载 | 失败静默；弱网仍有完整画面 |
| 进度反馈 | 值机登机牌收藏系统 | 把「读完」变成「集邮」，重访有据 |
| 亮暗对比 | 全页唯一奶油亮面板（放行单） | 工程事实用「纸质工单」质感与营销层区隔 |

## 四、工程坑

1. 翻牌换字必须卡在 49% 帧（.1s 的 50ms 处），早穿帮晚闪烁；错峰 30ms 一格才有「哒哒」感。
2. `transform-box:fill-box` 是 SVG 环形脉冲的关键，漏写则以视口为原点缩放。
3. 拨杆或滑轨拖拽期间必须关闭过渡，松手才恢复——否则旋钮追手指。
4. 懒加载视频要在入视口时才赋 src，且 `muted loop playsinline`；失败保留底图即可。
5. tabular-nums 配 `font-kerning:none` 才能保证大数翻动不抖。
6. 值机牌的 fixed 飞行层结束后务必落到真实 DOM 坞位，别让 fixed 层常驻（滚动容器变换会漂）。
