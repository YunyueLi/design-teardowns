# JourneyPilot 拆解：出处与方法

## 一、抽取链路

| 步骤 | 做法 | 产物 |
| --- | --- | --- |
| 全量捕获 | `capture_site.py`（Playwright，Chromium 148，1440×900 @1.5x） | tokens.json、design-tokens.css、real-assets（18 图 + 2 字体 + 源码）、recording、keyframes、screenshots |
| 样式通读 | 647 行展开逐节读完 | 翻牌、剧场、拨杆、版本机、值机牌、邮戳的全部选择器级数值 |
| 脚本反推 | 打包 JS 168,460 B，按类名、字符串（值机、已盖章、编队起飞、免审放行等）与结构反推 | 装置状态机与文案；未逐行还原 |
| 逐屏截图 | 逐屏滚动触发后按 section 顶、尾取样 | assets/screens/ 共 13 张（11 屏，两长屏加拍） |
| 素材补抓 | 登机牌纹理两件（pass-stub 1,884 B、pass-card 20,622 B） | 值机系统素材齐备 |

## 二、实锤清单

- 19 个 `:root` 变量、2 条贝塞尔（(.16,1,.3,1) 与 (.34,1.56,.64,1)）、6 个 keyframes 及全部关键帧值：tokens.json 与样式原文。
- 十一屏结构（hero、ch1 至 ch7、两幕间、arrival）、全部引文（含放行单五行、六层记忆名、二十一站名、幕间两句）：HTML 与分节抽取。
- H1 计算样式 102px / 字重 760 / 字距 −1.02px；body `rgb(13,31,60)` 底 `rgb(242,233,216)` 字，系统字栈：运行时探针。
- 出发信息板栅格 92px/1fr/84px/118px、翻牌格中缝渐变、flapTick ±86°、gatePulse 三帧、刮擦禁过渡、pathLength 归一描线、拨杆 60px 位移与回弹曲线、版本机四刻度、放行单奶油反转、邮戳 landed 门与 −8° 落章：样式原文。
- 值机系统全链路类名与文案（pass-claim、pass-fly、pass-stub、pass-card、ps-toast、「已盖章 · 值机」）：样式原文 + JS 字符串。
- 两支海报字子集（9,064 与 13,920 B）、18 张图、登机牌纹理：落盘 + manifest。
- 幕间三段视频为 `data-src` 懒加载：HTML 原文。

## 三、推断清单

| 推断 | 依据 | 置信 |
| --- | --- | --- |
| Vite 构建 | `./assets/index-<hash>.js` 命名 | 高 |
| canvas 用途为星空或帧序列 | JS 一处 getContext("2d") + 多个 star 字符串 + `take-frames`/`hero-frames` 类 | 中 |
| 值机牌飞行为 FLIP 式位移 | fixed 飞行层 + 起终点元素存在 | 中高（轨迹参数未实测） |
| 「一次航程」叙事意图 | 幕间文案与章节推进 | 高（意图类） |

## 四、局限

1. 打包 JS 未逐行还原；剧场每相位的时长、刮擦步进等运行参数未实测标定。
2. 三段幕间视频未触发下载（懒加载），以底图与 HTML 属性为证。
3. canvas 绘制内容未逐帧还原。
4. `chart-theater.webp` 与 `chart-tokyo.webp` 两张手绘底图未落盘（超出抓取配额），manifest 无其 URL 记录，仅在 CSS 中见引用。
5. 移动端真机未实测。

## 五、复算口径

- 「十一屏」= `<section>` 计数（两幕间与无 id hero 计入）。
- 「6 个 keyframes」= 样式表唯一名计数。
- 「23KB 装饰字」= 9,064 + 13,920 = 22,984 B。
- 放行单数值（+105%、13 舱、6 层等）为站点自述的产品工程指标，本拆解引用为页面文案而非独立验证的性能数据；站点自身以脚注标注口径。
