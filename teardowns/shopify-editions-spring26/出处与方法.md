> 每一类数值怎么来的、哪些实锤、哪些推断、还有什么没拿到。

## 二、实锤清单（直接抽取）

- **色**：`#090909` 与白/黑两阶透明度全表；`--color-theme-*` 语义变量在 dark / light 两态的全部取值；焦点 `#0062d3`、错误 `#e21c1c`；门户 `#adf0ff`（JS 常量 173/240/255）；tokens.topHex 词频
- **字**：三支自托管字体的文件与字节（National2 woff2 35,180 / ttf 44,860；ShopifyInter woff2 21,872 / ttf 21,848；Inter Variable woff2 67,188——落盘 6 个文件，其中 Inter 那支被两个前缀各存了一份，实为 5 个不同文件）；`ss01` 开启；`:lang(ja)` 切 NotoSansJP；全部字阶 clamp 原式与 `text-box: trim-both cap alphabetic`
- **布局**：容器 105rem；四档内边距 16/32/120/0；沟槽 16/32；6→12 列；产品卡 `col-span-6 → sm:3 → md:4` 与 `grid-cols-subgrid`；章头列宽；`h-svh` 与 `160lvh`；七个断点与按高度组合的自定义查询
- **滚动**：`@property --scroll-reveal` + `animation-timeline: view()` + `animation-range: entry 75% 100%` + `step-start` 全套原文；Lenis 五参数与 `1.001 − 2^(−10t)`；10 次 wheel 事件率 >50/s 判触控板、duration .1 / .75、2000ms 超时兜底；章节进度与 transition 公式；`data-section-transition-exit-scale`、`data-section-screen-offset-center-progress`
- **WebGL**：13 份场景预设的相机（position/target/fov/mobileFov/pointerInfluence/scrollDrift）、点云（sources、pointSize、maxPointSize、maxPoints、randomize、densityFill、opacity、blendMode）、flow（type/layout/conveyor 全字段）、fluid（八项）、caustics、colorCorrections、postprocessing、volumetric、videoLightVolume；点着色器尺寸链与剔除阈值原文及其注释；SDF 六形状枚举与 hero torus 参数；流体库默认值；转场四 pass 与 `scrollBendY` 原文
- **字环**：`heroRingTheatreControls` 的默认常量组；烘进 bundle 的 7 个字形（E v e r y w h）曲线数据、band 结构与字体度量（ascender 983 / descender −263）；hero sheet 里 `Ring / *` 五组静态覆写全字段；CSS 版 `.hero-ring` 与两支 keyframes 原文
- **Theatre**：hero sheet 长度 10、subUnitsPerUnit 30、14 个静态对象、8 个带轨对象、27 条轨、50 个关键帧（Python 复算）；其余 12 份同法枚举
- **点云格式**：mdpc-2 头字段实测，含 `encoder: mdpc-lab.quick.shopify.io`
- **分级**：`?tier=` 覆写、默认 deviceTier 3、四条 0 分支、`downgradeTier` 的三个不降条件、`__S26_FORCE_TIER_0__`
- **药丸与卡片**：全部 CSS 自定义属性与时长；`grid-template-rows: 0fr → 1fr`；34ms 倒序错位；`data-merch-open` 隐藏
- **彩蛋**：门户平面尺寸与位置、`window.open` 尺寸公式、`spring-webrtc-signaling` 与 `spring-popup-sync` 频道名、12 种消息名、`DRIVE_STATE` 字段、速度线阈值、时间倍率区间与 750ms 复位、race-track 预设、CMS 两个开关
- **口径**：`<article>` 219（正则计数）与 loaderData 产品总数 219（求和）互证；HTML 中 `150+` 出现 6 次、`100+` 出现 1 次

## 三、推断清单

| 推断 | 依据 | 置信 |
| --- | --- | --- |
| National 2 出自 Klim Type Foundry；ShopifyInter 为 Inter 的定制版 | 字族名与字形特征 | 中高 |
| 「点彩的世界」等三条视觉母题 | 点云内容、字环三重书写、色彩克制 | 高（意图类） |
| `x_mj-10-pointcloud` 系列部分来自 AI 生成图像的三维化 | 文件名中的 `mj` 与编号形态 | 中 |
| KTX2 帧纹理用作场景内屏幕内容 | 命名 `_50f_…_etc1s.ktx2` 与 `combined_13sources_92f` | 中高（URL 与命名实锤，用途为推断） |
| `knockout` 卡让三维层与 DOM 媒体互相挖空 | `LayerKnockoutPass` 存在且 CMS 有布尔字段 | 机制实锤，视觉效果为推断 |
| Tailwind 具体为 v4.3.3 | 样式表头注释 | 高（注释自述） |

## 四、局限（没拿到什么）

1. **JS 未全量读**：85 个引用 chunk 读了 22 个，另读 10 个动态 chunk，共 32 个。未读的多为 three.js/r3f 运行时、通用组件与 polyfill；场景、转场、字环、彩蛋、分级、滚动这六条主线的 chunk 均已覆盖。
2. **彩蛋未实测**：Developer 门户与 `/drive` 弹窗的跨窗 WebRTC 装置全部自源码读出，本轮**未打开弹窗实跑**，因此没有双窗握手的实测证据。
3. **点云只抽 3 份**：13 份预设引用的 `.mdpc` 只落盘 3 份（hero 的 256/512 与共用的 minipointcloud-256），用于验证格式头与体量；其余按预设 URL 记录未下载。
4. **KTX2 未解码**：18 个帧纹理只记录 URL、命名与尺寸档，未取回也未转码。
5. **软渲染截图**：tier 3 一轮走 SwiftShader，点云与后处理逐帧正确，但帧率不代表真机手感；流体的鼠标注入未在截图中体现。
6. **手机与真机未实测**：`mobileFov`、移动端 tier 上限 1、手机视差 `view-timeline` 均来自源码。
7. **Storefront 未下单**：merch 面板的价格来源与加购 URL 自源码读出，未发起真实购买。
8. **外部研究未启用**：无奖项、访谈或制作团队信息核验；本站判断全部落在源码与 CMS 数据这一个证据面上。

## 五、复算口径

- 「219 张产品卡」= HTML 中 `<article` 出现次数 219，与 loaderData 里 24 个 products 数组求和 219 互证；官方营销口径「150+ updates」与 shopInfo 里残留的「100+ updates」并存，三个数字都保留，不混用。
- 「6.5 万 / 26.2 万点」= mdpc 头 `N` 字段，256² = 65,536、512² = 262,144。
- 「渲染上限 161,001–629,000 点」= 13 份预设的 `maxPoints` 极值；它大于源点数，因为开启 `densityFill` 时会再画一遍带抖动的副本。
- 「hero 50 个关键帧」= 对 state JSON 递归收集 `keyframes` 数组后求长度和；27 条轨同法。
- 「fov 50–120」「curl 1.5–6」等区间 = 对 13 份预设逐份取值后求极值，不是估计。
- 「85 / 32 / 22 / 10」= HTML 内 `.js` 绝对 URL 去重计数、`source/js/*.pretty.js` 文件数、两集合交集与差集。
