# Shopify Editions Spring ’26 拆解：设计评审

> 评审对象：本目录 teardown.html 与五份文档。视角：以被拆对象自身的高度（Shopify 半年一届的旗舰发布站，上一届拿到 Awwwards SOTD + Developer Award）为标尺，检验拆解的精度与完成度。

## 一、达标之处

1. **针对性视觉成立**。拆解页生活在 Everywhere 的语言里：`#090909` 一底、白的透明度阶梯当全部层级、彩色只留给点云与产品图；三支真字体本地接入（National2 的 `ss01` 开着、ShopifyInter 走正文、Inter Variable 走标签）；标题带 `text-box: trim-both cap alphabetic` 与原站的负字距；首屏那个环是 CSS 兜底版本人，用原站的 102° 起手、−295° 落点、4.5s 入场接 150s 自转；整站的进场用原站那套 `animation-timeline: view()`，一行 IntersectionObserver 都没写。

2. **抽到了「数据即内容」这一层**。这届最难讲清的不是某个效果，而是**前端只是解释器**：13 份场景预设、13 份 Theatre 状态、219 张卡、视频五路 source 全由 CMS 下发。拆解把 13 份预设逐份解析成一张可比对的表（fov、pointSize、maxPoints、flow、fluid 八项、bloom），把 hero 的 Theatre 状态解析到 27 轨 50 帧，于是「设计师改一个 JSON 就能改时间轴」这句话是有证据的，不是感想。

3. **点云格式拆到了字节**。MDPC-2 的头被真正解开——`N`、`qpPos 12`、`chromaSub 8`、`bbox`/`fitBounds`、四段 deflate 长度，还有那行 `encoder: mdpc-lab.quick.shopify.io`（说明它出自 Shopify 内部工具链，不是通用格式）。《复刻指南》二之 4 给的是能直接跑的解码骨架，不是格式描述。

4. **一个环、三种实现的对应关系被打通**。GPU 矢量字形（字形缓存里只有 E v e r y w h 七个真字形）、CSS 3D 兜底、SVG 控制台版——三者共用 `.35` 字号比例、18° 倾角与 102° 起始角，而半径、时长、错位各有一套。这层「同一个设计，三套实现，共享哪几个常量」是本站最见功力的地方，也是最容易被写成「有个环」的地方。

5. **对抗审查动真格**。九处漂移当场改正并在《事实核查》留痕，其中三处改变了结论的量级或性质：JS 精读规模从无出处的「102 个 chunk」改为可复算的 85/32/22/10；粒子数从「6.5 万到 26 万」拆成「源点数」与「渲染上限 16.1 万–62.9 万」两个口径；流体六项参数区间全部重算（原区间取自部分预设）。另外主动记录了两处**没有定论**的事实——同一份 state 里两组冲突的指针排斥参数、以及九种布局枚举里只有两种在用——而不是挑一组写死。

## 二、相对原站仍差在哪（体裁取舍说明）

- **WebGL 舞台没有整套复现**。原站是 13 个 r3f 场景 + 流体 + SDF + 四种转场的完整管线；拆解页起了一个 WebGL 上下文，但只跑「点云 + SDF 环推开粒子」这一段（用真实解码出的 hero 点云，256 档 65,536 点），流体与后处理以参数表和逐章截图呈现。在文档型页面里重建整条管线会喧宾夺主。
- **彩蛋只有源码没有实测**。Developer 门户 → `/drive` 弹窗的跨窗 WebRTC 装置，12 种消息名、`DRIVE_STATE` 字段、速度线阈值、时间倍率区间全部读出来了，但本轮**没有打开弹窗实跑**。上一届 Winter ’26 的 `/key` 是双窗实测走通的，这一届没有——这是本次拆解相对上一届最明确的缺口，已在《出处与方法》四第 2 条与《设计解构》十显式声明。
- **KTX2 帧纹理未解码**：18 个纹理只记录了 URL、命名与尺寸档，用途仍是推断。
- **Rive 状态机未驱动**：Retail 的 POS 演示记录了状态机名与四个触发器，未加载 `.riv` 实跑。
- **无外部研究**：没有奖项、访谈或团队信息。本站的全部判断落在源码与 CMS 数据这一个证据面上，这一点被显式声明，而不是靠含糊带过。

## 四、一句话结论

这份拆解把 Everywhere 最难讲清的三件事——「CMS 下发一切、前端只做解释器」的架构、MDPC-2 点云从字节到屏幕的完整链路、以及同一个字环在 GPU / CSS / SVG 三处共享哪几个常量——拆到了可回溯、可复刻的程度，并在复核中纠正了三处量级性错误、保留了两处诚实的存疑；最明确的缺口是彩蛋只读源码未双窗实测，比上一届的 `/key` 少了一层实证。
