## 二、七个签名做法的复现

### 1. 滚动揭示：不用 JS，用 `view()` 时间轴

原站整站的进场都靠这一段。触发器是一个只在 `entry 75% → 100%` 区间用 `step-start` 把自定义属性从 0 拨到 1 的动画；子元素读这个属性走普通 transition，因此可以各自错位。

```css
@property --scroll-reveal{syntax:"<number>";inherits:true;initial-value:0}
@keyframes scroll-reveal-trigger{to{--scroll-reveal:1}}
.scroll-reveal-trigger{
  animation:step-start both scroll-reveal-trigger;
  animation-timeline:view();
  animation-range:entry 75% 100%;
}
.scroll-reveal-item{
  opacity:calc(var(--scroll-reveal));
  translate:0 calc((1 - var(--scroll-reveal)) * 1rem);
  transition:opacity .5s linear, translate 1s var(--ease-out-cubic);
  transition-delay:calc(var(--scroll-reveal-index, 0) * .1s);
}
```

要点：`inherits:true` 是关键——触发器挂在容器上，属性沿树往下传，子元素不需要各自带时间轴。`step-start` 让属性只有 0 和 1 两态，真正的缓动交给 transition，于是回滚时也能平滑倒放。

### 2. Everywhere 字环（CSS 版，tier 0 与减弱动态的兜底）

```css
@keyframes hero-ring-intro{

  to{transform:rotateX(var(--ring-tilt)) rotateY(var(--ring-to))}
}
@keyframes hero-ring-ambient{      /* 接力：从 --ring-to 再走一整圈 */
  0%{transform:rotateX(var(--ring-tilt)) rotateY(var(--ring-to))}
  to{transform:rotateX(var(--ring-tilt)) rotateY(calc(var(--ring-to) - 360deg))}

.hero-ring-letter{

```

字母就位与擦入分两条时间线：

```js
// 30 个字母 = "Everywhere" × 3；θ 均分 360°
const R = '37vmin', SIZE = 'calc(37vmin * .35)';
letters.forEach((el, i) => {
  const word = Math.floor(i / 10), idx = i % 10, theta = i * (360 / 30);
  el.style.setProperty('--letter-from',
    `translate(-50%,-50%) rotateY(${theta - 14}deg) translateZ(${R})`);
  el.style.setProperty('--letter-to',
    `translate(-50%,-50%) rotateY(${theta}deg) translateZ(${R})`);
  el.style.setProperty('--letter-delay', `${word * 600 + idx * 55}ms`);  // 就位 .65s
  el.style.setProperty('--reveal-delay', `${word * 600 + idx * 55 + 120}ms`); // 擦入 .3s
});
```

减弱动态：停在 60°，只做淡入，不转。

### 3. Everywhere 字环（WebGL 版，Slug 式矢量字形）

原站不用 SDF 也不用贴图，而是把 National2 的**二次贝塞尔控制点直接烘进 Float32 纹理**，片元里按带（band）做光线求交算覆盖率。字形数据就在 bundle 里：`curvesData`（扁平坐标数组）、`bandHeaders`、`bandRefs`，每个字形带 `bandCount 16`、`bandDimX/Y`、`bandsTexCoordX/Y`（横向按 32 步进），字体度量 `ascender 983 / descender −263`。

值得注意的是缓存里只有 **7 个字形加一个空字形**——`E v e r y w h`，因为「Everywhere」只用到这七个字母。

Theatre 覆写的动画常量（`state/hero-*.json` → `Ring / Animation`）：

### 4. MDPC-2 点云：130 KB 装 6.5 万点

自定义格式，`DecompressionStream` 就能解，不需要 wasm（brotli 编码时才懒加载 `brotli-wasm`）：

```js
// [4 字节小端头长][JSON 头][pos deflate][Y deflate][Cb deflate][Cr deflate]
const buf = await (await fetch(url)).arrayBuffer();
const headLen = new DataView(buf).getUint32(0, true);
const head = JSON.parse(new TextDecoder().decode(new Uint8Array(buf, 4, headLen)));
// head = {format:"mdpc-2", N:65536, qpPos:12, chromaSub:8, bbox:[...], fitBounds:[...],
//         codec:"deflate", posLen, yLen, cbLen, crLen, encoder:"mdpc-lab.quick.shopify.io"}

const inflate = async (slice) => new Uint8Array(await new Response(
  new Blob([slice]).stream().pipeThrough(new DecompressionStream('deflate'))
).arrayBuffer());
```

位置解码是三步：varint 增量 → 前缀和 → Morton 解交织 → 用 `qpPos = 12`（每轴 4096 级）与 `bbox` 反量化。颜色是 Y 全分辨率 + Cb/Cr 按 `chromaSub = 8` 子采样，再转 RGB。真实体量：`forest-1024-v3-moretrees` 的 256 档 65,536 点 137,491 B，512 档 262,144 点 508,600 B。

### 5. 点着色器的尺寸链（原式）

```glsl
float ps = uPointSize
         * max(uPointSizeScale, 0.001)
         * baseSize                      // rand⁴ 抖动 × splat × 距离 × 流生命
         * opaqueSizeScale
         * max(uDensityFillPointSizeScale, 0.001)
         * uDPR
         * (120.0 / max(dist, 0.1));
vProjectedPointSize = ps / uRenderScale;             // 归回屏幕像素再做剔除
gl_PointSize = clamp(ps, 0.0, uMaxPointSize * uRenderScale);
```

原站在这里留了注释解释为什么要除 `uRenderScale`：`ps` 是渲染目标像素，会随 renderScale 缩小，而片元里的最小尺寸剔除是**屏幕**阈值；不归一化的话，缩放动画进行时剔除会越收越紧，半透明的弱点会突然消失。片元丢弃阈值是投影小于 .55px。

SDF 碰撞最多 8 个形状，枚举为 `sphere 1 / box 2 / torus 3 / cylinder 4 / octahedron 5 / dodecahedron 6`；hero 的字环就是一个 torus（R .34、r .14、强度 .35、衰减 .5）。

```js
const DEFAULTS = { simSize:128, dyeSize:256, densityDissipation:.97,
```

### 8. 章间转场：swipe 的失谐 π

```glsl
// 与 knockoutShader 的 scrollBendY 逐字一致，这样切边能跟住挖空层的边
float scrollBendY(float x){
  float t = clamp(x, 0.0, 1.0);
  float arch = sin(t * 3.14159265);
  return (arch + sin(t * 3.1431853) * 2.0) * uScrollBendVUv;
}
```

第二个常数刻意比 π 大一点点（3.1431853），两条正弦缓慢错拍，切边因此不是对称拱形而是带轻微偏斜的活拱。四种 pass：swipe（默认方向 (−1, 0)）、crossfade、zoomBlur（柔度 .25、边缘辉光 .4、推进 .08）、hero 专用 wipe。转场读两层深度纹理，近者优先。

## 三、选型决策表

| 需求 | 原站做法 | 为什么 |
| --- | --- | --- |
| 整站滚动揭示 | `animation-timeline: view()` + `@property` | 不需要 IntersectionObserver，不占主线程；回滚自动倒放 |
| 十章三维场景 | 点云而非网格 | 点云可压到 130 KB、天然抗锯齿、且「无数点」正是 Everywhere 的隐喻 |
| 点云传输 | 自定义 MDPC-2 + `DecompressionStream` | glTF/Draco 要额外解码器；deflate 是浏览器原生，零依赖 |
| 场景编排 | Theatre.js state JSON 由 CMS 下发 | 设计师可脱离发版调时间轴；前端只做解释器 |
| 首屏标题 | GPU 矢量字形（Slug 式） | 环上字母要能被流体推、被 SDF 反推，位图字会糊 |
| 兜底标题 | 同一组常量的 CSS 3D 环 | tier 0 与减弱动态下仍是同一个设计，不是退化版 |
| 平滑滚动 | Lenis，且只在桌面细指针 | 触屏上抢原生滚动是负收益 |
| 平滑档位 | 先测 10 次 wheel 的事件率 | 触控板（>50/s）要 duration .1，滚轮要 .75，一个值伺候不了两种硬件 |
| 灯箱 | View Transitions API | 旧 contain / 新 cover，免手写 FLIP |
| 视频 | 每条 5 路 source × 双端 × 多宽档 | av01/hvc1/avc1 三格式覆盖全部浏览器，视口外卸载 source 省解码 |

## 四、工程坑

1. **`--scroll-reveal` 必须 `inherits:true`**。挂在容器上让子树共享一个时间轴；设成 false 每个子元素都得自带 `animation-timeline`，错位延迟就没地方挂了。
2. **`view()` 的 range 要用 `entry`**，不要用 `cover`：`cover` 从元素刚触底就开始，长块内容会在还没进视口时就把动画走完。
3. **点尺寸剔除要归回屏幕像素**（见上文 `/uRenderScale`），否则 renderScale 动画期间弱点会成片消失。
4. **swipe 与 knockout 必须共用同一支 `scrollBendY`**。原站把注释写在两处，任何一边改常数都会露出错位的边。
5. **`grid-template-rows: 0fr → 1fr` 需要子元素 `min-height: 0` 加 `overflow: hidden`**，否则内容会在收起时溢出。
6. **SSR 首帧要自己遮**。样式表以 `media="print"` 加载再换回 `all`，中间那一帧是无样式的；内联脚本立刻插一块 `#090909` 的 `#ssr-paint-cover`，1500ms / 8000ms 双兜底撕掉。
7. **tier 要能单向降**。`downgradeTier` 只在设备探测来源不是 default、且没有 `?tier=` 覆写、且当前不为 0 时才生效——防止运行时抖动把用户在 3 和 2 之间反复摔。
8. **拆字动画要留 `sr-only` 全文**，每个字符 span 加 `aria-hidden`；hero 退场后整块加 `inert`，否则键盘焦点会掉进看不见的标题里。
9. **`forced-colors` 与 `prefers-reduced-motion` 要分别覆盖**：前者关的是自绘图形，后者关的是运动；把两者写成一条会让高对比度用户失去所有内容。
10. **同一份 Theatre 状态里可能有两套同名覆写**。hero sheet 同时存在 `Ring / Animation`（旧的扁平键）与 `Ring / Animation / Pointer Repulse`（新的嵌套对象），两组指针排斥参数不同；复刻时要确认代码读的是哪一层，不要两组都套上。
