## 漂移清单与修正

1. **自定义变量数量**:页面此前写「自定义变量超过 120 个」,而实测抽取恰为 120 个(`_data` 的 `customProps` 长度 = 120)。已改为「自定义变量实测抽取到 120 个」,并补注 CSS 字节数「484,718 字节」。

2. **h1 字距**:线上 `probe.h1.letter-spacing = normal`,而页面首屏 h1 的 CSS 曾用 `letter-spacing:-.03em`(放大后的收紧偏移)。已把 h1 校准为 `letter-spacing:normal` 对齐实测;首屏字号仍作电影感放大(`clamp` 上限 90px),此为拆解页 display 处理,已在该规则旁注明。字重 600、取色 `rgba(255,255,255,.96)`(`--ink-96`)与实测一致,未动。

3. **像素等宽字体表述**:第一轮用 `Space Mono` 作 `Departure Mono` 的近似替身,且页面文案称「替身 / 刻意替换」。本轮已接入真实 `Departure Mono` 本尊(`@font-face` 引本地 woff2 / woff),`Space Mono` 降为 CDN 兜底。相关文案已同步更新:字体卡不再说「近似替身」;出处「推断」卡删去「Space Mono 替 Departure Mono」一句,改注「已换真实本尊」;页脚与出处段落一并校正。

4. **body 背景色**:token `--bg = #060608`,但 `probe.body.background-color` 实测为纯黑 `rgb(0,0,0)`。页面此前 `body` 背景取 `--bg`(#060608)。本轮把 `header` 背景显式设为 `#000`,并接入真实电影大图,首屏黑场与原站一致;色板中「画布纯黑 `#000000`(body 实际绘制)」与「近黑 `--bg #060608`(设计 token)」两条并列标注本就正确,保留。

## 说明性差异(非数值漂移)

- 拆解页导航高度 64px,而原站 `--official-header-height = 80px`。此为拆解页自身 chrome,并非对 tutti 的数值断言,不计漂移。
- 首屏版式取向差异(全幅背景 vs 原站居中卡片)属再创作,详见 `设计评审.md`。

## 「实锤 / 推断」标注复核

- 标「实锤」项(界面色、蓝紫全谱、暖纸白、字体规格、曲线次数、时长、圆角、玻璃参数、媒体计数、窗口红点)均可在 `_data/tutti.json` 或源样式表定位来源,标注正确。
- 标「推断」项(沙丘暖橙、窗口黄绿、前端技术栈、图像换态底层实现)无直接抽取来源,标注正确;其中 `libs` 抽取为空,故「未探测到具名库」表述准确。
- 本轮新增的真实素材(字体 / 电影大图 / shader 视频 / 产品截图)已在页面注明「从站点提取」,并指向 `real-assets/manifest.json`,标注正确。

结论:除上述 4 处已修正的漂移外,页面内其余色值、字体、缓动、时长、圆角、媒体计数与线上真实抽取逐条一致;「实锤 / 推断」标注全部核对无误。
