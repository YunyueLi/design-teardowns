## 2. 电影大图压标题加滚动视差(签名一)

分层叠场景,监听滚动给每层不同的位移速率。纯 CSS 星球与沙丘作氛围兜底,不依赖图片。

```css
.hero{position:relative;min-height:100svh;overflow:hidden;background:#000;isolation:isolate}
/* 蓝色星球:从右上切入 */
.hero .planet{position:absolute;right:-18vw;top:-10vh;width:70vw;aspect-ratio:1;border-radius:50%;
  background:radial-gradient(circle at 32% 30%,#2a3a8f 0%,#141a54 40%,#05070d 72%);
  box-shadow:inset 40px -20px 120px rgba(var(--glow),.35),0 0 200px rgba(var(--glow),.15)}
/* 橙红沙丘:铺满下缘 */
.hero .dune{position:absolute;left:0;right:0;bottom:0;height:42vh;
  background:linear-gradient(180deg,transparent,var(--warm-2) 60%,#3a1608);
  clip-path:polygon(0 62%,42% 40%,100% 70%,100% 100%,0 100%)}
.hero h1{position:relative;z-index:2;font:600 clamp(40px,7vw,86px)/1.05 var(--sans);color:rgba(255,255,255,.96)}
.hero h1 .hl{color:var(--accent)}   /* 关键词高亮 */
```

```js
/* 滚动视差:每层乘不同系数 */
const layers=[[".planet",0.18],[".dune",-0.10],["h1",0.06]];
addEventListener("scroll",()=>{
  const y=scrollY;
  for(const [sel,k] of layers)
    document.querySelector(sel).style.transform=`translate3d(0,${y*k}px,0)`;
},{passive:true});
```

鼠标视差同理,把 `scrollY` 换成指针相对中心的偏移即可,收尾统一用 `var(--ease)`。记得在 `@media (prefers-reduced-motion:reduce)` 里关掉。

## 3. 首屏图像换态:真实态到点阵态(签名二)

用 CSS 滤镜近似点阵/半调,两态叠放交叉淡入。

```css
.hero-img{position:absolute;inset:0;background-size:cover;transition:opacity .9s var(--ease)}
.hero-img.ascii{                     /* 点阵/半调中间态 */
  filter:grayscale(1) contrast(1.4) brightness(.9);
  -webkit-mask-image:radial-gradient(#000 1px,transparent 1.4px);
  mask-image:radial-gradient(#000 1px,transparent 1.4px);
  -webkit-mask-size:3px 3px;mask-size:3px 3px}  /* 纱网点阵 */
.hero-img[hidden]{opacity:0}
```

切换时切 `hidden`,`opacity` 走 `.9s var(--ease)`,对应真实关键帧 `hero-base-fade-out` 到 `hero-ascii-fade-in`。

## 6. 星形描边扫光(签名工艺)

给任意圆角容器加一道沿边跑动的锥形渐变光,纯 CSS,零图片。对应 `--onboard-*-star-border-*` 与 `onboard-message-center-star-border-path`。

```css
.star-border{position:relative;border-radius:16px;isolation:isolate}
.star-border::before{content:"";position:absolute;inset:0;border-radius:inherit;padding:2px;
  background:conic-gradient(from var(--a,0deg),
    transparent 0 42%,
    color-mix(in srgb,#5274ff 90%,transparent) 50%,
    transparent 58% 100%);
  -webkit-mask:linear-gradient(#000 0 0) content-box,linear-gradient(#000 0 0);
  -webkit-mask-composite:xor;mask-composite:exclude;   /* 只留边框一圈 */
  filter:drop-shadow(0 0 8px color-mix(in srgb,#5274ff 58%,transparent));
  animation:star-run 5.8s linear infinite}
@keyframes star-run{to{--a:360deg}}
@property --a{syntax:"<angle>";inherits:false;initial-value:0deg}
```

## 7. 暖纸白反转卡(明暗节奏)

## 8. 选型决策

| 元素 | 选型 | 理由 |
|---|---|---|
| 首屏宇宙场景 | 纯 CSS 星球加沙丘加 canvas 星场 | 完全可主题化、可视差,不锁死一张图 |
| 首屏氛围段 | 少量视频(全站仅 2 段) | 只在最需要电影感处用,其余交给 CSS |
| 图像换态 | CSS 滤镜加 mask 近似,交叉淡入 | 无需预生成多套位图 |
| 药丸与徽章 | 999px 加玻璃 backdrop-filter | 与主结构统一,轻量 |
| 扫边光 | conic-gradient 加 mask-composite | 纯 CSS,任意圆角可用 |
| 微交互 | CSS transition,统一 `0.2s var(--ease)` | 手感一致 |
| 氛围漂移 | CSS 长循环 16 到 72 秒 | 察觉不到却始终在动 |

## 9. 工程坑

- **暖橙是图像色不是变量**:界面强调色只用蓝紫 `#7f90ff`,暖橙留给大图与落日光。别把暖橙提成 UI 强调色,会破坏冷暖分工。
- **按钮圆角是 0**:主文字 CTA 用方角,圆角只给药丸类控件,别一刀切全圆角。
- **`backdrop-filter` 要带 `-webkit-` 前缀**,并给不支持的浏览器留一个半透明底兜底。
- **`prefers-reduced-motion`**:关掉视差、星场、呼吸、扫边光与图像换态自动循环。
- **字体授权**:Lexend 与 Departure Mono 均为免费开源字体(Departure Mono 走 SIL OFL,但不在 Google CDN,需自托管;开发占位可用 Space Mono 临摹终端气质)。
- **变量按区块拆分**:抄这套系统时,建议照它把变量拆到区块粒度(如 `--hero-*` `--pricing-*`),比一堆全局魔法数字好维护。
