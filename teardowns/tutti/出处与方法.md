# tutti · 出处与方法

## 来源

拆解对象:线上站点 <https://tutti.sh>(页面标题 `Tutti — Where People and Agents Build in Tune`,语言 en)。所有真实值来自对该线上页面的直接抽取,非应用包逆向。

## 抽取链路

1. **计算样式(playwright)**:用无头浏览器真实渲染页面,读取 `body`、`h1`、`nav`、按钮等关键元素的 computed style(背景、文字色、字体、字号、行高、字重、圆角、过渡曲线)。这类值是浏览器最终绘制值,最可靠。
2. **样式表文本(服务端抓取)**:直接抓取站点样式表原文(约 473KB,`cssBytes:484718`),不受 CORS 限制,从中统计:
   - CSS 自定义变量(`--*`)共 120 余个,含基底色、强调色、字体、圆角、缓动、以及大量按区块命名的尺寸变量。
   - 高频十六进制色值(按出现次数排序)。
   - 全部 `cubic-bezier(...)` 缓动曲线及出现次数。
   - `font-family` 引用及次数、`transition/animation` 时长梯度、`border-radius` 取值分布、`@keyframes` 名称。
3. **字体清单**:读取 `document.fonts`,得到真实加载的六款字体(Lexend Variable、Archivo Black、Inter、Merriweather、Poppins、Departure Mono)。
4. **媒体清单**:统计页面内 `video`、`canvas`、`svg`、`img` 数量。
5. **真实渲染截图**:`assets/actual-full.jpg`(整页)与 `assets/actual-hero.jpg`(首屏),以肉眼可见的真实渲染为准。另有 `keyframes/` 下逐屏滚动关键帧与 `recording/scroll.webm` 滚动录屏,用于还原视差与区块节奏。

抽取产物固化在 `teardowns/_data/tutti.json`,并据此生成 `teardowns/tutti/design-tokens.css`。

## 实锤与推断

**实锤(源自抽取)**

- 基底与文字色:纯黑 `rgb(0,0,0)`(body 计算值)、`--bg:#060608`、`--ink:#f2f2f6`、`--ink-dim`、`--ink-faint`、`--line`,以及高频色值统计。
- 蓝紫强调色全谱:`#7f90ff`(`--accent`)、`#aab2ff`、`#6a78ee`、`#5274ff`、`#5b69e6`、`#6d7ff5`,及 `--glow:127,144,255`、`--accent-bg`、`--accent-line`。
- 暖纸白 `#f3f1ea`(`--paper`)与纸上文字 `#0a0a0c`。
- macOS 窗口红点 `#ff5f57`(高频色值出现 3 次)。
- 字体:实际加载六款,主字 Lexend(`--sans` 引用 192 次),像素等宽 Departure Mono(`--pixel` 引用 42 次);h1 规格 58px/600/行高 68px/取色 `rgba(255,255,255,.96)`。
- 缓动曲线:主曲线 `cubic-bezier(.22,1,.36,1)`(52 次)、`cubic-bezier(.65,0,.35,1)`(16 次)、`cubic-bezier(.2,.84,.24,1)`(12 次)、`--feature-motion-ease:cubic-bezier(.22,.61,.36,1)`(4 次)。
- 时长梯度:按钮过渡 `0.2s`;短时长 `0.18s`/`0.52s`/`0.72s`/`0.9s`;长循环 `16s`/`18s`/`22s`/`25s`/`28s`/`42s`/`52s`/`72s`;星形描边 `5.8s`。
- 圆角分布:`999px`(82 次,主导)、`16px`/`14px`/`12px`/`8px`,按钮计算值 `0px`。
- 玻璃与光:导航下拉 `blur(14px) saturate(140%)`、`rgba(255,255,255,.08)`、投影 `0 18px 44px rgba(0,0,0,.36)`;星形描边用 `color-mix(in srgb,#5274ff ...)` 与 `drop-shadow`。
- 关键帧名称:`hero-base/ascii/shader/interactive-fade-*`、`onboard-home-demo-window-enter`、`onboard-home-demo-auto-cursor-move`、`onboard-message-center-star-border-path`、`application-icon-float`、`story-pill-dot-breathe`、`floaty`、`blink` 等。
- 媒体计数:svg 76、img 70、video 2、canvas 1。

**推断(公开观察或标准值补齐)**

- 沙丘地表的暖橙精确色值:非具名 CSS 变量,取自 hero 图渲染取色,标注为近似(约 `#b9552a` 到 `#e0824a`)。
- macOS 窗口黄点与绿点:抽取只锤到红点,黄绿按标准 macOS 交通灯值 `#febc2e`/`#28c840` 补齐。
- 前端技术栈:未探测到具名动画库(`libs` 为空),判断动效以手写 CSS 加少量脚本为主,属观察推断。
- 首屏"图像换态"的具体实现(是否用 WebGL 着色器、点阵是滤镜还是预生成位图):仅由关键帧名与截图中间态推断存在此手法,未逆向实现细节。
- 复刻页字体:主字用 Google Fonts 的 Lexend 本尊;像素等宽因 Departure Mono 不在 Google CDN,用 Space Mono 近似替身,已在文中注明,属刻意替换而非原字。

## 局限

- 只拆了首页公开渲染,未覆盖登录后的产品界面与多语言版本。
- 站点为线上动态页面,样式随发布可能变动;本包反映的是抽取当时的快照。
- 暖色系与图像内容属生成式大图,精确参数不可从 CSS 完全还原,复刻以气质对齐为准。
- 交互版 `teardown.html` 的电影视差、图像换态、macOS 窗口演示是用真实 token 与真实缓动**复现气质**,并非搬运站点源码。
