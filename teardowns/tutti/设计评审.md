# tutti · 设计评审(第二轮)

以顶级设计视角,评审这份拆解页相对原站 <https://tutti.sh> 的精度与完成度:已达标在哪、仍有差距在哪,并给出可执行改进。能当场改的已在本轮改掉,标注 [已做];需要更大改动的标 [建议]。

## 一、本轮已达标(精度提升)

- **字体同源**。主字 Lexend Variable、像素等宽 Departure Mono 都换成从站点提取的真实字体本尊,可变字重轴齐全。标题、正文、徽章标签、终端字与首屏 ASCII 的字形、字宽、字重过渡与原站同一来源,不再是 CDN 近似或 Space Mono 替身。这是本轮最大的一档精度提升。
- **首屏真材实料**。首屏接入真实电影大图 `official-home-hero-v1.webp`(历史名人与黑色人形围坐用笔记本、蓝色星球、橙色地表)与真实着色器视频 `official-home-hero-shader.webm`,替换掉第一轮的 CSS 星球 / 沙丘近似;冷暖对撞、点阵着色器质感都是原素材本身。CSS 场景保留为加载失败兜底。
- **图像换态签名可信**。签名区「首屏图像换态」的 base 态用真图、shader 态直接播放站点 shader 视频本尊,点阵态用 CSS 网点近似,换态演示从「用滤镜模拟」升级为「真素材切换」,与 `hero-base-fade-out → hero-shader-fade-in` 的真实关键帧对得上。
- **窗口裱框自洽**。macOS 窗口内改裱真实产品截图(AI canvas),与「产品截图裱进窗口」的论述一致,消除了第一轮「窗口里画的是宇宙场景、文字却说产品截图」的自相矛盾。红点 `#ff5f57` 实锤,窗口入场与自动光标保留。
- **token 逐值对齐**。色值、缓动曲线及出现次数、时长梯度、圆角分布均对齐实测;h1 字距按实测校准为 `normal`(详见 `事实核查.md`)。

## 二、相对原站仍有的差距(诚实评估)

1. **首屏版式取向不同**。原站首屏是「居中圆角卡片式」的电影画面:纯黑大留白托一块裱框大图,像影厅放映。本页把大图做成全幅背景 + 居中大标题的沉浸式处理。两者都成立,但气质有别——原站更克制、更「放映厅」,本页更「沉浸海报」。若追求 1:1,应改为居中卡片版式。
2. **换态节奏未完全复刻**。原站 base / ascii / shader 是自动定时的连续交叉淡入;本页首屏用真图常驻 + shader 视频低透明度叠加呼吸,仅在签名区提供手动三态切换,没有还原「自动连续换态」的时间节奏。
3. **排印克制度**。原站以 h1 = 58px 为准,整体排印克制;本页首屏放大到 `clamp` 上限 90px 追求海报感,与原站的克制略有出入(已注明为 display 处理)。
4. **shader 视频的浏览器兼容**。视频为 VP9 webm,Safari 老版本对 VP9 支持有限,可能只显示 poster 静帧。已用真图 poster + CSS 场景双重兜底,不会白屏,但动态着色器在这类环境下会退化为静态。
5. **暖橙沙丘无法进一步实锤**。原站无具名暖色变量,沙丘暖橙只能图像取色,精度到此为止(已标「推断」)。

## 三、可执行改进

- [已做] 主字与像素等宽换真实本尊;首屏接真实大图 + shader 视频;签名换态与窗口裱框改用真素材;h1 字距校准 `normal`;文案去除「替身」表述并指向 `real-assets/manifest.json`。
- [已做] 修正「自定义变量 >120」为实测 120 个;补注 CSS「484,718 字节」;`header` 背景设为纯黑 `#000` 对齐 body 实绘。
- [已做] `prefers-reduced-motion` 下暂停首屏 shader 视频、冻结呼吸动画与视差,只留真实大图静帧,尊重降低动效偏好。
- [建议] 若要更贴原站首屏,把 hero 大图改为「居中圆角卡片」版式:纯黑大留白 + 16 到 24px 圆角裱框 + shader 在卡内交叉淡入,更接近原站「影厅放映」母题。
- [建议] 给首屏 base 与 shader 增加自动定时交叉淡入(参照 `hero-base-fade-out → hero-shader-fade-in`,约 16s 一轮),复刻「连续换态」而非仅低透明叠加。
- [建议] 首屏大标题尺寸回收到更接近 58px 的克制刻度,保留原站排印气质。

## 四、总评

第二轮把「精度」的短板补齐了:字体与关键媒体都换成真素材,拆解页从「气质对、数值对、但媒体是近似」提升到「气质对、数值对、媒体也真」。剩余差距集中在**首屏版式的再创作取向**(全幅沉浸 vs 居中卡片)与**换态节奏的自动化**,均已在上面标为可选改进——属风格选择与工作量权衡,不属错误。数值层面已无未修正漂移。
