# tutti · 设计解构

> 站点 <https://tutti.sh> 的完整设计拆解。除特别标注,数值均来自对线上站点的真实抽取(playwright 计算样式加样式表文本),标注为**实锤**;来自肉眼观察渲染或公开资料的判断,标注为**推断**。抽取方法与局限见同目录《出处与方法.md》。
>
> 一句话定位:Where people and agents build in tune(人与智能体在同一实时共享工作空间里同频协作)。基调是纯黑电影感。

---

## 1. 两层设计:先分清,再复刻

tutti 的首页把两种气质叠在一起,复刻前要先拆开。

| | 电影营销层 | 产品界面层 |
|---|---|---|
| 载体 | 首屏超现实大图、星球与沙丘的宇宙场景、页脚的聚光剪影 | 裱进 macOS 窗口框的产品截图、应用轨道、玻璃描边控件 |
| 基调 | 电影级打光、冷暖对撞、渺小人形对广袤地景的叙事张力 | 克制、深色、圆角柔和、玻璃质感 |
| 手法 | 大标题压在场景上加滚动视差、图像在真实照片与点阵态之间切换 | 窗口入场动画、自动光标演示、应用图标漂浮环绕 |
| 时间尺度 | 慢速氛围漂移,16 到 72 秒的长循环 | 敏捷微交互,180 到 900 毫秒 |

**复刻目标等于营销层的电影语言乘以产品层的克制。** 首页的叙事逻辑是:先用一张广角宇宙大图把"人与智能体同处一地"讲成一个画面,再把这份电影感注入一个个真实可用的产品界面。

## 2. 色彩系统

### 2.1 基底与文字(实锤,源自计算样式与 CSS 自定义变量)

| 名称 | 值 | 角色 | 来源 |
|---|---|---|---|
| 画布纯黑 | `rgb(0,0,0)` | body 实际绘制底色 | 计算样式 `body.background-color` |
| 近黑 token | `#060608` | 设计变量 `--bg`,比纯黑略带一点冷 | 自定义变量 |
| 深空蓝黑 | `#05070d` | 星球区块底层 | 高频色值第 5 位(出现 8 次) |
| 蓝黑 | `#080b1c` | 星球场景背景 | 高频色值(出现 3 次) |
| 面板黑 | `#0b0b10` `#16161c` | 卡片与叠层 | 高频色值 |
| 主文字 | `#f2f2f6`(`--ink`) | 正文与标题 | 自定义变量,计算样式一致 |
| 标题白 | `rgba(255,255,255,.96)` | h1 实际取色 | 计算样式 `h1.color` |
| 次级文字 | `#9c9caa`(`--ink-dim`) | 副标题、说明 | 自定义变量 |
| 弱文字 | `#61616b`(`--ink-faint`) | 脚注、占位 | 自定义变量 |
| 描边线 | `rgba(255,255,255,.1)`(`--line`) | 分隔线、卡片边 | 自定义变量 |

### 2.2 冷色:蓝紫星球光谱(实锤)

这是 tutti 的品牌强调色,也是"build in tune"高亮词、玻璃描边、星球边光用的色。它是一支偏蓝的紫,通常叫长春花蓝(periwinkle)。

| 名称 | HEX | 角色 | 来源 |
|---|---|---|---|
| 主强调 | `#7f90ff` | `--accent`,高亮关键词 | 自定义变量,高频色值第 4 位 |
| 强调亮 | `#aab2ff` | `--accent-soft`,浅态强调 | 自定义变量 |
| 强调深 | `#6a78ee` | `--accent-2` | 自定义变量 |
| 星轨蓝 | `#5274ff` | 引导星形描边基色 | `--onboard-agent-star-border-color` |
| 深靛蓝 | `#5b69e6` | 高频色值第 3 位(出现 13 次) | 样式表统计 |
| 中间蓝 | `rgb(109 127 245)` 即 `#6d7ff5` | 消息中心星形描边色 | `--onboard-message-center-star-border-color` |

发光基数以 `--glow:127,144,255` 存放,即把 `#7f90ff` 拆成 RGB 分量,方便在阴影里写 `rgba(var(--glow),...)` 复用同一束光晕。强调底与强调线固定为 `rgba(127,144,255,.12)` 与 `rgba(127,144,255,.3)`。

### 2.3 暖色:沙丘地表(推断)

冷暖对撞里的"暖"来自首屏那片橙红色的沙丘地表与落日光。它不是一个具名 CSS 变量,而是大图与径向渐变里的颜色,所以精确色值为**推断**(从渲染取色近似)。代表值大约在 `#b9552a` 到 `#e0824a` 的落日橙区间。页脚背景遮罩用的却是冷色 `rgba(3,6,15,.16)` 到 `rgba(3,6,15,.34)`(实锤,`--bottom-design-bg-overlay-*`),可见暖色是刻意只交给图像、界面结构保持冷调,冷暖的分工很清楚。

### 2.4 暖纸白:反转的浅色卡片(实锤)

定价区把卡片翻成暖纸白,压在深蓝黑底上,制造一处明亮的呼吸点。

| 名称 | HEX | 角色 | 来源 |
|---|---|---|---|
| 暖纸白 | `#f3f1ea` | `--paper`,浅色卡片底 | 自定义变量,高频色值 |
| 纸上文字 | `#0a0a0c` | 浅卡上的深色字 | `--t-btn-fg` / `--t-bar-fg` |
| 按钮白 | `#f2f2f6` | 主按钮底 | `--t-btn-bg` |

### 2.5 macOS 窗口交通灯(部分实锤)

产品截图裱进窗口框,左上角三个圆点。红点 `#ff5f57` 是**实锤**(高频色值出现 3 次);黄点与绿点抽取里没单独锤到,按标准 macOS 值 `#febc2e` 与 `#28c840` 补齐,标注为**推断**。

## 3. 字体系统

### 3.1 实际加载字体(实锤,源自 `document.fonts`)

线上真实加载了六款字体:Lexend Variable、Archivo Black、Inter、Merriweather、Poppins、Departure Mono。但按样式表里的实际引用次数,主力只有两三款。

| 角色 | 字体 | 引用证据 | 来源 |
|---|---|---|---|
| 全站主字(标题与正文) | **Lexend Variable** | `--sans` `--display` `--heavy` 都指向它,引用 192 次,占绝对主导 | 计算样式与变量 |
| 像素等宽(标签与 ASCII) | **Departure Mono** | `--pixel`,引用 42 次 | 变量与加载清单 |
| 局部正文 | Inter | 引用 56 次 | 样式表统计 |
| 衬线点缀 | Merriweather | 引用 10 次 | 样式表统计 |
| 圆润标题点缀 | Poppins | 引用 6 次 | 样式表统计 |
| 超粗展示 | Archivo Black | 引用 2 次(疑似 logo 字标) | 样式表统计 |

### 3.2 大标题规格(实锤,h1 计算样式)

字号 58px,字重 600,行高 68px,字距 normal,取色 `rgba(255,255,255,.96)`。全部用同一个 `--sans` 家族,没有单独的衬线大标题——tutti 把电影感交给图像和打光,而不是靠花哨的字体,这一点和很多用衬线撑场面的站点不同。

### 3.3 关键词高亮(实锤观察)

大标题里把动词短语单独换成强调色 `#7f90ff`(例如"build in tune"整行变蓝紫),其余保持白色。这是整站唯一的文字彩色,克制且精准,呼应星球的冷光。

> 本页复刻用 Google Fonts 上的 **Lexend** 本尊承接主字;像素等宽 **Departure Mono** 是开源字体(SIL OFL)但不在 Google CDN,故用 **Space Mono** 作近似替身承接终端标签气质,并在文中注明。

## 4. 动效系统

### 4.1 双时间尺度(实锤,源自 duration 统计)

tutti 把两种速度叠在一起,和它两层设计正好对应。

- **敏捷微交互**:按钮过渡固定 `0.2s`;另有 `0.18s` `0.52s` `0.72s` `0.9s` 一组短时长,负责悬停、焦点、切换的即时手感。
- **电影级慢层**:`16s` `18s` `22s` `25s` `28s` `42s` `52s` `72s` 一组超长循环(其中 18 秒出现 27 次、72 秒出现 17 次),负责星场漂移、图标漂浮、星球呼吸这类几乎察觉不到在动却始终在动的氛围层。
- **中间层**:`2s`(出现 37 次,最高频)多用于呼吸与脉冲;`3s` `4s` `9s` 用于中速循环。

### 4.2 签名缓动曲线(实锤,源自样式表 cubic-bezier 统计)

| 曲线 | 值 | 出现次数 | 用途 |
|---|---|---|---|
| 主曲线(快出长尾) | `cubic-bezier(.22,1,.36,1)` | 52(两种写法合并) | `--ease`,位移与淡入淡出的默认曲线,按钮过渡即用它 |
| 对称进出 | `cubic-bezier(.65,0,.35,1)` | 16 | 需要匀称加减速的过渡 |
| 柔出 | `cubic-bezier(.2,.84,.24,1)` | 12 | 更轻的收尾 |
| 功能缓动 | `cubic-bezier(.22,.61,.36,1)` | 4 | `--feature-motion-ease`,功能卡片开合 |

主曲线 `cubic-bezier(.22,1,.36,1)` 是绝对主力,冲出快、尾巴长,是"高级顺滑"的那种手感。本页所有过渡都用它运动,让页面像它拆解的对象一样运动。

### 4.3 关键帧母题(实锤,源自 `@keyframes` 清单)

抽取到的关键帧名字直接暴露了签名手法:

- **首屏图像换态**:`hero-base-fade-out` 到 `hero-ascii-fade-in` 到 `hero-shader-fade-in` 到 `hero-interactive-fade-in`——首屏大图会在真实照片、点阵化(ASCII/半调)、着色器三种渲染态之间淡入淡出。真实首屏截图 `assets/actual-hero.jpg` 抓到的正是那张被点阵化、罩上纱网质感的中间态,而 `assets/actual-full.jpg` 里是彩色的真实态。
- **窗口入场**:`onboard-home-demo-window-enter` 配 `onboard-home-demo-auto-cursor-move`——macOS 窗口滑入,再由一个自动光标演示点击。
- **星形描边**:`onboard-message-center-star-border-path`——沿卡片或药丸边缘跑一圈锥形渐变光,时长 `5.8s`。
- **应用漂浮**:`application-icon-float` 配 `application-mode-use-out` 与 `application-mode-build-in`——应用图标环绕窗口缓慢漂浮,并在"用应用"与"造应用"两个模式间切换。
- **细节呼吸**:`story-pill-dot-breathe`(徽章里的圆点在呼吸)、`floaty`、`blink`(终端光标闪烁)、`hero-download-spinner`。

## 5. Hero 手法与签名视觉母题

### 5.1 电影大图压标题加滚动视差(签名一)

首屏是一整块宇宙场景:右侧一颗巨大的蓝色星球从画面外切入(冷),底部一片橙红沙丘地表铺满下缘(暖),沙丘脊线上坐着一个渺小的人影,面前一盏台灯与一台电脑。大标题"Where people and agents build in tune"压在场景中央,"build in tune"整行换成蓝紫强调色。往下滚动时,星球、沙丘、星场、文字以不同速率位移,产生纵深视差。这套手法把产品的抽象主张(人与智能体同处一地)变成一张一眼即懂的电影画面。

另有一版首屏(`assets/actual-full.jpg` 上部)把多位历史名人形象与黑色人形并排围坐在一张桌前,各自用着笔记本电脑,身后同样是蓝色星球与橙色地表——超现实、电影级打光,强化"人与智能体共事"的隐喻。

### 5.2 图像换态(签名二)

首屏大图不是一张静态图,而是在三种渲染态之间过渡:彩色真实照片、点阵半调化(带纱网/CRT 质感)、着色器态。切换用 `hero-*-fade-*` 一组关键帧完成。这既是视觉噱头,也暗示产品把真实与生成揉在一起的气质。

### 5.3 产品裱进 macOS 窗口框(签名三)

所有产品截图都裱进一个 macOS 窗口框:左上角红黄绿三个交通灯圆点,顶部一条标题栏,窗口以圆角收边。窗口入场有滑入动画,内部还有自动光标演示点击。窗口里通常是同一套宇宙场景(蓝色星球、由 ASCII 字符拼出的 @ 符号、坐在星球斜坡上的小人),把产品界面也浸在电影感里。

### 5.4 玻璃描边药丸(签名四)

导航右侧的 Waitlist、首屏的两枚 CTA、右下角的语言切换、首屏那枚"a real-time shared workspace"徽章,全是 999px 全圆角的玻璃药丸:半透明白底、细描边、背景模糊。徽章左侧还有一个会呼吸的小圆点(`story-pill-dot-breathe`)。

### 5.5 应用轨道(签名五)

"应用活在 tutti 里"一节,产品窗口四周漂浮着一圈应用图标(文档摘要、AI 文档、群聊、自动化任务等),沿轨道缓慢浮动(`application-icon-float`,`--orbit-size:58.681cqw`),下方有"Use Apps / Build Apps"分段开关,切换时图标在两个模式间过渡。

## 6. 工艺细节

- **圆角语言**:999px 全圆角出现 82 次,是绝对主导——药丸按钮、徽章、标签、头像全用它;卡片用 `16px`(`--radius`)、`12px`、`8px`、`14px` 一档;定价浅卡与页脚卡用 `8px`(`--bottom-design-card-radius`)。有趣的是按钮的计算圆角是 `0px`,说明主 CTA 用的是方角文字按钮,圆角只留给药丸类控件。
- **玻璃**:导航下拉用 `blur(14px) saturate(140%)` 加半透明白底 `rgba(255,255,255,.08)` 加投影 `0 18px 44px rgba(0,0,0,.36)`(实锤,`--official-header-dropdown-*`)。药丸控件同款玻璃。
- **星形描边光**:引导控件的边缘跑一圈锥形渐变光,用 `color-mix` 把 `#5274ff` 与透明按比例混,配 `drop-shadow(0 0 8px ...)` 的辉光,光带长度 `clamp(88px,18%,160px)`,周期 `5.8s`。这是很值得学的一手:不用图片,纯 CSS 就能给任意圆角容器加一道扫边光。
- **暖纸白反转卡**:深色站里插入 `#f3f1ea` 的浅色卡片(定价区),深色字压浅底,制造明暗节奏。
- **媒体选型**:整页 SVG 76 个、图片 70 张、视频 2 段、画布 1 个。可见矢量图标与静态大图是主力,视频只用在少数关键氛围段,画布很可能是星场或某段生成式效果。没有探测到常见前端动画库,动效基本是手写 CSS 加少量脚本。
- **体量**:抓到的 CSS 约 473KB(`cssBytes:484718`),自定义变量超过 120 个,命名高度语义化(`--official-*` `--onboard-*` `--application-*` `--terminal-free-*`),说明这是一套按页面区块精细拆分、变量驱动的设计系统。

## 7. 关键发现

1. **电影感靠图像与打光,不靠字体。** 全站只有一个 `--sans`(Lexend)家族撑标题和正文,没有华丽衬线大标题。仪式感来自超现实大图、冷暖对撞、渺小人形的叙事,以及慢速氛围层。
2. **冷暖分工明确。** 蓝紫是唯一的界面强调色(实锤色变量),暖橙只交给图像和落日光(推断色),连页脚遮罩都用冷色。这让页面在浸满暖调大图时,界面结构依然冷静统一。
3. **首屏大图会换态。** `hero-base/ascii/shader/interactive` 一组关键帧证明首屏不是静态图,而是在真实照片、点阵化、着色器之间过渡,真实截图恰好抓到点阵中间态。这是公开观察容易漏掉的一层。
4. **一颗光晕拆成 RGB 分量复用。** `--glow:127,144,255` 把强调色拆开存放,配合 `color-mix` 与 `rgba(var(--glow),...)`,让同一束蓝光在描边、辉光、底色里反复出现,成本极低。
5. **变量按区块精细拆分。** 从 `--official-home-story-columns` 到 `--application-orbit-icon-size`,变量命名精确到每个区块的每个尺寸,是一套工程化程度很高的、可维护的设计系统,而不是散落的魔法数字。

> 交互版见同目录 `teardown.html`,含可跑的电影视差首屏、图像换态切换、macOS 窗口框演示、真实缓动曲线实验台与色板点击复制。
