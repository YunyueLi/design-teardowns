### 2. 顶点着色器（扫描线 + 故障，可直接使用）

```glsl
attribute vec4 pointMoreData;               // active/size/layer/delay
uniform float scanLineY1, scanLineY2, scanLineY3;  // 每层一条
uniform float scanLineWidth;                 // 20
uniform bool  isActive;
uniform vec4  glitchEffects0, glitchEffects1, glitchEffects2, glitchEffects3;

float scanY = (layer==2.) ? scanLineY2 : (layer==3.) ? scanLineY3 : scanLineY1;
float band  = scanY - delay;
float d     = abs(band - position.y);
vColor = (d>0. && d<scanLineWidth) ? vec3(1.,1.,.2) : vec3(.8,.8,.8);
float range = 100.;
if (isActive) {                     // 点亮：带上方未达的点渐隐
  if (position.y > band)
    alpha = (d>=range) ? 0. : clamp(cos(d*3.1415926/(range*2.)),0.,1.);
} else {                            // 熄灭：带下方的点碎落
  if (position.y < band) {
    newPosition.y -= 0.05*d*d;
    alpha = (d>=range) ? 0. : clamp(cos(d*3.1415926/(range*2.)),0.,1.);
  }
}
vAlpha = 0.6*alpha*distanceAlpha*(-0.25*layer+1.25)*pointActive;
// 故障：8 条屏幕空间水平带
for (int i=0;i<4;i++){ /* 每 vec4 携两条带 (y,强度) */
  if (abs(mvPosition.y-g.x)<10.) mvPosition.x += 20.*g.y;
  if (abs(mvPosition.y-g.z)<10.) mvPosition.x += 20.*g.w;
}
gl_PointSize = size*pointSizeScale*distanceAlpha + 4.0;
```

## 四、选型决策表

| 需求 | 原站选择 | 为什么 |
| --- | --- | --- |
| 地标全息 | 预烘焙点云 + 裸 Float32 | 「工业感」的实体化；零解析成本、无 glTF 依赖 |
| 点亮仪式 | 扫描线三层 + 激光 + 故障 | 仪器开机的叙事；全部顶点着色器内完成，CPU 零参与 |
| 特效浮层 | 亮度抠像视频 | 一条 mp4 携 alpha，跨端最稳 |
| 滚动 | 自研全屏分区 + hash | 章节制叙事不需要连续滚动 |
| 适配 | rem 图纸缩放 | 比例恒定的「制图」哲学；国产浏览器逐 UA 特判 |
| 时序 | anime.js | 轻量、够用（对数延迟、easeInOutQuad） |

## 五、工程坑

1. **点数上万必须做 pixelRatio 降级**（原站 renderLevel 2 → 0.75），否则低端独显直接掉帧。
2. **双缓冲 actor**：切换期间绝不改在播几何——两套 geometry 交替 setAttribute。
3. **激光用实例池**，只改 attribute 不增删对象；`progress=0` 即隐藏。
4. **float16 传点云**可再省一半（本拆解 demo 即 float16），但要自写解码（JS 无原生 f16 读取，Safari 的 Float16Array 尚新）。
5. **requestVideoFrameCallback 的 Android 兼容**：UA 检测回退 rAF，否则部分国产 WebView 永不触发。
6. **鸿蒙系 viewport**：DPR 重写要写在 rem 计算之后，且 orientationchange 时节流重算。
7. **裸 .bin 无校验**：原站以 try/catch + 空数组兜底（「加载二进制文件失败」），复刻时至少校验 byteLength % 12。
