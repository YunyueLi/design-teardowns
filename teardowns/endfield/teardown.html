Positioning

定位与设计意图

《明日方舟：终末地》官网（v4，当前版本主题「向渊行 · 武陵决战篇」）。它是游戏工业美学的门面：白纸黑字的工程制图 + 荧光黄警示 + 点云全息。整站像一份被扫描进终端的纸质技术档案——纸的部分用印刷语言（套印错位、警示条、图例编号），屏的部分用仪器语言（点云、扫描线、故障）。

意图证据
工业制图感黄底分隔带里的螺栓爆炸图、图标轨、REC 括号、编号 1/31（实锤：截图与 CSS 模块名）
印刷套印错位品红 #ff1aac 与荧光绿 #00ffa2 的错位描边与三色条（实锤：CSS 词频 6/9 处）
仪器全息E.P.S 点云 + 扫描线 + 激光束 + 故障位移（实锤：着色器原文）
命名即宣言：点云系统在控制台自称 [E.P.S]（打印性能测试与画质分级日志）。六个地标模型 spaceship（帝江号）、anchor、factory、pile、trinity、enemy 以裸 Float32 二进制下发——不是 glTF，不是 Draco，是最朴素的 xyz 流。快、小、无依赖，这是把「工程味」贯彻到传输层的选择。
营销层 vs 产品层：官网只做「世界观陈列 + 预下载转化」；账号、支付、社区走 SDK 与独立系统（hg-account-web-sdk 实锤）。左轨与底部下载矩阵永远在场——所有戏剧性都服务于「前往游戏」。

E.P.S Point Cloud

点云系统全解剖 · 签名装置

Lore 章的六座地标（1/6 帝江号起）是全站的心脏。它不是「图片转粒子」——而是预烘焙的 3D 点云：六个裸 Float32 二进制（合计约 218,441 点、2.6MB），运行时归一化到高 1900 的舞台，由三条扫描线逐层点亮，扫描期间天花板向扫描带附近的点投下激光束。

数据为真实 anchor.bin 的 3,000 点降采样样本（float16，研究用途）；归一化数学与原站 setup 相同（AABB → 高度 1900 → 居中）。渲染管线与原站同构：顶点/片元着色器逐行照抄（羽化点精灵 coreRadius .1 / featherWidth .1、内辉光 .6、Reinhard 压缩 mix .5、非对称暗角中心 x=0.4、层级 alpha (−0.25·layer+1.25)×0.6、点径 size×scale×distA+4、带内变黄 vec3(1,1,.2)、故障带 ±10 视图空间 y × 位移 20），混合为 three.js AdditiveBlending 同款 blendFunc(SRC_ALPHA, ONE)、depthWrite 关。扫描期间天花板（x∈{−3000,400,3000}, y=2000）向带 ±40 内的真实点发射激光：噪声调制、尾部渐隐、次线强度 0.4——池 240（原站 renderLevel 分档 500–2000，等比缩）。仅剩差异：无 benchmark 三档降级。

Luminance Keying

自研 @hg-web/trans-video 亮度抠像

你猜的「黑白分明的图转坐标」在这套系统里应验了一半：Hypergryph 确实把黑白亮度变成透明度——但用途是让特效视频镂空浮在页面上（WebGL 逐帧 keying），而非生成粒子坐标。库名自曝：[@hg-web/trans-video]。三种模式原样复现：

亮度抠像三模式（getBrightness = .3R + .59G + .11B）着色器原文逐行复现 · 素材为合成示意（原站为 FX 视频帧）
SOURCE 左右拼装（video 模式）
KEYED 合成结果
LUMINANCE 模式（自身亮度 + uReverse）
video 模式：一条视频里左半是彩色、右半是黑白遮罩（另有 right-left / top-bottom / bottom-top 四种拼法，实锤），片元同时采样两个半区：gl_FragColor = vec4(color, brightness(mask))。luminance 模式直接用自身亮度当 alpha（uReverse 反相）。渲染循环用 requestVideoFrameCallback（Android 回退 rAF），WebGL 不可用时退 Canvas2D getImageData 逐像素——三条路径全部在源码里。
套印故障字（glitch 带位移的 CSS/JS 复现）带宽 ±10 · 位移 20px×强度 · 3–6 连发 × 80ms——参数取自 E.P.S 故障调度器
EndfieldEndfieldEndfield
品红/荧光绿双层错位 = 印刷套印失准的数字化。原站把同一逻辑用于点云（顶点着色器里 8 条水平故障带）与 DOM 装饰（flashing 关键帧）。悬停触发。

Verdict

评审结论

终末地官网的杀手锏是「把游戏的工业世界观翻译成 Web 的仪器语言」：预烘焙点云 + 扫描线 + 激光 + 故障，全部自研自持（连噪声都不引库）；而印刷层的套印错位与荧光黄警示，让屏幕看起来像一张被扫描进终端的图纸。五份文档：设计解构 · 复刻指南 · 出处与方法 · 事实核查 · 设计评审
