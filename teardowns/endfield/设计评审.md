# Arknights: Endfield 官网拆解：设计评审

> 评审对象：本目录 teardown.html 与四份文档。标尺：这站的核心价值在自研工程（E.P.S 与 trans-video），拆解必须拆到「可独立重建」的深度才算配得上。

## 一、达标之处

1. **针对性视觉成立**。拆解页是终末地的语言：档案黑 + 制图白 + 签名黄警示带、左侧图标轨、黄底分隔带、品红/荧光绿套印错位、方角切角按钮——与原站同一车间出品。
2. **签名装置用真数据复现**。E.P.S 点云剧场加载真实 anchor.bin 的降采样样本（3,000/7,484 点，float16），扫描线三线时序（3000/(i+1)、2000·ln(i+1)、滞后 200）、带内变黄、cos 衰减、碎落公式、故障连发、拖拽/自转/惯性、切换冲刺 ×20——全部原值可交互验证。这不是「像」，是同一套数学在跑。
3. **把用户的假说核查成了结论**。「黑白图转坐标」被精确地拆成两半：亮度→透明度的管线真实存在（trans-video 三模式全文），但服务于视频抠像；点云坐标来自预烘焙二进制。拆解页同时给出两台 demo，让两条管线各自现形。
4. **深读到了别人读不到的层**：着色器中文注释、Reinhard 反过曝、非对称暗角（中心 x=0.4）、`[E.P.S]` 自检日志、鸿蒙系 viewport 重写、裸 Float32 传输层——这些是打开 DevTools 看不见、必须逐行才有的发现。
5. **版权处置克制**：完整点云挡在公共仓外（.gitignore），公共仓只携带降采样研究样本；商业字体同规。

## 二、相对原站仍差在哪（体裁取舍说明）

- **demo 为 Canvas 2D 投影**，非 three.js Points + 着色器：少了羽化点精灵、加法混合的辉光堆积与 500–2000 条激光束（参数已全部记录，《复刻指南》给了逐段配方）。
- **抠像 demo 素材为合成示意**：原站的 FX 视频未落盘（懒加载未触发 + 版权考虑），管线逐行复现、素材以程序合成替代（已标注）。
- **H5 竖屏版**未走查。
- 干员页/日历页的次级交互（轮播细节、2D/3D 切换动画）以走查记录为主。

## 四、一句话结论

这份拆解把终末地官网最值钱的两件自研——E.P.S 点云仪式与 trans-video 亮度抠像——拆到了逐行可重建的程度，并用真实数据把核心装置搬进了拆解页本身；剩余差距集中在 three.js 级的完整复现与移动端走查，属完成度加分项而非精度缺口。
