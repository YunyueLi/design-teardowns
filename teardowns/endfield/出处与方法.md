## 二、实锤清单

- **色**：topHex 词频（#191919 84 / #fff 77 / #fffa00 56 / #d9d9d9 21 / #35373c 15）；CSS 中 #ff1aac（6）与 #00ffa2（9）；着色器 vec3(1,1,.2) 与 vec3(.8,.8,.8)
- **字**：15 个字体文件落盘（Novecento Bold/Medium、Gilroy ExtraBold、Protest Strike、Roboto Black 等）；fontsLoaded 探针 18 族；@font-face 原文（latin 部分）
- **E.P.S 全部参数**：六模型 binarySrc/offset/pivot/scale/雾距/laserMode 装配表；pointMoreData 四维口径；扫描线三条的时长/延迟/起止（3000/(i+1)、2000·ln(i+1)、−1150→1350/1150、显示滞后 200）；带宽 20、衰减 range 100、掉落 0.05·d²；层级 alpha (−0.25·layer+1.25)×0.6；点径 4–8 + 保底 4；故障 16 float 打包、带宽 ±10、位移 20px、连发 3–6×80ms、循环 4–6s；激光池 1000、天花板 x∈{−3000,400,3000} y=2000、目标 ±40、生命周期 (0.5+rand)×400ms、次线强度 0.4；benchmark 10,000 点/800×600、阈值 60/30ms、三档激光与像素比；相机 fov 75/(0,300,2000)/横竖屏 lookAt；渲染高 1080；拖拽 0.01、自转 0.005、lerp 0.1、切换冲刺 ×20（400ms→800ms 回落）；Perlin fBm 3 倍频 256²；`[E.P.S]` 控制台日志原文
- **trans-video 全部**：库名 console.warn 原文；三模式片元全文；亮度系数 .3/.59/.11；四种拼装 rect；三级降级链；requestVideoFrameCallback + Android UA 回退；blendFunc(SRC_ALPHA, DST_ALPHA)
- **布局**：rem 缩放公式与 2560×1440/1080×1920 画布；鸿蒙系 viewport 重写；九屏 CSS 模块名；唯一自定义贝塞尔 (1,0,.7,1)；加载页模块（progress/core/symbol）
- **文案**：h1 探针「核心章节版本向渊行武陵决战篇焕新相见 共赴新章」；帝江号简介（截图）；干员页字段结构（截图）
- **中文注释**：「=== glitch效果 ===」「亮度压缩插值，防止高密度过曝」「镜头暗角」「网络请求失败」「加载二进制文件失败」——原文照录

## 三、推断清单

| 推断 | 依据 | 置信 |
| --- | --- | --- |
| 点云由游戏 3D 模型离线采样烘焙 | 数据形态（均匀表面采样、无索引）、地标与游戏场景一致 | 高 |
| 中文字族为 HarmonyOS Sans 系或等价定制 | SDK 注入 + 代码内鸿蒙 UA 密集特判；未取到字体文件 | 中 |
| anime.js 为时序库 | targets/easing/complete 调用形态与包体特征 | 高（形态） |
| 滚轮切换约 1s 级 | 实测观察（截图会话 hash 变化节奏），未从源码定位到常量 | 中（实测） |

## 四、局限

1. **中文 webfont 未捕获**：SansMedium 系由 SDK 运行时注入，九份 CSS 无其 @font-face；拆解页中文用系统栈替身（已标注）。
2. **63874443 异步 chunk（495KB）未逐行**：初判为次要媒体/动画模块。
3. **滚轮切换毫秒数未定位**：标「实测」而非原值。
4. **点云 .bin 属游戏衍生数据**：完整六件仅存本地 `real-assets/model/`（已加入 .gitignore，公共仓不携带）；公共仓只携带 3,000 点 float16 降采样研究样本（18KB），口径类比「截图之于原画」。
5. **H5（竖屏）版未实测**：h5-cn/h5-oversea 模块在册，未做移动端逐屏。

## 五、复算口径

- 「218,441 点」= 六个 .bin 字节数 ÷ 12 之和（57,682+7,484+45,254+47,191+33,578+27,252）。
- 「延迟 0/1386/2197ms」= 2000·ln(1)/ln(2)/ln(3) 四舍五入。
- 「设计画布 2560×1440」= rem 公式分母直接读出；竖屏 1080×1920 同法。
- demo 样本预归一化：按原站 setup 相同数学（AABB→1900→居中）后再采样量化，故 demo 内无需重复归一化。
