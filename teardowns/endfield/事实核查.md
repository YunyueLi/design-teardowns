## 二、发现并已改正的漂移

| # | 漂移 | 处置 |
| --- | --- | --- |
| 1 | 初稿把用户假说「图片转粒子坐标」直接当成该站机制描述 | 核查后区分为两套系统：点云坐标来自预烘焙 .bin（非图片）；「亮度→透明度」真实存在但用于视频抠像（trans-video）。拆解页第 06 区已明确「应验一半」的表述 |
| 2 | 初稿写扫描线「从 −1150 到 1350」适用于三线出入两种状态 | fadeOut 实为 −1150→**1150**（非 1350）且三线同时无延迟——已分开表述 |
| 3 | 初稿把 fadeIn 延迟写作「0/1400/2200ms」 | 精确为 2000·ln(i+1) = 0/1386/2197ms——按公式改写并注明取整口径 |
| 4 | 初稿称「三段视频」为在播视频 | probe.media.video=3 为 DOM 计数，实际懒加载（data-src）；已写作「三段懒加载视频」 |
| 5 | demo 最初直接引用完整 anchor.bin | 版权口径修正：完整 .bin 挡在公共仓外（.gitignore），demo 改用 3,000 点 float16 降采样研究样本，并在页内与文档双处标注 |
| 6 | 初稿把「滚轮切换约 1.2s」写成原值 | 源码未定位到该常量，降级为「实测约 1s 级」并入推断表 |

## 三、易错点自查

- **CV 姓名**：干员页截图含中日配音真实姓名——文档一律写「中日配音字段」，不录人名（红线）。
- **glitch 带宽**：着色器内带宽 ±10（视图空间 y）。旧版 Canvas demo 曾用 ±24 舞台等效并注明；本轮 demo 升级为 WebGL 后**着色器逐行照抄**，±10 原值直接生效，该换算说明随之退役。
- **「无 07 分区」**：CSS 模块从 06-Notice 跳到 08-AIC，如实记录，不虚构 07。
- **swiper 存在但非主滚动**：swiper 只用于轮播，主滚动为自研——避免「该站用 swiper 做全屏滚动」的误读。
- **点色 #ccc 与 #d9d9d9**：着色器点色 vec3(.8,.8,.8)≈#ccc 与 CSS 银灰 #d9d9d9 是两个值，色卡分列。

## 四、结论

抽样逐项与抽取源一致；六处漂移当场改正并留痕；本轮把 demo 升级为着色器原文的 WebGL 复现（含激光池与羽化点精灵），关闭了 63874443 与 H5 两条局限；样本降采样与残余简化（无 benchmark 三档降级）均已显式标注。
