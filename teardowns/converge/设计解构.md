# converge 设计解构

> 顶级 UI 视角的完整拆解。除特别标注，所有数值均来自对 `https://converge.ai` 线上样式的真实抽取（Playwright 计算样式加服务端样式表文本，见 `teardowns/_data/converge.json` 与 `design-tokens.css`），标注为**实锤**；观感描述与从渲染截图读到的信息标注为**推断**。

页面标题实测为 `Converge AI — The Gateway to AI-native Business.`（实锤）。

---

## 1. 定位与设计意图

converge 是一套把「散落」收敛成「秩序」的黑白系统。首屏一句话点破主张：从 Individual Intelligence 走向 Institutional Intelligence（个体智能汇聚为机构智能）。整站几乎不用彩色，靠纯白底与近黑字之间的张力、极大留白，以及明暗场交替的节奏来推进叙事。

它的设计意图可以拆成三条互相咬合的原则。

| 原则 | 做法 | 意图 |
|---|---|---|
| 近乎零彩色 | 通篇白底黑字，灰阶过渡；唯一一次真正的彩色出现在一屏深黑过渡屏上（一道蓝色光弧） | 让「收敛」这件事本身成为主角，而不是靠颜色抢注意力 |
| 明暗场交替 | 白色内容屏与深黑过渡屏轮流出现，深黑屏承担情绪与转场 | 用节奏而非装饰制造高级感与呼吸感 |
| 收敛作隐喻 | 首屏散落的物理感黑色小球，带景深模糊，缓慢向中心汇聚 | 把公司名 converge（收敛）做成看得见、能感受到的动作 |

**一句话概括复刻目标**：用最少的颜色，把「散」与「聚」的对比做到极致；页面的高级感来自留白、字体与节奏，而不是来自色彩。

一个值得记录的取舍：站点底层其实带着一整套 Tailwind 的彩色调色板（红、橙、黄、绿、蓝、紫都在自定义变量里定义好了，见 §2 与 §7），但设计刻意「按住不用」，只在暗场放出一次蓝色。**克制是主动选择，不是没有能力上色。**

## 2. 色彩系统（真实 token）

### 2.1 明场基底与墨色

body 背景实测为 `lab(100 0 0)`，即纯白；正文颜色 `lab(2.75381 0 0)`，是一层几乎纯黑、略带暖度的墨；h1 颜色为纯正 `rgb(0,0,0)`（实锤）。日常灰阶从样式表出现频次里可以直接读出来。

| 浅灰面 | `#f5f5f5` | 28 | 输入框底色 |
| 浅灰面 | `#f8f8f8` | 24 | 次级浅底 |

| 近黑 | `#0f0f0f` | 34 | 正文主色 |
| 深墨 | `#171717` | 26 | 深色区块 |
| 深墨 | `#0a0a0a` | 20 | 深黑过渡屏底色 |
| 深墨 | `#18181b` | 16 | 深色层次 |
| 纯黑 | `#000000` | 16 | 标题、主按钮底 |
| 中灰文字 | `#767676` | 12 | 副标题与次要文字，按钮文字实测 `rgb(118,118,118)` 即此值 |

### 2.2 唯一的强调色

| 名称 | HEX | 出现次数 | 角色 |
|---|---|---|---|
| 电光蓝 | `#0285ff` | 32 | **全站唯一有分量的彩色**，用于深黑过渡屏上的那道光弧（实锤为色值与频次，「用在光弧」为推断） |

蓝色系里还能读到 `#3080ff`、`#155dfc`、`#1456f0`、`#2563eb`、`#93c5fd` 等（Tailwind 蓝阶），但真正在视觉上被「放出来」的是 `#0285ff`。

### 2.3 被定义却按住不用的调色板（关键发现）

站点 CSS 自定义变量里完整定义了 Tailwind 的语义色（实锤，逐条来自 `customProps`）：`--color-red-500:#fb2c36`、`--color-orange-500:#fe6e00`、`--color-yellow-500:#edb200`、`--color-green-500:#00c758`、`--color-blue-500:#3080ff`、`--color-purple-500:#ac4bff` 等。红色 `#dc2626` 在样式表里出现 16 次，但在营销页正文几乎不露脸。这说明**调色板是现成的，设计选择了不用**——这正是「近乎零彩色」的证据，而非推测。

站点自身的 `--accent`（品牌强调变量）实测解析为 `lab(96.52% -.0000298 .0000119)`，换算约等于 `#f3f3f3`——**它的「强调色」本身就是一层更白的白**。这条实锤，把「零彩色」推到了近乎自嘲的程度。

## 3. 字体系统

首屏大标题实测用 **Instrument Sans**，字重 500，字号 64px，字距 `-1.92px`（约 `-0.03em`），行高 70.4px（约 1.1），颜色纯黑（全部实锤，来自 h1 计算样式）。body 同样以 Instrument Sans 打底。

实测加载的字体家族（实锤，来自 `fontsLoaded`）：Inter、Instrument Sans、Schibsted Grotesk、Reddit Sans、Bitcount Prop Single Variable，以及整套 KaTeX 数学字体。样式表里还登记了对应的 CSS 变量：`--font-inter`、`--font-instrument-sans`、`--font-schibsted`、`--font-reddit-sans`（实锤）。

| 角色 | 字体 | 说明 |
|---|---|---|
| 大标题与正文 | **Instrument Sans** | 人文气质的无衬线，圆润里带秩序感；巨型标题就靠它的中等字重加负字距撑起张力（实锤：h1 计算样式） |
| 展示 grotesk | **Schibsted Grotesk** | 更硬朗的 grotesque，登记了字体变量并已加载（实锤为加载，具体落在哪些元素为推断） |
| 辅助无衬线 | **Reddit Sans** | 已加载并有变量（实锤为加载，用途为推断） |
| UI 与兜底 | **Inter** | 界面与回退字体（实锤为加载） |
| 数学排版 | **KaTeX 家族** | 产品内的公式渲染需要（实锤） |

预加载字体数实测为 4（`preloadFont: 4`，实锤），说明首屏对字体首帧很在意。

对复刻友好的一点：Instrument Sans、Schibsted Grotesk、Inter 均可从 Google Fonts CDN 直接取到，因此本拆解页用的就是**站点真字体**，不必找替身。

## 4. 动效系统

### 4.1 真实缓动曲线（按出现频次）

| 曲线 | 值 | 频次 | 用途（频次为实锤，用途为推断） |
|---|---|---|---|
| 标准缓入缓出 | `cubic-bezier(.4,0,.2,1)` | 8（最高） | 出现最多的主曲线，按钮的颜色与背景过渡即用它 |
| 减速进入 | `cubic-bezier(0,0,.2,1)` | 4 | 元素入场的 ease-out |
| 缓入缓出偏后 | `cubic-bezier(.4,0,.6,1)` | 2 | 少量过渡 |

按钮过渡实测为一长串属性统一走 `0.15s cubic-bezier(0.4, 0, 0.2, 1)`（颜色、背景、边框、描边、渐变停靠等一起过渡，实锤）。这是典型的「一套曲线管到底」的克制做法。

### 4.2 双时间尺度

站点把两种时间叠在一起（时长均为实锤，语义为推断）：

- **敏捷微交互**：`0.15s` 按钮过渡、`0.2s`、`0.3s`、`0.5s`，保证手感即时。
- **缓慢氛围层**：`15s`（出现 12 次，最高）、`40s`（4 次）这样的超长循环，配合 `spin`、`pulse`、`testimonial-marquee-left` 等关键帧，驱动证言走马灯、点阵 logo 的缓慢自转、以及小球的漂浮氛围。中间还有 `1.2s`、`1.55s`、`2s`、`3s`、`5s` 等过渡档。

实测关键帧清单（实锤）：`spin`、`pulse`、`enter`、`exit`、`accordion-down`、`accordion-up`、`loading-icon-rotate`、`brand-spinner-step`、`testimonial-marquee-left`。其中 `enter`/`exit` 与自定义变量里的 `--tw-enter-*`/`--tw-exit-*` 对应，是 tailwindcss-animate 一类插件的入场出场动画（实锤为变量存在，插件归属为高置信推断）；`accordion-*` 与 `brand-spinner-step` 是 shadcn/ui 与品牌加载态的惯用命名（推断）。

## 5. Hero 手法

首屏是一套「居中大标题加散落小球加对话输入框」的组合（以下版式为渲染截图观察，属**推断**；字体与色值为实锤）。

- **居中巨型标题**：两行黑色 Instrument Sans，`Individual Intelligence` 到 `Institutional Intelligence`，标题右侧嵌一枚点阵 logo 母题。
- **散落的物理感黑色小球**：分两种存在——前景是小而实的纯黑圆点，背景是更大、更虚、带景深模糊的灰色圆斑（散景）。它们缓慢漂浮并向中心方向汇聚，是 converge（收敛）的字面可视化。
- **副标题**：中灰 `#767676`，`Where teams, context, and agents converge to power real businesses.`
- **内嵌对话输入框**：浅灰 `#f5f5f5` 圆角大输入框，占位文案 `Ask anything, or describe a task...`，右下角一枚**纯黑圆形发送按钮**（白色上箭头）。AI-native 信号被前置到首屏。

media 清单（实锤）：`video 1`、`canvas 1`、`svg 52`、`img 38`。大量 SVG 与图片支撑了点阵 logo、产品截图裱框与证言头像；`canvas 1` 很可能就是小球或点阵动效的载体（推断）。

## 6. 签名视觉母题

### 6.1 浮动收敛小球（本拆解的交互核心）

这是全站最强的记忆点，也是本拆解页必做的可跑 demo。要点：

- **景深分层**：一部分球是前景，小、纯黑、边缘锐利；另一部分是背景，大、灰、带 `blur` 的散景。景深差把二维画面推出层次。
- **物理感漂浮**：球体不是规则排列，而是各自带轻微速度与噪声地缓慢游动。
- **向心收敛**：整体存在一个朝画面中心的弱引力，球群缓慢聚拢又不完全塌陷，呼应「收敛」。

实现选型（推断，因为站点的具体物理参数未从 JS 包中还原）：可用 `canvas`（站点实测有 1 个 canvas）承载多球粒子，或用 DOM 加 CSS `filter: blur()` 做景深、用 `requestAnimationFrame` 跑物理。本拆解页采用后者，便于逐球控制模糊与透明度。

### 6.2 深黑过渡屏与蓝色光弧

在两段白色内容之间，插入一屏纯黑过渡（底色约 `#0a0a0a`），白色大标题压在上面（渲染可见 `See our labor of love, New intelligences on the horizon.`），一道 `#0285ff` 的蓝色椭圆光弧横扫而过。这是全站唯一放出彩色的时刻，也是明暗节奏的枢纽。

### 6.3 点阵 logo 母题

品牌标记是一簇大小不一的黑色圆点，松散排成螺旋或环形的「点云」，像是小球收敛的定格。它在导航、分区图标与页脚巨型字标里反复出现，把「散点收敛」的主题贯穿到品牌层。

## 7. 工艺细节

- **圆角语言（实测频次）**：`0px`（8 次）、`14px`（8 次）、`0`（8 次）、`9.625px`、`10px`、`12px`、`20px`、`26px`、`30px`、`62px`、以及 shadcn 惯用的 `calc(var(--radius) - 2px)`。可见三种并存：主 CTA 是 `62px` 全圆药丸（纯黑底白字），卡片多在 `14px` 上下，还有一批**刻意的 `0px` 直角**元素——直角与药丸并置，是它克制里的一点硬朗。
- **技术栈（高置信推断）**：自定义变量里成片的 `--tw-*`（`--tw-gradient-*`、`--tw-ring-*`、`--tw-enter-*` 等）、`--color-*` 语义色、`--spacing:.25rem`、`--breakpoint-xl:80rem`、`--container-*`、`--text-xs` 全是 **Tailwind CSS v4** 的主题令牌；`accordion-down/up` 关键帧与 `calc(var(--radius) - 2px)` 是 **shadcn/ui** 的招牌；`enter`/`exit` 与 `--tw-enter-*` 指向 tailwindcss-animate 一类动画插件。
- **背景不用毛玻璃**：导航实测 `backdrop-filter: none`、背景纯 `rgb(255,255,255)`（实锤）。它不靠玻璃拟态，靠的是干净的白与滚动时的分隔线。
- **媒体选型**：产品能力用真实产品截图裱进圆角卡（`img 38`），证言用横向走马灯（`testimonial-marquee-left` 加 `15s` 循环），而不是堆形容词。
- **巨型页脚字标**：页脚底部一行超大 `converge` 黑色字标，把点阵 logo 融进字母，作为品牌落款。
- **CSS 体量**：抓取到 3 个样式表，合计约 `627126` 字节（实锤），量级不小，主要是 Tailwind 生成的原子类。

## 8. 关键发现

1. **「零彩色」是主动克制，不是能力缺失**：底层备着整套 Tailwind 彩色调色板（红橙黄绿蓝紫俱全，实锤），设计选择只在暗场放出一次 `#0285ff` 蓝。连品牌 `--accent` 变量都解析成近白 `#f3f3f3`。
2. **节奏由明暗场交替扛起**：没有花哨背景，高级感来自白色内容屏与深黑过渡屏轮流出现的呼吸感。复刻时，别把整页做成一个色调。
3. **签名效果是「物理加景深」的合成**：小球的记忆点来自景深模糊（前景锐利、背景散景）与缓慢向心漂浮的叠加，而不是单纯的位移动画。
4. **一套曲线管到底**：主缓动 `cubic-bezier(.4,0,.2,1)` 一条曲线覆盖几乎所有微交互，`0.15s` 是它的默认手感。克制到了动效层。
5. **直角与药丸并置**：`0px` 直角与 `62px` 全圆药丸同时存在，是它黑白气质里刻意留的一点硬边。

> 完整交互版见同目录 `teardown.html`：可跑的浮动收敛小球（含景深与向心汇聚）、内嵌 Ask anything 输入框触发汇聚、黑白缓动实验台、明暗场交替节奏演示、色板点击复制。
