## 2. 签名效果：浮动收敛小球（景深加向心）

核心是「前景锐利、背景散景」的景深分层，加上朝中心的弱引力。用 DOM 加 CSS `filter: blur()` 做景深，用 `requestAnimationFrame` 跑物理，便于逐球控制模糊度。

HTML：
```html
<div class="cvg-stage" id="stage"></div>
```

CSS：
```css
.cvg-stage{position:relative;overflow:hidden;background:var(--paper)}
.cvg-ball{position:absolute;top:0;left:0;border-radius:50%;
  will-change:transform;pointer-events:none}
```

JS（要点版）：
```js
function initField(stage, N){
  var reduce = matchMedia('(prefers-reduced-motion:reduce)').matches;
  var W=stage.clientWidth, H=stage.clientHeight, balls=[], mode='ambient';
  var cx=()=>W/2, cy=()=>H/2, R=Math.min(W,H);
  for(var i=0;i<N;i++){
    var focus=Math.random();            // 1=前景锐利, 0=背景散景
    var sharp=focus>0.6;
    var size = sharp ? 10+Math.random()*16 : 30+Math.random()*54;
    var b=document.createElement('div'); b.className='cvg-ball';
    b.style.width=b.style.height=size+'px';
    b.style.background = sharp ? '#0a0a0a' : '#171717';
    b.style.filter = sharp ? 'none' : 'blur('+(4+(1-focus)*16)+'px)';
    b.style.opacity = sharp ? 0.95 : 0.10+focus*0.22;
    stage.appendChild(b);
    var a=Math.random()*6.28, r=(0.12+Math.random()*0.34)*R;   // 家点：中心附近的松散点云
    balls.push({el:b,size:size,
      x:cx()+Math.cos(a)*r, y:cy()+Math.sin(a)*r,
      hx:cx()+Math.cos(a)*r, hy:cy()+Math.sin(a)*r,
      ex:cx()+Math.cos(a)*R*0.6, ey:cy()+Math.sin(a)*R*0.6, // 散开目标
      vx:0, vy:0, ph:Math.random()*6.28, sp:0.4+Math.random()*0.7});
  }
  function frame(){
    for(var o of balls){
      var tx = mode==='converge'?cx() : mode==='disperse'?o.ex : o.hx;
      var ty = mode==='converge'?cy() : mode==='disperse'?o.ey : o.hy;
      var k  = mode==='converge'?0.02 : mode==='disperse'?0.014 : 0.006;
      o.vx += (tx-o.x)*k; o.vy += (ty-o.y)*k;
      o.ph += 0.01*o.sp;                                   // 布朗漂浮
      o.vx += Math.cos(o.ph)*0.05; o.vy += Math.sin(o.ph*1.3)*0.05;
      o.vx*=0.92; o.vy*=0.92;                              // 阻尼
      o.x+=o.vx; o.y+=o.vy;
      o.el.style.transform='translate('+(o.x-o.size/2)+'px,'+(o.y-o.size/2)+'px)';
    }
    if(!reduce) requestAnimationFrame(frame);
  }
  if(!reduce) requestAnimationFrame(frame);
  return {
    converge(){mode='converge';setTimeout(()=>mode='ambient',1600);},
    disperse(){mode='disperse';setTimeout(()=>mode='ambient',900);}
  };
}
```

- **默认（ambient）**：球群朝各自的「家点」轻弹加噪声漂浮，家点是中心附近的松散点云，视觉上就是缓慢向心的浮动。
- **converge**：家点目标切到正中心，球群聚拢。可以让首屏输入框的发送按钮触发它——「提问」时上下文收敛成答案，与品牌隐喻同构。
- **disperse**：目标推到边缘，球群散开。

## 3. 明暗场交替的节奏

把内容切成白屏与黑屏轮流出现，黑屏承担转场与情绪，并在黑屏里放出唯一的蓝：

```css
.sec-light{background:var(--paper);color:var(--ink)}
.sec-dark{background:var(--dark);color:#fafafa}
/* 深黑过渡屏上的蓝色光弧（唯一彩色时刻）*/
.arc{position:absolute;inset:0;pointer-events:none;
  background:
    radial-gradient(120% 60% at 50% 120%, rgba(2,133,255,.55), transparent 60%),
    radial-gradient(80% 40% at 50% 108%, rgba(2,133,255,.9), transparent 55%)}
```

要更接近原站的「一道弧」，可用一个大尺寸、被裁切的椭圆径向渐变从底部升起，配 `blur` 柔化边缘。

## 4. 微交互与按钮

一条曲线管到底，`0.15s` 是默认手感：

```css
.btn{transition:color .15s var(--ease-std),
     background-color .15s var(--ease-std),
     border-color .15s var(--ease-std);}
.btn-primary{background:#000;color:#fff;border-radius:var(--r-pill);
  padding:14px 26px}                    /* 主 CTA：纯黑全圆药丸 */
.btn-ghost{color:#767676;border-radius:var(--r-btn)}  /* 直角幽灵按钮 */
```

入场动画用减速曲线，呼应站点的 `enter` 关键帧：

```css
@keyframes enter{from{opacity:0;transform:translateY(16px)}to{opacity:1;transform:none}}
.reveal{animation:enter .5s var(--ease-dec) both}
```

## 5. 选型决策表

| 元素 | 选型 | 理由 |
|---|---|---|
| 浮动收敛小球 | DOM 加 CSS blur 加 rAF 物理（或 canvas 粒子） | 需要逐球不同的景深模糊与透明度，DOM 最直观；球多则转 canvas |
| 深黑屏蓝色光弧 | 被裁切的大椭圆径向渐变加 blur | 纯 CSS 即可，零依赖 |
| 点阵 logo | 内联 SVG 圆点簇 | 可缩放、可复用到导航与页脚字标 |
| 产品能力展示 | 真实产品截图裱圆角卡 | 靠真实 mock 建立信任，不堆形容词 |
| 证言 | 横向 marquee（15s 线性循环） | 对应实测 `testimonial-marquee-left` |
| 微交互 | CSS transition，统一 `--ease-std` 加 `0.15s` | 与站点一致，手感克制 |

## 6. 工程坑

- **别把整页做成一个色调**：converge 的高级感来自明暗交替，全白或全黑都会丢掉节奏。
- **蓝色要吝啬**：`#0285ff` 只在暗场放一次。多放一处就破坏了「近乎零彩色」的张力。
- **暖白不是纯白的替代**：`#fafafa` 用于分区大底，`#ffffff` 用于主背景，二者并存才有层次。
- **景深靠 blur 不是靠缩放**：背景球是「散景」，要的是模糊加低透明度，单纯缩小会失去照片感。
- **尊重 `prefers-reduced-motion`**：关掉小球物理、marquee、光弧呼吸，给出静态散布即可。
- **字体授权友好**：Instrument Sans、Schibsted Grotesk、Inter 都在 Google Fonts 开源可用，生产可直接引用真字体，无需替身。
