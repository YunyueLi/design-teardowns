# converge 拆解页 · 事实核查（第二轮）

对 `teardown.html` 里出现的每一个数值与断言，逐条比对四个真实来源，列出漂移并说明已如何改正。零编造，拿不准的一律标「推断」。

## 核对所用的真实来源

- `_data/converge.json` —— 第一轮线上抽取的权威记录（Playwright 计算样式 + 样式表频次统计，`cssBytes: 627126`）。
- `design-tokens.css` —— 从该记录整理出的 token（含 `--accent` 的 lab 实测值）。
- `real-assets/source/`（`index.html` 渲染 DOM + 三份线上样式表）—— 用于复核文案与 `@font-face`。
- `real-assets/fonts/*.woff2` —— 真实字体文件，用 fonttools 读回 name 表与可变轴确认字族。

一处方法论前提：`_data/converge.json` 分析的是约 62.7 万字节的完整 CSS，而 `real-assets/source/` 只落盘了其中 3 个 chunk（约 29.7 万字节）。因此**用落盘子集重新 grep 得到的频次约为记录值的一半，这是抓取只保存了部分样式表所致，不是矛盾**。页面里的频次以 `_data/converge.json` 为准，后续维护者请勿据子集「改正」。

## 二、发现的漂移与修正

### 1. 品牌强调色：`#f3f3f3` → `#f5f5f5`（数据型漂移，已改）

- 页面原写 `--accent` 解析为近白 `#f3f3f3`，出现在三处（定位节 callout、色彩节色板、出处节 callout）。
- 真实来源：`probe.accentGuess = lab(96.52% ...)`，换算 sRGB 为 **(245,245,245) = `#f5f5f5`**。且 `#f3f3f3` 在 `topHex` 与三份样式表里出现 **0 次**，而 `#f5f5f5` 出现 28 次，正等于 `--color-neutral-100`。
- 结论：`#f3f3f3` 是第一轮的换算/誊写漂移。已三处统一改为 `#f5f5f5`，并补上硬证据 `lab(96.52 0 0)` 与「等于 neutral-100」这一更有说服力的发现。

### 2. 首屏 h1 字重与字距：与自身文档不一致（已校准）

- 页面「字体系统」节正确记录了 h1 实测 **字重 500 / 字距 -1.92px(≈-.03em) / 行高 70.4px(≈1.1)**，但首屏 h1 的 CSS 却用了 `font-weight:600; letter-spacing:-.035em; line-height:1.02`——首屏没按自己文档的实测值来。
- 已把首屏 h1 校准为 `font-weight:500; letter-spacing:-.03em; line-height:1.08`，与站点实测对齐（`clamp` 上限由 92px 微调到 88px，仍保留响应式放大）。

### 3. 字体来源表述：「从 Google Fonts 取」→ 自托管真实文件（已更新）

- 第一轮用 Google Fonts CDN 作字体，页面表述为「从 Google Fonts 直接取到，无需替身」。
- 本轮已把从 converge.ai 提取的真实字体文件经 `@font-face` 自托管接入，CDN 降为兜底。相关表述（字体系统节、出处节、页脚）已同步更新为「自托管真实文件、CDN 兜底」。

## 三、真实字体：字族映射复核（实锤）

`real-assets/fonts/` 4 个文件名是 Next.js 哈希，无法看名识别。用两条独立证据交叉确认字族：站点自带的 `@font-face`（`real-assets/source/b7556a_*.css`）与 fonttools 读 name 表 / fvar 轴。结论一致：

| 文件 | 字族 | 可变字重轴 | 本页是否接入 |
|---|---|---|---|
| `4c5e98_f06bf9da926bae75-…woff2` | **Instrument Sans** | wght 400–700 | 是（标题 + 正文） |
| `a7cbd9_31a9145ccb84606d-…woff2` | **Schibsted Grotesk** | wght 400–900 | 是（展示体 / 页脚字标） |
| `cbf47b_83afe278b6a6bb3c-…woff2` | Inter | wght 100–900 | 否（站点兜底字，非本页所用） |
| `f01b3f_7c1d6751972ac70b-…woff2` | Reddit Sans | wght 200–900 | 否（站点辅助字，非本页所用） |

按第二轮规范「只接该站真正用于标题/正文/等宽的 1 到 3 支」，只自托管了页面确实使用的 Instrument Sans 与 Schibsted Grotesk；两支都是可变字体，页面用到的字重（400/500/600 与 800/900）全部落在各自轴内，**无合成假粗、无 tofu 风险**（等宽走系统 `ui-monospace` 栈，无需网络字体）。
