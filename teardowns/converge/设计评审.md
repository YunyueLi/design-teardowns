# converge 拆解页 · 设计评审（第二轮）

以顶级设计视角，评这份拆解页相对 converge.ai 原站的精度与完成度：哪些已达标，哪些还差一口气，并给出可执行改进（能当场改的已改，标注 [已改] / [建议]）。

## 总评

这份拆解页最难得的地方，是它不满足于「描述」converge 的高级感，而是让**自己也遵守 converge 的设计语言**运行：纯白底、近黑字、明暗场交替、全站唯一一道蓝、近乎零彩色的克制。第二轮把字体从 CDN 替身换成站点真实可变字体、嵌入真实的收敛母题图与视频、并修掉强调色漂移之后，它在「气质保真」上已经非常接近原站。剩下的差距主要在几个高保真细节，而非方向问题。

## 已达标（与原站同一水准）

- **黑白克制的纪律**：色板、明暗场节奏、蓝的吝啬，都不是观感描述而是被 `_data/converge.json` 频次坐实的。强调色实测等于 neutral-100（`#f5f5f5`）这一发现，比原站自己的营销叙事更能说明它的克制。
- **真实字体接入**：标题 / 正文用真实 Instrument Sans（可变 400–700），展示体用真实 Schibsted Grotesk（可变 400–900），自托管、`font-display:swap`、CDN 兜底。首屏 h1 校准到实测的 500 字重与 -1.92px 字距后，巨型标题的「中等字重 + 负字距」张力与原站一致。
- **签名母题**：浮动收敛小球用逐球 `blur` 做景深、`requestAnimationFrame` 驱动向心物理，交互（提问 / 汇聚 / 散开 / 漂浮）完整；再并置站点真实的 `landing-convergence-orbit.png`，把「抽象复现」与「官方定格」摆在一起，可信度拉满。
- **动效与工艺 token**：三条缓动曲线、时长阶梯、圆角语言均为实测值，`0.15s + 一条主曲线覆盖几乎所有微交互`的结论有数据支撑。

## 相对原站仍有的差距

1. **收敛母题的结构差异**：原站 `landing-convergence-orbit.png` 是带轨道环的、有摄影景深的定格；本页小球是很好的抽象，但缺少那种「同心轨道」的隐含结构，聚拢时略显随机。
2. **首屏标题的原文母题未展示**：原站 h1 是 `Individual Intelligence → Institutional Intelligence` 的双行对照（个体智能走向机构智能），这正是品牌主张；本页首屏用的是拆解页自己的中文框架，字体样例区也没把这句英文原文摆出来做 1:1 对照。
3. **真实视频的角色被略微放大**：站点上它默认 `hidden`、是页脚暗色带的装饰循环；本页为呈现动态而 `autoplay`，虽有诚实标注，但展示权重高于它在原站的实际存在感。
4. **蓝弧为观感逼近**：`#0285ff` 是实测最高频蓝（实锤），但光弧的精确渐变停靠点与位置未逐点提取，仍是高置信推断。
5. **仅桌面视口**：未覆盖移动端断点与登录后界面；原站在窄屏下的巨型标题与小球密度策略未验证。

## 可执行改进

1. **[已改] 强调色漂移**：`#f3f3f3` → `#f5f5f5`（源自 `lab(96.52 0 0)`，且等于 neutral-100），三处统一并补硬证据。
2. **[已改] 首屏 h1 校准**：字重 600→500、字距 -.035em→-.03em、行高 1.02→1.08，与站点实测对齐，消除了「文档说 500、首屏却用 600」的自相矛盾。
3. **[已改] 真素材回填**：真实字体自托管、真实收敛母题图与真实视频嵌入、出处指向 `real-assets/manifest.json`。
4. **[建议] 给小球加极淡的同心轨道导引线**：在演示舞台底层加一两圈 `1px` 近透明圆环，聚拢时让球更贴合环，呼应真实 orbit 图的结构，成本很低。
5. **[建议] 字体样例区补原文母题**：在 Instrument Sans 样例里加一行 `Individual → Institutional Intelligence`（原站 h1 原文），做真字体的 1:1 观感对照，顺带点出品牌主张。
6. **[建议] 视频改为「点击播放」并降存在感**：把 `autoplay` 改成静帧 + 点击播放（`preload="none"`），更贴合它在原站「默认隐藏的装饰循环」的真实角色；同时给三张产品截图补 `srcset @2x`，向原站的清晰度看齐。

## 一句话结论

方向与气质已经到位，第二轮补齐了真字体、真媒体与强调色这三块最影响「像不像原站」的地方；接下来若要再逼近，价值最高的是**收敛母题的结构（轨道导引）**与**移动端断点**这两处细节，而非再动色彩或字体。
