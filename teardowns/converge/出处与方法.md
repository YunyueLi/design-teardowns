# 出处与方法：Provenance

## 来源

拆解对象为线上站点 `https://converge.ai`（页面标题实测 `Converge AI — The Gateway to AI-native Business.`）。所有 token 来自对线上样式的真实抽取，落盘在同目录 `teardowns/_data/converge.json` 与 `design-tokens.css`；配套还有真实渲染证据：`assets/actual-hero.jpg`（首屏）、`assets/actual-full.jpg`（整页）、`keyframes/`（滚动逐帧）与 `recording/scroll.webm`（滚动录屏）。

## 提取链路

1. **Playwright 计算样式**：加载线上页面后，对 `body`、`h1`、`nav`、按钮等关键元素读 `getComputedStyle`，拿到背景色、文字色、字体族、字号字重字距行高、圆角、过渡曲线等。首屏 h1 的字号 `64px`、字重 `500`、字距 `-1.92px`、行高 `70.4px`、颜色 `rgb(0,0,0)`，body 的 `lab(100 0 0)`，导航 `backdrop-filter: none` 等均出于此，是**元素级实锤**。
2. **服务端抓样式表文本**：直接取样式表源文本（不受浏览器 CORS 限制），抓到 3 个样式表、合计约 `627126` 字节。对文本做频次统计，得到高频 HEX、`cubic-bezier` 曲线、`font-family`、时长、圆角、`@keyframes` 名与全部 CSS 自定义变量。这些是**样式表级实锤**（频次真实，语义用途需另判）。
3. **真实渲染截图与录屏**：整页与首屏截图、滚动逐帧、滚动录屏，用于核对版式、明暗场顺序、小球与蓝弧的观感。截图里读到的文案（如 `Individual Intelligence`、`New intelligences on the horizon`、`200K+`、`Try Our Products`）属**as-seen 实锤**，其营销语义为推断。

## 什么是实锤，什么是推断

**实锤（源自抽取）**

- 基底与文字：body `lab(100 0 0)`、正文 `lab(2.75381 0 0)`、h1 `rgb(0,0,0)`、按钮文字 `rgb(118,118,118)`。
- 高频色值及次数：`#fafafa`(44)、`#fff`(42)、`#0f0f0f`(34)、`#0285ff`(32)、`#f5f5f5`(28)、`#171717`(26) 等。
- 缓动曲线及次数：`cubic-bezier(.4,0,.2,1)`(8)、`cubic-bezier(0,0,.2,1)`(4)、`cubic-bezier(.4,0,.6,1)`(2)；按钮过渡统一 `0.15s`。
- 时长梯：`15s`(12)、`2s`(6)、`40s`(4) 以及 `1.2s`、`1.55s`、`0.15s`、`0.2s`、`0.3s`、`0.5s` 等。
- 圆角：`0px`、`14px`、`9.625px`、`10px`、`12px`、`20px`、`62px`、`calc(var(--radius) - 2px)` 等及次数。
- 关键帧名：`spin`、`pulse`、`enter`、`exit`、`accordion-down/up`、`loading-icon-rotate`、`brand-spinner-step`、`testimonial-marquee-left`。
- 字体加载清单：Inter、Instrument Sans、Schibsted Grotesk、Reddit Sans、Bitcount Prop Single Variable、KaTeX 家族；`preloadFont: 4`。
- CSS 自定义变量全集：整套 Tailwind `--tw-*`、`--color-*` 语义色、`--spacing`、`--breakpoint-*`、`--container-*`、`--font-*`；站点 `--accent` 解析约 `#f3f3f3`。
- media 计数：`video 1`、`canvas 1`、`svg 52`、`img 38`、`preloadVideo 0`。

**推断（公开资料与渲染观察）**

- 小球的具体物理参数（速度、噪声、向心引力系数、景深模糊半径）未从 JS 包还原，本拆解的复现是按观感逼近的近似。
- 蓝色光弧使用 `#0285ff`：`#0285ff` 是抽取到的最高频蓝（32 次），深黑过渡屏渲染上也确有蓝色椭圆光弧，「这道弧就用这个值」为高置信推断，其精确渐变停靠点未逐点提取。
- 技术栈为 Tailwind CSS v4 加 shadcn/ui 加 tailwindcss-animate 一类：`--tw-*` 与 `--color-*` 令牌坐实了 Tailwind v4（近乎实锤）；`accordion-*` 关键帧与 `calc(var(--radius) - 2px)` 指向 shadcn/ui，`enter`/`exit` 与 `--tw-enter-*` 指向动画插件，这两条为高置信推断。
- 各时长具体驱动的元素（如 `15s` 走证言 marquee、`40s` 走小球或点阵缓转）为按命名与观感的推断。
- 大标题落在 Instrument Sans 为实锤（h1 计算样式）；Schibsted Grotesk 与 Reddit Sans 落在哪些具体元素为推断（仅确认已加载并登记了变量）。
- 「按住不用的调色板体现主动克制」是对实锤（调色板存在、正文几乎不上色）的解读，属推断性结论。

## 局限

- 只抓了桌面视口的线上样式与截图，未覆盖移动端断点差异与登录后的产品内界面。
- 未解包或反混淆 JS bundle，因此小球物理、canvas 具体用途、埋点等运行时行为均为观察推断。
- 频次统计反映的是样式表里的书写次数，不完全等于运行时的视觉权重（原子类会被大量复用），语义解读已逐条标注置信度。
- 站点会迭代，本拆解对应某一次抓取快照；如与线上出现出入，以 `teardowns/_data/converge.json` 的时间戳为准。

## 复现资产清单

同目录内可直接取用：真实 token（`design-tokens.css`）、抽取原始数据（`teardowns/_data/converge.json`）、首屏与整页真实截图（`assets/`）、滚动逐帧（`keyframes/`）、滚动录屏（`recording/scroll.webm`）、交互式拆解页（`teardown.html`）。
