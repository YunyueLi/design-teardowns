# Lagom（imlagom.com）设计解构

> 逆向对象：https://imlagom.com/ ，抓取于 2026 年 7 月 30 日，Chromium 148，视口 1440×900（device_scale_factor 1.5）。
> 数值来源约定：**实锤** = 直接抽取自计算样式、样式表原文、页面脚本或真实资产文件；**推断** = 证据充分但非直接读出的判断。冲突处一律以抽取为准。

## 一、定位与设计意图

- 站点自述（meta description，实锤）：「Lagom 的个人网站：三个 AI 项目、按旅行整理的摄影年册，和项目做完后的思考与记录。」标题「Lagom｜摄影、软件与技术写作」，`lang="zh-CN"`。
- 站名 Lagom 取瑞典语「不多不少，刚好」；终章落款「Lagom，刚好在此处」（页面文案，实锤）。
- **一个隐喻贯穿整站：摄影**（推断，视觉证据高度一致）：
  - 首屏取景器：黑白湖景上，指针所到之处以 190px 圆形区域透出彩色，配十字准星；
  - 暗房显影：全站照片默认褪色装裱，入视野或悬停才显影为彩色；
  - 终章收卷：LAGOM 字标如相纸淡入，随后散开沉底，让位给三张逐一显影的相片——「观察—摄影」「构建—项目」「书写—博客」（frame-verb 与 frame-label 配对，实锤），文案回扣首屏的「时间的倒影」。
- **营销层与产品层分离**（实锤）：首页统一在「暖纸、玄墨、朱印」的纸面语言里；每个项目的独立页面另起整套美术与字体（海龟汤事务所页 fontsLoaded 为 Noto Serif SC、Special Elite、Caveat、Long Cang），首页「案卷柜」是这些世界的抽屉入口。
- 五幕结构（页面脚本的场景选择器原文，实锤）：`.hero, .project-field, .photo-archive, .notes-index, .finale`；对应文案「所有的偶遇与构建，都是时间的倒影。」「项目作品」「记忆的坐标」「墨水与思想」与终章。

**中文加载管线**（实锤）：

1. 两族中文共 176 条 `@font-face`，每条一个按字频组织的 unicode-range 切片，文件名带 `.sub-<hash>` 二次子集化标记，平均单片约 8.7KB；
2. 首页 `<link rel="preload" as="font">` 共 9 条：2 支拉丁主字体（Inter、Newsreader）加最高频的 7 片宋体 400 切片（片号 111 至 119 中的 7 片）；
3. `fonts-cjk.css`（195.6KB 纯声明）用 `media="all"` + `onload` 技巧异步挂载；
4. 拉丁三件套的 `@font-face` 直接内联在 HTML `<head>`，家族名带构建哈希（如 `Inter-fb232d4c94bf52a0`），并各自注册 `:root` 变量 `--font-inter` `--font-newsreader` `--font-jetbrains`；
5. 为 JetBrains Mono 生成了度量兼容兜底字：`size-adjust:99.9837%; ascent-override:102.0166%; descent-override:30.0049%`（以 Courier New 为宿主）；
6. 霞鹜文楷 Note 不切片，直接裁到全站用字（8.9KB 单文件）。

拉丁管线特征与 Astro 的字体优化 API 输出一致（哈希家族名 + `/_astro/fonts/` + 内联声明 + 度量兜底）——**推断**。

导航用衬线（`font-family: var(--font-display)`，1.05rem，字距 .05em，默认不透明度 .74）；当前项加 2px 朱色下划线（实锤）。

## 五、动效系统

### 缓动（实锤）

| 名称 | 值 | 分工 | 样式表频次 |
| --- | --- | --- | --- |
| `--ease-heavy` | `cubic-bezier(.32,.72,0,1)` | 「重物落定」主缓动：案卷开合、纸片入场、终章字母 | 9 |
| `--ease-focus` | `cubic-bezier(.2,.8,.2,1)` | 跟手反馈：对焦、悬停、按压 | 1（变量引用另计） |

### 双时间尺度（实锤）

微交互毫秒级：菜单 240ms、对焦圈显隐 380ms、圆形裁剪扩张 650ms、案卷柜开合 860ms、分页滚动 260—820ms 自适应、终章 900/1150/200/900ms 四段。
氛围层分钟级：雨幕 15s 一循环、灯光呼吸 6.5s（ease-in-out alternate）、云层 110s 漂完一屏。相差两个数量级，画面「静中有动」。

### 手写分页滚动（页面脚本逐行读出，实锤）

- 快照点 = 每幕顶部 + 幕内每满一屏加一档；终章在桌面横屏时不加内部档（交给三幕接管）；
- 滚轮累计 |Δ| ≥ 28 翻一幕，200ms 无输入清零；触摸纵向位移 ≥ 56px 翻一幕，横向优先判定（8px 阈值定轴）；
- 键盘完整支持：方向键、PageUp/PageDown、空格、Home、End；
- 平滑滚动时长 `clamp(820 × 距离/视口高, 260, 820)` ms，easeOutExpo；落定后 150ms 才重新接受输入；
- `data-scene` 写在 `<html>` 上驱动样式（如滚动提示只在第 0 幕显示）；`history.scrollRestoration = 'manual'`；
- 尺寸重算五重保险：load、resize（160ms 防抖）、body 高度 ResizeObserver（±2px 容差、180ms 防抖）、每张图片 load、外加 400ms 与 1200ms 两次定时兜底。

### keyframes 清单（17 个，实锤）

`cue-word-in` `cue-draw` `cue-sink`（滚动提示三连）、`enter-flare`（按钮闪耀）、`stamp-slam`（印章砸落）、`rain-fall`（雨幕）、`cloud-drift`（云层）、`glow-breathe`（灯光呼吸）、`caret-blink`（打字光标）、`read-scan`（判读扫描线）、`action-nudge`（按钮轻推）、`pen-redraw`（钢笔圈重描）、`line-swap`（换行闪底）、`board-flip`（翻牌板）、`finaleBloom`（终章光晕）、`frameSheen`（相框扫光）、`np-wash`（墨晕点染）。

## 六、五幕逐幕拆解

### 第一幕 Hero：取景器

- 黑白化：`img { filter:grayscale(1) contrast(1.08) brightness(.7); transform:scale(1.045) }`；
- 彩色对焦区：`::after` 同图为背景，`clip-path:circle(var(--focus-size) at var(--focus-x) var(--focus-y))`，`--focus-size` 190px（≤580px 视口时 112px），opacity .38s ease-focus、clip-path .65s ease-heavy；对焦时底图 scale 回落到 1.025；
- 准星：80px 容器，1px 朱色十字（上下左右各溢出 8px），内缩 18px 的 1px 白框（72% 白）；指针坐标 rAF 节流写入百分比；触摸设备按下即对焦、不随移出取消；
- 构图网格：12 列 × 8 行发丝线（--line-dark），opacity .33，上下渐隐遮罩；
- 文字可读性：左 58% 与下 68% 双向渐变压暗；
- H1 规格 `360 clamp(4.2rem,12vw,11.8rem)/1.1`，再叠 `min(…, 10.4cqw)` 容器约束（h1 的容器查询单位用法，少见且实锤）；
- 滚动提示编排：字样 1.6s 后淡入（cue-word-in .8s）、雪佛龙 2.15s 描线（cue-draw .64s，stroke-dashoffset）、2.9s 起整体 3s 周期下沉（cue-sink）；提示只在 `data-scene="0"` 出现。

### 第二幕 项目案卷柜

- 三联栅格 `grid-template-columns: var(--col-1,1fr) var(--col-2,1fr) var(--col-3,1fr)`，展开项 6fr，**直接过渡栅格轨道**：`transition: grid-template-columns .86s ease-heavy`；缝隙 2px 露出 `#0d0b09` 衬底；
- 卷宗态（未展开）：横竖两套美术图互换（is-live 显 wide、否则 portrait），并做旧 `grayscale(.62) sepia(.08) contrast(.94) brightness(.66)`，悬停书脊回暖到 `.25/.04/.97/.82`；
- 书脊：竖排字（writing-mode:vertical-rl）、mono 编号、2px 朱色标记线 scaleY 入场（.52s，延迟 .24s）；悬停展开有 150ms 意图延迟，点击立即；
- 桌面视频（海龟汤案头 mp4，810,072 B）播放条件四重与门：展开中、区块入视口 ≥ .25、桌面横屏、未开启减少动效；未播时以 webp 雨幕兜底（15s 线性循环、mix-blend screen、纵向渐隐遮罩），视频就绪即隐藏雨幕；
- 三个小剧场都是 `data-step` 状态机 + `aria-live="polite"` 隐形解说：
  - **海龟汤**：三问各自盖章（答案「不是」「是也不是」「是」，stamp-slam .4s：scale 1.9→.94→1、rotate −12°→−3°→−6°），三问用尽汤底开封——判词以霞鹜文楷 `#891f19` 分两段 clip-path 擦除（延迟 .64s 与 1.36s）；「继续查案」按钮变印泥红 `#9a221b` 并 enter-flare；拍立得证据照延迟 .75s 旋转入场；纸条各带 `--slip-angle`（1°、−.8°、.45°）与错峰入场（.26/.33/.4s）；
  - **EasyCode**：六态机（初稿、录制中、待验证、判读中、发现偏移、交稿），代码逐行打字（320ms 起步、每行 +360ms、朱色光标 caret-blink .7s steps(2)）；「验证」触发 read-scan 扫描线（.95s 线性、`#b3402a` 2px + 12px 辉光）980ms 后判出「发现偏移：02:00」；「修复」把 `return left` 换成 `return -1`（时码 02:00→03:30，line-swap 闪底 .36s），批注被划掉（text-decoration-color 过渡）、下划线转灰、「通过」章落下、钢笔圈 pen-ring 描边变纸色；行首 `data-tc` 伪元素是时间码标尺；
  - **JourneyPilot**：登机牌（纸 `#f2e9d8`、左侧 2px 虚线打孔、圆角 11px），航段逐条「打印」（360ms 起步、每条 +900ms、board-flip .34s：`perspective(340px) rotateX(84°)` 进场，机场翻牌板式），打印中的行尾带 `#c2451c` 光标；完成后「已放行」双圈章（2.5px 边框 + 内缩 6px 的 1px outline，−8° 落章）；入口按钮做成撕角票根（rotate 1.6°、虚线打孔）；氛围层云 110s、灯 6.5s。

### 第三幕 记忆的坐标（胶片墙）

- 横向拖拽自带动量：速度混合 `v = .35v + .65v_inst`（夹在 ±6），逐帧衰减 `.91^(Δt/16.67)`，|v| < .04 停；拖拽与点击用 5px 位移消歧；

### 第四幕 墨水与思想（博客索引）

- 版式 4.5fr + 7fr：左侧「焦点记录」sticky（top 4rem，顶部 2px 墨线，朱色 mono 标签），右侧行表 `110px / 1fr / 80px / 110px`（日期、标题、时长、标签）；
- 行悬停或聚焦即接管左侧焦点区（标题、摘要、链接三处同步换），当前行右移 .6rem 并划出 2px 朱色下划线（scaleX，.52s ease-heavy）；
- 整节入场：IO 阈值 .18，从 opacity .38 + 48px 位移浮起（.72s/.9s ease-heavy）。

### 第五幕 终章（三幕接管）

- 结构：sticky 舞台 100svh + 三行占位 `.finale-steps`（每行都是 snap 点）；`perspective:1300px`；
- JS 只写三个进度：`--fe`（入场 −1→0）、`--fq1`（散场 0→1）、`--fq2`（收卷 1→2），几何全部在 CSS 派生：
  - 每字母 `--lq = clamp(0, (fq1 − lo)/.62, 1)`，`--lo` 从中心向外 0/.06/.12——中心字母先沉；
  - 字母入场即 `--fe`：blur 26px→0、字距 +.175em→−.055em、scale 1.08→1；散场时 blur 至 14px、scale −.32、按字母位移（±20%/48% 等五组，实锤）；
  - 每相框 `--fq = clamp(0, (fq1 − .28 − i×.08)/.5, 1)`：52px 上移入场 + scale .94→1 + 显影（grayscale 1→.15、brightness .86→1.06）；
  - 文案层 `--cq = clamp(0, (fq2 − 偏移)/.55, 1)`，偏移 0/.12/.24 依次是格言、簪言、联系带；
- 滚轮时序（smootherstep）：进入 900ms；下滚 1150ms 散场 + 停 200ms + 900ms 收卷；上滚 760ms + 160ms + 1000ms 反演；
- 点缀：finaleBloom 光晕 1.15s（朱色 radial，opacity 0→.6→0、scale .55→1.3）、frameSheen 扫光 1s（−180%→360%、skew −14°，逐帧错峰 i×.14s+.26s）、指针视差（sheet rotateX/Y ±2.4°、图内 ±5px 反向）；

## 七、工艺细节

- **全局胶片颗粒**：fixed 层、z-index 15、opacity .035、内联 SVG feTurbulence（baseFrequency .86、3 倍频、180px 平铺）；
- **纸纹**：photo-archive、notes-index、finale 共用 `paper-texture.webp`（217,278 B，1024px 平铺，multiply）；海龟汤纸卡另有 420px 专属纸纹（`--turtle-paper-image`，multiply，卡面 .22 / 纸条 .18 不透明度）；
- **装裱公式**：相框 = 7px 纸边 + 1px `--border` + 图面内嵌 1px 阴影线；灯箱大图边框加厚至 `clamp(8px,1.2vw,14px)`；
- **圆角策略**：版面直角；圆角只给「实体道具」——菜单 14px、传送门面板 18px、卡片 9—12px、登机牌 11px、放行章 4px、关闭钮 999px；
- **暗面材质**：遮罩统一 `blur(14px) saturate(.9)`；传送门面板双层投影 `0 42px 90px` + `0 6px 18px`；
- **品牌双套印**：图标与字标各备墨、纸两色 webp（合计 4 文件，21KB），按 `data-overlay`/`data-scrolled` 切换，不用 CSS 滤镜反色；
- **无障碍**：skip 链接（朱底纸字，focus 落下）；`aria-live="polite"` 隐形解说区（「已盖章：是。已问 2/3。」「行程已出票：五日分三段，已放行。」）；案卷 stage 收起时 `inert`；书脊 `aria-expanded`；灯箱 Escape + 关闭钮 aria-label；分页滚动全键盘；`:focus-visible` 双色描边（accent-ink，offset 4px）；aria-label 全部口语化中文（「三个问题，点击听主持人回答」）；
- **减少动效**：所有动画与过渡压至 .01ms、雨幕与云层与终章装饰隐藏、分页与吸附退回原生、三幕直接终态——整站级降级；
- **性能**：照片 AVIF 三档（960/1440/1920）、纹理与品牌 webp、道具插画 AVIF；字体 preload 9 片 + 内联临界声明；视频 `preload` 且仅在四条件齐备时播放；ResizeObserver 与图片 load 双通道防布局漂移。

## 九、关键发现（给同行的十条）

1. **JS 写进度、CSS 派生几何**：终章每帧只 setProperty 三次，stagger 与位移全是 `clamp()` 数学——改动效参数不用碰 JS（实锤）。
2. **`transition: grid-template-columns`**：案卷柜开合直接过渡栅格轨道，一行 CSS 替代一套 FLIP（实锤）。
3. **同图双层 + `clip-path:circle()`** 做取景器：黑白垫底、彩色走圆形裁剪，加一枚十字准星就是完整的摄影隐喻（实锤）。
4. **视频的正确姿势**：四重与门（展开、入视口、桌面横屏、允许动效）+ CSS 雨幕兜底，视频永远只是锦上添花（实锤）。
5. **中文字体 176 片按需切片**，高频片 preload，手写体裁到 8.9KB——中文个人站字体方案的教科书（实锤）。
6. **度量兼容兜底字**（size-adjust 等三参数）压住等宽字换字跳动（实锤）。
7. **双时间尺度**：微交互毫秒级、氛围层分钟级（15s 雨、6.5s 灯、110s 云），静中有动（实锤）。
8. **渐进增强的滚动**：CSS snap 兜底、JS 分页器接管、reduced-motion 全关，三层各自完整（实锤）。
9. **示范性无障碍**：交互叙事全程 aria-live 解说、inert 管理焦点、全键盘分页（实锤）。
10. **总分世界观**：主页统一气质、产品页放开美术，个人站里罕见的架构自觉（实锤 + 推断）。
