# Lagom 拆解：出处与方法

> 本文交代每一类数值是怎么来的、哪些是实锤、哪些是推断、还有什么没拿到。

## 一、抽取链路

| 步骤 | 工具与做法 | 产物 |
| --- | --- | --- |
| 1. 真实捕获 | `skills/design-teardown/scripts/capture_site.py`（Playwright + Chromium 148，视口 1440×900 @1.5x，UA 桌面 Chrome）单次会话完成 | `tokens.json`（计算样式探针 + 样式表挖掘）、`design-tokens.css`、`real-assets/**` + `manifest.json`、`recording/scroll.webm`、`keyframes/00-07.jpg`、`screenshots/hero.jpg + full.jpg` |
| 2. 样式表原文精读 | 三份 CSS 落盘后展开美化，逐节读出五幕、终章、传送门、导航的全部规则 | 本目录各文档中的选择器级数值 |
| 3. 脚本逐行读出 | 追加抓取页面模块 JS（14,899 B）与 finale 模块（6,119 B），美化后通读 | 分页滚动、对焦、案卷状态机、胶片动量、终章三幕的全部参数 |
| 4. 内页轻探针 | 同脚本 `--no-assets --no-record` 跑 /photography/、/blog/、/blog/case-turtle-soup/、/projects/turtle-soup/ | 各页 tokens.json 与截图（存于会话工作目录，关键结论已录入文档） |
| 5. 交叉验证 | 浏览器实滚 + 录屏关键帧比对整页截图；拆解页本身用 Playwright 验证（fonts.ready、逐屏滚动、控制台零报错） | as-seen 图与 demo 截图 |

补充抓取（同会话、服务端直连）：JetBrains Mono 主文件 `eb8cefc0a57905aa.woff2`（首屏未触发下载故不在自动清单）、`/home/paper-texture.webp`、品牌四枚 webp——均已入 `real-assets/`，文件名带 `manual_`/`extra_` 前缀以示手工补抓。

## 二、实锤清单（直接抽取）

- **54 个 `:root` 自定义属性**：`tokens.json → tokens.customProps`（含 `--bg` `--accent` `--ease-heavy` `--w1..w3` `--focus-size` 等全部原值）。
- **色值词频**：`tokens.topHex`（`#b3402a` 19 次为首）；样式表原文中的世界色（`#eee3c8` `#0d1f3c` `#9a221b` 等）。
- **5 条贝塞尔曲线与出现次数**：`tokens.cubicBezier`。
- **17 个 `@keyframes` 名与定义**：`tokens.keyframes` + 三份 CSS 原文（stamp-slam、np-wash、board-flip 等关键帧逐帧摘录）。
- **计算样式探针**：body 底色与字族、H1 的 93.67px/360/−1.87px/103px、nav 与按钮样式、`accentGuess`、`fontsLoaded` 七族、媒体统计（video 1、canvas 0、svg 6、img 51、preload font 9）。
- **字体管线**：176 条 CJK `@font-face`（unicode-range 原文）、拉丁三件套内联声明与 `:root` 变量、JetBrains Mono 度量兜底三参数、9 条 preload、文件体积（58,084 / 48,256 / 40,404 / 8,900 B 等）——全部来自 `real-assets/fonts/**` 与 `source/**` 原文。
- **交互参数**：滚轮阈值 28、触摸阈值 56、轴判定 8px、时长 clamp(…, 260, 820)、settle 150ms、easeOutExpo 与 smootherstep 函数体、终章 900/1150/200/900 与 760/160/1000 时序、胶片动量 .35/.65 混合与 .91^(Δt/16.67) 衰减、速度夹 ±6、停阈 .04、灯箱 440ms 卸载延迟、菜单 150ms 悬停意图——页面 JS 原文。
- **页面文案与结构**：五幕选择器、三段 h2、hero H1、终章格言与簪言、frame 动词标签对、15 张照片的标题与年份、三问答案（不是、是也不是、是）、EasyCode 六态标签、「已放行」「通过」章文、aria-label 全文、`aria-live="polite"` 隐形解说区——HTML 原文。
- **真实资产**：视频 `turtle-desk-loop.mp4`、雨幕 webp、三个世界美术 AVIF、摄影 AVIF 多档、纸纹、品牌四 webp、179 个字体文件——`real-assets/manifest.json` 有逐文件 URL 与字节数。
- **内页**：/photography/ 等三页 120 个变量与 `libs=['Lenis']`；/projects/turtle-soup/ 的 fontsLoaded（Noto Serif SC、Special Elite、Caveat、Long Cang）——各页探针 JSON。

## 三、推断清单（证据充分，非直读）

| 推断 | 依据 | 置信 |
| --- | --- | --- |
| 构建栈 Astro | `/_astro/` 路径、`*.astro_astro_type_script_*` 命名、`data-astro-cid-*` 属性 | 高 |
| 拉丁字体走 Astro 字体优化管线 | 哈希家族名 + `/_astro/fonts/` + 内联声明 + 度量兜底的组合特征 | 中高 |
| CJK 切片基于 fontsource 分片再二次子集化 | 文件名 `noto-serif-sc-<片号>-<字重>-normal.<hash>.sub-<hash>.woff2` 的双哈希与片号规律 | 中高 |
| 托管在 Cloudflare 边缘 | insights beacon 注入（beacon 本身实锤；具体产品形态如 Pages/Workers 不详） | 中 |
| 「取景器、显影、案卷」隐喻为有意设计 | 全站视觉与文案一致性（黑白到彩色、快门收卷、档案柜） | 高（意图类推断） |
| 站主身份为摄影与软件双栖的个人作者 | 站点自述与内容结构 | 高（不涉及具体个人信息） |

## 四、局限（没拿到什么、为什么）

1. **构建配置与源码**：站点为静态产物，无 sourcemap，Astro 配置、组件划分、字体子集化脚本均不可见——管线细节按输出特征推断。
2. **图片自动抓取配额**：脚本限前 18 张大图，其余照片（共 51 张 img）未全量落盘；关键美术已补抓。
3. **登机牌航段的完整文案**：`data-journey-stages` 列表在捕获 HTML 中为脚本渲染前状态，仅从 JS 推得节奏（900ms/条）与样式，逐条文字未录。
4. **项目独立页已单独立档**：/projects/ 下三页（海龟汤事务所、EasyCode、JourneyPilot）各有完整拆解档案（全量捕获、逐屏走查、可跑 demo 与五份文档），见本仓 teardowns/turtle-soup、teardowns/easycode、teardowns/journeypilot；本档的内页一节只保留系统级对照。
5. **移动端真机行为**：触摸阈值等来自源码而非真机实测；iOS Safari 的 dvh/svh 表现未实测验证。
6. **录屏为合成滚动**：scroll.webm 由脚本匀速滚动生成，不代表真人操作节奏；终章三幕在录屏中按滚动接管逻辑触发，帧序真实。
7. **`700.DsoVlJfy.css` 的文件名由来**（为何叫 700）不可考——不影响任何数值结论。

## 五、复算口径

- 「176 片」= fonts-cjk.css 中 `@font-face` 计数（Noto Serif SC 88 + Noto Sans SC 88，含 400/600 与 400/700 两档字重）；43 指 serif 400 档的独立片号数。
- 「CSS 总量 266,674 B」= 捕获时三份样式表字节和（tokens.json `cssBytes`）；单文件字节数以磁盘落盘为准（195,584 + 42,839 + 28,255 = 266,678，与探针值差 4 字节，来自换行归一，不影响结论）。
- 「9 处 ease-heavy」= `cubicBezier` 表中 `.32,.72,0,1` 两种书写形态之和（8 + 1）。
- 所有「实测 H1 93.67px」类数值均为 1440×900 视口下的计算样式，其它视口按 clamp 公式换算。
