# Lagom 拆解：设计评审

> 评审对象：本目录的 teardown.html 与四份文档。视角：以顶级产品设计与前端工艺的标准，检验这份拆解的**精度**（数值是否可回溯）与**完成度**（是否配得上被拆对象），并给出可执行改进。

## 一、达标之处

1. **针对性视觉成立**。拆解页完全生活在 Lagom 的语言里：真实的暖纸底与玄墨字、印泥朱强调、全局 .035 胶片颗粒、1024px 纸纹 multiply、发丝线双色制、`--ease-heavy` 驱动的滚动揭示——放在原站旁边是同一家人，不是通用模板。
2. **真字体真素材落地**。Newsreader、Inter、JetBrains Mono、霞鹜文楷与 176 片中文切片全部以本地真文件接入（Playwright 验证 `document.fonts` 六族 loaded、渲染无 tofu、控制台零报错、零请求失败）；案卷 demo 用的是原站真实桌面视频加雨幕 webp，取景器与终章用的是站主的真实摄影 AVIF。
3. **签名效果不止一个，而且是「公式级」复现**。四个可跑 demo（取景器、案卷柜、终章三幕、墨晕点染）全部使用真实缓动、真实时长与真实派生公式；终章 demo 的滑杆直接暴露 `--fe/--fq1/--fq2` 三变量与每字母、每相框的 clamp 数学——读者可以拖着进度条看懂原站最复杂的一段编排。
4. **实锤与推断分级贯穿**。色卡逐一标注来源（变量实锤或词频实锤），技术栈判断全部给出依据与置信级；事实核查抓出七处漂移并当场改正，诚实列账。
5. **深度对齐库内标杆**。五幕逐幕拆到选择器级；三大项目小剧场的状态机、时序、文案逐字核对；中文字体管线（切片、preload 构成、度量兜底三参数）是同类拆解中少见的完整记录。

## 二、相对原站仍差在哪（体裁取舍说明）

- **分页滚动没有做成可跑 demo**。它是原站最核心的工程系统，本拆解以参数表加曲线图呈现（阈值 28/56、时长 clamp、easeOutExpo），但没有让读者「亲手滚一幕」——在拆解页里劫持滚轮容易伤害页面自身的可用性，属有意取舍。
- **终章 demo 的几何是缩配版**：sheet 宽 `min(88%,860px)`（原站 `min(82vw,1080px)`）、演示相片为 960/1440 档而非原站 3:2 全档；公式与时序为真，画幅为适配。
- **灯箱（photo-lens）与传送门（proj-portal）未复现**，只以数值记录（遮罩、边框、投影、Escape 语义）。
- **原站 H1 的 10.4cqw 容器约束**在拆解页标题上未套用（拆解页标题更长，直接用了较小的 clamp）；规格已如实记录在案。

## 四、一句话结论

这份拆解把 imlagom.com 最难的三件事——中文字体管线、JS 写进度 CSS 派生几何的终章、以及「摄影」隐喻的系统性——全部拆到了可回溯、可复刻的程度；剩余差距集中在「把更多系统做成可跑演示」，属完成度加分项而非精度缺口。
