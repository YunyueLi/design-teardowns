let raf = 0, px = 0, py = 0;
const apply = () => { raf = 0;
  const r = hero.getBoundingClientRect();
  hero.style.setProperty('--focus-x', Math.max(0, Math.min(100, (px - r.left) / r.width * 100)) + '%');
  hero.style.setProperty('--focus-y', Math.max(0, Math.min(100, (py - r.top) / r.height * 100)) + '%');

hero.addEventListener('pointerenter', e => { hero.classList.add('is-focused'); track(e); });
hero.addEventListener('pointermove', track);
hero.addEventListener('pointerdown', e => { hero.classList.add('is-focused'); track(e); });
hero.addEventListener('pointerleave', () => {

## 三、字体接入

| 字族 | 方式 | 要点 |
| --- | --- | --- |
| Newsreader | 自托管可变 woff2（58KB，拉丁 unicode-range） | 标题字重用 360；`font-display:swap` |
| Inter | 自托管可变 woff2（48KB） | 正文与 Noto Sans SC 混排 |
| JetBrains Mono | 自托管可变 woff2（40KB）+ 度量兜底 | 见上文代码块 8 |
| Noto Serif SC / Noto Sans SC | 每族 88 片 unicode-range 切片 | 用 fontsource 分片起步，再按站点语料二次子集化；最高频 7 片宋体切片与 2 支拉丁主字体一并 preload |
| 霞鹜文楷 Note | 按用字子集化的单文件（8.9KB） | 批注专用；配 −1.1° 旋转更像手写 |

CJK 切片声明放独立 CSS 异步挂载（`media` 切换技巧），拉丁临界声明内联进 `<head>`。

## 四、选型决策表

| 取舍点 | 它的选择 | 为什么成立 |
| --- | --- | --- |
| 滚动引擎 | 首页手写分页器；内页 Lenis | 首页要「幕」，长文要「流」；一套引擎打不了两种仗 |
| 雨夜氛围 | mp4 视频为主，webp 雨幕 CSS 循环兜底 | 视频有四重播放条件；没播时雨幕顶上，画面永远有雨 |
| 滚动驱动动画 | JS 写进度变量，CSS `clamp()` 派生几何 | 每帧 3 次 setProperty；stagger 全在 CSS，可调参不改码 |
| 案卷开合 | `transition: grid-template-columns` | 一行 CSS 替代 FLIP；配 2px 缝隙露衬底 |
| 对焦效果 | 同图双层 + `clip-path:circle()` | 双层同源图避免二次请求（缓存命中），裁剪比 mask 便宜 |
| 照片格式 | AVIF 三档（960/1440/1920） | 摄影站带宽大头在图；纹理与品牌 webp |
| 中文字体 | 176 片 unicode-range + 高频 preload | 比整包省两个数量级；比按文案硬裁可长大 |
| 项目展示 | 首页装抽屉，产品页开世界 | 主页统一气质，产品页放开美术 |

## 五、工程坑（复刻时最容易踩的）

1. **`transition: grid-template-columns` 要求轨道数量与单位形态稳定**：始终保持三条 `fr` 轨道、只动数值（1fr ⇄ 6fr），混入 auto 或增删轨道会跳变。
2. **派生进度公式里的 `--i` 必须是无单位整数**，且要写在元素内联 style 或独立规则里；`calc()` 除法的除数不能带单位。
3. **`clip-path` 的过渡只在同形状间成立**：`circle(0px)` 到 `circle(190px)` 可过渡；从 `none` 开始会闪跳。
4. **指针驱动变量务必 rAF 节流**，并写百分比而不是像素——resize 后无需重算。
5. **视频兜底顺序**：先渲染 CSS 雨幕，`video.play()` 的 Promise resolve 后再标记 `.is-playing` 隐藏雨幕；autoplay 需 `muted playsinline`，被拒时静默保持雨幕。
6. **滚动接管的退出条件**要完整：`prefers-reduced-motion`、竖屏、窄屏都应退回原生滚动；别忘了 `history.scrollRestoration='manual'` 与 Home、End 键。
7. **`scroll-snap` 与 JS 分页并存会打架**：接管时给 `<html>` 加类关闭 snap（`scroll-snap-type:none`），JS 失效时 CSS 兜底仍在。
8. **unicode-range 切片站**在开发环境批量注入 @font-face 时，注意浏览器仅按需下载——本地磁盘路径也一样成立，不必担心 176 条声明的加载成本，成本只在 CSS 体积。
9. **oklch 需要现代浏览器**（2023+）；要兼容旧栈就同时输出 sRGB 回退值，或用构建期转换。
10. **`background-blend-mode:multiply` 的纸纹**在深色底上会整体压黑——深色区块（案卷、终章暗面）别贴同一张纹理，原站深色区用的是美术图自带质感。
11. **印章类动画的「落定感」全在中间帧**：stamp-slam 的 62% 处 scale .94（过冲回弹）与终态 −6° 的歪斜缺一不可，删掉就假。
12. **iOS 高度单位**：全屏幕用 `100dvh`/`100svh`（原站 sticky 舞台用 svh、幕高用 dvh），混用 vh 会在地址栏收放时跳。
