## 2. 签名一:彩色高亮胶囊(纯 CSS,零依赖)

关键词外套浅色胶囊,前置实心圆点,入场用 Notion 的 `popIn` 回弹曲线"弹"出来。

```css
.hl{
  display:inline-flex;align-items:center;gap:.28em;
  padding:.02em .5em .02em .42em;
  background:var(--hl-green-fill);
  border-radius:var(--r-round);      /* 药丸 */
  color:var(--ink);
  animation:popIn .34s var(--ease-pop) both;
}
.hl::before{                         /* 状态灯圆点 */
  content:"";width:.5em;height:.5em;border-radius:50%;
  background:var(--hl-green-dot);flex:none;
}
@keyframes popIn{
  from{transform:scale(.6);opacity:0}
  to  {transform:scale(1);opacity:1}
}
```

```html
<h1>Where teams and agents
  <span class="hl">Ship</span> together.</h1>
```

换色只改两个变量:`--hl-*-fill`(填充)与 `--hl-*-dot`(圆点)。六套糖果色见 §1。

## 3. 签名二:手绘涂鸦圆形头像(内联 SVG + 彩环)

每个头像 = 白底圆 + 手绘黑线五官(SVG 路径)+ 彩色描边圆环;一排并置,hover 轻微旋转弹跳。

```css
.doodle-row{display:flex;gap:0}
.doodle{
  width:64px;height:64px;border-radius:50%;
  background:#fff;border:3px solid var(--hl-teal-dot);
  display:grid;place-items:center;margin-left:-10px;   /* 轻叠 */
  transition:transform .25s var(--ease-pop);
}
.doodle:first-child{margin-left:0}
.doodle:hover{transform:translateY(-6px) rotate(-6deg)}
.doodle svg{width:66%;height:66%}
.doodle svg path,.doodle svg circle{
  stroke:#111;stroke-width:2.4;fill:none;stroke-linecap:round;stroke-linejoin:round;
}
```

彩环颜色按 Notion 交替:蓝 `#2383e2`、黑 `#111`、红 `#ff6522`、黄 `#ffb600`。手绘五官用几条随性的 `path`(眼睛两点、一条弧嘴、几缕头发)即可,不求工整——越"抖"越像手绘。

## 4. 签名三:漂浮描边小图标(极慢长循环)

产品图四周飘几枚彩色描边小图标,用 15 到 25s 的超长循环上下浮动,几乎察觉不到在动,只给纯白页面一点生气。

```css
.float-icon{
  position:absolute;width:40px;height:40px;border-radius:var(--r-700);
  background:#fff;border:1.5px solid var(--line);
  box-shadow:0 8px 24px rgb(0 0 0/8%);
  display:grid;place-items:center;
  animation:drift 18s var(--ease-1) infinite alternate;
}
.float-icon.slow{animation-duration:25s}
@keyframes drift{
  from{transform:translateY(-6px) rotate(-3deg)}
  to  {transform:translateY(8px)  rotate(3deg)}
}
@media(prefers-reduced-motion:reduce){.float-icon{animation:none}}
```

图标本身是彩色描边 SVG(书、勾选框、GitHub 等),描边用高亮糖果色 `--hl-*-dot`。

## 6. 选型决策表

| 元素 | 选型 | 理由 |
|---|---|---|
| 巨标题气场 | 超大字号 + 极紧字距(`-4.6px@96px`)+ 贴合行高,字重仅 600 | 力量来自参数不来自加粗;保留 Inter 的亲和圆度 |
| 高亮关键词 | 纯 CSS 胶囊 + `::before` 圆点 + `popIn` 回弹 | 零依赖,可无限套;回弹注入俏皮 |
| 手绘头像 / 插画 | 内联 SVG 路径 | 矢量可缩放、可上色、体积小;Notion 全站 41 SVG 仅 1 video |
| 漂浮小图标 | SVG + 超长 CSS transform 循环 | 15 到 25s 环境层,不抢戏 |
| 分块 | 纯白底 + 发丝线 + 暖灰卡 | 不用毛玻璃(导航 `backdrop-filter:none`),纸感更强 |
| 滚动导航 | 加投影(`navShadowScrolled`)而非模糊 | 比 blur 更轻、更"纸" |
| 强调色 | 只留一枚蓝给 CTA,活力交给高亮糖果色 | 克制但不闷 |

## 7. 工程坑

- **暖灰不是纯灰**:灰阶微微偏暖(`#f9f9f8` 而非 `#f9f9f9`),这是"亲和"观感的隐形来源,别换成中性灰。
- **底是纯白不是暖白**:Notion 底色实测 `#fff`(与 Comet 的暖白 `#FBFAF4` 相反),别照搬别站。
- **只有一枚蓝**:忍住不要再加第二枚强调色;需要色彩时用高亮胶囊,不要扩张 CTA 蓝的用途。
- **CSS 体积**:整页 CSS 约 1.5MB(多语言 + 大量组件)。复刻单页无需背这个包袱,但要意识到 Notion 的做法是"组件化样式全量下发"。
- **`prefers-reduced-motion`**:关掉漂浮、回弹、慢循环;高亮胶囊改为直接显示不弹。
- **字体授权**:NotionInter、Lyon Text、iA Writer Mono 均为商业或定制字体,生产需自购或自定制。开发占位用 Inter、Newsreader、IBM Plex Mono 临摹血统;Permanent Marker 在 Google Fonts 上有同名开源版可直接用。
