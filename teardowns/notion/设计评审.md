# Notion 拆解页 · 设计评审(第二轮)

> 视角:以顶级设计评审的标准,衡量这份拆解页相对原站(notion.com)的**精度**与**完成度** —— 哪些已达标、哪些仍有差距,并给出可执行改进(能当场改的已在本轮落地)。
> 前提:本页是一份**设计解构 / 分析页**,不是首页克隆。因此「贴近原站」指的是所展示 token 与签名母题的还原精度,以及分析本身的诚实度,而非整页 1:1 复制。

## 一、总体判断
第二轮把精度从「血统临摹」抬到了「真材实料」:标题与正文换成真实 NotionInter、等宽换成真实 iA Writer Mono,主色由推断的 Google 系蓝纠正为 Notion 真实蓝阶,Hero 巨标题按实测的 96px / 600 / -4.6px / 行高 100px 校准,并嵌入了站点原样的 Hero 与 Agent 视频。观感上,标题的字形收肩、字距张力与「靠参数不靠字重」的气质,现在与原站基本可对齐,不再是「像 Notion 的字」。分析诚实度也更硬:每个数值都能回到 `notion.json` 或真实 CSS,`#1a73e8` 这类第三方污染被点名剔除。

## 二、已达标
- **字体真实度**:标题 / 正文 / 等宽三条主线全部为站点原字体,`@font-face` 自托管、先真后兜底,首屏两支关键字重(400 / 600)预加载。
- **色彩纪律与真实度**:纯白底、暖灰阶九档、编辑器高亮色板(青 / 琥珀 / 橙 / 紫 / 红均实锤)、蓝阶 400–700 全实锤;「只一枚蓝,只给 CTA」的克制被完整呈现。
- **巨标题参数**:字号 / 字重 / 字距 / 行高逐项对齐实测,示范卡直接用真实字体演示,论点与证据自洽。
- **动效诚实度**:11 条真实曲线(去重自 16 条声明),签名回弹 `popIn` 被证实是站点真有的 `@keyframes`,缓动实验台逐条可重放。
- **真实媒体为证**:as-seen 区用站点原样视频呈现 Hero 工作区与两个 Agent 的真实动态,读者可与页内手绘 mock 直接对照。
- **无障碍**:`prefers-reduced-motion` 下关闭漂浮、回弹与视频自动播放;视频带 `controls` 可手动控制。

## 三、相对原站仍有的差距
1. **衬线(Lyon Text)仍是替身**:类型区「引用 / 编辑感」示范卡目前用开源 Newsreader,而非真实 Lyon Text —— 本轮按「只接标题 / 正文 / 等宽」的取舍纪律刻意未接。
2. **插画为致敬性重绘**:手绘涂鸦头像、漂浮小图标、产品 mock 均为原创 SVG 临摹,非站点原图。这是出于授权与原创安全的主动取舍,不追求逐像素一致。
3. **绿胶囊为近似**:topHex 未抓到绿色高亮样本,Hero「Ship」胶囊改用真实 `--color-green` 阶(`#d0f4d8 / #1aae39`),已远优于此前的 Google 绿,但仍非对 Hero 像素的直接取色。
4. **poster 兜底稳健性**:Hero 视频的 `poster` 指向无扩展名的真实文件(`real-assets/image/6da6d3_image`),个别静态服务器可能不以 `image/*` 返回而致 poster 不显示;已用静音自动播放兜底(首帧即出),影响有限。

## 四、可执行改进(本轮落地 + 建议)

已在本轮落地:
1. **接入真实字体**:NotionInter(4 档)+ iA Writer Mono(2 档)自托管替换替身。
2. **主色纠偏**:CTA 蓝 `#2383e2 → #097fe8`、悬停 `→ #0075de`、软蓝 `→ #e6f3fe`;绿胶囊改真实绿阶;`#1a73e8` 重标为第三方并剔除。
3. **巨标题校准**:字重 700 → 600、字距 -.045em → -.048em、行高 → 1.04、上限 → 96px。
4. **真实媒体**:嵌入 Hero 与两段 Agent 视频,并把「16 条曲线」更正为「11 条(16 声明)」。
5. **真实阴影**:接入 `--shadow-100/200/300` 多层阴影,用于卡片悬停与产品 mock,层次更接近原站的轻柔投影。

建议(未做,附理由 / 成本):
6. **为衬线示范单独接入真实 Lyon Text**(约 +53KB woff2):仅让「引用 / 编辑感」那一张卡显示真字。当前按取舍纪律未接;若要把类型区做到「四条字线全真」,这是唯一缺口,可低成本补上。
7. **正文字距按真实分档细化**:目前正文用单一 `-.006em`,原站按字号分档(如 `sans-300` 为 `-0.0078125rem`)。对长正文可逐档套真实 letter-spacing,属锦上添花的排版精度。

## 五、结论
这份拆解页在**排版、色彩、动效、媒体**四条主线上都完成了从「近似」到「真材实料」的升级,分析诚实度经得起对抗式核查(第三方污染被识别、计数被去重、推断被证伪或坐实)。剩余差距(衬线替身、插画为致敬重绘、绿胶囊近似)均为**有意识的取舍**,已在页内出处栏与本评审中如实标注,不构成误导。就一份「拆到可复刻」的解构页而言,精度与完成度已达可交付水准。
