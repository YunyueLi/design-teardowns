# Notion 拆解页 · 事实核查(第二轮)

> 目的:把 `teardown.html` 里出现的每一个数值(色值 / 字体 / 缓动 / 时长 / 圆角 / 阴影)与真实抽取逐条对照,列出漂移并改正,并复核「实锤 / 推断」标注是否属实。
> 依据来源:
> - `../_data/notion.json`(Playwright 计算样式 + 12 个样式表正则统计,`cssBytes` 约 1.58MB);
> - `real-assets/source/*.css`(站点样式表原文,含完整 `--color-*` / `--font-*` / `--motion-*` / `--shadow-*` 设计 token);
> - `real-assets/manifest.json`(真实字体 / 视频 / 图片清单);
> - `design-tokens.css`、`assets/actual-hero.jpg`(抓取时首屏实拍)。

## 一、逐项核对

说明:核对结论分三类 —— 「一致」(页面值与真实抽取相符)、「已改」(本轮发现漂移并已在页面改正)、「标注更正」(数值没错但真伪归属标注需修正)。

### 1. 基底与文字
| 项 | 页面 | 真实抽取 | 结论 |
| --- | --- | --- | --- |
| 背景 | `#ffffff` | body `background-color: rgb(255,255,255)` | 一致 |
| 主文字 | `rgba(0,0,0,.95)` | body / h1 `color: rgba(0,0,0,0.95)` | 一致 |

### 2. 暖中性灰阶
逐一对照真实 `--color-gray-*`:`100 #f9f9f8`、`200 #f6f5f4`、`300 #dfdcd9`、`400 #a39e98`、`500 #78736f`、`600 #615d59`、`700 #494744`、`800 #31302e`、`900 #191918` —— 页面九档全部一致。这套灰阶「微偏暖」(如 `#f9f9f8` 而非 `#f9f9f9`)属实。

### 3. 高亮糖果色(Notion 编辑器高亮色板,独立于基础 `--color-*` 色阶)
| 色 | 页面(填充 → 圆点) | 真实来源 | 结论 |

| 青 teal | `#ddfcfa → #03c1ba` | topHex 各计 6 次 | 一致(实锤) |
| 琥珀 amber | `#fff4cb → #ffb600` | topHex 各计 4 次 | 一致(实锤) |

| 红 red | `#fef3f1 → #f64932` | `--color-red-100 / -500` | 一致(实锤) |
| 绿 green(Ship) | 原 `#d3f0dd → #0f9d58` | 见下 | 已改 |

补充:青 / 琥珀 / 橙 / 紫 来自 topHex,与基础色阶(如 `--color-teal-500 #27918d`)不同,属编辑器高亮色板,均为实锤。

### 4. 绿色「Ship」胶囊 —— 已改
- 漂移:第一轮用 `#d3f0dd`(填充)/`#0f9d58`(圆点),标「推断」。经全文检索,这两个值在 Notion 自有 CSS 中**零命中**,`#0f9d58` 实为 Google 系绿。
- 真实值:Notion 有完整绿色阶,`--color-green-200 #d0f4d8`、`--color-green-500 #1aae39`(各出现于真实 CSS)。topHex 中并无绿色高亮项,故 Hero 胶囊的像素级精确绿无直接抽取样本。
- 处置:改用真实绿阶 `#d0f4d8 / #1aae39`,较此前的 Google 绿更贴近实拍中的胶囊观感;标注升为「实锤」(值取自真实 `--color-green`),同时在页面出处栏说明其为 Hero 胶囊的近似,而非逐像素取色。

### 5. 蓝色 CTA —— 本轮最大修正
- 漂移一:第一轮 CTA 主蓝记为 `#2383e2`(推断),恰为 Google 蓝同值;悬停记为 `#1a73e8`;次级软蓝 `#eaf2fb`(推断)。
- 真实值:站点 CSS 给出完整蓝色阶 —— `blue-400 #62aef0`(即 `--accent`)、`blue-500 #097fe8`、`blue-600 #0075de`、`blue-700 #005bab`;软蓝 `blue-200 #e6f3fe`。`#097fe8` 在真实 CSS 出现 3 次,`#0075de`、`#005bab` 各 1 次。
- 处置:主蓝改 `#097fe8`、悬停改 `#0075de`、软蓝改 `#e6f3fe`;`--accent #62aef0` 保留(实锤)。
- 漂移二(标注更正):第一轮把高频蓝 `#1a73e8` 标为「实锤」(样式表 15 次)。计数属实(topHex `n:15`),但该值在 **Notion 自有样式表中检索为零命中**,与同榜 `#0052cc`(Atlassian)、`#e8eaed`、`#5f6368`(Google)同属页面内嵌第三方组件的颜色。处置:重标为「第三方」,明确剔除出 Notion 品牌色,并在正文与出处栏说明。

### 6. 字体
| 项 | 页面(第一轮) | 真实抽取 | 结论 |
| --- | --- | --- | --- |
| 正文 / 标题字族 | 开源替身 Inter | `--font-family-primary-sans: NotionInter`;fontFamily 命中 32 次 | 已改:接入真实 NotionInter(400/500/600/700)自托管 |
| 等宽字族 | 开源替身 IBM Plex Mono | `--font-family-primary-mono: "iA Writer Mono"` | 已改:接入真实 iA Writer Mono(400/700)自托管 |
| 衬线字族 | 开源替身 Newsreader | `--font-family-primary-serif: "Lyon Text"` | 保留替身:衬线非「标题/正文/等宽」,本轮按纪律未接入 |
| Hero 字号 | clamp 上限 92px | `font-size: 96px` | 已改:上限提到 96px |
| Hero 字重 | 700 | `font-weight: 600` | 已改:改为 600(与「气场靠参数不靠字重」一致) |
| Hero 字距 | `-.045em` | `letter-spacing: -4.6px`(96px 处 ≈ `-0.048em`) | 已改:统一为 `-.048em` |

真实 letter-spacing 阶(semibold)佐证:`sans-1100-semibold = -0.2875rem = -4.6px`,与实测完全吻合。

### 7. 缓动曲线 —— 已改(计数更正)
- 漂移:第一轮称「16 条不同的三次贝塞尔曲线」。`notion.json.cubicBezier` 数组确有 16 条,但含同一曲线的不同写法(如 `.645,.045,.355,1` 与 `0.645, 0.045, 0.355, 1`)。去重后为 **11 条**不同曲线。
- 处置:正文与首屏标签改为「11 条曲线(16 声明)」。
- 复核签名曲线:回弹越界 `cubic-bezier(.175,.885,.32,1.275)` 在真实 CSS 命中,且存在同名 `@keyframes popIn` —— 「签名回弹」为实锤,非臆测。平滑收尾 `cubic-bezier(.16,1,.3,1)` 亦命中。

### 8. 时长阶梯
页面档位 `75ms / 150ms / 200ms / 250ms / 1s / 2s / 15s / 25s` 与「甚至抓到 218s」,逐一对上 `notion.json.durations`(`0.15s` 计 13、`75ms` 计 4、`218s` 计 4 等)。按钮过渡 `background-color 0.15s` 与探针一致。结论:一致。

### 9. 圆角与阴影
- 圆角:真实 `--border-radius-700 = 0.75rem = 12px` 使用最频(radii `n:29`),页面把 `--r-700 12px` 标为「最高频 · 卡片」正确;按钮 `4px`(`n:14`)、`3px`(`n:9`)均对得上。结论:一致。
- 阴影(本轮新增):接入真实 `--shadow-100/200/300`(多层堆叠),用于卡片悬停与产品 mock,替换第一轮的临时单层阴影。属实锤补强。

### 10. `@keyframes` 命名
页面所列 `navShadowScrolled`、`thinkTogether…HeroExit`、`loadingDots_pulse`、`popoverSlideDown`、`popIn`、`fadeIn/Out`、`scaleIn/Out`、`rotate` —— 在真实 CSS 中逐一命中(带 hash 后缀,如 `globalNavigation_navShadowScrolled__pZKcg`)。结论:全部一致(实锤)。

### 11. 媒体与框架
`SVG 41 / 图片 73 / video 1 / canvas 0 / 预加载字体 4`,与 `notion.json.media`(`svg:41, img:73, video:1, canvas:0, preloadFont:4`)一致;框架 Next.js 与 `libs` 一致。

## 三、「实锤 vs 推断」标注复核结论
- 更正 1 处**误标为实锤**:`#1a73e8`(实为第三方污染),已改为「第三方」并从品牌色剔除。
- 升级 1 处**由推断转实锤**:绿胶囊改用真实 `--color-green` 阶。
- 消除 1 处推断项:CTA 主蓝由推断值更正为真实蓝阶。
- 其余「实锤」项(灰阶、高亮色、缓动、时长、圆角、`@keyframes`、媒体、字体)经复核均属实,标注保持。
