# Notion 官网首页 · 设计解构

> 顶级 UI 视角的完整拆解。除特别标注,所有数值均来自对 <https://www.notion.com> 的真实抽取(Playwright 计算样式加服务端抓取的样式表文本,见 `../_data/notion.json` 与 `design-tokens.css`),标为**实锤**;来自截图观察或公开常识的信息标为**推断**,绝不编造精确数值。

---

## 1. 定位与设计意图

Notion 首页的这一版主打一句话:**Where teams and agents Ship together.**(团队与智能体一起交付)。它要同时说服两类人——已经在用 Notion 的团队,和刚被"AI 工作区"吸引来的新访客——所以整页的核心张力是:

- **一边是极致的亲和与温度**:纯白底、圆脸手绘头像、彩色高亮胶囊、飘在产品图周围的涂鸦小图标。它不端着,像一个愿意陪你干活的伙伴。
- **一边是极高的信息密度**:一屏之内塞进大标题、副标题、双 CTA、真实产品截图、九家客户 logo 墙;往下每一屏都是"标题加真实产品 mock"的密排卡片。它要在最短的滚动距离里证明"这个工具真能干活"。

把这两股力捏在一起而不显得吵,靠的是三件事:**纯白底统一一切**、**卡片化切分信息块**、**一枚克制的蓝色只留给 CTA**。温度由插画注入,秩序由留白与卡片维持。这正是 Notion 区别于冷静工具派(如 Linear)的地方——它选择"亲和"而不是"精密"作为第一印象。

> 一句话概括复刻目标:**用纯白与卡片托住高密度信息,再用手绘插画与彩色高亮把温度打进去。**

## 2. 色彩系统(真实 token)

Notion 的底色不是"高级灰",而是**偏暖的中性灰阶**——灰里带一点点棕,配纯白底显得干净又不冷。强调色只有一枚蓝色留给 CTA;真正的"色彩表演"全部交给**高亮胶囊**的一组糖果色。

### 2.1 基底与文字(实锤,computed)

| 名称 | 值 | 角色 | 来源 |
|---|---|---|---|
| 背景白 | `rgb(255,255,255)` | 页面底,纯白非暖白 | `body` computed |
| 主文字 | `rgba(0,0,0,0.95)` | 近黑,非纯黑,略透一点点底色 | `body` / `h1` computed |
| 文字-深 | `#111111` | 强调文字 `--text-color-dark` | 样式表变量 |
| 文字-常规 | `#040404` | 正文 `--text-color-regular` | 样式表变量 |
| 文字-中 | `rgb(0 0 0 / 60%)` | 次级 `--text-color-medium` | 样式表变量 |
| 文字-浅 | `rgb(0 0 0 / 40%)` | 辅助 `--text-color-light` | 样式表变量 |
| 文字-极浅 | `rgb(0 0 0 / 20%)` | 占位 `--text-color-extra-light` | 样式表变量 |
| 发丝线 | `rgb(0 0 0 / 8%)` | 边框 `--border-color-regular` | 样式表变量 |

### 2.2 暖中性灰阶(实锤,`--color-gray-*`)

一整套九档灰,注意色相不是纯灰而是微微偏暖(green/red 通道略高),这是 Notion 底色"温"的技术来源:

| 档 | HEX | 档 | HEX |
|---|---|---|---|
| gray-100 | `#f9f9f8` | gray-600 | `#615d59` |
| gray-200 | `#f6f5f4` | gray-700 | `#494744` |
| gray-300 | `#dfdcd9` | gray-800 | `#31302e` |
| gray-400 | `#a39e98` | gray-900 | `#191918` |
| gray-500 | `#78736f` | | |

其中 `#f6f5f4`(gray-200)是样式表高频色之一,正是各 section 之间浅灰分隔带与卡片底的用色。

### 2.3 高亮胶囊糖果色(签名色,实锤 topHex + 推断绿)

Notion 的招牌是把关键词用彩色胶囊框住,每个胶囊是"**浅色填充 + 同色系圆点/文字**"。以下配对中,青、琥珀、橙、紫、红均来自样式表高频色值(实锤);Hero 里那枚 "Ship" 绿色胶囊的精确绿值未落在抽取的高频表内(抽取到的绿家族是青 `#03c1ba`),故其值标为**推断/观察**。

| 高亮 | 填充(浅) | 圆点/文字(深) | 来源 |
|---|---|---|---|
| 青 | `#ddfcfa` | `#03c1ba` | 实锤 topHex |
| 琥珀 | `#fff4cb` | `#ffb600` | 实锤 topHex |
| 橙 | `#ffe9d3` / `#ffebe3` | `#ff6522` | 实锤 topHex |
| 紫 | `#f7e5ff` | `#a361ff` | 实锤 topHex |
| 红 | `#fef3f1` | `#f64932` (`--color-red-500`) | 实锤变量 |
| **绿(Hero "Ship")** | 浅绿约 `#d3f0dd` | 绿约 `#0f9d58` | **推断/观察** |

> **签名做法**:胶囊 = 浅填充底 + 前置一个实心小圆点 + 关键词用深色。圆点像"状态灯",把普通词变成"被标注过的重点"。这套色板同样出现在下方 bento 卡的大色块背景(琥珀、珊瑚红、蓝、棕),只是饱和度更高、面积更大。

### 2.4 蓝色 CTA(实锤高频 + 推断品牌值)

| 名称 | 值 | 角色 | 来源 |
|---|---|---|---|
| `--accent`(抽取) | `#62aef0` | 站点 `--accent` 变量实测(偏浅) | **实锤** computed 变量 |
| 高频蓝 | `#1a73e8` | 样式表出现 15 次(可能含第三方内嵌) | 实锤 topHex(**存疑**) |
| CTA 主蓝 | 约 `#2383e2` | "Get Notion free" 按钮观察值(Notion 品牌蓝) | **推断/观察** |
| 次级软蓝底 | 约 `#eaf2fb` | "Request a demo" 浅蓝按钮底 | **推断/观察** |

> **诚实纠错**:抽取到的 `--accent` 是偏浅的 `#62aef0`,而 Hero 上的实心蓝按钮明显更饱和。样式表高频蓝 `#1a73e8` 恰好与 Google 系蓝同值,不排除来自内嵌第三方脚本,故不敢把它当作 Notion 主蓝的铁证。本拆解把 CTA 主蓝按观察记为约 `#2383e2`(Notion 长期品牌蓝),并明确标注为推断。复刻时二选一皆可,重点是"**只有一枚蓝,只给 CTA**"这条纪律。

## 3. 字体系统

Notion 用**同一款无衬线**扛起了从 96px 巨标题到正文的绝大多数场景,只在少数"引用/编辑感"处切一款衬线,在代码/技术处切一款等宽,在手绘涂鸦处切一款马克笔体。

| 角色 | 字体 | 说明 | 来源 |
|---|---|---|---|
| 品牌、UI、标题、正文 | **NotionInter** | 定制版 Inter;首页 32 处 font-family 命中它 | 实锤 computed 与 fontFamily 统计 |
| 引用 / 编辑感衬线 | **Lyon Text** | "Your AI everything app." 一类引用、编辑气质 | 实锤 fontsLoaded |
| 代码 / 技术文本 | **iA Writer Mono** | 等宽;血统源自 IBM Plex Mono | 实锤 fontsLoaded |
| 手绘 / 涂鸦标注 | **Permanent Marker** | 马克笔体,配合手绘插画的随性感 | 实锤 fontsLoaded |
| 阿拉伯 / 希伯来 | Noto Sans Arabic / Hebrew | 多语言回退 | 实锤 fontsLoaded |

**Hero 大标题实测(实锤 computed)**:字号 `96px`,字重 `600`,**字距 `-4.6px`**(极紧),行高 `100px`(仅比字号高 4px,行与行几乎贴合)。这套参数是"黑色粗无衬线大标题"气场的技术真身——**字重不必到 800,靠超大字号加极紧字距**就压出了力量感,同时保持 Inter 的亲和圆度。

> **本页字体替身**:NotionInter 是 Notion 定制的 Inter,故本解构页正文与标题直接用 **Inter**(Google Fonts)临摹,血统一致。衬线 Lyon Text 为商业字体,用 **Newsreader** 作高质量开源替身;等宽 iA Writer Mono 的血统是 IBM Plex Mono,故直接用 **IBM Plex Mono**;手绘 **Permanent Marker** 在 Google Fonts 上即有同名开源版,可原样使用。

## 4. 动效系统

首页抓到 **16 条不同的三次贝塞尔曲线**与一梯清晰的时长档。整体动效克制:入场靠 `fadeIn`/`scaleIn`/`popIn`,滚动时导航加投影,背景有极慢的环境循环,交互只给 100 到 250ms 的轻反馈。

### 4.1 双时间尺度

- **敏捷微交互层**:按钮 `background-color 0.15s`(实锤),配 `75ms`/`0.1s`/`0.2s`/`0.25s` 等短时长——鼠标一碰即时回应,手感干脆。
- **环境慢层**:抓到 `1s`、`2s`、`3s`,以及极长的 `15s`、`25s`、乃至 `218s`(实锤)。这些长循环多用于背景插画的漂浮、渐变缓移一类"几乎察觉不到在动"的氛围,给纯白页面一点呼吸感而不抢戏。

### 4.2 签名缓动曲线(样式表实测)

| 曲线 | 值 | 出现次数 | 用途推断 |
|---|---|---|---|
| 工作马 · 柔顺进出 | `cubic-bezier(.645,.045,.355,1)` | 5(最高) | 位移、淡入淡出的默认曲线 |
| 强进出 | `cubic-bezier(.86,0,.07,1)` | 2 | 大幅度、有力度的切换 |
| 对称进出 | `cubic-bezier(.76,0,.24,1)` | 2 | 面板展开/收起 |
| 正弦进出 | `cubic-bezier(.45,0,.55,1)` | 2 | 轻柔往复 |
| **回弹越界** | `cubic-bezier(.175,.885,.32,1.275)` | 1 | `popIn` 的"啵"一下(y>1 越界回弹) |
| 平滑收尾 | `cubic-bezier(.16,1,.3,1)` | 1 | Expo-out 感的长尾沉降 |

其中**回弹越界曲线**是高亮胶囊、头像入场那种"弹一下"手感的关键:第四控制点 `1.275` 让元素先弹过头再收回,把"亲和/俏皮"写进了运动本身。

### 4.3 真实关键帧(实锤 keyframes 名)

抓到的 `@keyframes` 命名直接暴露了动效意图:`fadeIn`、`fadeOut`、`scaleIn`、`scaleOut`、`popIn`(入场四件套加一个弹入)、`rotate`(旋转)、`loadingDots_pulse`(加载点脉动)、`popover_popoverFadeIn` 与 `popoverSlideDown`(浮层),以及一组 `globalNavigation_*`——包括 **`navShadowScrolled`(滚动后导航加投影)**、`slideDown`,还有多条 `thinkTogether*HeroExit`(Hero 退场时导航配色、背景与 logo 填充的联动过渡)。这说明**导航栏的滚动投影与 Hero 退场联动是刻意编排的**,不是随手加的。

## 5. Hero 手法

Hero 是整套签名语言的浓缩展台,自上而下三层:

1. **一排手绘涂鸦圆形头像**(约 7 个):黑色手绘线条的圆脸(短发女生、卷发、路标、扎发带的人、简笔脸、文件夹机器人、戴眼镜的人),每个套一枚**彩色描边圆环**(蓝、黑、红、黄、黑、蓝、红交替)。它像一支"团队 + 智能体"的合影,一上来就把"一起干活"的温度立住。
2. **黑色粗无衬线巨标题**:`Where teams and agents [·Ship] together.`——关键词 **Ship** 被一枚**浅绿高亮胶囊**框住,胶囊内前置一个**绿色实心圆点**。这是全站最强的签名瞬间:巨大的黑字里,唯一的彩色是这枚"被标重点"的绿胶囊。
3. **产品真身加漂浮小图标**:居中蓝色主 CTA("Get Notion free")配浅蓝次级 CTA("Request a demo");下方是裱在浏览器窗框里的**真实产品截图**;产品图左右**飘着几枚彩色描边小图标**(黄色翻开的书、灰色手势、GitHub、紫色勾选框加闪光),用极慢的漂浮动画让静态截图"活"起来。
4. **客户 logo 墙**:首屏底部一行灰度客户名(OpenAI、Figma、Ramp、Cursor、Vercel、NVIDIA、Volvo、L'Oréal、Discord),用小圆点分隔,建立信任。

**信息密度的处理**:不同于"首屏只留一句话"的极简派,Notion 首屏就把头像、标题、副标题、双 CTA、产品图、logo 墙**六件事**全放上。它敢这么密,是因为纯白底加充分行距把每一块都"框"得很清楚——密而不乱。

## 6. 签名视觉母题

| 母题 | 做法 | 复现方式 |
|---|---|---|
| **彩色高亮胶囊** | 浅色填充圆角胶囊 + 前置实心圆点 + 深色关键词;入场用 `popIn` 回弹 | 纯 CSS:`border-radius` 大圆角 + `::before` 圆点 + `popIn` @keyframes |
| **手绘涂鸦头像** | 黑色手绘线条圆脸,外套彩色描边圆环,一排并置 | 内联 SVG 手绘路径 + `border` 彩环;hover 轻微旋转/弹跳 |
| **漂浮描边小图标** | 产品图四周飘彩色描边小图标,极慢上下浮动 | SVG 图标 + `transform: translateY` 长循环动画(15 到 25s) |
| **客户 logo 墙** | 一行灰度品牌名,小圆点分隔 | 文本 wordmark + 统一降饱和,作"意象"呈现 |
| **bento 大色块卡** | 标题加真实 mock,卡底铺高饱和糖果色块(琥珀/珊瑚/蓝/棕) | 卡片 + 大圆角 + 色块背景 + 黑色圆形箭头按钮 |

## 7. 工艺细节

- **圆角语言(实锤)**:一整套 token,`--border-radius-200` 到 `900`(4px 到 16px),外加 `--border-radius-round`(≈9999px 药丸)。实测使用频率最高的是 **`--border-radius-700`(12px,29 次)**,其次 `--border-radius-300`(5px)、`--border-radius-600`(10px)、`4px`。按钮圆角实测 **4px**(小而利落),大卡片则用 12px 以上,层次分明。
- **发丝线**:边框统一 `rgb(0 0 0 / 8%)`(极淡),不用重描边,靠留白与浅灰底分块。
- **无玻璃拟态**:导航 `backdrop-filter: none`(实锤)——不追求毛玻璃,滚动时改用 `navShadowScrolled` 加一道投影来区隔层级,比模糊更"纸感"。
- **栅格(实锤)**:12 列(`--grid-columns: 12`),常规栏距 `28px`(`--grid-gutter`),小屏 `12px`(`--grid-sm-gutter`)。导航高 `64px`(`--global-navigation-height`),基础内边距 `20px`(`--base-padding`)。
- **媒体选型(实锤)**:整页 `svg` 41 个、`img` 73 张,`video` 仅 1、`canvas` 0。**几乎不用视频与画布**——插画与产品截图都是 SVG/图片,轻、快、可无限缩放。预加载 4 个字体(`preloadFont: 4`),优先保证首屏字体不闪。
- **技术栈(实锤)**:Next.js。整页 CSS 体积约 **1.5MB**(`cssBytes: 1,577,418`,抓到 12 个样式表)——多语言与大量组件样式的代价。

## 8. 关键发现

1. **"黑色巨标题"的力量来自参数而非字重**:96px 字号加 `-4.6px` 极紧字距加 `100px` 贴合行高,字重只有 600。想复刻这股气场,别去加粗,去**放大字号、收紧字距、压低行高**。
2. **只有一枚蓝**:全站强调色克制到只给 CTA 一枚蓝;真正的色彩活力全部外包给"高亮胶囊"的糖果色系。这让页面既克制又不闷。
3. **暖灰是温度的隐形来源**:灰阶不是纯灰而是微偏暖(`#f9f9f8`→`#191918`),配纯白底,是"亲和"观感里最容易被忽略的一环。
4. **回弹曲线把俏皮写进运动**:`cubic-bezier(.175,.885,.32,1.275)` 的越界回弹用在 `popIn`,让高亮胶囊与头像"弹"出来——插画负责静态的可爱,回弹负责动态的可爱。
5. **不靠视频靠 SVG**:41 个 SVG、73 张图、仅 1 个 video——签名插画全是矢量,这也是为什么整页在纯白底上依然轻快不卡。
6. **导航滚动投影是编排过的**:`globalNavigation_navShadowScrolled` 与多条 Hero 退场联动动画说明,连"滚动时导航加影子"这种细节都进了动效系统,不是默认行为。

> 详见交互式版 `teardown.html`(含可编辑的高亮胶囊生成器、手绘头像悬停、漂浮小图标、缓动曲线实验台,全部用 Notion 抽取到的真实曲线与时长驱动)。
