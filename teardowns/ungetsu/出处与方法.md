# ungetsu · 雲月 — 出处与方法

本文件回答一个问题：**拆解页与设计解构里的每个数值，是怎么来的。**

---

## 一、抽取链路

1. **真实浏览器会话**。Playwright 驱动 Chromium 打开 `https://ungetsu.net/`，
   在同一次会话里完成：读取计算样式探针、挖掘 CSS 自定义属性与色值/缓动/时长词频、
   下载全部字体与图片、逐屏滚动录屏、截取首屏与整页。
2. **样式表原文**。把页面引用的两份 CSS 按原文取回（505 532 + 31 373 字节），
   直接读 `:root[data-theme=…]` 与各组件规则，而不是依赖计算样式的二手结果。
3. **脚本原文**。把页面引用的 JS 模块从源站取回，读原文而不是从行为猜实现——
   着色器公式、粒子规模、阻尼系数、动画节拍全部来自这一步。
4. **补充素材**。按源码里出现的路径，补取月球反照率贴图、落款顺序图、印章字形、
   毛毡与黑胶纹理、页脚水墨月图。
5. **实测编排距离**。脚本把分段距离写在 `.gallery-entrance` 的 data 属性上
   （`morphDistance`、`lunarHold`、`exhibitionDistance`、`exitDistance`、`particleCount`、
   `moonResolution`、`renderer`），在 1440×900、1512×982、1920×1080、390×844 四种视口下
   各读一次，得到真实分段表，而不是从 `clamp()` 公式反推。
6. **新鲜度校验**。抓取当天再取一次线上 HTML，比对资源指纹：
   `index.BKu8iCnB.css`、`index.BiYKfXdb.css`、`GalleryEntrance…a1BdAbg9.js`
   三者与本地快照一致，确认拆解针对的是当前线上构建而非缓存旧版。

## 三、实锤清单

以下全部可回溯到上表某个文件的原文：

**色彩** — 两套主题各 10 个变量；4 个场景色变量；`uDark = paper.r < .1` 的判据。

**字体** — 5 个字族变量与各自声明频次（49 / 15 / 55 / 2 / 1）；
471 条 `@font-face` 的字族与字重分布（EB Garamond 21、Noto Serif JP 248、Noto Serif SC 202）；
全部自托管于 `/fonts/`；全部 `font-display: swap`。

**动效** — 4 条 cubic-bezier 及其用途；`--t-ui .25s`、`--t-content .8s`；
时长梯全部具名值（.26 / .3 / .4 / .45 / .7 / .8 / .9 / 1.1 / 1.15 / 1.8 / 2.4 / 4.6 / 6.4 / 7s）；
逐字节拍 26 / 105 / 300 / 1150ms 与 `cubic-bezier(.22,.61,.36,1)`。

**编排** — 首屏四段高度公式（桌面与移动各一套）；`--ge-exhibition-share` `.28` / `.3`；
四个 `data-phase` 及其阈值；阻尼系数 `4.2`（指针平滑）与 `3 / 5`（滚动跟随）、吸附阈值 `.05`；
20 次二分求驻留反函数；相机 FOV 38、距离 `h/(2·tan19°)`；
指针视差 `±12px / ±9px` 与衰减 `1-smoothstep((p-.72)/.26)`；
`--ge-exit-caption`、`--ge-plate-opacity`、`--ge-framing-opacity` 三条公式；
故事文案错峰 `[.59,.64,.69,.73,.77]`、跨度 `.23`、位移 24px；`inert` 阈值 `.94`；
交接微弓 `sin(uv.y·π)·sin(uExit·π)·h·.022`。

**着色器** — `lunarFront` / `lunarErosion` / `lunarRelease` 三个函数全文；
月面着色的 pigment / luminance / earthshine 三段公式；
光向 `normalize(sin.48·cos.32, sin.48·sin.32, cos.48)`；
`uProgress` 的 `.45 → .7` 与 `visible = p < .72`；
`photoArrival` / `photoCoverage` 全文；出场换片着色器全文（field / front / grain / arrival）；
`lunarStream` 全文。

**规模** — 粒子 `480×360` / `240×180`；球体分段 `256×192` / `160×112`；
raymarch 44 / 28 步；云 3 层；`HalfFloat` RT 0.65 倍；噪声 `64³` 与八度权重 `.57/.28/.15`；
LCG 种子 `21717`、乘子 `1664525`、增量 `1013904223`；点尺寸 `clamp(.7,12)`；
像素比上限 1.75 / 1.25；贴图 4096 / 2048。

**落款** — SVG `529×205`；`feFuncA type=linear slope=-90 intercept=10.9265625`；
`data-ink-progress="0.121"`；`data-duration="6400"`；
`<noscript>` 与 `prefers-reduced-motion` 下 `mask:none`；
页脚水印 `.16`、长按升到 `.5`（`.78s linear`）、`vault-veil` 白场。

**工艺** — 画框 12 / 7px 与 1px 内线；幕布 `min(620px,88svh)` / `min(440px,82svh)`
与 `translateY(44px) scale(1.06)`；幕布底图双主题混合模式；印章 `1.55em` 圆角 2px；
月相开关 4px / 11px 与 `.7s`；水印 `clamp(6.5rem,17vw,15rem)` `opacity .04`；
作品卡 `.55` 与 `max-height 0→6em`；网点 `.5px/5px opacity .05`；
流光环 `arc-flow 2.4s` 默认 paused；阅读进度的双层 `@supports` + `@media` 闸门；
唱机 `m-spin 4.6s`、唱臂 26°→7°、延迟 `.24s`、`transform-origin: 50% 13px`；
唱片架入场 `100px / -100px / rotateX 24deg`、hover `-7px / rotateX -5deg`；
唱片厅 `690svh`。

**站点事实** — 标题、语言与 `hreflang`（zh-CN / ja / en）；
`schema.org/Person` 的 `knowsAbout` 四项；Astro + View Transitions + three.js r185；
首次访问强制深色的内联脚本；五个频道与对应 `data-ghost` 文案。

## 四、推断清单

以下是观察与判断，不是抽取，正文均已就地标注：

- 目标读者画像（会滚到底的人：同行、合作方、被照片留住的陌生人）
- 「先给气质，再给信息」的意图，以及叙事 / 展陈 / 档案三层的划分
- 自托管字体的动机（首屏确定性、预加载排序、规避第三方抖动）
- UI 色与场景色分层命名是为了「再加一套主题也不用改着色器」
- 固定随机种子意在「每次刷新画面完全一致」，把网页当作品
- 双份唱机实现（WebGL + DOM）是刻意的降级路径
- `cubic-bezier(.34,1.5,.64,1)` 的使用节制程度
- 页脚长按彩蛋是刻意留的隐藏入口，`--gold` 只服务它
- 「每一步都有 B 计划」反映作者对低端设备与国内网络的预期
- 档案层的朴素是刻意对照，但对照来得略突然（见设计评审）

## 五、局限

1. **未逐行分析 `three.module.js`**：体量过大，只读了被本站引用的导出符号。
2. **未进入隐藏页**：页脚长按彩蛋通向的页面未访问，其设计未纳入拆解。
3. **唱机三维场景未逐值还原**：只读了它的 CSS 布局与降级路径，
   `spatial-deck` 的几何、材质、镜头推轨曲线未展开。
4. **只拆了中文首页**：`ja` 与 `en` 版本、以及 `/photos/`、`/music/`、`/posts/`
   等二级页未做对照抽取。
5. **拆解页的三个 demo 是 Canvas 2D 重写**：公式、贴图、颜色、光向与原站相同，
   但实现方式（逐像素重建 vs GPU）、粒子体量（9 000 vs 172 800）、
   是否有体积云与相机视差都不同。**不能拿它当原站的性能参考。**
6. **整页截图大面积为黑**：23 468 设备像素高的整页截图里，首屏那 6 084px（CSS）的滚程
   在不滚动时就是纯黑。逐屏关键帧才是可用的 as-seen 证据。
7. **探针的 `h1` 文本无效**：`probe.h1.text` 抓到的是 `<h1>` 内 `<noscript>` 与
   内联 `<script>` 的文本，因为该 `<h1>` 里没有文字节点，只有 SVG。
   真实语义在 `aria-label="雲月 Ungetsu"` 上。已在事实核查中改正。

## 六、素材与版权

`real-assets/` 下的照片、插画、字体、贴图、音频预览链接均来自
`ungetsu.net` 及其引用的第三方（含商业唱片封面）。
这些素材在本仓库中**仅用于设计比对与技术还原**，未做再分发用途。
EB Garamond 与 Noto Serif SC / JP 为 SIL OFL 授权的开源字体。
拆解页中出现的示例文案由拆解者另写，未复用站点的诗句、歌词与文章正文；
唱片封面等第三方图像未嵌入拆解页。
