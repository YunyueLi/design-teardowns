## 二、签名效果一：落款书写

最便宜、最像的一个。只要有一张「书写顺序图」——PNG 的 alpha 通道从 0 到 1 表示笔画先后——
就能做任何笔迹，包括 `stroke-dashoffset` 根本做不了的行书连笔与飞白。

```html
<svg viewBox="0 0 529 205" fill="currentColor" aria-label="你的落款" data-duration="6400">
  <defs>
    <filter id="ink" color-interpolation-filters="sRGB">
      <feComponentTransfer>
        <feFuncA type="linear" slope="-90" intercept="0"/>
      </feComponentTransfer>
    </filter>
    <mask id="m" x="0" y="0" width="529" height="205"
          maskUnits="userSpaceOnUse" style="mask-type:alpha">
      <image href="order-map.png" x="0" y="0" width="529" height="205" filter="url(#ink)"/>
    </mask>
  </defs>
  <g class="signature-ink" mask="url(#m)">
    <path d="…笔迹矢量…"/>
  </g>
</svg>

<noscript><style>.signature-ink{mask:none!important}</style></noscript>
```

```css
@media (prefers-reduced-motion: reduce){ .signature-ink{ mask:none } }
```

```js
const svg = document.querySelector('svg[data-duration]');
const fn  = svg.querySelector('feFuncA');
const dur = Number(svg.dataset.duration) || 6400;
const t0  = performance.now();
(function tick(now){
  const p = Math.min(1, (now - t0) / dur);
  fn.setAttribute('intercept', String(p * 90 + 1));   // 笔尖位置 × 90
  if (p < 1) requestAnimationFrame(tick);
})(t0);
```

**原理**：`a' = slope·a + intercept`。`slope = -90` 意味着软边宽度 `1/90`；
`intercept / 90` 就是笔尖当前位置。想让笔锋更硬就把 `slope` 调到 `-200`，更软就 `-30`。

**顺序图怎么做**：沿笔画中轴画一条从 alpha 0 到 alpha 1 的渐变带，
用同样的笔刷宽度覆盖整个字形；或者用脚本按笔画采样时间戳烘焙。

## 三、签名效果二：颗粒显影换图

不需要 WebGL。预先算好每像素的 `field`，之后每帧只做一次阈值比较。

```js
// 一次性：field 与 grain
const field = new Float32Array(W * H);
const grain = new Float32Array(W * H);
for (let y = 0; y < H; y++) for (let x = 0; x < W; x++){
  const u = x / W, v = y / H, i = y * W + x;
  field[i] = u * .60 + v * .20 + noise(u * 4, v * 4) * .20;
  grain[i] = hash(Math.floor(u * 2200), Math.floor(v * 1800)) - .5;
}

// 每帧：front 越过 field 的像素换成新图
const front = smoothstep(.08, .82, exit) * 1.24 - .12;
for (let i = 0; i < W * H; i++){
  const a = clamp01((front - field[i] + grain[i] * .038 + .008) / .016);
  out[i] = a <= 0 ? prev[i] : a >= 1 ? next[i] : blend(prev[i], next[i], a);
}
```

配套的两个整数常量（与站点同源，换掉会失去同样的颗粒手感）：

```js
const hash = (x, y) => { const s = Math.sin(x * 127.1 + y * 311.7) * 43758.5453; return s - Math.floor(s); };
const noise = (x, y) => { /* 双线性插值 hash，smoothstep 权重 */ };
```

**三个参数的作用**

| 参数 | 值 | 改了会怎样 |
| --- | --- | --- |
| `field` 的 x:y 权重 | `.60 : .20` | 决定锋面倾角；对调即变竖扫 |
| 噪声权重 | `.20` | 调小锋面变直，调大变成破碎斑块 |
| `grain` 振幅 | `.038` | **最值钱的一个数**。归零则锋面是塑料味斜线；调到 `.1` 以上会糊成噪点 |
| 过渡带宽 | `.016` | 调宽则重新出现叠影 |

## 四、签名效果三：月相消解

如果确实要做三维版，核心只有三个函数（GLSL 原文）：

```glsl
float lunarFront(vec3 n, float albedo){
  return .5 + (n.x*.927 + n.y*.375)*.35 + (albedo-.6)*.22;
}
float lunarErosion(float p){ return smoothstep(.27,.70,p)*1.45 - .2; }
float lunarRelease(vec3 n, float albedo, float p){
  float front = lunarFront(n, albedo);
  return smoothstep(front-.16, front+.16, lunarErosion(p));
}
// 月面：opacity = 1. - lunarRelease(...)；粒子：release 即「这颗已脱落」的程度
```

配套数值：光向 `normalize(vec3(sin(.48)*cos(.32), sin(.48)*sin(.32), cos(.48)))`；
`uProgress` 只从 `.45` 走到 `.7`；`p > .72` 时整颗月亮 `visible = false`。

**用 Canvas 2D 做轻量版**（本拆解页 hero 用的就是这套）：

1. 逐像素重建月面一次：由屏幕坐标反解球面法线 → 反解贴图 uv → 采样 albedo →
   算颜色与 `lunarFront`，把颜色和 front 各存一份 typed array；
2. 每帧只按当前 `lunarErosion(p)` 重算每像素透明度，`putImageData`；
3. 粒子另建一套种子（LCG，种子 `21717`），共用同一套 `front` 公式。

成本：一次性 O(R²) 的重建 + 每帧 O(R²) 的阈值比较，1280×720 下约 2–3ms。

## 五、滚动编排骨架

```css
.stage-wrap{
  height: calc(100svh
    + clamp(2600px,360svh,4200px)   /* 变形 */
    + clamp(240px, 36svh, 440px)    /* 驻留 */
    + clamp(1350px,180svh,2250px)); /* 退场 */
}
.stage{ position:sticky; top:0; height:100svh; overflow:clip }
@media(max-width:700px){
  .stage-wrap{ height: calc(100svh + clamp(1800px,320svh,2800px)
    + clamp(180px,32svh,320px) + clamp(1080px,165svh,1650px)); }
}
```

```js
const clamp01 = t => Math.max(0, Math.min(1, t));
const smootherstep = t => { t = clamp01(t); return t*t*t*(t*(t*6-15)+10); };

// 阻尼：常态 U=3，退场段 U=5；差值 <.05 直接吸附
function follow(current, target, dt, exiting){
  const U = exiting ? 5 : 3;
  const v = current + (target - current) * (1 - Math.exp(-Math.min(dt, .05) * U));
  return Math.abs(target - v) < .05 ? target : v;
}

// 按需排帧：稳定即停摆
let raf = 0;
const schedule = () => { if (!raf && visible && !document.hidden) raf = requestAnimationFrame(frame); };
addEventListener('scroll', schedule, { passive: true });
```

**驻留怎么实现**：不要 `setTimeout`。把驻留距离 `hold` 塞进滚动 → 进度的映射里，
在 `[morph*.32, morph*.56]` 区间插入一段 smootherstep 平台，再用二分（20 次足够）求它的反函数。
这样正反向滚动完全对称。

## 六、选型决策表

| 场景 | 站点的选择 | 为什么不是别的 |
| --- | --- | --- |
| 首屏月亮 | three.js 自写 ShaderMaterial + GPU 粒子 | 视频不能响应滚动与主题；序列帧体积过大且不能换色 |
| 月面纹理 | 反照率贴图 + 法线贴图 | 程序化噪声做不出真实月海分布 |
| 体积云 | 3 层 raymarch + `HalfFloat` RT（0.65 倍） | 位图云不能随场景推进变形；全分辨率 raymarch 太贵 |
| 照片换片 | 片元着色器颗粒锋面 | CSS 交叉淡入必然叠影 |
| 中文笔迹动画 | 位图顺序图 + `feComponentTransfer` | `stroke-dashoffset` 处理不了连笔与粗细变化 |
| 唱机 | WebGL 场景 + 一套完整 DOM 兜底 | 纯 CSS 3D 做不出镜头推轨；纯 WebGL 则无降级路径 |
| 阅读进度条 | `animation-timeline: scroll()` | 不值得为它挂一个 JS 滚动监听 |
| 页面切换 | Astro View Transitions | 手写转场要维护两套 DOM 生命周期 |
| 字体 | 全部自托管 + `unicode-range` 分片 | 第三方 CDN 在部分网络下抖动，且不便排预加载优先级 |

## 七、工程上会踩的坑

| 坑 | 站点的解法 |
| --- | --- |
| 用 `100vh` 做 sticky 舞台，移动端地址栏一收就跳 | 全站用 `svh`：`100svh`、`88svh`、`360svh` |
| 滚动驱动直接读 `scrollY`，触控板抖 | 指数阻尼 `1 - e^(-dt·U)`，差值 `< .05` 吸附 |
| 长滚程里常驻 rAF，手机发烫 | 事件驱动排帧；`IntersectionObserver` 出视口即停；`dialog[open]`、`visibilitychange` 也停 |
| WebGL 与 DOM 交接时两张图同时可见 | `--ge-plate-opacity` 到 1.0 才显形，并用硬锋面而非透明度过渡 |
| 未入场的区块仍能被 Tab 聚焦 | `section.inert = progress < .94` |
| 中文衬线在深色底发灰 | 标题色比正文亮一档；行高 2.0–2.2；靠留白立骨架 |
| 暖白被写成纯白，整页发冷 | `--bg: #f6f4ef`，正文 `#2d2d2d` 不用纯黑 |
| CJK 字体一次性全量加载 | `unicode-range` 分片（中文 101 片），`font-display: swap` |
| 轮播换图时闪一下 | 先 `await img.decode()` 再切 `is-active` 类 |
| 自动播放不可停 | 暂停键是真键：44px 触控目标 + 改写 `aria-label`；`prefers-reduced-motion` 下默认暂停 |
| 丢 WebGL 上下文白屏 | 监听 `webglcontextlost`，立刻整体降级为静态图 |
| 路由切换后资源泄漏 | `astro:before-swap` 上统一 dispose，含 `forceContextLoss()` |
| 逐字动画让读屏逐字念 | 拆两份：可读版视觉隐藏、动画版 `aria-hidden` |
| 装饰性 canvas 对读屏是噪声 | 容器 `role="img"` + 一句中文 `aria-label` 说明画面 |
