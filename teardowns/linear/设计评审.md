# Linear 拆解页 · 设计评审（第二轮）

> 以顶级产品设计视角，评审 `teardown.html` 相对 `linear.app` 原站的**精度与完成度**：
> 哪些已达标、还差在哪，并给出可执行改进。能当场改的已改，标注「已改」；其余给出清晰做法。

---

## 1. 总体判断

这份拆解页**站得住顶级标准**：它不是把 Linear「换皮」，而是用 Linear 自己的实测语言重讲一遍——
近黑底、负字距的克制标题、发丝线分层、单一非回弹缓动、纯 SVG 的 agent 点阵。第二轮把真实
`Inter Variable` 字体接入后，标题与正文**就是原站字体本体**，字重 510 与 -1.408px 字距首次
「所见即真值」，是本轮最大的精度跃升。整页信息密度、编号大纲、药丸按钮的工程气质，与原站同频。

**与原站仍存在的、可感知的差距**主要有两处，且都属**有意的再诠释、已在页面标注**，非疏漏：

1. 原站首屏以**真实产品截图**领衔，本页以抽象点阵 + 渐隐幕布领衔（点阵是对 `grid-dot-*-*-agent`
   关键帧的合理还原，落点已标「推断」）。真实渲染截图放在第 1、5 节兜底，诚实可查。
2. 原站是**多屏叙事的营销首页**，本页是**单页拆解报告**；信息结构不同属预期。

---

## 2. 已达标（相对原站）

- **字体**：真实 `InterVariable.woff2` 内嵌，字重 510 / 字距 -1.408px / 行高 1.0 与计算样式逐条对齐。
- **底色与文字**：`#08090a` / `#f7f8f8` 与 body 计算样式一致；发丝线 `#ffffff14` 与 `Header.css` 原文一致。
- **缓动**：全站单一 `cubic-bezier(.25,.46,.45,.94)`，与被测按钮计算值一致，无越界回弹，符合 Linear 克制取向。
- **形状语言**：小圆角（4/5/6/8px）与按钮 `9999px` 全圆的对比，命中实测频次。
- **媒体取向**：纯 SVG 点阵，呼应实测 `canvas 0 / video 0 / svg 180`；无多余位图与视频。
- **标识**：改用站点真实 `favicon.svg` 字形，替掉首轮手绘近似。

---

## 3. 本轮已当场改进

1. **强调色出处诚实化（对抗审查核心）· 已改**
   首轮把 `#7170ff` 标为「实测 `--accent/--brand` 变量」；复核证明源码无此变量、该值只是探针
   `accentGuess`，而真正字面出现在页面里的品牌紫是内联 SVG 的 `#5E6AD2`。已把二者并列如实标注、
   色板补入 `#5E6AD2`，并撤下错误的「实测覆盖历史」叙述。设计诚信 > 好看的确定性。

2. **可变字体光学尺寸 · 已改**
   `body` 加 `font-optical-sizing:auto`，让真实 Inter Variable 在大标题与小正文下各自取更合适的字形，
   贴近原站在超大 H1 上的观感。

3. **标题平衡换行 · 已改**
   `h1,h2,h3` 加 `text-wrap:balance`，多行标题左右更齐、避免孤字尾行，逼近 Linear 标题的排布手感。

4. **工程数字对齐 · 已改**
   等宽/代码/表格加 `font-variant-numeric:tabular-nums`，让色值、频次、时长等数字**列对列对齐**，
   强化「技术规格书」气质——这正是 Linear 用等宽体想传达的精密感。

---

## 4. 进一步改进建议（未做，附做法）

5. **首屏可加一帧真实产品图作「锚」（建议）**
   点阵抽象度高，若在 hero 右侧或第 1 节顶部嵌一张 `real-assets/image/` 的真实产品面板
   （如 `9e7235_…png`），以发丝线卡片 + 轻微透视呈现，可在不破坏点阵母题的前提下，让「所拆即所见」
   更直观。注意压缩尺寸（原图达 6304×3520），并保留点阵为背景层。

6. **等宽体的长期精度（建议，受授权约束）**
   原站等宽为商业字体 `Berkeley Mono`，本页以 JetBrains Mono 顶替、已披露。若未来取得授权，
   换回 Berkeley Mono 可让编号大纲与代码块的字形宽度、字腔与原站完全一致；在此之前维持现状即可。

---

## 5. 结论

第二轮后，这份拆解页在**字体、色值、缓动、形状、媒体取向**上均与原站实测对齐，并且——更重要——
把唯一一处「看起来确定、其实是猜测」的强调色出处**主动纠正**。它既好看，又经得起逐条追问，
达到「可当场复刻、且每个数字都说得清出处」的顶级拆解标准。剩余差距均为有意的再诠释且已标注，
不影响作为设计研究与复刻参考的可信度。
