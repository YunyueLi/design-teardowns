# Linear 出处与方法 —— 什么是实锤，什么是推断

> 本拆解拒绝“凭印象”。下面说明数值怎么来的、哪些可当事实引用、哪些只是观察或推断，以及抽取的局限。

---

## 1.0 抽取方法

用 playwright 打开 `https://linear.app`，做两件事：

1. **计算样式（computed styles）**：对代表性元素（`body`、`h1`、`nav`、主按钮）读 `getComputedStyle`，拿到背景色、文字色、字体族、字号、字重、字距、行高、圆角、过渡等**浏览器最终渲染值**。这一层不受作者书写方式影响，是最硬的证据。
2. **样式表文本（server-side fetch）**：直接抓取页面引用的 12 个样式表原文（服务端抓取，不受浏览器 CORS 限制），用正则统计 CSS 自定义变量（`customProps`）、高频十六进制色值（`topHex`）、时长（`durations`）、圆角（`radii`）、关键帧名（`keyframes`）、字体族（`fontFamily`）、显式贝塞尔曲线（`cubicBezier`），并记录媒体元素计数（video、canvas、svg、img）与已加载字体（`fontsLoaded`）。

产出物：

- `teardowns/_data/linear.json` —— 结构化抽取结果。
- `teardowns/linear/design-tokens.css` —— 据抽取生成的真实 token CSS。
- `teardowns/linear/assets/actual-hero.jpg` 与 `actual-full.jpg` —— 首屏与整页的**真实渲染截图**。
- `teardowns/linear/keyframes/` —— 滚动过程的关键帧，用于还原页面分节结构。

## 2.0 实锤（源自抽取，可直接引用）

- 背景 `rgb(8,9,10)`、主文字 `rgb(247,248,248)`（`body` 计算样式）。
- H1 字号 `64px`、字重 `510`、字距 `-1.408px`、行高 `64px`（`h1` 计算样式）。
- 次级文字与 ghost 按钮色 `rgb(138,143,152)`、按钮圆角 `9999px`（`btn` 计算样式）。
- 按钮过渡 `cubic-bezier(.25,.46,.45,.94)`、时长 `0.1s`（`btn.transition` 计算样式）。
- `--duration:.18s`、`--anchor-glass-bg:#ffffff14`、灰阶 `--gray1` 到 `--gray12`、栅格 `--grid-columns:12`、`--offset:16px`、`--grid-gap:0`、`--border-radius:8px`（样式表 `customProps`）。
- 时长频次：`3200ms`（75）、`2800ms`（50）、`1600ms`（50）等；圆角频次：`6px`（7）、`8px`（5）、`4px`（4）、`5px`（3）等（样式表统计）。
- 关键帧 `grid-dot-0-0-agent` 至 `grid-dot-3-4-agent` 共 20 条（样式表 `keyframes`）。
- 媒体计数 `video 0`、`canvas 0`、`svg 180`、`img 32`；已加载字体 `Inter Variable` 与 `Berkeley Mono`（`fontsLoaded`）。
- 强调色 `#7170ff`：为探针 `accentGuess`（计算样式启发值）。**更正（第二轮）**：抓取到的 12 份样式表内并无取此值的 `--accent/--brand` 变量，页面内 `--accent` 实为标签分类色（指向 `var(--color-green)` 之类），故不宜称其为"`--accent/--brand` 实测"。详见《事实核查》。
- 顶栏 `backdrop-filter: blur(20px)`（`nav` 计算样式）。

## 3.0 推断与观察（非源码级，谨慎引用）

- **招牌“模糊到清晰”渐入**：来自研究文档的观察描述，未在本次抽取中拿到对应的具体关键帧数值。
- **点阵在首屏的确切位置**：`grid-dot-行-列-agent` 关键帧是实锤，但本次首屏实拍拍到的是产品 mock，未直接拍到点阵在页面上的落点，故其位置为推断。
- **琥珀色状态点的精确色值**：产品 mock 里的 “In Progress” 圆点与收藏星标是观察到的强调色，抽取 token 中无精确十六进制，不给具体值。
- **品牌紫 `#5E6AD2`**：Linear 长期沿用的品牌紫，公开资料常引；**第二轮真素材复核发现它确实出现在页面内联 SVG 的描边中**（`stroke="#5E6AD2"`），并非只是"历史值"。它与探针 `accentGuess` 的 `#7170ff` 是两个紫、两种出处，本页以 `#7170ff` 作交互强调、如实并列标注二者，不再说其中之一"覆盖"另一个。
- **“双时间尺度”这一叙事命名**：各档时长值是实锤，但把它们解读为“慢层氛围加微层手感”的叙事框架属于推断性归纳。

## 4.0 局限

- **单次快照**：抽取为某一时刻的静态快照，悬停态、聚焦态、以及可能存在的 A/B 变体或响应式断点样式未必覆盖。
- **文本正则统计**：样式表统计基于原文正则，运行时由脚本注入的样式、或经构建工具压缩改名的变量，可能统计不全。
- **关键帧列表被截断**：抽取里点阵关键帧只列到 `grid-dot-3-4-agent`（rows 0–3、cols 0–4）20 条，而样式表总量达 256591 字节，真实点阵规模应更大，复刻时按更大网格处理。
- **计算样式只取代表性元素**：只对 `body`、`h1`、`nav`、`btn` 读了计算样式，卡片、面板等其余元素的精确值需按需补测。
- **字体为商业字体**：`Berkeley Mono` 需授权，本拆解页用开源等宽体顶替；`Inter` 开源可直接用。
