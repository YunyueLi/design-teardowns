# Linear 拆解页 · 事实核查（第二轮真素材复核）

> 逐条核对 `teardown.html` / `design-tokens.css` 里出现的每个数值，与真实抽取
> （`teardowns/_data/linear.json` 计算样式与样式表统计、`real-assets/` 真素材与源码）比对；
> 列出漂移并说明已如何改正，最后复核「实锤 vs 推断」的标注是否到位。
> 口径：**计算样式（computed）= 浏览器最终渲染值，最硬**；**样式表原文 = 作者书写值**；
> 二者可因变量解析而在字面上不同，但都算实锤，需说清来源。

## 1. 核对结论速览

- 页面绝大多数数值与真实抽取**逐条一致**（见下表），第二轮无需改动。
- **一处实质漂移**：强调色 `#7170ff` 的**出处**被首轮写成「实测 `--accent/--brand` 变量」——不成立，已在
  `teardown.html`、`design-tokens.css`、`出处与方法.md` 三处改正（详见第 3 节）。

- 真素材接入无 tofu：`@font-face` 字族名 `'Inter Variable'` 与文件 `36a968_InterVariable.woff2` 对得上，
  路径 `real-assets/fonts/…` 相对 `teardown.html` 正确，且保留 Google Inter 兜底。

## 3. 本轮发现的漂移与修正

### 3.1 强调色出处：`#7170ff` 并非「`--accent/--brand` 变量实测」（实质漂移，已改正）

**首轮说法**：`#7170ff` 是「实测 `--accent/--brand` 变量」，并称历史品牌紫 `#5e6ad2`「与实测不一致，以实测为准」。

**复核证据**（对 `real-assets/source/` 15 份 CSS 与 `index.html` 全文检索）：

1. `#7170ff` 及其等价 `rgb(113,112,255)` **在源码里任何形态都搜不到**——它是 `linear.json` 里的
   `accentGuess`（探针对计算样式的启发式取样），不是某个字面写着的变量值。
2. 源码里确实存在名为 `--accent` 的自定义属性，但它是**标签分类色**，取值 `var(--color-green)`、
   `var(--color-yellow)` 之类（用于 label 按钮），并非品牌紫；也没有名为 `--brand` 且取 `#7170ff` 的变量。
3. 反倒是 `#5E6AD2`（Linear 长期沿用的品牌紫）**字面出现在 `index.html` 的内联 SVG 描边**里
   （`stroke="#5E6AD2"`）。

**修正**（保留 `#7170ff` 作交互强调色，符合第二轮基准；只纠正「出处」这一虚标）：

- `teardown.html`：
  - `:root` 注释由「实测 --accent/--brand」改为「探针 accentGuess（计算样式启发值）」。
  - 色彩节导语重写为「两个紫、两种出处」，如实并列 `#7170ff`（accentGuess）与 `#5E6AD2`（内联 SVG 实见）。
  - 色板新增 `#5E6AD2`「品牌紫 · 页面内联 SVG 描边实见」一格。
  - 出处节：把 `#7170ff` 从「实锤」移入「推断/观察」并注明缘由；原「一处资料被实测修正」的
    callout 改写为「两个紫，两种出处（第二轮对抗审查修正）」，不再说其中之一「覆盖」另一个。
- `design-tokens.css`：`--accent` 行注释改为「探针 accentGuess…样式表内无取此值的 --accent/--brand 变量」，
  并补一行 `#5E6AD2` 的内联 SVG 出处。
- `出处与方法.md`：更正第 2、3 节里对 `#7170ff` 与 `#5e6ad2` 的旧表述。

### 3.2 口径细化（非错误，只是讲得更准，已就地补注）

- **主缓动来自变量解析**：`cubic-bezier(.25,.46,.45,.94)` 是 btn 计算样式的值，源码里写作
  `var(--ease-out-quad)`（其定义不在抓取到的 12 份样式表内）。计算值即实锤，出处已注明。
- **顶栏模糊两个值**：nav 计算样式为 `blur(20px)`（页面所引，正确）；`Header.css` 组件源码另有
  `blur(32px)` 与 `blur(var(--header-blur))`。页面引的是被测 nav 的最终值，已在出处注明差异。
- **按钮时长两个档**：被测 btn 计算 `.1s`（页面所引）；`Button.css` 另有 `.16s`。均为真值，属不同按钮档。

## 4.「实锤 vs 推断」标注复核

复核后标注**准确、无越界**：

- **实锤**（计算样式或源码原文可证）：`#08090a`、`#f7f8f8`、`#8a8f98`、`#ffffff14`（Header.css 实见）、
  h1 的 64/510/-1.408px/64、按钮圆角 9999px、主缓动、`--duration:.18s`、灰阶、时长/圆角频次、
  关键帧 20 条、媒体计数、已加载字体、顶栏 `blur(20px)`（计算值）。
- **推断 / 观察**（已明确标注，不冒充实锤）：`#7170ff` 为 accentGuess、`#5E6AD2` 的角色定位、
  琥珀状态点色值、点阵在首屏的确切落点、「模糊到清晰」渐入、「双时间尺度」这一叙事命名。
- 首轮唯一错置——把 `#7170ff` 当「实锤变量」——**已在本轮下架并改正**。

## 5. 真素材接入自检

- **字体**：`@font-face { font-family:'Inter Variable'; src:url('real-assets/fonts/36a968_InterVariable.woff2') format('woff2'); font-weight:100 900; font-display:swap }`；
  文件头 4 字节为 `wOF2`，是合法 WOFF2；字族名与文件名（InterVariable）对得上，无 tofu 风险；
  失败时回落 Google Inter → 系统栈。`--font-sans` 已改为真字族优先，并原样镜像 Linear 计算样式的系统兜底链。
- **标识**：nav 与 footer 的手绘近似标识，替换为站点真实 `favicon.svg` 字形（深底取白）。
- **视频**：Linear 首页 `manifest.json → video: []`，无 hero 视频，故不嵌，符合规范；精度靠真字体 + token 校准。
- **图**：保留首轮真实渲染截图（as-seen）；真素材 PNG 多为无上下文的产品 mock 局部，未强行替换。
