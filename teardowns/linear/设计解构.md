# Linear 设计解构 —— 深色精密的工程美学，拆到每一个数值

> 顶级 UI 视角的完整拆解。除特别标注，所有数值均来自对 `https://linear.app` 的真实抽取（`teardowns/_data/linear.json` 与 `teardowns/linear/design-tokens.css`，playwright 计算样式加样式表文本），均为**实锤**；来自官网观察与公开研究的信息标注为**推断**。

---

## 1.0 定位与设计意图

- 主标题实测为 “The product development system for teams and agents”，副标题 “Purpose-built for planning and building products. Designed for the AI era.”（实锤，来自 `probe.h1` 文本与首屏实拍）。
- 气质是近黑底色、超大留白、发丝线描边、字重克制。它把产品本身“精密、快、给工程团队用”的性格，直接翻译成了官网的视觉。
- 核心设计意图是**让官网成为产品的延伸**。首屏不用插画或三维渲染，而是铺一块真实的产品界面 mock（issue 详情、左侧导航、右侧属性面板、浮动的 agent 面板），传达“这就是你每天要盯着的界面”。
- 章节采用十进制编号（1.1、3.2、4.0），配等宽字体，像一份技术规格文档。这套“规格书”隐喻是 Linear 区别于其他深色站的识别点（实锤，见滚动帧中的编号大纲）。

## 2.0 色彩系统

### 基底与强调（计算样式实测，实锤）

| 名称 | 值 | 角色 | 来源 |
|---|---|---|---|
| 背景 bg | `rgb(8,9,10)` = `#08090a` | 页面底色，近黑而非纯黑 | `body.background-color` |
| 主文字 ink | `rgb(247,248,248)` = `#f7f8f8` | 正文与标题，近白而非纯白 | `body.color` |
| 强调紫 accent | `#7170ff` | 品牌强调，链接高亮、agent 提及 | `--accent/--brand` 实测 |
| 次级文字 muted | `rgb(138,143,152)` = `#8a8f98` | 弱化文字与 ghost 按钮 | `btn.color` |
| 玻璃与发丝线 | `#ffffff14`（约 `rgba(255,255,255,.078)`） | 描边、玻璃层底 | `--anchor-glass-bg` |

高频色值（样式表出现次数由多到少，实锤 `topHex`）：`#000`（24）、`#fff`（4）、`#3f3f3f`、`#e8e8e8`、`#3b3d45`、`#08090a`。深色页面靠这几档中性灰拉开层次，不靠彩色。

### 灰阶梯度（设计系统 token，实锤 `customProps`）

`--gray1` 到 `--gray12` 是一套 HSL 明度梯度，从 `hsl(0,0%,99%)` 一路降到 `hsl(0,0%,9%)`。

需要说清的一点：这套灰阶是**浅色语境**的刻度（样式表里主要给 toast 等浅底组件用），而深色首页另取主文字 `#f7f8f8`、次级文字 `#8a8f98`。同一套设计系统同时供浅色与深色两种主题，这是很典型的“一套刻度、双主题取值”做法。

### 观察项（推断）

首屏产品 mock 里的琥珀色状态点（“In Progress” 圆点、收藏星标）是观察到的强调色，但未在抽取 token 中出现精确值，故不给具体十六进制。历史资料常引的 Linear 品牌紫 `#5e6ad2` 与本次实测的 `#7170ff` 不一致，**以实测为准**。

## 3.0 字体系统

| 角色 | 字体 | 说明 |
|---|---|---|
| 无衬线（品牌与正文） | **Inter Variable** | `fontsLoaded` 实测。首屏一切文字都用它 |
| 等宽（编号与代码） | **Berkeley Mono** | `fontsLoaded` 实测；`var(--font-monospace)` 在样式表出现 65 次，是高频角色 |

- H1 实测为字号 `64px`、字重 `510`、字距 `-1.408px`（约 `-0.022em`）、行高 `64px`（实锤）。行高等于字号意味着 1.0 倍行距，标题被压得很紧；负字距再收一档，形成“精密”而非“厚重”的观感。
- 字重刻意克制。`510` 属于中等偏上，介于常规 Medium（500）与 SemiBold（600）之间，只有可变字体才取得到这个非整数档。Linear 用这个细微的字重加负字距，而不是靠加粗来强调。
- 等宽体承担“工程气质”的表达：十进制编号大纲（1.1、3.2、4.0）、代码片段、状态标签、键盘快捷键徽标都用它。
- 授权说明：Inter 开源可直接用；Berkeley Mono 为商业字体，复刻时用开源等宽体（如 JetBrains Mono）顶替并注明。

## 4.0 动效系统（双时间尺度）

### 4.1 两层时间叠加（实锤 `durations` 频次）

样式表里的时长呈现明显的两层分布：

- **慢层**：`1600ms`（出现 50 次）、`2800ms`（50 次）、`3200ms`（75 次），以及更长的 `18s`（5 次）、`22s`（2 次）、`4s`、`2s`。这一层负责氛围与“agent 呼吸”式的缓慢运动。
- **微交互层**：`0.4s`、`0.2s`、`0.1s`，以及 `--duration:.18s`（实锤 `customProps`）。这一层保证悬停、聚焦这类操作的手感即时。

两层叠加，就得到“背景在慢慢呼吸、指尖操作却毫不拖沓”的双时间尺度。慢层的高频出现（尤其 3200ms 达 75 次）说明这不是偶发，而是系统性的节奏设计。

### 4.2 签名缓动（实锤，来自按钮过渡）

计算样式里按钮的过渡实测为：`color 0.1s cubic-bezier(0.25,0.46,0.45,0.94), background 0.1s cubic-bezier(0.25,0.46,0.45,0.94)`。

`cubic-bezier(.25,.46,.45,.94)` 属于 easeOutQuad 家族，特征是**开头较快、结尾平滑收住、不回弹**。这条曲线与“克制、精密”的整体气质完全一致——没有 Q 弹越界，只有干净的减速。

需要诚实说明：抽取到的显式 `cubicBezier` 数组为空，页面主缓动是从计算样式里的按钮过渡读到的。样式表文本里没有再发现其他显式贝塞尔曲线，因此**只认这一条为实锤**，不臆造第二条。

## 5.0 Hero 手法

- 结构（实锤，首屏实拍加文本）：左对齐的超大 H1（64px）占据视觉主体，下方一句灰色副标题，右侧一行小字链接 “New — Coding Sessions →”。信息极少，留白极大。
- 首屏下半部铺一块**真实产品 mock**：issue 详情（“Faster app launch”）、左侧导航（Inbox、My issues、Reviews、Pulse，以及 Workspace 下的 Initiatives、Projects）、右侧属性面板（In Progress、High、指派人）、以及一块浮动的 agent 面板（“Linear Opus 4.8 / Examining the startup path… / Thinking…”）。用真实界面而非示意图，是把“产品力”直接摆上台面。
- 顶栏是**透明玻璃**：`backdrop-filter: blur(20px)`（实锤），背景色为透明；滚动后加一道发丝线底边。右上角 “Sign up” 是白色实心药丸按钮，“Log in” 是 ghost 文字。
- 招牌的“模糊到清晰”渐入（推断，来自研究文档观察）：首帧近乎全黑，随加载或滚动逐步浮现，配合慢层时长营造仪式感。

## 6.0 签名视觉母题：agent 点阵

- **实锤**：样式表含一组具名关键帧 `grid-dot-{行}-{列}-agent`，抽取到 `grid-dot-0-0-agent` 至 `grid-dot-3-4-agent` 共 20 条（rows 0–3、cols 0–4），每条频次为 3；样式表总量 `cssBytes` 达 256591，实际点阵规模应更大（抽取列表被截断）。
- 命名法 `grid-dot-行-列-agent` 本身就说明了这是一块**按行列坐标编排的点阵**：每个点有独立关键帧，后缀 `agent` 指这块点阵随 agent 活动错落亮起或呼吸。
- **媒体选型是关键佐证**（实锤 `media`）：`video 0`、`canvas 0`、`svg 180`、`img 32`。Linear 不用 canvas，也不用视频做动画，这块点阵是**纯 SVG 加 CSS 关键帧**。这与“精密、可访问、低功耗”的取向完全一致。
- 母题语义：点阵像一块“注意力网格”，agent 扫过时以对角波纹的方式点亮，呼应主标题里的 “teams and agents”。
- 点阵在首屏的**确切位置为推断**：本次首屏实拍拍到的是产品 mock，未直接拍到点阵；但关键帧本身是实锤。复刻方式见交互式拆解页与《复刻指南》。

## 7.0 工艺细节

- **圆角梯度**（实锤 `radii` 频次）：`6px`（7）、`8px`（5）、`4px`（4）、`5px`（3），另有 `10px`、`14px`、`50%`；按钮圆角 `9999px`（全圆药丸）；`--border-radius:8px`。小圆角克制精确，只有按钮走极端全圆，形成对比。
- **发丝线**：描边用 `#ffffff14`（约 `rgba(255,255,255,.078)`，实测 `--anchor-glass-bg`），`--inner-card-border:1px`。卡片靠 1px 极淡描边分层，而不是投影。
- **玻璃**：顶栏 `backdrop-filter: blur(20px)`（实锤）。
- **栅格**：`--grid-columns:12`、`--offset:16px`、`--grid-gap:0`（实锤）。十二列、16px 外距、栅格之间不留 gap，靠内距对齐——一种偏“印刷网格”的严整做法。
- **编号大纲母题**：章节用 `1.1`、`3.2`、`4.0` 十进制编号（等宽字体，实锤），像技术规格书，强化“工程系统”气质。
- **按钮系统**：白色实心药丸为主行动，深色描边药丸为次级，ghost 文字为三级，全部 `9999px`。
- **键盘徽标**：`--kbd-size:16px`、`--kbd-offset:-6px` 等（实锤）。产品对键盘操作的重视，延伸到了官网的组件细节。

## 8.0 关键发现

1. **官网视觉等于产品界面的直接外化**。首屏用真实 UI mock 而非插画，把“产品长什么样”当成最大的卖点。
2. **双时间尺度是系统性的**。慢层（1600、2800、3200ms，高频出现）做氛围与 agent 呼吸，微层（0.1、0.18、0.2、0.4s）做手感，两者叠加而非二选一。
3. **全 SVG、零 canvas、零视频**。签名点阵是纯 SVG 加具名关键帧，忠实到媒体选型这一层，也符合可访问与低功耗的取向。
4. **“工程规格书”隐喻是它的识别点**。十进制编号大纲加等宽字体，是 Linear 与其他深色科技站拉开差距的地方。
5. **强调色实测为 `#7170ff`**，与历史资料常引的 `#5e6ad2` 不一致，以实测为准。
6. **一套灰阶、双主题取值**。`--gray1` 到 `--gray12` 是浅色语境刻度（toast 等），深色首页另取 `#f7f8f8` 与 `#8a8f98`，是同一设计系统服务两种主题的证据。
