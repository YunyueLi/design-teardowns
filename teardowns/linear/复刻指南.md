## 2.0 签名效果一:忠实于 Linear 的具名关键帧写法

Linear 样式表里，点阵的每个点都对应一条 `grid-dot-<行>-<列>-agent` 关键帧。用极少代码即可还原这种“按行列坐标错落点亮”的对角波纹：

```css
.dotgrid{--gap:22px}
.dot{
  fill:var(--muted);
  opacity:.14;
  transform-box:fill-box;
  transform-origin:center;
}
/* 亮起 = 变强调紫、放大、拉高不透明度，用真实慢层时长与实测缓动 */
@keyframes grid-dot-agent{
  0%,100%{opacity:.12; fill:var(--muted); transform:scale(1)}
  50%    {opacity:1;   fill:var(--accent); transform:scale(1.9)}
}
.dot{
  animation:grid-dot-agent var(--slow-2) var(--ease) infinite;
  /* 延迟 = (行 + 列) × 步长，形成从左上扫向右下的对角波纹 */
  animation-delay:calc((var(--r) + var(--c)) * 90ms);
}
```

配一小段生成点与坐标变量的脚本（纯 SVG，呼应 Linear 零 canvas 的选型）：

```js
const NS='http://www.w3.org/2000/svg';
function buildDotGrid(svg, cols=28, rows=10, gap=22){
  const pad=gap; svg.setAttribute('viewBox',
    `0 0 ${pad*2+(cols-1)*gap} ${pad*2+(rows-1)*gap}`);
  for(let r=0;r<rows;r++) for(let c=0;c<cols;c++){
    const d=document.createElementNS(NS,'circle');
    d.setAttribute('class','dot');
    d.setAttribute('cx',pad+c*gap);
    d.setAttribute('cy',pad+r*gap);
    d.setAttribute('r',2.2);
    d.style.setProperty('--r',r);
    d.style.setProperty('--c',c);
    svg.appendChild(d);
  }
}
```

## 3.0 签名效果二:可交互引擎（扫描 + 鼠标注意力）

要做“鼠标靠近就亮”“可切对角扫描或从中心涟漪”，用一段 `requestAnimationFrame` 驱动更省心。它每帧算出每个点的强度，再在次级灰与强调紫之间插值。核心思路：

```js
// 每个点的强度 = 行进波前的贡献 + 鼠标邻近的贡献（0..1）
// 波前:一条沿对角推进的亮带，宽度固定，用真实慢层周期决定推进速度
function intensity(dot, t, pointer){
  const cycle = 2800;                 // --slow-2 实测
  const phase = (dot.r + dot.c) * 0.5; // 对角相位
  const wave  = Math.max(0, 1 - Math.abs(((t/cycle)%1)*12 - phase % 12));
  let near = 0;
  if(pointer){
    const dx=dot.x-pointer.x, dy=dot.y-pointer.y;
    near = Math.max(0, 1 - Math.hypot(dx,dy)/120); // 120px 注意力半径
  }
  return Math.min(1, wave*0.8 + near);
}
// 应用:在灰与紫之间插值，并放大半径；缓动交给 CSS 或直接用 easeOutQuad 采样
```

工程上：把 `fill`、`fill-opacity`、`r` 每帧写回 SVG 属性即可。控制点数在数百量级、标签页隐藏时 `requestAnimationFrame` 自动暂停、并为 `prefers-reduced-motion` 提供一版静态点亮态，性能就没问题。

## 5.0 选型决策

- **点阵用纯 SVG**。Linear 实测 `canvas 0`、`video 0`、`svg 180`，动画全走 SVG 加 CSS。静态或规律的波纹用具名关键帧最省（见 2.0）；需要鼠标交互或切换形态时，用一小段 rAF 驱动 SVG 属性（见 3.0）。
- **缓动只用一条**。全站统一 `cubic-bezier(.25,.46,.45,.94)`，不追加回弹曲线；这正是 Linear 克制感的来源。
- **分层不靠投影靠发丝线**。用 1px 的 `#ffffff14` 描边分隔卡片，不用 box-shadow 堆叠。
- **强调色只在关键处点一下**。紫色 `#7170ff` 只落在链接高亮、agent 提及、点阵亮起，其余全是中性灰阶。

## 6.0 工程坑

- **字重 510 需要可变字体**。用 Google Fonts 时请求 Inter 的可变轴（`Inter:wght@100..900`），否则 `font-weight:510` 会回落到最近的静态权重 500。
- **backdrop-filter 要加前缀且父层别裁剪**。Safari 需 `-webkit-backdrop-filter`；祖先元素上的 `overflow` 或 `filter` 可能让玻璃失效。
- **点阵每帧写数百个属性**。把点数控制在数百量级；标签页隐藏时依赖 rAF 自动停；一定要给 `prefers-reduced-motion` 一版静态态。
- **发丝线用低透明白，不用实色灰**。`rgba(255,255,255,.078)` 能在不同底色上保持一致的“若有若无”，实色灰会在深浅底上观感漂移。
- **字距要用 em**。实测 `-1.408px` 是 64px 下的值，换算约 `-0.022em`，随字号缩放才不会在小字号上过紧。
- **Berkeley Mono 是商业字体**。生产环境需购买授权；开发与演示用 JetBrains Mono 顶替，并在页面注明。
