# 出处与方法（Provenance）

## 对象

线上站点 **Moonshot AI** —— <https://www.moonshot.ai>（`title` 实测 `Moonshot AI`，`lang=en`）。与 Comet（逆向本地应用包）不同，moonshot 是**面向公网的营销站**，因此抽取走的是“浏览器计算样式 + 服务端抓样式表文本”这条链路。

## 抽取链路

1. **playwright 计算样式**：无头浏览器打开线上页，对 `body`、`h1`、`nav`、`button` 等关键节点读 `getComputedStyle`，拿到**渲染后真实生效**的 `background-color`、`color`、`font-family`、`border-radius`、`transition`、`backdrop-filter` 等。这类值是浏览器最终裁决的结果，属最硬的实锤。
2. **服务端抓样式表文本**：直接请求页面引用的 CSS 文件（共 `cssFetched: 4` 份，合计 `cssBytes: 29569`），在原始文本里正则统计高频 HEX、`cubic-bezier`、`transition-duration`、`border-radius`、`@keyframes` 名与 `font-family`。服务端抓取**不受 CORS 限制**，能拿到浏览器里跨域读不到的整份样式表文本。
3. **字体探测**：读 `document.fonts` 已加载集合（`fontsLoaded`）与 `<link rel=preload as=font>` 计数（`preloadFont`）。
4. **媒体清单**：统计 DOM 里 `video`、`canvas`、`svg`、`img` 数量与预加载数。
5. **真实渲染截图**：首屏 `assets/actual-hero.jpg` 与整页 `assets/actual-full.jpg`，另有 `keyframes/` 下 8 帧首屏截图用于观察故障字的动态形态。

产物落在 `_data/moonshot.json`（原始抽取）与 `design-tokens.css`（据此生成的可复用 token）。

## 实锤 vs 推断

### 实锤（抽取所得）
- **色彩**：`body` 背景 `rgb(0,0,0)`、文字 `#fff`、按钮文字 `rgba(255,255,255,.56)`、导航底 `rgba(0,0,0,.4)`；样式表高频 HEX 梯（`#fff`、`#000`、`#121212`、`#1f1f1f`、`#737373`、`#323232`、`#45454e`、`#333`、`#262626`、`#6d6d6d`、`#141414`）及其出现次数。
- **字体**：已加载 `M PLUS 1`、`MiSans`、`NotoSans-Latin`；主字体栈 `"M PLUS 1",MiSans,PingFang SC,…`（频次最高）；h1 排版 `16px、400、字距 0.15008px、行高 24px`。
- **缓动**：4 条 `cubic-bezier`（`.16,1,.3,1` ×5、`.4,0,.2,1` ×2、`.34,1.56,.64,1` ×1、`.22,1,.36,1` ×1）。
- **时长**：`2s`(×15) `3s` `4s` `5s` `6s` `9s` `15s` `25s` `35s` `1.05s`；按钮 `transition: color 0.2s`。
- **圆角**：`100px`、`50%`、`24px`、`16px`、`12px`、`20px`、`8px`、`999px` 等梯（含 `23.5px`、`150px` 特例）。
- **玻璃**：nav `backdrop-filter: blur(16.75px)`。
- **关键帧名**：`vike-react-shine`。
- **媒体**：3 段 video，4 个 canvas，1 个 svg，25 张 img，预加载 video 为 0，预加载字体为 3。
- **CSS 体量**：4 份样式表、约 29.6KB。
- **技术栈信号**：`libs` 与 `scriptHints` 探测为空（无主流第三方库外露）。

### 推断（观察、命名与重建）
- **技术栈**：Vike（vite-plugin-ssr）+ React —— 由关键帧前缀 `vike-react-` 推断，非源码确认。
- **首屏由 canvas 渲染**：由 `canvas 4` + `preloadVideo 0` + 唯一具名关键帧 `vike-react-shine` 综合推断；未反编译其 JS。
- **日食光环的渐变停靠点、外冕范围与呼吸参数**：据 `actual-hero.jpg` 观察**重建**，非抽取值。
- **色散通道颜色（红、绿、蓝）与错位量**：复现 chromatic aberration 的**标准做法**，站点抽取的静态样式表中并无这三支色值（真彩只存在于运行时渲染）。
- **文案**（slogan、输入框占位、按钮标签、导航项）：来自实拍与页面观察，属“观察到的真实文案”，非样式 token。
- **各 token 的语义角色映射**（哪个灰用于卡片、哪个用于描边）：据频次与常见工程惯例推断，站点未暴露具名 CSS 自定义属性（`customProps` 实测为空）。

## 局限

1. **只测到线上生效的静态样式**：动态由 JS 或 canvas 生成的视觉（故障字的真实算法、光环的实际绘制）未被抽取，本拆解以纯 CSS 与 JS 做**等效复现**，非逐像素还原。
2. **无 CSS 自定义属性可取**：`customProps` 为空，token 的“命名”是本拆解据实测值归纳的，非站点原始变量名。
3. **单次快照**：抽取为某一时刻的线上状态，站点更新后数值可能变化。
4. **字体形近替身**：页面用 M PLUS 1（Google Fonts 可取真字）；CJK 原站用 MiSans，本仓 HTML 以 Noto Sans SC 与系统中文兜底渲染中文正文，气质接近但非同一字。

## 复现取向说明

`teardown.html` 的签名 demo（日食光环 + 色散故障字）是**纯 CSS 与 JS + 一个内联 SVG 横向模糊滤镜**的自包含实现，服务于“可跑、可嵌、可调”。它忠实于实拍观感与实测的缓动、时长、圆角、色彩，但**不声称**与原站 canvas 算法逐帧一致——凡涉及运行时渲染的部分，均按上文标注为推断与重建。
