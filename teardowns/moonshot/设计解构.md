# Moonshot AI 设计解构

> 顶级 UI 视角的完整拆解。除特别标注，所有数值均来自对线上站点 <https://www.moonshot.ai> 的**真实抽取**（playwright 计算样式 + 服务端抓取的样式表文本），记为**实锤**；从截图与公开观察得到的信息记为**推断**。真实 token 见 `_data/moonshot.json` 与 `design-tokens.css`。

---

## 1. 定位与设计意图

| | 内容 |
|---|---|
| 站点 | Moonshot AI（`title` 实测为 `Moonshot AI`，`lang=en`） |
| 一句话定位 | Seeking the optimal conversion from energy to intelligence（首屏 slogan，观察） |
| 基调 | 纯黑到底、极大留白、居中排版、圆润几何无衬线 |
| 首屏母题 | 一轮**日食环形白光**居中；品牌字 “Moonshot AI” 带 **RGB 色散与故障**动效穿过光环 |
| AI-native 信号 | 首屏直接内嵌一个对话输入框（占位 “Throw me a hard one. I'm ready.”） |
| 行动入口 | 两枚 **ghost pill**（描边透明）按钮，标签为 Try Kimi 与 Try API |

**设计意图（推断）**：把公司信条“能量到智能的转化”视觉化成一次**日食**——月掩日的瞬间，能量收束为一道纯白光环。品牌字被这道光环“撕扯”出 RGB 色散与横向扫描残影，既是科技的故障美学，也是“能量态到智能态相变”的隐喻。整站几乎零品牌色，把全部注意力交给两件事：**形**（日食的圆）与**动**（故障的裂）。

> 与 Comet 的关键区别：Comet 是暖调、宇宙、电影级的“大片感”；moonshot 是冷调、极简、近乎单色的“留白 + 一处强签名”。两者都黑，但气质相反——所以这份拆解的视觉语言必须是 moonshot 自己的，绝不套 Comet 模板。

## 2. 色彩系统（真实 token）

moonshot 的调色板可以一句话概括：**纯黑、纯白，加一条中性灰梯，此外零品牌色**。

### 2.1 基底与中性灰梯（样式表实测频次 top）

| 名称 | HEX | 出现次数 | 角色（推断映射） |
|---|---|---|---|
| Pure Black | `#000` | 8 | 页面基底（`body` 背景计算值 `rgb(0,0,0)`，实锤） |
| White | `#fff` | 20 | 文字、光环、图标，最高频 |
| Ink 12 | `#121212` | 4 | 一级抬升面（卡片底） |
| Ink 14 | `#141414` | 1 | 抬升面变体 |
| Ink 1f | `#1f1f1f` | 3 | 二级面、输入框底 |
| Ink 26 | `#262626` | 1 | 卡片描边内侧 |
| Ink 32 | `#323232` | 2 | 三级面、描边 |
| Ink 33 | `#333` | 1 | 描边变体 |
| Slate 45 | `#45454e` | 1 | 冷灰描边（略带蓝紫，唯一偏色的中性） |
| Grey 6d | `#6d6d6d` | 1 | 次要文字 |
| Grey 73 | `#737373` | 2 | 占位、弱文字 |

### 2.2 语义色（计算样式实测）

| 用途 | 值 | 来源 |
|---|---|---|
| 正文、标题文字 | `#fff`（`rgb(255,255,255)`） | h1 计算值，实锤 |
| ghost 按钮文字 | `rgba(255,255,255,.56)` | btn 计算值，实锤 |
| 导航栏底色 | `rgba(0,0,0,.4)` | nav 计算值，实锤 |

### 2.3 关键发现：色彩克制到只剩“色散残影”

- 全站没有一个品牌 accent 色。`#45454e` 是唯一略微偏色（冷蓝紫）的中性，其余全部落在无彩灰阶。
- **唯一的彩色出现在两处**：其一是故障品牌字的 **RGB 色散**（红、绿、蓝通道错位形成的边缘残影，属动效合成，非静态 token）；其二是 Kimi 应用图标上的一个蓝色小圆点（观察）。
- 这是极高级的取舍：当画面里唯一的颜色是“光被拆开”的瞬间，日食与故障这两个母题就被无限放大了。**复刻时务必守住这条纪律——别给它补品牌色。**

> 色散通道颜色（红 `#ff0000`、绿 `#00ff00`、蓝 `#0000ff`，屏幕混合还原白）为**推断**：这是复现 chromatic aberration 的标准做法，站点实际抽取的样式表中并无这三支色值（真彩只在动态渲染里，见 §7）。

## 3. 字体系统

| 角色 | 字体 | 来源 |
|---|---|---|
| 显示、UI 主字 | **M PLUS 1** | `fontsLoaded` 实测含 `M PLUS 1`；主字体栈 `"M PLUS 1",MiSans,PingFang SC,…` 出现 7 次（最高频），实锤 |
| 中文 | **MiSans** | `fontsLoaded` 实测；字栈次序紧随 M PLUS 1，实锤 |
| 拉丁兜底 | **NotoSans-Latin** | `fontsLoaded` 实测，实锤 |

**字形气质**：M PLUS 1 是一款几何无衬线（日文 M+ 家族的现代成员），字面方正、字重跨度大、字腔开阔、笔端收得干净利落——正对应 brief 里“圆润几何无衬线”的观感。moonshot 用它承担从超大标题到细体 slogan 的全部拉丁排版。

**排版实测（h1 计算值，实锤）**：字号 16px，字重 400，字距 0.15008px，行高 24px，颜色 #fff。

> 关键发现：moonshot 的默认排版**克制到偏小**——正文与次级标题落在 16px、400、字距只有 0.15px 的微正值。真正的大字号（如 “Complex problems, solved with ease”“Kimi K2.6”）是刻意的例外，靠尺度对比制造重音，而不是靠字重堆砌。这与整站“极大留白”的节奏一致。

字体授权（对复刻很友好）：M PLUS 1 是 Google Fonts 开源字体（SIL OFL），MiSans 由小米发布、可免费商用。**与 Comet 的商业字体不同，moonshot 这套排版可以合法直接复刻。**

## 4. 动效系统

### 4.1 双时间尺度

moonshot 把两种极端的时间叠在一起：

- **手感层（快）**：按钮 `transition: color 0.2s`（实测）——只过渡颜色，即时、克制。
- **环境层（极慢）**：`15s、25s、35s`（实测时长梯里的长段）——首屏故障字的横向漂移、光环外冕的呼吸与自转这类“几乎察觉不到在动”的环境运动。
- **签名层（中）**：`1.05s、2s、3s、4s、5s`——故障脉冲、扫描线抖动、光环微搏动。其中 **`2s` 出现 15 次**，是站点动画时长的主音。

### 4.2 签名缓动（样式表实测）

| 曲线 | 值 | 频次 | 角色（推断） |
|---|---|---|---|
| 主曲线（Expo Out） | `cubic-bezier(.16,1,.3,1)` | 5 | 最高频。极快冲出、长尾沉降的“高级顺滑”，用于位移与淡入 |
| Material 标准 | `cubic-bezier(.4,0,.2,1)` | 2 | 通用进出，手感层常用 |
| 回弹（Back） | `cubic-bezier(.34,1.56,.64,1)` | 1 | 控制点 `y=1.56>1`，越界回弹的“啵一下” |
| Expo Out 变体 | `cubic-bezier(.22,1,.36,1)` | 1 | 主曲线的更缓版本 |

### 4.3 关键帧线索

样式表里抽到的唯一具名关键帧是 **`vike-react-shine`**（实测）。两点价值：

1. **技术栈线索（推断）**：`vike-react-` 前缀说明站点用 **Vike（前身 vite-plugin-ssr）+ React** 构建；`libs`、`scriptHints` 都探测为空，印证其打包干净、无第三方动效库外露。
2. **命名即手法**：`shine` = 光泽扫过。这正是日食光环上那道游走的高光，以及故障字被“擦亮”的一瞬。

### 4.4 媒体选型（实测清单）

实测计数为 3 段 video，4 个 canvas，1 个 svg，25 张 img，预加载 video 为 0，预加载字体为 3。

- **4 个 `<canvas>`** 是最重要的线索：首屏的故障品牌字与日食光环很可能由 **canvas 或 WebGL 逐帧渲染**，而非纯 CSS（见 §7 复现说明）。
- 3 段 video 用于下方 Research 卡的单色抽象流体与星球片段。
- 只有 1 个 svg、0 个 video 预加载——首屏刻意轻，把重量交给 canvas 实时绘制。

## 5. Hero 手法

自上而下的首屏结构（观察 + 实拍）：

1. **顶栏**：左品牌（球体 logo + “Moonshot AI”），中导航（Kimi、API、Research、Download、Careers），右语言切换（EN、中文，选中态是一枚浅色 pill）。底色 `rgba(0,0,0,.4)` + `backdrop-filter: blur(16.75px)`（实测），滚动时才显形。
2. **日食光环**：画面正中一轮暗色圆盘（“月”），下缘一道极亮的纯白光环（总日食的“钻石环”），外圈一层柔和白色外冕 glow。
3. **故障品牌字**：“Moonshot AI” 沿水平方向重复平铺，穿过光环；带 **RGB 色散**（红、青、品红边缘残影）、**横向扫描线撕裂**与**运动模糊**，像信号被日食干扰。光环的黑盘遮住字的中段，外冕的白光把邻近的字“提亮”。
4. **slogan**：一行细体白字 “Seeking the optimal conversion from energy to intelligence”。
5. **对话输入框**：深色圆角面板（圆角约 24px），占位 “Throw me a hard one. I'm ready.”，右下角一枚圆形上传与发送按钮。**把 AI-native 信号前置到首屏**。
6. **ghost pill 按钮**：Try Kimi、Try API，圆角 100px、背景透明、描边淡白、文字 `rgba(255,255,255,.56)`，hover 提亮。

节奏：首屏之后是**大段纯黑留白**与逐段揭示——“Latest Research”（单色星球与流体艺术卡）→ “Complex problems, solved with ease” → “Kimi K2.6”（模型模式选择器）→ “Discover Kimi doodles”（节日涂鸦卡）→ “Built for the future. Available today.”（透视网格地面 + 下载入口）→ 页脚。

## 6. 签名视觉母题

**日食环 + 色散故障字**，是这份拆解的核心，也是交互 demo 必须复现的效果。拆成可复刻的三层：

1. **日食光环**
   - 暗盘：一个 `border-radius:50%` 的近黑圆盘，压在纯黑底上，仅靠边缘光被看见。
   - 亮环（钻石环）：一圈极细的纯白高光，下缘最亮——用 `radial-gradient` 做出“透明→白→透明”的细环，再叠一层偏下的高光。
   - 外冕：一层大范围、低透明度的白色 `radial-gradient`，缓慢“呼吸”，营造光晕。
2. **RGB 色散（chromatic aberration）**
   - 把同一行文字拆成红、绿、蓝三层，各自水平错位若干像素，用 `mix-blend-mode:screen` 在黑底上叠加：三层对齐处还原为白，错位处露出红、青、品红的边缘残影。
   - 错位量随时间抖动，形成“信号不稳”的故障感。
3. **横向撕裂 + 运动模糊**
   - 横向运动模糊：一个仅 x 方向的高斯模糊（`feGaussianBlur stdDeviation="8 0"`），把字沿水平方向抹开。
   - 扫描线：一层极细的重复水平暗线（`repeating-linear-gradient`），叠出 CRT 信号质感。
   - 偶发切片：某一层用 `clip-path` 做突发的横向错位，制造“跳帧”。
   - 整条文字带以 `15–25s` 的超慢速度水平漂移（对应实测长时长），让画面始终“活着”。

> 复现取向（见 `复刻指南.md`）：站点原版很可能是 canvas 逐帧（4 个 canvas，实锤）；本拆解用**纯 CSS 与 JS + 一个内联 SVG 滤镜**做等效复现，自包含、零依赖、可跑。

## 7. 工艺细节

### 7.1 圆角语言（实测频次）

| 值 | 次数 | 角色（推断） |
|---|---|---|
| `100px`、`999px` | 4、1 | ghost pill 按钮、语言切换 pill |
| `50%` | 3 | 日食暗盘、圆形发送按钮、圆点 |
| `24px` | 3 | 对话输入框、大卡片 |
| `16px` | 3 | 中卡片 |
| `12px` | 3 | 小卡片、弹层 |
| `20px` | 2 | 卡片变体 |
| `8px` | 1 | 小按钮（btn 计算值，实锤） |
| `4px`、`2px`、`6px`、`15px`、`23.5px`、`150px` | — | 细节与特例 |

一条清晰的圆角梯：药丸用 100px 与 999px，输入框与大卡 24px，卡片 16px 与 12px，小按钮 8px，圆盘与圆点 50%。

### 7.2 玻璃与描边

- 导航玻璃：`background: rgba(0,0,0,.4)` + `backdrop-filter: blur(16.75px)`（实测）。注意 blur 半径是精确的 `16.75px` 而非整数——多半是某个设计变量换算的结果。
- 描边：靠中性灰梯（`#1f1f1f`、`#262626`、`#323232`、`#45454e`）做极低对比的分隔，几乎只在 hover 时才“亮一档”。

### 7.3 按钮解剖（ghost pill，btn 实测）

背景 `transparent`，文字 `rgba(255,255,255,.56)`，圆角小按钮 `8px`、药丸 `100px`，过渡 `color 0.2s`。描边用淡白，hover 只把文字从 `.56` 提到接近 `1`——**克制到只动颜色**。

### 7.4 布局哲学

极大留白 + 居中对齐 + 单栏叙事。首屏把信息压到最少（一句 slogan + 一个输入框 + 两枚按钮），靠日食这一处强签名撑起整屏。CSS 总量仅约 **29.6KB**（`cssBytes 29569`，实测）——极其精简，印证“少即是多”不是口号而是工程事实。

## 8. 关键发现

1. **零品牌色是刻意的**：全站唯一的彩色是故障字的 RGB 色散残影。色彩克制到极致，把注意力全部交给形（日食圆）与动（故障裂）。复刻第一纪律：别补 accent 色。
2. **首屏 canvas 驱动**：4 个 `<canvas>` + 0 个 video 预加载 + 唯一具名关键帧 `vike-react-shine`，共同指向“首屏签名效果由 canvas 实时绘制”。本拆解给出纯 CSS 与 JS 的等效复现。
3. **双时间尺度**：手感层 `0.2s`（按钮只过渡颜色）叠环境层 `15–35s`（超慢漂移），签名脉冲居中（`2s` 为主音）。快得即时、慢得像没动，中间那层才是“故障”的心跳。
4. **排版故意偏小偏轻**：默认 16px、400、字距 0.15px，大字号是刻意的例外——用尺度对比而非字重堆砌制造重音。
5. **技术栈可推断且干净**：`vike-react-shine` 泄露了 Vike + React；`libs`、`scriptHints` 全空、CSS 仅 29.6KB——一个刻意精简、无动效库外露的现代 SSR 站。
6. **字体可合法复刻**：M PLUS 1（Google Fonts，SIL OFL 授权）与 MiSans（小米，免费商用），跟 Comet 的商业字体不同，这套排版能直接搬进生产。

> 详见交互式版 `teardown.html`：含可跑的日食光环 + 色散故障字（纯 CSS 与 JS）、缓动曲线实验台、时长梯、色板点击复制、以及可调色散与模糊的签名实验室。
