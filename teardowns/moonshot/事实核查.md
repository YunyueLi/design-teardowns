## 二、本轮发现并修正的漂移

1. **视频描述失真**:原文案「3 段 video 单色抽象片段」。核对真实视频（`real-assets/video/`,VP9/webm）后确认是 **Kimi K2.6 能力演示**——模式选择弹层（Instant / Thinking / Agent / Agent Swarm）、文档画布、能力卡（Deep Research / Auto Sheets / Create Websites）。已改为准确描述,并把三段真视频以 `<video muted autoplay loop playsinline>` 接入「工艺」节。
2. **研究卡描述失真**:出处节 figcaption 原写「Latest Research 单色星球卡」。真实图（`real-assets/image/`）为**带色散的宇宙意象**——棱镜折射、日食彩虹冕、引力透镜,并非单色。已改为「宇宙意象研究卡:棱镜 / 日食冕 / 引力透镜」,并把三张真图接入「签名」节作母题参照。

4. **圆角梯不全**:缺 `4px`（`n=2`）。已补入,并在注解补一句其角色。

## 三、读回自检:字体是否 tofu

用 `fontTools` 直接读三支 woff2 的 `cmap` 与轴,确认字族与文件对得上、页面用到的字符都有字形:

- `78ffc3_MPLUS1-Latin.woff2` → 内部 `M PLUS 1`,**可变**(`wght 100..900`),覆盖基础拉丁（A/a/0/M 等,220 字形）。页面显示字「Moonshot AI」「Aa Gg 0123」均在覆盖内,不 tofu。缺 `→`(U+2192)与 CJK —— 由回退链补(见下)。
- `b31219_MiSansVF.woff2` → 内部 `MiSans VF`,**可变**(`wght 150..700`),为**中文子集**(469 字形,不含拉丁)。字体样例「智 能 未 来」四字经核实**均在子集内**,以真字渲染,不 tofu。
- `5adcb7_NotoSans-Latin.woff2` → 内部 `Noto Sans`,**非可变**,极小子集(53 字形,仅含大小写字母,**无数字**)。故只用于「Fallback」这一纯字母样例（已核实 F/a/l/b/c/k 均在内）,**未**接入正文栈,以免数字与标点 tofu。
- 回退链设计:`"M PLUS 1"`(拉丁)→ `"MiSans"`(中文子集)→ `"PingFang SC"`(系统,补齐子集外中文)→ `"Noto Sans SC"`(CDN,跨平台中文兜底)。逐字形回退,页面大量中文正文由 PingFang SC / 思源黑体补齐,不 tofu；`→` 等符号回落系统字。
