# 设计评审（Design Review）

> 以顶级设计视角评审这份拆解页相对原站 `www.moonshot.ai` 的**精度**与**完成度**:已达标在哪、仍差在哪,并给出可执行改进（能当场改的已改）。

## 一、总评

这份拆解页抓住了 moonshot 最难的一点——**克制与签名的平衡**:全站压到纯黑、无彩灰阶、极大留白,只让日食光环加 RGB 色散故障字一处承担全部张力。它没有被「多加点东西」的冲动带偏,这与原站的取舍一致,是这份拆解成立的根。

本轮把精度从「近似替身」抬到「真素材回填」:真实字体、真实视频、真实关键图都已就位,数值全部可回溯抽取。**从设计还原度看,静态层(排版 / 色板 / 圆角 / 缓动 / 玻璃)已接近原站;差距主要落在首屏那处 canvas 驱动的动态签名——这是逆向的固有天花板,而非本页的粗糙。**

## 二、已达标（与原站同一水准）

- **零品牌色纪律**:全站只有黑白与一条中性灰梯,唯一彩色留给色散残影。这条最容易被破坏的纪律守住了,与 `accentGuess` 为空的抽取一致。
- **排版气质**:真 M PLUS 1 领衔,几何无衬线的方正字面与开阔字腔到位;默认偏小偏轻（16px / 400 / 字距 0.15px）、靠尺度对比而非字重堆砌制造重音,节奏与原站一致。
- **色板与圆角**:灰梯、药丸、卡片圆角、8px 小按钮全部落在实测梯上,`backdrop-filter: blur(16.75px)` 这种非整数细节也照搬。
- **动效语言**:主缓动 `cubic-bezier(.16,1,.3,1)` 贯穿全页运动,双时间尺度（手感层 0.2s、环境层 15–35s）的叙述与真实时长分布吻合。
- **信息设计**:可复制色板、可重放缓动、可调签名实验室——把「拆到可复刻」这件事做成了可交互的证据,而不是一堆截图,这一点甚至比很多官方设计文档更清楚。

## 三、仍有差距（相对逐像素）

1. **首屏动态签名**:原站首屏由 canvas 逐帧渲染（实测 `canvas 4`、`preloadVideo 0`),故障字的横向运动模糊比本页更重、更「糊」,RGB 色散是细腻的彩虹边而非本页偏硬的纯三通道。本页以等效 CSS 复现,神似但非逐帧一致——已在页面明确声明。
2. **日食环的明度分布**:原站的环最亮处在**底部一弯**（钻石环 / 贝利珠效应）,上缘偏暗；本页的环更接近整圈均匀。是可收敛的差距（见下建议）。
3. **中文真字覆盖**:MiSans 只拿到站点子集,拆解页大量中文由 PingFang / 思源黑体补齐;观感接近,但严格说不是每个中文都用真 MiSans。这是子集抽取的固有限制。

## 四、本轮已执行的改进

1. **接入三支真实字体**（最关键的精度提升）:`M PLUS 1`（拉丁显示与 UI,可变 100–900）、`MiSans`（中文,可变 150–700）、`NotoSans-Latin`（拉丁兜底）以 `@font-face` 落地,`--mplus / --font` 改为真字领衔并镜像站点最高频栈,CDN 同名字降为兜底。
2. **回填真实媒体**:三段真视频（Kimi K2.6 能力演示）以 `<video muted autoplay loop playsinline>` 接入,并尊重 `prefers-reduced-motion` 关自动播放;三张真图（棱镜 / 日食冕 / 引力透镜）接入签名节作母题参照。
3. **首屏仍用 CSS 而非硬塞视频**:真视频经核实是产品能力演示而非首屏日食循环,若塞进 hero 反而降真;故保留等效 CSS 日食,并把结论写进页面。
4. **token 校准**:补齐时长梯（`3s / 5s / 9s`,其中 `3s` 是第二高频）与圆角梯（`4px`）,现与真实集合逐项对齐。
5. **修正两处描述漂移**:「单色抽象片段」「单色星球卡」改为准确表述（详见 `事实核查.md`）。
6. **预加载真实显示字**:镜像站点 `preloadFont=3` 的行为,加一条 `M PLUS 1` 的 `<link rel=preload>`,加速首屏落字。

## 五、后续可执行建议（附具体旋钮）

1. **收敛日食环明度**（中等收益,低风险）:在 `.eclipse .ring` 的底部高光那支 `radial-gradient(62% 52% at 50% 96%,…)` 提高亮度与收窄范围,让底部一弯更亮、上缘更暗,贴近钻石环。建议连带把 `.diamond` 的 `spark` 峰值再抬一点。
2. **加重首屏横向运动模糊**（提神似度）:把 hero 的 `filter #hblur` 的 `stdDeviation` 由 `6 0.5` 调到约 `8–10 0.5`,让故障字更「糊」,更接近实拍的拖影量;可先在签名实验室用滑块试到满意值再落到默认。
3. **色散由硬转柔**（提神似度）:默认色散位移已是 4px 较克制,可再让三通道边缘叠一层极淡的彩虹渐变（而非纯 R/G/B）,更接近实拍的彩虹边。
4. **中文真字覆盖**（若允许扩素材）:当前 MiSans 为子集。若后续能取到更大字重 / 更全字集,可让拆解页正文也尽量落在真 MiSans 上,进一步缩小中文观感差。
5. **wireframe-bg.svg 未用尽**（补完成度）:站点「Built for the future」的真实透视网格 SVG 已在素材内,可作某节的极淡背景纹理,呼应原站尾屏,同时又一次「用真素材」。

> 前两条是当前与原站观感差距最大的地方,建议优先;但都涉及首屏签名的视觉微调,宜配合渲染回看逐步收敛,不宜盲调,故本轮留作建议、附上确切旋钮而未强改。
