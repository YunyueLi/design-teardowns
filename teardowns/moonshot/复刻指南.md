# 复刻指南：把 moonshot 的日食故障首屏接进你的产品

配套文件：[`design-tokens.css`](./design-tokens.css)（从线上真实抽取，复制即用）。所有值均为实测，除非标注“推断与重建”。

## 1. 落地 token（真实值）

```css
:root{

  --ink-56:rgba(255,255,255,.56);  /* ghost 按钮文字（btn 实测）*/

  /* —— 中性灰梯（样式表频次 top，做抬升与描边）—— */
  --ink-12:#121212; --ink-14:#141414; --ink-1f:#1f1f1f;
  --ink-26:#262626; --ink-32:#323232; --ink-45:#45454e;
  --grey-6d:#6d6d6d; --grey-73:#737373;

         "Segoe UI",Roboto,"Helvetica Neue",Arial,sans-serif;

  /* —— 圆角（实测梯）—— */
```

## 2. 日食光环（纯 CSS，零依赖）

暗盘 + 钻石环 + 外冕三层叠加，压在纯黑底上。

```css
.eclipse{
  position:relative; width:min(46vmin,420px); aspect-ratio:1;
  border-radius:50%;
  /* 暗盘：中心近黑，边缘略亮，模拟月掩日的球体 */
  background:radial-gradient(circle at 50% 46%, #060606 60%, #0d0d0d 72%, #000 78%);
}
/* 钻石环：一圈极细白高光，下缘最亮 */
.eclipse::before{
  content:""; position:absolute; inset:-2%; border-radius:50%;
  background:
    radial-gradient(circle, transparent 69%, rgba(255,255,255,.95) 70.4%, transparent 72.5%),
    radial-gradient(60% 60% at 50% 92%, rgba(255,255,255,.9), transparent 60%);
  filter:blur(.4px);
}
/* 外冕：大范围低透明白光，缓慢呼吸 */
.eclipse::after{
  content:""; position:absolute; inset:-70%; border-radius:50%; z-index:-1;
  background:radial-gradient(circle, rgba(255,255,255,.16), transparent 62%);
  animation:corona 6s var(--ease-1) infinite alternate;
}
@keyframes corona{ from{opacity:.7;transform:scale(.98)} to{opacity:1;transform:scale(1.03)} }
```

## 3. 色散故障字（纯 CSS 与 JS + 一个内联 SVG 滤镜）

站点原版很可能是 canvas 逐帧（实测 4 个 canvas）；这里给出**自包含的等效复现**：RGB 三通道 screen 叠加 + 仅 x 方向的高斯模糊 + 扫描线 + 慢漂移。

**HTML**：把同一行文字放三层，另加一个内联 SVG 横向模糊滤镜。
```html
<svg width="0" height="0" style="position:absolute">
  <filter id="hblur"><feGaussianBlur stdDeviation="7 0.4"/></filter>
</svg>

<div class="glitch">
  <span class="ch r">Moonshot AI&nbsp;Moonshot AI&nbsp;Moonshot AI</span>
  <span class="ch g">Moonshot AI&nbsp;Moonshot AI&nbsp;Moonshot AI</span>
  <span class="ch b">Moonshot AI&nbsp;Moonshot AI&nbsp;Moonshot AI</span>
</div>
```

**CSS**：
```css
.glitch{position:relative; filter:url(#hblur); mix-blend-mode:screen;}
.glitch .ch{
  position:absolute; inset:0; white-space:nowrap;
  font:700 clamp(40px,9vw,120px)/1 var(--font);
  mix-blend-mode:screen;               /* 三通道叠加还原白 */
  animation:drift 22s linear infinite; /* 超慢横向漂移（实测 15–25s）*/
}
.glitch .r{color:var(--ca-r); animation:drift 22s linear infinite, jitR 2s steps(12) infinite;}
.glitch .g{color:var(--ca-g); animation:drift 22s linear infinite;}
.glitch .b{color:var(--ca-b); animation:drift 22s linear infinite, jitB 2.4s steps(12) infinite;}

@keyframes drift{ from{transform:translateX(0)} to{transform:translateX(-33.33%)} }
@keyframes jitR{ 0%,100%{margin-left:0} 20%{margin-left:-4px} 55%{margin-left:3px} 80%{margin-left:-2px} }
@keyframes jitB{ 0%,100%{margin-left:0} 30%{margin-left:4px} 60%{margin-left:-3px} 85%{margin-left:2px} }

/* 扫描线：极细水平暗线叠 CRT 质感 */
.glitch::after{
  content:""; position:absolute; inset:0; pointer-events:none;
  background:repeating-linear-gradient(0deg, transparent 0 2px, rgba(0,0,0,.35) 2px 3px);
  mix-blend-mode:multiply;
}
```
- **叠放顺序**：故障字带 `z-index` 低于日食；日食暗盘遮住字的中段，外冕（白光、screen）把邻近的字提亮——与实拍一致。
- **偶发跳帧**：给某一层加 `clip-path:inset()` 的 steps 动画，做突发横向切片错位。
- **触发式故障**（JS）：想要“信号突然更乱”的一下，用 JS 临时放大 `--ca` 位移再回落即可（见 `teardown.html` 签名实验室）。

## 4. ghost pill 按钮（btn 实测）

```css
.pill{
  background:transparent; color:var(--ink-56);
  border:1px solid rgba(255,255,255,.22);
```

## 7. 选型决策表

| 元素 | 选型 | 理由 |
|---|---|---|
| 日食光环 | 纯 CSS 多层 `radial-gradient` | 静态形态 CSS 最省，外冕用 `@keyframes` 呼吸即可 |
| 色散故障字 | CSS 三通道 screen + 内联 SVG 横向模糊 | 自包含、可跑；原站的 canvas 方案成本更高、更难嵌入 |
| 扫描线、CRT | `repeating-linear-gradient` + `mix-blend-mode` | 零资源，纯合成 |
| 慢漂移、外冕呼吸 | CSS `@keyframes` 15–25s、6s | 对应实测长时长，几乎察觉不到在动 |
| 按钮、微交互 | CSS `transition: 0.2s var(--ease-1)` | 手感层，只动颜色 |
| Research 卡背景 | `<video>` 单色抽象片段 | 原站用 3 段 video；复刻可用循环 mp4 或静态图占位 |

## 8. 工程坑

- **色散靠 `mix-blend-mode:screen` + 黑底**：底不是纯黑，白就还原不出来，色散会发灰。守住 `--bg:#000`。
- **横向模糊要用 SVG 滤镜**：CSS `filter:blur()` 是各向同性的，做不出“只横向抹开”。用 `feGaussianBlur stdDeviation="x y"` 分离 x 与 y。
- **`backdrop-filter` 兜底**：不支持时给 nav 一个更实的 `rgba(0,0,0,.7)` 回退，别让文字糊在透明上。
- **别补品牌色**：这是 moonshot 的灵魂。整页守住无彩灰阶，彩色只留给色散残影。
- **`prefers-reduced-motion`**：关掉漂移、抖动、外冕呼吸；日食静态保留即可。
- **精简**：原站 CSS 仅约 29.6KB。复刻时抵抗“再加个渐变或阴影”的冲动，留白本身就是设计。
