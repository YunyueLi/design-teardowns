## 2. 点阵底纹(纯 CSS,ojo 的空间底纹母题)

```css
.dotgrid{
  background-color:var(--black);
  background-image:radial-gradient(rgba(255,255,255,.055) 1px, transparent 1px);
  background-size:22px 22px;              /* 单元约 22px */
  background-position:-1px -1px;
}
```
深色段的"死黑"靠这一层圆点获得坐标感与呼吸。密度与透明度按段落远近微调即可。

## 3. 星夜氛围(纯 CSS 渐变加滤镜,零图片)

不用油画底图也能造出《星夜》的漩涡流动感:用两三层大尺度径向渐变叠一层锥形渐变旋转,再上高斯模糊。

```css
.starry{
  position:absolute; inset:0; overflow:hidden; filter:blur(38px) saturate(1.1);
}
.starry::before{  /* 漩涡:锥形渐变缓慢自转 */
  content:""; position:absolute; inset:-30%;
  background:
    radial-gradient(38% 30% at 22% 26%, #eac54a55, transparent 60%), /* 星子的黄 */
    radial-gradient(46% 40% at 74% 30%, #2b4a8c88, transparent 62%), /* 夜空的蓝 */
    conic-gradient(from 210deg at 30% 34%, #14264f, #3a5a9c, #16305f, #14264f);
  animation:starry-swirl 18s linear infinite; /* 氛围层长循环 */
}
@keyframes starry-swirl{ to{ transform:rotate(360deg) } }
```
`18s` 与 `saturate` 取自站点氛围层时长梯与 `hero-breathe` 的量级。要更还原就把 `assets/actual-full.jpg` 的真实油画首屏当底图,这层渐变做叠加辉光。

## 4. 打字机式代码叙事(对应 `landingpage-code-flicker`)

把"配置智能体"讲成"塑造一位画家",逐字浮现:

```html
<pre class="code-narrate"><code id="typed"></code><span class="caret"></span></pre>
```
```js
const src =
`canvas = ojo.Canvas()
agent  = ojo.Agent(
  name="Vincent",
  goal="evoke emotion through color",
  tools=[Search(), Code(), Draw()],
)
canvas.flow().add(agent).run()`;
let i=0, el=document.getElementById('typed');
(function type(){ el.textContent = src.slice(0, i++);
  if(i<=src.length) setTimeout(type, 24); })();   /* 约 24ms/字符 */
```
```css
.caret{display:inline-block;width:.5ch;height:1.05em;background:var(--yellow);
  vertical-align:-2px;animation:blink 1s steps(1) infinite}
@keyframes blink{50%{opacity:0}}

```

## 5. 深黑玻璃对话框加流动边框(对应 `agent-team-input-border-flow`)

签名组件。玻璃底加一圈会流动的渐变边框,用 `border-image` 或伪元素遮罩实现。这里用最稳的锥形渐变伪元素法:

```css
.chatbox{position:relative;border-radius:var(--r-md);
  background:linear-gradient(180deg,#141414ee,#0d0d0dee);
  backdrop-filter:blur(20px);padding:20px 22px;isolation:isolate}
.chatbox::before{ /* 流动边框 */
  content:"";position:absolute;inset:0;border-radius:inherit;padding:1px;
  background:conic-gradient(from var(--a,0deg),
    #ffc00000,#ffc000aa,#5f86a8aa,#ffc00000);
  -webkit-mask:linear-gradient(#000 0 0) content-box, linear-gradient(#000 0 0);
  -webkit-mask-composite:xor; mask-composite:exclude;
  animation:border-flow 4s linear infinite}    /* 氛围层 4s */
@property --a{syntax:"<angle>";inherits:false;initial-value:0deg}
@keyframes border-flow{ to{ --a:360deg } }
```
框内结构从上到下:团队标签药丸加"加号",占位文案,底行左侧"加号"、右侧"OJO Master ⌄"模型选择加圆形发送键。发送键 `border-radius:50%`,按钮过渡统一 `background-color .18s, transform .12s`。

不支持 `@property` 时降级为静态渐变边框,不影响可用性。

## 6. 技能走马灯(对应 `agent-team-skill-marquee`)

一排技能药丸横向无缝滚动。把内容复制一份首尾相接,平移一半即无缝。

```css
.marquee{overflow:hidden;-webkit-mask:linear-gradient(90deg,transparent,#000 8%,#000 92%,transparent)}
.marquee-track{display:flex;gap:12px;width:max-content;
  animation:marquee 18s linear infinite}      /* 氛围层 18s */
.marquee:hover .marquee-track{animation-play-state:paused}
@keyframes marquee{ to{ transform:translateX(-50%) } }
.skill{display:inline-flex;align-items:center;gap:8px;white-space:nowrap;
  padding:8px 14px;border-radius:var(--pill);
  border:1px solid #ffffff14;background:#ffffff08;color:#cfcfcf;font-size:13px}
```
两端用遮罩渐隐,避免生硬的进出。真实站点技能包括 Visual DNA、UI/UX practice、Web Search、Product page structure、Design review、Product analysis、Structure Analysis、Wireframe generation 等。

## 7. 浮动画布卡(对应 `agent-team-card-float`)

```css
.float{animation:float 8s var(--ease-std) infinite alternate}
.float:nth-child(2){animation-duration:6s;animation-delay:.6s}
.float:nth-child(3){animation-duration:7s;animation-delay:1.1s}
@keyframes float{ from{transform:translateY(0)} to{transform:translateY(-10px)} }
.team-card{border-radius:var(--r-lg);padding:16px;position:relative;overflow:hidden;
  background:#111}
.team-card.blue::after{ /* 品牌色辉光 */
  content:"";position:absolute;inset:0;
  background:radial-gradient(70% 90% at 80% 90%, #2d6cdf55, transparent 60%)}
```
入场用 `--ease-out`(`cubic-bezier(.16,1,.3,1)`),空闲用上面的 `float` 缓慢漂移,错开时长与延迟避免同步。

## 8. 选型决策表

| 效果 | 选型 | 理由 |
|---|---|---|
| 星夜首屏底 | 预渲染 AI 油画插画(1 张大图) | 油画笔触难用 CSS 造真,插画成本低且质感满;媒体清单实测 58 图 1 视频 |
| 星夜氛围辉光 | 纯 CSS 径向加锥形渐变叠模糊 | 叠在底图上做流动光晕,零额外资源 |
| 点阵底 | 单层 `radial-gradient` 平铺 | 一行 CSS,GPU 友好 |
| 代码叙事 | JS 逐字打字加闪烁光标 | 轻量,叙事节奏可控 |
| 玻璃边框流动 | `@property` 角度动画加锥形渐变遮罩 | 平滑且可降级为静态渐变 |
| 技能走马灯 | 内容翻倍加 `translateX(-50%)` | 无缝、无需 JS |
| 卡片漂浮 | CSS `@keyframes` 错相位 | 氛围层长循环,统一 `--ease-std` |
| 悬停与焦点 | CSS `transition` | 120 到 400 毫秒,`background-color .18s, transform .12s` |

## 9. 工程坑

- **双时间尺度别混用**。手感用 120 到 400 毫秒,氛围循环用 4 到 18 秒。把氛围曲线套到点击反馈上会显得"黏",反之会显得"躁"。
- **暖白不是纯白**。大标题用 `#fff8eb` 而非 `#fff`,压在深色油画上更耐看、不刺眼;强调黄用 `#ffc000` 这一支。
- **两套语言别串味**。叙事层(深黑、Faculty Glyphic 衬线、暖黄)与产品层(白底、Geist、Radix 灰、橙蓝)各自成体系,混用会两头不讨好。
- **走马灯要偶数复制**。技能带必须精确复制一半宽度并 `translateX(-50%)`,否则循环处会跳。两端加遮罩渐隐。
- **尊重 `prefers-reduced-motion`**。关掉星夜自转、卡片漂浮、走马灯与打字机,静态呈现同样成立。
- **`@property` 兼容性**。流动边框依赖 `@property` 做角度插值;老浏览器降级为静态渐变边框即可。
- **字体授权无忧**。Faculty Glyphic、Geist、Georama、Lexend、DM Serif Text、Miss Fajardose 全部在 Google Fonts 免费提供,直接用真字,无需替身。
