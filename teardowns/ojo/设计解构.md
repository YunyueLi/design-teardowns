# ojo 设计解构 —— 把星夜叙事拆到可复刻的每一个数值

> 顶级 UI 视角的完整拆解。除特别标注,所有数值均来自对线上站点 `https://ojo.art` 的真实抽取(Playwright 计算样式加服务端抓取的样式表文本,共 278292 字节 CSS),均为**实锤**;技术栈与创作意图等无法从源码直接确认的信息标注为**推断**。
>
> 配套真实 token 见同目录 `design-tokens.css`,原始抽取数据见 `../_data/ojo.json`,实拍见 `assets/actual-full.jpg`。

---

## 1. 两套设计:先分清,再复刻

ojo 和许多顶级 AI 产品站一样,存在两套并行的设计语言。抽取数据里这两套语言的证据清晰可辨,别把它们混为一谈。

| | 叙事营销层(Landing) | 产品 UI 层(App) |
|---|---|---|
| 载体 | 首页 `ojo.art` 首屏与滚动叙事 | 登录后的工作台、对话与画布界面 |
| 基调 | 深黑打底,梵高《星夜》油画质感,克制的仪式感 | 近乎无彩的浅色,干净、功能优先 |
| 底色 | 黑(`#000` 样式表出现 25 次,居首) | 白(`#fff` 出现 21 次;`--color-background` 为 `0 0% 98%`) |
| 文字 | 暖白奶油色 `#fff8eb`(h1 计算色) | 纯黑 `#000`(`--color-text-primary` 为 `0 0% 0%`) |
| 强调 | 明黄 `#ffc000`(按钮计算色) | 橙 `#f97316`(`--color-commercial-accent` 为 `24 95% 53%`) |
| 标题字体 | Faculty Glyphic 衬线(计算值,`60.48px/400`) | Geist Sans 无衬线(`--font-ui-default`) |
| 中性色 | 手工深色层次 `#0a0a0a`、`#0d0d0d`、`#111` | Radix 灰阶 `--gray1` 到 `--gray12` |
| 运动 | 星夜氛围、卡片漂浮、走马灯的长循环(4 到 18 秒) | 悬停与焦点的短过渡(120 到 400 毫秒) |

**复刻目标等于营销层的叙事氛围叠加产品层的克制手感。** 首页正是这两层的交汇处:它用产品级的干净对话组件(深黑玻璃输入框、模型选择、技能标签),去承载一个艺术化的叙事母题(把智能体拟人成正在作画的艺术家)。本解构聚焦于首页。

> **一处需要澄清**:抽取到的 `<body>` 计算样式是白底黑字、Geist Sans,这是登录态应用的默认底。首页首屏的暖白 h1 与明黄按钮才是营销层的真实取值。两组数据都是实锤,分别对应上表两层。

## 2. 色彩系统(真实 token)

点击交互页里的任意色块可复制 HEX。所有色值取自样式表高频色统计与计算样式,是实锤;由 HSL 到 HEX 的换算为忠实转换。

### 2.1 叙事营销层(首页)

| 名称 | 值 | 角色 | 来源 |
|---|---|---|---|
| 深黑基底 | `#000` | 首屏与深色段的底 | 样式表出现 25 次(最高) |
| 近黑层次 | `#0a0a0a`、`#0d0d0d`、`#111` | 段落分层与玻璃卡底 | 样式表高频 |
| 奶油暖白 | `#fff8eb` | 大标题文字,非纯白,压在油画上更耐看 | h1 计算色 `rgb(255,248,235)` |
| 明黄强调 | `#ffc000` | 主按钮、Sign in、Get early access | 按钮计算色 `rgb(255,192,0)` |
| 星夜蓝 | `#5f86a8` | 《星夜》油画的主调蓝,贯穿背景与产品缩略图 | 样式表出现 10 次 |
| 暖白纸感 | `#f4f3f0`、`#f6f4ef`、`#e4dbc9` | 白板、画布纸张、UI 原型底 | 样式表高频 |

### 2.2 智能体卡片光谱(浮动卡与技能卡)

首页第二屏的四张智能体团队卡,各带一种品牌色辉光;第五屏的技能卡组则是一副摊开的彩色卡牌。这套光谱是页面里唯一的高饱和用色。

| 名称 | 值 | 角色 |
|---|---|---|
| 改版蓝 | `#2d6cdf` | Redesign Team 卡的蓝色辉光 |
| 原型绿 | `#34c759` | Prototype Team 卡的青绿辉光 |
| 酸性柠檬 | `#d6ff41` | 技能卡与点缀的高亮色 |
| 珊瑚橙 | `#ff6b54`、`#ff6a2a` | 暖色点缀 |
| 商用橙 | `#f97316` | 产品层强调色,`hsl(24 95% 53%)` |
| 警示红 | `#d9381e`、`#ef4444` | 状态与点缀 |

> Game Workshop 卡的品红辉光在样式表里未落成命名色值,推断为运行时生成的渐变(见第四节 `agent-team-card` 系列关键帧)。

### 2.3 产品 UI 层(Radix 灰阶,实锤)

产品层的中性色是一条完整的 Radix `gray` 纯灰阶,从近白到近黑十二级,取自站点自定义变量。

| 变量 | 值 | 约等于 |
|---|---|---|
| `--gray1` | `hsl(0 0% 99%)` | `#fcfcfc` |
| `--gray3` | `hsl(0 0% 95.1%)` | `#f2f2f2` |
| `--gray6` | `hsl(0 0% 88.7%)` | `#e2e2e2` |
| `--gray9` | `hsl(0 0% 56.1%)` | `#8f8f8f` |
| `--gray11` | `hsl(0 0% 43.5%)` | `#6f6f6f` |
| `--gray12` | `hsl(0 0% 9%)` | `#171717` |

产品主题另有一组语义色变量:主色 `--color-primary` 为 `hsl(210 52.5% 35.5%)`(约 `#2b5b8a`,一种去饱和的蓝),文字分三级透明度(主 `0 0% 0%`、次 `/.5`、三级 `/.3`)。这套灰阶与语义色是典型的设计系统底座,与首页的艺术叙事完全分层。

## 3. 字体系统

站点实测加载了五款字体:Faculty Glyphic、Geist、Georama、Lexend、DM Serif Text、Miss Fajardose(共六款,预加载四款)。它们全部能在 Google Fonts 免费获取,本页与复刻可直接用真字,无需替身。

| 角色 | 字体 | 说明 | 来源 |
|---|---|---|---|
| 叙事大标题 | **Faculty Glyphic** | 衬线雕刻风,压在油画上有手作感;首页大标题就是它 | h1 计算 `font-family` |
| 产品 UI 与正文 | **Geist Sans** | Vercel 出品的现代无衬线,`--font-ui-default` 与 `--font-numeric` | `<body>` 与变量计算值 |
| 辅助无衬线 | **Georama**、**Lexend** | 可变字重,用于副文与标签 | `fontsLoaded` 清单 |
| 产品内衬线展示 | **DM Serif Text** | 产品原型里 "Aurelle"、"Journey to the Edge of Light" 一类展示标题 | `fontsLoaded` 清单 |
| 手写签名点缀 | **Miss Fajardose** | 极细的花体草书,呼应艺术家签名的意象 | `fontsLoaded` 清单 |

首页首屏还引用了 `--landing-title-font-family` 与 `--landing-aux-font-family` 两个变量,把标题字与辅助字抽成 landing 专用 token(推断标题字即 Faculty Glyphic)。

**大标题真实排印(实锤)**:字号 `60.48px`,行高 `86.4px`,字重 `400`,字距 `normal`,颜色 `#fff8eb`。行高约为字号的 1.43 倍,给衬线大标题留了充足的呼吸。

站点另带一条完整的 CJK 回退栈(Noto Sans CJK 全字族到 PingFang、微软雅黑),说明产品本身面向多语言。

## 4. 动效系统 —— 双时间尺度是关键

ojo 的动效同时叠了两种时间尺度,这也是它"活"起来的秘密。

### 4.1 微交互层(手感)

短过渡,保证点击与悬停的即时反馈。按钮的计算过渡逐字为:

```
background-color 0.18s, color 0.18s, opacity 0.18s, transform 0.12s
```

位移比变色更快(`0.12s` 对 `0.18s`),让按下的形变先于颜色到位,手感更"脆"。时长梯里 `0.15s`(出现 12 次)、`0.2s`(11 次)、`0.18s`(5 次)、`0.4s`(6 次)构成微交互主力区。

### 4.2 氛围层(叙事)

长循环,营造《星夜》的流动与画布的生命感。时长梯里 `1s`(16 次)、`2s`(11 次)、`4s`(8 次)、`8s`(6 次)、`15s`(12 次)、`18s`(5 次)构成氛围区。星夜漩涡、卡片漂浮、技能走马灯都跑在这一层。

### 4.3 签名缓动(样式表实测)

| 曲线 | 出现次数 | 用途推断 |
|---|---|---|
| `cubic-bezier(0.4, 0, 0.2, 1)` | 24(两种写法合计) | 主力微交互曲线,标准 ease,几乎所有过渡的默认 |
| `cubic-bezier(0.16, 1, 0.3, 1)` | 8 | 强出场缓动,极快冲出加长尾沉降,用于揭示与卡片入场的"高级顺滑" |
| `cubic-bezier(0.4, 0, 0.15, 1)` | 1 | 主力曲线的加速变体 |
| `cubic-bezier(0, 0, 0.2, 1)` | 1 | 纯减速(decelerate),元素滑入停稳 |
| `cubic-bezier(0.22, 1, 0.36, 1)` | 1 | ease-out-quart,轻微越界的顺滑收束 |

一句话:日常交互用 `.4,0,.2,1`,想要"高级揭示感"就换 `.16,1,.3,1`。

### 4.4 真实关键帧清单(实锤,签名母题都在这里)

样式表里的 `@keyframes` 命名直接暴露了首页的每一个签名效果,含义一目了然。

| 关键帧名 | 复现的效果 |
|---|---|
| `hero-breathe` | 首屏《星夜》氛围的缓慢呼吸 |
| `hero-headline-reveal` | 大标题分段揭示入场 |
| `hero-headline-description-reveal` | 副标题延迟揭示 |
| `landingpage-code-flicker` | 代码叙事的打字机式闪现 |
| `landingpage-cursor-wander-1` | 无限画布上光标的自主游走 |
| `landingpage-placeholder-shimmer` | 占位内容的微光加载 |
| `agent-team-input-border-flow` | 深黑玻璃输入框的流动渐变边框 |
| `agent-team-card-float` | 智能体团队卡的悬浮漂移 |
| `agent-team-card-enter` | 团队卡入场 |

## 5. Hero 手法解剖 —— 把智能体拟人成艺术家

首屏是整站的叙事核心,信息层次从后到前叠了四层(见 `assets/actual-full.jpg`)。

1. **最底:梵高《星夜》油画场景**。一位戴帽、着蓝衣的画家背对镜头,正在一面白板前作画。整幅是油画笔触质感的插画,主调是《星夜》的蓝(`#5f86a8`)与向日葵的黄。
2. **左侧:黑底代码叙事**。一段发着暖光的代码浮在最左,把智能体写成艺术家:
   ```
   canvas = ojo.Canvas()
   agent  = ojo.Agent(
     name="Vincent",
     goal="evoke emotion through color and expressive strokes",
     tools=[Search(), Code(), Draw()],
   )
   canvas.flow()
     .add(agent)
     .connect("imagination", "coder")
     .connect("coder", "ui_builder")
     .run()
   ```
   代码以打字机方式逐字浮现(`landingpage-code-flicker`),把"配置一个智能体"讲成"塑造一位画家"。
3. **中央:Infinite Canvas 白板**。带无限符号图标的白板,上面钉着线框、《星夜》与向日葵画作、UI 原型卡、素描草稿,四周有连接线与游走的光标(`landingpage-cursor-wander-1`),暗示这是一个多智能体协作的画布。
4. **最前:大标题压图**。奶油白 Faculty Glyphic 衬线大标题 "The world's first Design Agent Team Workspace",首字母 T 做成超大的装饰性首字下沉。下接副标题 "Turns your idea into real product design"、私测说明,以及明黄药丸按钮 "Get early access"。

手法的高级之处:它没有用抽象的科技视觉去讲"AI 智能体",而是借一个人人都认得的艺术符号(梵高作画),把抽象的多智能体编排落成"一支会画画的团队"。叙事驱动压过了功能罗列。

## 6. 签名视觉母题

- **梵高《星夜》**:漩涡状的星空、向日葵、画家背影,是全站的情绪锚点。推断底图为 AI 生成的油画风插画(媒体清单里 58 张图、1 段视频)。
- **点阵底纹**:深色段普遍铺一层极淡的圆点网格,是 ojo 的空间底纹母题,让纯黑不至于死板,也呼应"画布"的坐标感。
- **深黑玻璃对话框**:第二屏中央的输入框是产品能力的浓缩展示,带团队标签、加号、模型选择(OJO Master)、圆形发送键,边框有流动渐变(`agent-team-input-border-flow`)。
- **浮动画布卡**:智能体团队卡、字体卡、代码卡、图片卡在深黑上悬浮漂移(`agent-team-card-float`),模拟无限画布上散落的素材。
- **技能走马灯**:一排带图标的技能药丸横向无缝滚动(`agent-team-skill-marquee`),把"超过 200 种技能"可视化成流动的能力带。
- **摊开的卡牌**:第五屏把技能卡像一副扑克一样扇形摊开,高饱和配色是全站唯一的"色彩爆发",与深黑形成张力。

## 7. 工艺细节

- **圆角语言**:药丸 `999px`(按钮、标签、CTA,出现 8 次)是主导;基础圆角 `8px`(`--border-radius`);玻璃输入框与大卡 `24px` 与 `28px`;圆形 `50%`(发送键、头像);另有 `12px`、`6px`、`4px` 用于小控件。整体是"大控件用药丸、容器用中圆角"的柔和体系。
- **点阵底**:用一层 `radial-gradient` 圆点平铺实现(推断),叠在深黑上,单元约 20 余像素。
- **玻璃与辉光**:对话框是深色半透明玻璃,配细边框;团队卡在卡底叠品牌色径向辉光,营造"发光的能力块"。
- **边框**:细线普遍是低透明度白(产品层用 Radix 灰边),不喧宾夺主。
- **媒体选型**:图片主导(58 张),SVG 图标 9 个,Canvas 2 处(推断用于点阵或光标游走),视频仅 1 段。氛围靠预渲染插画而非重量级 WebGL,是成本可控的选择。
- **栅格**:居中单列叙事为主,内容宽度受控,首屏用大图满幅出血。

## 8. 关键发现

1. **叙事是第一设计决策**。ojo 没有把首屏让给功能点或产品截图,而是让给一个艺术隐喻。把"多智能体协作"讲成"一支画家团队",是它区别于同类 AI 站的根本手法。
2. **两套设计语言各司其职**。营销层负责"让人心动"(深黑、油画、衬线、暖黄),产品层负责"让人好用"(白底、Geist、Radix 灰、橙蓝)。抽取数据里两套色板与两套字体清晰分层。
3. **关键帧命名直接泄露了签名效果**。`agent-team-input-border-flow`、`agent-team-skill-marquee`、`landingpage-code-flicker`、`landingpage-cursor-wander-1` 这些名字,等于把"该复刻什么"写在了脸上。
4. **双时间尺度是"活"的来源**。120 到 400 毫秒管手感,4 到 18 秒管氛围,两层叠加既即时又不焦躁。
5. **真字全部可免费获取**。Faculty Glyphic 与 Geist 都在 Google Fonts 上,复刻无需商业授权或替身,还原度可以做满。
