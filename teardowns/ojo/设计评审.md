# 对抗性审查 · 设计评审

以设计总监视角，评审这份拆解页相对原站 `ojo.art` 的精度与完成度，分 MUST-FIX 与 POLISH。以下均已在 `teardown.html` 落地。

## 相对原站：已达标 vs 仍有差距

**已达标**：深黑加点阵底、暖白奶油标题 `#fff8eb`、明黄强调 `#ffc000`、星夜蓝 `#5f86a8` 的双层色语言；被主缓动 `cubic-bezier(.4,0,.2,1)` 统治、辅以强揭示 `(.16,1,.3,1)` 的运动；药丸 `999px` 主导、容器 `24–28px` 的圆角语言；「微交互 120–400ms + 氛围 4–18s」双时间尺度。本轮**标题真字已到位**——首字下沉与英文大标题跑的是真实 Faculty Glyphic，不再是替身；产品层与营销层两套语言分层清晰，与抽取证据一致。

**仍有差距**：星夜首屏底图是站点整幅梵高风 AI 油画（漩涡、向日葵、画家背影），本页首屏仍是抽象 CSS 漩涡，笔触与叙事密度不及原画（这是资产客观局限，见下）；正文/UI 的 Geist 走 CDN 真字体，与自托管在字节层面不完全等同，但字形一致，无可感差异。

## MUST-FIX（已修）

1. **标题字此前只是 CDN 替身**——这是全页最关键的精度短板，直接决定「像不像 ojo」。已把站点五款自托管字体（Faculty Glyphic、Miss Fajardose、DM Serif Text、Georama、Lexend）从 `real-assets/fonts/` 经 `@font-face` 接进来，真字优先、同名 Google Fonts 降为兜底；字重按真实 `@font-face` 对齐（Faculty Glyphic 400，避免伪粗体）。
2. **媒体清单里的「1 段视频」只是文字声明**——页面并无视频，读者无从验证。已把站内唯一那段真实产品演示视频直接内嵌「所见即所得」段，静音自动循环，并配真视频抽帧作 poster。声明变实锤。
3. **字体数量与「用真字」的口径含糊**。原写「加载六款字体」，与 `document.fonts` 实测的五款不符，且未讲清 Geist 是被引用的 UI 字体。已订正为「五款自托管 + Geist（CDN 真字体）」，并在字体节、复刻节、出处节三处口径一致，不含糊、不夸大。

## POLISH（已采纳）

1. **真实「智能体魔法卡组」入页**。八张原图铺进工艺节——全站唯一的高饱和用色几乎都在这一组，其中「星夜漩涡」正是把梵高母题压进一张卡，比任何 CSS 复述都更精确，也把「真实星夜母题」落到了可见处。
2. **复现旁并置真件**。签名节的深黑玻璃对话框旁，放上站点真实素材「输入框」原件；字体节那款 DM Serif Text，配上真实原型「Aurelle」的落地图——复现与原件并置，精度可当场核对。
3. **真实商标 + 清单指路**。出处段加入真实 `ojo-wordmark.svg`（填 `--cream` 呈色）作来源标记，并把可复刻资产清单指向 `real-assets/manifest.json`，读者可循清单核对每一份真素材。
4. **「代码即创作」母题落到真素材**。签名舞台底部以极低透明度叠了 landing 的真实「双手」ASCII 艺术（`手 (1).png`），把「智能体团队协作创作」的意象接在真图上，而非纯装饰。

## 未阻断的判断与诚实说明

- **星夜首屏保留 CSS 近似，是资产局限不是偷懒**。本次抓取没有可独立复用的整幅油画文件（星夜只作为截图存在于整页实拍里），把截图当首屏背景会陷入「拿站点截图当站点背景」的循环，故不做；改以魔法卡「星夜漩涡」与整页实拍承载真实星夜母题，并在出处段写清这一取舍。
- **Geist 是真字体、经 CDN 加载**。它不是替身，只是未由 ojo 自托管；页内已标明来源，不构成误导。
- **拆解页自身层级用衬线 600 是页面 chrome**，与 ojo 真实 h1（Faculty Glyphic 400）不冲突：面向复现的英文大标题specimen已按真值跑 400，中文标题用思源宋体的页面自有层级，两者未混淆。
- **下一轮若能拿到整幅星夜油画或自托管 Geist**：优先把首屏氛围从 CSS 近似换成真图，并把 Geist 也做成 `@font-face`，进一步收窄与原站的最后差距。

整体：二轮把最关键的精度短板——标题真字与真实媒体——补齐，标题、点缀、辅助字与产品演示视频全部换成从站点提取的真素材，魔法卡、真实对话框、真实原型与真实商标就位；星夜首屏因客观限制仍为 CSS 近似，但已如实交代并用真实卡组母题补位。达到可发布水准，不像 AI 套模板——真实 token、真实字体、真实媒体，与抽取数值一一绑定。
