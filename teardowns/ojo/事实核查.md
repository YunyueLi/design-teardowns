# 对抗性审查 · 事实核查

第二轮：接入真实资产后，逐条把拆解页 `teardown.html` 里出现的数值与真实抽取（`../_data/ojo.json`、`design-tokens.css`、`real-assets/manifest.json`）比对，确认「实锤 vs 推断」标注无误。

## 结论

页面里的色值、缓动曲线及次数、时长梯、圆角梯、媒体数量、CSS 字节数、Radix 灰阶换算与 `@keyframes` 名，经复核**全部可溯源到真实抽取**。本轮只发现并改正**一处数值漂移**：字体数量把「五款自托管字体」误记为「六款加载字体」。同时把此前走 CDN 的替身字体升级为**真实自托管字体文件**，并内嵌了站点唯一的真实产品演示视频与真实素材图。最重要的局限如实记录在案：**站点星夜首屏是整幅 AI 油画，本次抓取未拿到可独立复用的整幅油画文件，故首屏氛围仍为纯 CSS 近似；正文/UI 的 Geist 站点未自托管，继续走 Google Fonts 的真实字体。**

## 已修正

1. **字体数量漂移（本轮唯一的数值改正）**。第一轮字体节写「实测加载六款字体」、手写体卡写「六款加载字体里最具叙事性的一支」。复核 `probe.fontsLoaded` 只有五款（Georama、Lexend、DM Serif Text、Faculty Glyphic、Miss Fajardose）——**Geist 不在 `document.fonts` 报告的加载列表里**，它是经 `--font-ui-default: "Geist Sans"` 引用的正文/UI 计算字体，站点大概率用另一套机制（如 next/font）加载，本次抓取未暴露其字体文件。已把两处「六款加载」改为「五款自托管字体」，并写清 Geist 是被引用的 UI 字体、走 Google Fonts。字体可得性仍是六款（五款自托管 + Geist）全部免费，这一点不变。
2. **媒体「1 段视频」由声明变为实锤内嵌**。第一轮只在媒体清单里声明「视频 1」，页内并无视频。本轮把站点唯一那段真实视频（`real-assets/video/…demo.mp4`，1106×1080、H.264、9.8s）以 `<video muted autoplay loop playsinline>` 直接内嵌到「所见即所得」段，静音自动循环。
3. **替身字体升级为真字**。标题/点缀/辅助字此前全走 Google Fonts 替身，现把五款自托管文件经 `@font-face` 接入（真字优先、同名 CDN 兜底）；`.specimen`／`.dropcap` 字重显式设 `400`，与 Faculty Glyphic 只发行 400 一致，避免此前默认渲染出的伪粗体。

## 需知的溯源细节与局限

- **无可独立复用的整幅星夜油画文件（重点）**。星夜首屏是站点整幅 AI 油画，`real-assets/image/` 里没有干净的整幅油画背景可直接铺进首屏（只在整页实拍 `assets/actual-hero.jpg` 里作为截图存在）。因此首屏氛围**继续用纯 CSS 漩涡近似**（这本就是拆解页要演示的「CSS 造星夜」母题），真实星夜母题改由魔法卡「星夜漩涡」与整页实拍呈现，不用截图伪装成首屏背景。
- **Geist 走 CDN 是真字体、非替身**。站点未在本次抓取暴露自托管的 Geist 文件，正文/UI 继续经 Google Fonts 加载 Geist / Geist Mono——那是 Geist 本尊，只是不由 ojo 自托管，不是近似替身。
- **视频是产品产出演示、不是首屏背景视频**。站点首屏没有背景视频（`media.video=1` 那一段就是这个手机演示），故按其真实用途放进「所见即所得」段，未硬塞进 hero。
- **导航标识仍是拆解页专用**。顶栏沿用解构专用的「眼睛」标记，避免与原站混淆；真实商标 `ojo-wordmark.svg` 只在出处段作来源标记出现（填 `--cream` 呈色）。
- 各色值/次数为第一轮抽取所得，本轮与 `../_data/ojo.json` 复核一致，未重新爬站；`design-tokens.css` 顶部 `--font-sans:"Geist Sans"` 与 `fontsLoaded` 注释同源，无冲突。
- 同目录 `出处与方法.md` 第一轮把「字体可得性核验」写作「实测加载的六款字体」，同属把「加载(5)」与「可得性核验(6)」的口径混写；本轮已就该行同步订正为「五款自托管 + Geist」。
