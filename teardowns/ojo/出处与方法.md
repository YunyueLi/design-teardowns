# 出处与方法 · Provenance

## 抽取对象

线上站点 `https://ojo.art`(标题 `OJO`,语言 `en`)。抽取产物见 `../_data/ojo.json`,整理后的 token 见同目录 `design-tokens.css`,真实渲染实拍见 `assets/actual-hero.jpg`(首屏)与 `assets/actual-full.jpg`(整页),滚动关键帧见 `keyframes/00.jpg` 到 `07.jpg`,滚动录屏见 `recording/scroll.webm`。

## 提取链路

1. **计算样式(Playwright)**:用无头浏览器打开线上站点,读 `<body>`、`<h1>`、`<nav>`、按钮等元素的最终计算样式(`getComputedStyle`),拿到实际生效的背景色、文字色、字体、按钮圆角与过渡等。这类值是浏览器渲染后的真实结果,不受源码写法影响。
2. **样式表文本(服务端抓取)**:直接抓取站点引用的样式表原文(共抓到 2 份,合计 278292 字节),用正则统计高频十六进制色、cubic-bezier 曲线、时长、圆角、字体族、CSS 自定义变量与 `@keyframes` 名称。服务端抓取不受浏览器 CORS 限制,能拿到完整文本。
3. **真实渲染截图与录屏**:对线上页面首屏与整页截图,并录制一段滚动过程,作为"所见即所得"的证据图与关键帧来源。
4. **字体可得性核验**:对六款字体(五款自托管 + 被 `--font-ui-default` 引用的 UI 字体 Geist)逐一请求 Google Fonts CSS2 接口,确认全部返回真实 `@font-face`(HTTP 200)。第二轮已把五款自托管字体下载到 `real-assets/fonts/` 并经 `@font-face` 直接接入拆解页;Geist 站点未自托管,继续走 Google Fonts 真字体。

## 实锤 vs 推断

- **实锤(源自抽取)**:
  - 底色与文字色(计算值):`<body>` 白底黑字 Geist Sans;h1 暖白 `#fff8eb`、`60.48px/86.4px/400`;按钮明黄 `#ffc000`、圆角 `999px`、过渡 `background-color .18s, color .18s, opacity .18s, transform .12s`。
  - 高频色板:`#000`、`#fff`、`#5f86a8`、`#fff8eb`、`#ffc000`、`#f97316` 等及其出现次数。
  - 完整 Radix 灰阶变量 `--gray1` 到 `--gray12`,产品语义色 `--color-primary`、`--color-commercial-accent`、`--color-text-*` 等。
  - 五条 cubic-bezier 曲线及出现次数,时长梯,圆角梯。
  - 签名 `@keyframes` 名称:`hero-breathe`、`hero-headline-reveal`、`landingpage-code-flicker`、`landingpage-cursor-wander-1`、`agent-team-input-border-flow`、`agent-team-card-float`、`agent-team-skill-marquee` 等。
  - 加载字体清单:`document.fonts` 实测五款自托管拉丁字体(Georama、Lexend、DM Serif Text、Faculty Glyphic、Miss Fajardose);正文/UI 计算字体为 Geist Sans(经 `--font-ui-default` 引用,不在这五款自托管列表内)。
  - 媒体清单:视频 1、Canvas 2、SVG 9、图片 58、预加载字体 4。
- **推断(公开资料或观察)**:
  - 技术栈:样式表出现大量 `--tw-*`(Tailwind)、`lightningcss` 变量、Radix 灰阶、Sonner 吐司变量,关键帧截图里出现 `motion.div` 代码,据此推断为 Next.js 加 Tailwind 加 Radix 加 Sonner,动效含 Framer Motion。探测器的 `libs` 与 `scriptHints` 字段为空,故这些是指纹推断,非直接声明。
  - 星夜首屏底图为 AI 生成的油画风插画(据笔触与题材观察,非源码确认)。
  - Game Workshop 卡的品红辉光在样式表里无命名色值,推断为运行时生成的渐变。
  - `--landing-title-font-family` 推断即 Faculty Glyphic(变量本身未在抽取中展开到具体字体)。
  - 首屏叙事文案 `agent = ojo.Agent(name="Vincent", ...)` 及 Infinite Canvas 白板取自实拍观察,是站点自身的艺术叙事(把智能体拟人成画家 Vincent),非本文杜撰。

## 局限

- 抽取到的 `<body>` 计算样式对应登录态应用默认(白底 Geist),而非首屏营销层的深黑。两组值都真实,分属"产品 UI 层"与"叙事营销层",已在解构正文分层说明,勿混淆。
- 只抓到 2 份样式表,若站点存在按路由懒加载的额外样式,可能未覆盖;但首页签名效果的关键帧与 token 均已捕获。
- 色值出现次数反映"在样式表文本中被书写的频次",不完全等于"视觉上的占比";已结合实拍交叉印证主色。
- 技术栈判断基于指纹,非官方声明,若有出入以站点实际为准。
