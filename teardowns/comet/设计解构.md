# Comet 首启引导 · 设计解构

> 顶级 UI 视角的完整拆解。除特别标注,所有数值均来自 Comet 应用包源码(`resources.pak` → `chrome://perplexity-onboarding`)与提取出的 Lottie / 视频资产,均为**实锤**;营销层信息标注为**推断**。

---

## 1. 两套设计:先分清,再复刻

| | **A · 宇宙营销层** | **B · 产品 UI 层** |
|---|---|---|
| 载体 | 官网 `perplexity.ai/comet`、发布影片 | 浏览器本体、首启引导、侧栏 |
| 基调 | 电影级、宇宙叙事、"大片感" | 克制、近乎无彩、圆角柔和 |
| 字体 | **PP Editorial New**(衬线) | **FK Grotesk / Neue** |
| 运动 | 太空→地球滚动旅程、轨道抛物线、可变字重 hover 膨胀 | 呼吸行星、微交互、电影级慢淡入 |
| 技术 | Lenis + GSAP、AI 生成影片(Midjourney→AE) | Chromium WebUI、React SPA、Lottie |
| 操刀 | Studio Freight(推断) | Perplexity(内部代号 **Indigo**) |

**复刻目标 = A 的运动语言 × B 的产品分寸。** 首启引导正是这两层的交汇处——它把营销层的"宇宙 / 行星 / 影片质感"母题,用产品层的克制注入一个真实可用的界面。本仓库聚焦于此。

## 4. 动效系统 —— "炫"的真身

### 4.1 双时间尺度
Comet 把两种时间叠在一起:
- **电影级慢层**:`opacity 1300–1500ms ease-in-out`(+ transform)——营造氛围、渲染仪式感。
- **敏捷微交互**:`120ms`(`--minor-animation-time`)/ `150–400ms`——保证手感即时。

### 4.2 签名缓动(源码取值)
| 曲线 | 值 | 用途 |
|---|---|---|
| 主曲线 · Expo Out | `cubic-bezier(.19,1,.22,1)` = `--transition-func` | 位移 / 淡入淡出,配 `--transition-duration:400ms` |
| 回弹 · Back | `cubic-bezier(.34,1.29,.64,1)` | `transform 500ms` 的"啵一下" |
| 柔和进出 | `cubic-bezier(.65,.05,.36,1)` | 出现频次最高(源码 ×4) |
| **参数化弹跳** | `cubic-bezier(.64, var(--bounce-coefficient,1.75), .61,.77)` | 头像宽度过渡;**回弹强度做成 CSS 变量,一处调全局** |

`@keyframes`:`slide-in`(`translateY(100%)→0`)、`shimmer-slide`(加载微光)。

### 4.3 两个视觉母题
- **呼吸行星(Lottie)**:8 个动画 = 三形态(9-cookie / slanted / oval)× 明暗 + 2 个 welcome back。60fps,5–8s 循环,图层名含 `breathing`——渐变缓慢流动,像行星在"呼吸"。头像选择用的就是它们。
- **电影级 intro(MP4)**:`comet_intro.mp4` 1920×1080 **24fps**(刻意电影感)。真实录屏可见:光泽行星弹珠特写(浅景深 + 胶片颗粒)→ 拉远穿越星场 → 远处星系与太阳 → 收束为同心弧 Comet 标志。另有 `sphere`(旋转颗粒行星)、`rotating_bubble`(虹彩肥皂泡棱镜)两段方形循环。

## 5. 首启引导解剖

### 5.1 真实流程(见 `recording/`)
`欢迎(接受条款)` → `导入浏览器设置` → `选择用户名` → `选择头像(行星球)` → `选择主题(浅/深/跟随设备)` → `最后一步:设为默认浏览器`。真实录屏可见主题切换时**背景从深色云海过渡到明亮朝霞**。

### 5.2 架构(`chrome://perplexity-onboarding`,壳仅 932B)
```
index.html (932B)
  ├─ <base href="chrome://perplexity-onboarding">
  ├─ <link rel="preload" as="video">  comet_intro.mp4 / sphere.mp4 / rotating_bubble.mp4
  ├─ <link rel="preload" as="audio">  ambient.mp3      ← 声音设计(评测提示"调高音量")
  ├─ 内联 importmap(满足严格 CSP)
  └─ <div id="root"> + <script type="module" src="/main.js">   ← React SPA
        └─ window.chromeOnboarding  ← 原生↔页面 JS 桥
           埋点 Indigo.Onboarding.Start / Complete / step advanced
```

### 5.3 头像交互(逐字来自 `22315.css`)
- 球体 `width:73px`(`--b-planet-size`),`object-fit:cover`,初始 `opacity:0` → `--loaded` 淡入。
- **悬停**:`transform: rotate(-20deg)`——行星轻轻一歪。
- 过渡:`width 300ms cubic-bezier(.64,1.75,.61,.77)`(弹) + `opacity/transform 400ms var(--transition-func)`(expo)。
- 悬停时露出**编号徽标**(Berkeley Mono,32px 圆)与**名称**,二者 `slide-in 300ms` 上滑,名称**延迟 100ms**——交错入场。

## 6. 视觉语言(来自真实录屏与素材)

- **宇宙 / 行星**:光泽渐变行星、旋转颗粒球、虹彩泡泡、星场——把品牌的"planet"母题贯穿始终。
- **触感 / 胶片**:重颗粒、浅景深、24fps——电影感而非扁平矢量。
- **克制的仪式感**:大量留白 + 缓慢淡入 + 环境音,让"选个头像"这种小事有仪式感,但不喧宾夺主。
- **玻璃与发光**:`backdrop-filter: blur(50px)` 玻璃层;`box-shadow: 0 0 0 rgba(--glow-color,.3), inset 0 0 30px rgba(--glow-color,.5)` 的 inset 发光晕。
- **圆角语言**:名称输入 42px 药丸、卡片 20px、叠层 32px、药丸按钮 80px——统一的柔和。

## 7. 关键发现 & 对已有认知的纠正

1. **"Comet 无 Lottie"是错的**:产品内置 Lottie 播放器(`53099.js` 的 `<cr-lottie>` / `LottieElement`)+ 8 个引导动画。公开评测普遍漏判。
2. **产品 token 并非"未公开"**:圆角、blur、阴影、缓动、时长、行星渐变全部可从源码提取(本仓已提取)。
3. **动效是"影片 + 矢量 + 声音"的合成**,不是纯 CSS:重氛围段用预渲染 MP4(24fps),循环球用无缝 MP4,头像用 Lottie,微交互用 CSS transition——**按成本与可控性分层选型**,这是最值得学的开发思路。
4. **参数化弹跳**把回弹强度抽成 CSS 变量,是很实用的一手(全局统一"Q 弹度")。

> 详见交互式版 `teardown-offline.html`(含可跑的呼吸行星、头像悬停、缓动曲线实验台)。
