# 出处与方法 · Provenance

## 来源
逆向对象:`/Applications/Comet.app`,Perplexity Comet **`v149.0.7827.1093`**(macOS,Chromium 149 内核)。

## 提取链路(全部脚本见 `../../tools/`)
1. **解包 `resources.pak`**(`unpack_pak.py`):Chromium GRIT data pack v5,含 gzip + Chromium-brotli 压缩。还原出 `chrome://perplexity-onboarding` 的 HTML/CSS/JS(React 打包)、Lit/Polymer 组件、Lottie JSON 等 6799 个资源;筛出 162 个 Perplexity-authored 文件(`real-assets/source/`)。
2. **抽媒体**(`extract_media.py`):从 pak 的原始二进制资源里按魔数捞出 4 段 MP4、2 段 MP3、PNG、woff 字体。
3. **析 Lottie**(`analyze_lottie.py` / `lottie_grad.py`):解析 8 个 Lottie 的尺寸/帧率/时长/图层名与**渐变停靠点**(0–1 浮点 → HEX)。
4. **真实录屏**(`cdp_capture.py`):详见 `recording/录制方法.md`。
5. **字体**:直接取自 `Comet.app/Contents/Resources/Fonts/`。

## 实锤 vs 推断
- **实锤(源码级)**:全部设计 token(色/缓动/时长/圆角/blur/阴影/发光)、行星渐变、字体文件、引导架构(React SPA + preload MP4 + Lottie + audio)、头像交互 CSS、内部代号 Indigo、`chrome://perplexity-onboarding` 结构。
- **推断 / 公开资料**:营销层技术栈(Lenis + GSAP、Studio Freight)、宇宙叙事概念、可变字重 hover、PP Editorial New——来自公开访谈与官网观察,非源码。

## 审查
经两个对抗性审查 Agent 核查(见 `事实核查.md、设计评审.md`):
- **事实核查**:所有数值可溯源,无编造;修正了两处行星渐变插值停靠点(改用真实提取值)与 token 明暗标签。
- **设计评审**:交互式解析页修复移动端 viewport、键盘可达性、对比度、回弹可见性、reduced-motion 等 7 项后重新发布。
