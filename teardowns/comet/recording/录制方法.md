# 真实录屏方法 · 它到底是怎么"录"出来的

## 结论先行
`comet-onboarding.mp4` 是 Comet **真实引导页在真实 Comet 里运行**、由渲染器直出的帧——**真实像素,非合成拼接**。

## 为什么不是普通桌面录屏
一个后台 Agent 在 macOS 上撞两堵**系统安全墙**:
1. **屏幕录制权限**(TCC):只有真人能在"系统设置▸隐私与安全性▸屏幕录制"里手动授予,程序无法自授。
2. **无桌面 GUI 自动化**:Agent 无法移动鼠标 / 代点安装器与引导流程。

所以"后台全自动录你的桌面"物理上不可行。于是改走内核直取。

## 用的路线:Chromium 远程调试(CDP)截帧
Comet 是 Chromium 内核,自带 DevTools 远程调试协议。步骤:
1. **另起一个隔离的一次性 Comet 实例**(独立调试端口 + 全新临时 profile),强制进入引导;**不碰你正在用的真实 Comet 会话与数据**。
   ```bash
   open -na "/Applications/Comet.app" --args \
     --remote-debugging-port=9334 "--remote-allow-origins=*" \
     --user-data-dir=/tmp/comet_onb2 \
     --force-indigo-onboarding --no-default-browser-check
   ```
   > 注:zsh 下 `--remote-allow-origins=*` 的 `*` 必须加引号,否则被通配符展开导致启动失败。
2. **CDP 连接** `chrome://perplexity-onboarding` 目标,`Page.startScreencast` 从渲染器直接拿 JPEG 帧(**无需屏幕录制权限**)。
3. **温和驱动**引导:用 `Runtime.evaluate` 填用户名、点头像(`.b-profile-avatar__root`)、选主题、点"继续";刻意**避开** google/登录/导入等外部流程。
4. **按帧时间戳编码**成 30fps MP4(`ffmpeg` concat,保留真实节奏)。

脚本:[`../../../tools/cdp_capture.py`](../../../tools/cdp_capture.py)。

## 如何重录
```bash
# 1) 起隔离实例(见上)
# 2) 取 onboarding 目标的 ws 地址
WS=$(curl -s http://127.0.0.1:9334/json | python3 -c "import sys,json;[print(t['webSocketDebuggerUrl']) for t in json.load(sys.stdin) if 'perplexity-onboarding' in t.get('url','')]")
# 3) 录 ~44s,driving 开
python3 ../../../tools/cdp_capture.py "$WS" ./frames 44 1
# 4) 编码
ffmpeg -f concat -safe 0 -i ./frames/frames.txt -vf "fps=30,scale=1500:-2,format=yuv420p" -c:v libx264 -crf 20 out.mp4
# 5) 收尾:pkill -f comet_onb2 ; rm -rf /tmp/comet_onb2
```

## 局限
- **无音频**:CDP 截帧只有画面。真实环境音见 `../real-assets/audio/ambient.mp3`(不与视频合成,以尊重"要真实、不要合成")。
- **DMG 拖拽安装**那一段是原生 macOS GUI(非网页),不在 CDP 可截范围;引导页的"炫酷动效"才是重点,已完整捕获。
- 想要真·桌面录屏(含 DMG 与系统音):需你本人授予屏幕录制权限后运行 [`../../../tools/RECORD_INSTALL.sh`](../../../tools/RECORD_INSTALL.sh)。
