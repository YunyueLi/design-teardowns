# 复刻指南 · 把 Comet 的引导动效接进你的产品

配套文件:[`design-tokens.css`](design-tokens.css)(复制即用)。

## 1. 落地 token
直接引入 `design-tokens.css`,或取其中:
```css
:root{
  --paper:#FBFAF4; --ink:#13343b;
  --teal:#20808D; --cyan:#1FB8CD;
  --func:cubic-bezier(.19,1,.22,1); --dur:400ms; --minor:120ms;
  --bounce-coefficient:1.75;               /* 一处调全局回弹 */
  --radius:8px; --pill:42px;
  --glass-blur:blur(50px);
}
```

## 2. 呼吸行星(纯 CSS,零依赖)
```css
.orb{width:96px;aspect-ratio:1;border-radius:50%;
 background:radial-gradient(circle at 34% 30%,#d4e9d7,#6acc97 46%,#00af57);
 animation:breathe 6s var(--func) infinite alternate}
@keyframes breathe{
 from{transform:scale(.96);filter:brightness(.94) saturate(.96)}
 to  {transform:scale(1.04);filter:brightness(1.08) saturate(1.06)}}
```
蓝球 `#b3cbf7→#3186ff→#2e69cd`;金球 `#fbebb8→#fec700→#e79d2d`。要更还原就用 `real-assets/lottie/` 里的真 Lottie。

## 3. 头像交互(逐字复刻 `22315.css`)
```css
.avatar{width:73px;will-change:width,transform;opacity:0;
 transition:width 300ms cubic-bezier(.64,var(--bounce-coefficient,1.75),.61,.77),
            opacity var(--dur) var(--func), transform var(--dur) var(--func)}
.avatar--loaded{opacity:1}
.avatar:hover{transform:rotate(-20deg)}          /* 行星轻歪 */
@keyframes slide-in{from{transform:translateY(100%)}to{transform:translateY(0)}}
.avatar__label{animation:slide-in 300ms var(--func) forwards;animation-delay:100ms} /* 名称延迟入场 */
```

## 4. 引导架构模式(照抄这套骨架)
```
onboarding.html  (极薄壳)
  <link rel="preload" as="video">  ← 预加载重资源,避免首帧卡顿
  <link rel="preload" as="audio">  ← 环境音
  内联 importmap                    ← 满足严格 CSP
  <div id="root"> + React/任意 SPA
     └─ 原生↔页面 桥(如需与外壳通信)
```
- **重氛围段** → 预渲染 **MP4**(intro 用 24fps 拿电影感;循环球用无缝 MP4,正反拼接消接缝)。
- **头像 / 图标级动画** → **Lottie** 或纯 CSS 渐变。
- **微交互** → CSS `transition`,统一用 `--func` / `--dur`。
- **声音** → 需首个用户手势后 `play()`(浏览器自动播放策略)。

## 5. 选型决策表
| 元素 | 选型 | 理由 |
|---|---|---|
| 宇宙 intro 旅程 | 预渲染 MP4 24fps | WebGL 粒子成本高难控,官方选影片 |
| 循环球体 / 泡泡 | 方形 MP4 无缝循环 | 30fps,正反拼接无接缝 |
| 头像行星 | Lottie(矢量渐变)/ CSS | 静态形态 CSS 最省,复杂流动用 Lottie |
| 悬停 / 焦点 / 步骤切换 | CSS transition | 120–400ms + `--func` |
| 慢氛围淡入 | CSS 1300–1500ms | 仪式感层 |

## 6. 工程坑
- **严格 CSP**:importmap 内联、资源同源;嵌入/Artifact 场景把媒体转 data URI。
- **暖白不是纯白**:`#FBFAF4` 比 `#fff` 更耐看;深色端 `#13343b/#1a1a1a`。
- **`prefers-reduced-motion`**:关掉呼吸 / 星场 / 悬停动画。
- **字体授权**:FK Grotesk / Berkeley Mono 均商业字体,生产需自购;开发占位可用 Helvetica Neue 等系统 neo-grotesque 临摹气质。
